算法笔记 06｜字符串

字符串哈希

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），先把它预处理一遍，之后反复询问：圈出两段子串问它们是否相等、有多长的公共前缀，或者问指定的一段是不是回文、允许 kkk 次失配时能匹配到哪里。时间 O(n)O(n)O(n) 预处理、O(1)O(1)O(1) 单次查询，空间 O(n)O(n)O(n)。

原理

实现

应用

最长公共前缀（二分 + 哈希）

两个后缀的 LCP 有单调性，二分长度再用哈希 O(1)O(1)O(1) 判定，单次 O(log⁡n)O(\log n)O(logn)。

回文判定

「子串 [l,r][l,r][l,r] 回文」等价于「正着读的哈希等于反着读的哈希」；预处理正序与逆序两套哈希即可 O(1)O(1)O(1) 判定。

允许 kkk 次失配的匹配

逐段跳：用 LCP 一次跳过一整段相等部分，遇到失配就跳过 1 个字符，总共 k+1k+1k+1 段，复杂度 O((k+1)log⁡n)O((k+1)\log n)O((k+1)logn)。

被卡的应对（双哈希 / 随机基）

单哈希会被构造数据卡掉，竞赛里常用「随机基 + 双模数」或直接用 2642^{64}264 自然溢出配随机基。

KMP

一句话

给一个长为 mmm 的模式串 PPP 和一个长为 nnn 的文本 TTT（n≤106n\le 10^6n≤106），要你从头到尾扫一遍文本，找出 PPP 在其中出现的每一个位置。时间 O(n+m)O(n+m)O(n+m)，空间 O(m)O(m)O(m)。

原理

实现

应用

最长 border / 最小循环节

最长 border 是 πn\pi_nπn​；最小循环节长度是 n−πnn-\pi_nn−πn​（当 nnn 能被它整除时才是完整的循环）。

前缀出现次数

每个前缀 s[1..i]s[1..i]s[1..i] 都会出现在它的所有「祖先」前缀里；在失配树上按子树大小统计即可。

失配树（nxt 树）上的性质

把 iii 连向 nxt[i]\mathrm{nxt}[i]nxt[i] 得到一棵树；s[1..i]s[1..i]s[1..i] 的所有 border 就是根到 iii 的路径上的点。

KMP 自动机

把「匹配失败后跳到哪」预处理成转移表，字母表大小为 σ\sigmaσ 时状态数 ×σ\times\sigma×σ；之后每个字符 O(1)O(1)O(1) 转移。

Z 函数（扩展 KMP）

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你对每个位置 iii 求出后缀 s[i..n]s[i..n]s[i..n] 与整个串的最长公共前缀 ziz_izi​。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（用「已经算出的最右匹配段 [l,r][l,r][l,r]」把 ziz_izi​ 的初值直接继承过来。）

应用

字符串匹配

把「模式 + 分隔符 + 文本」拼成一个串，zi≥∣P∣z_i \ge |P|zi​≥∣P∣ 的位置就是匹配位置。

公共前缀之和

∑izi\sum_i z_i∑i​zi​ 就是「每个后缀与整串的 LCP 之和」，直接累加即可。

扩展 KMP（两个串之间）

求「TTT 的每个后缀与 PPP 的 LCP」：先对 PPP 求 zzz，再用完全相同的逻辑扫 TTT。

最小表示法

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），它的每个循环位移都是一种读法，要你找出字典序最小（或最大）的那种读法的起始位置。时间 O(n)O(n)O(n)，空间 O(1)O(1)O(1) 额外。

原理

实现

（双指针：iii、jjj 是两个候选起点，kkk 是已比较的公共长度；哪边「更大」就整段跳过。）

应用

判断两串是否循环同构

分别求最小表示，再逐字符比较；相同则循环同构，O(n)O(n)O(n)。

最大表示

把比较符反过来：a<ba<ba<b 时跳 iii，得到最大表示。

Manacher

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你以每个位置为中心向两边撑开，求出那里最长的回文半径。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（插入分隔符把奇偶回文统一；用「当前最右回文段的对称点」直接继承半径。）

应用

回文子串计数

以每个中心 iii 的回文子串个数是 ⌈Ri/2⌉\lceil R_i/2\rceil⌈Ri​/2⌉，累加起来就是总个数（按中心计）。

以每个位置开头 / 结尾的最长回文

用一个差分数组把「以 iii 为中心的半径」摊到区间上，再做前后缀 max。

Trie 树

一句话

给 nnn 个字符串（总长 ≤106\le 10^6≤106，字母表大小 σ\sigmaσ），把它们按字符一层层挂到树上，之后每次询问一个串 sss，要你沿着树走一遍回答它作为前缀出现了多少次（∣s∣|s|∣s∣ 是这次问的串长）。时间 O(总长)O(\text{总长})O(总长) 建树、O(∣s∣)O(|s|)O(∣s∣) 单次查询，空间 O(总长×σ)O(\text{总长}\times\sigma)O(总长×σ)。

原理

实现

应用

01-Trie（异或最值）

把数按二进制位从高到低插进 Trie；查询「与 xxx 异或最大」时每一步尽量走相反位。

可持久化 Trie

对每个前缀建一棵 Trie，查询 [l,r][l,r][l,r] 时用两个版本的「计数差」判断某条分支里有没有元素。

字典序排序

把所有串插进 Trie，按「先 0 后 1」的字典序 DFS 输出，就是字典序排序（O(总长)O(\text{总长})O(总长)）。

AC 自动机

一句话

给 nnn 个模式串（总长 ≤106\le 10^6≤106）和一个文本，要你把所有模式串建成自动机后拿文本在上面跑一遍，数出每个模式串在文本里出现了多少次。时间 O(总长+文本长)O(\text{总长}+\text{文本长})O(总长+文本长)，空间 O(总长×σ)O(\text{总长}\times\sigma)O(总长×σ)。

原理

实现

（Trie + 失败指针；建完 fail 后可以像 KMP 一样扫文本。）

应用

模式串出现次数

扫文本时每到一个状态就给它的「计数」加一，最后在 fail 树上自底向上累加。

多模式串匹配（禁止串 DP）

求「长度 LLL 且不含任何模式串的串的个数」时，把自动机的转移当边跑 DP，标出「含模式串」的状态（本身命中或 fail 链上有命中）。

拓扑排序优化

fail 树的子树和可以用「按 BFS 序的逆序」直接累加，不必显式建树。

序列自动机

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106，字母表大小 σ\sigmaσ），预处理出每个位置往后各字符第一次出现的位置，之后每次给你一个串 sss，要你从前往后跳着看它是不是子序列。时间 O(nσ)O(n\sigma)O(nσ) 预处理、O(∣s∣)O(|s|)O(∣s∣) 单次判定，空间 O(nσ)O(n\sigma)O(nσ)。

原理

实现

（nxt[i][c] = 从位置 i 往后第一个字符 c 的位置。）

应用

子序列判定

从位置 0 出发，每读一个字符就跳到它的下一次出现；跳不过去就不是子序列。

最短未出现子序列

从后往前：fif_ifi​ 表示「从位置 iii 出发，能拼出的最短未出现子序列长度」，若某个字符从 iii 起再没出现，则 fi=1f_i=1fi​=1。

子序列计数 / 本质不同子序列

gig_igi​（以下标 iii 结尾的本质不同子序列数）用「上一次同字符出现位置」去重。

后缀数组（SA）

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你把它的所有后缀按字典序排好，求出排名数组 sasasa、rankrankrank 以及相邻后缀的高度数组 heightheightheight。时间 O(nlog⁡n)O(n\log n)O(nlogn)（倍增）或 O(n)O(n)O(n)（SA-IS），空间 O(n)O(n)O(n)。

原理

实现

应用

任意两后缀的 LCP

两后缀的 LCP 等于它们排名之间 heightheightheight 的最小值，用 ST 表 O(1)O(1)O(1) 查询。

本质不同子串个数

每个后缀的新增子串数是「后缀长度减掉它和上一个后缀的 LCP」，累加即可。

至少出现 kkk 次的最长子串

出现至少 kkk 次的子串对应「连续的 k−1k-1k−1 个 heightheightheight 都 ≥L\ge L≥L」，二分 LLL 后用滑动窗口检查。

最长公共子串（两个串）

把两串拼起来（中间加一个不会出现的分隔符），求「来自不同串的两个后缀的 LCP 最大值」。

后缀自动机（SAM）

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你在线地往里一个个加字符、建出它的后缀自动机，从而数出本质不同子串的个数和每个子串的出现次数。时间 O(n)O(n)O(n) 建机，空间 O(n)O(n)O(n)。

原理

实现

应用

本质不同子串个数

每个状态贡献 len(v)−len(link(v))\mathrm{len}(v)-\mathrm{len}(\mathrm{link}(v))len(v)−len(link(v)) 个不同子串，累加即可。

子串出现次数

把 occ 按 len 从大到小（即拓扑序）累加到 link 上，occ[v]occ[v]occ[v] 就是状态 vvv 代表的子串出现次数。

两个串的最长公共子串

在 SAM 上跑另一个串：能走就走、长度加一；走不动就跳 link 并缩短长度。

广义 SAM（多串）

每插入一个新串时把 sam_last 重置为 1；若要严格处理重复子串，插入前还要判「这个转移是否已存在且长度匹配」。

后缀树

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你把它所有后缀的公共前缀组织成一棵压缩过的树，树里每个内部结点都对应着一个重复子串。时间 O(n)O(n)O(n) 建树（常用 O(nlog⁡n)O(n\log n)O(nlogn) 的 SA + LCP 建法），空间 O(n)O(n)O(n)。

原理

实现

（后缀树 = 所有后缀的压缩 Trie；用后缀数组 + heightheightheight 的笛卡尔树可以等效地建出来。）

应用

后缀树上的统计

每个内部结点对应的子串「出现了多少次」= 它子树的叶子数；用它可以直接求重复子串。

最长重复子串

就是 heightheightheight 数组的最大值（至少出现两次的最长子串）。

后缀平衡树

一句话

一开始有一个字符串，接下来有若干次操作（总长 nnn），每次操作是「在末尾追加一个字符」或「在开头插入一个字符」，插入之后随时可以问任意两个后缀谁的字典序更小，两种操作交替出现。时间 O(log⁡n)O(\log n)O(logn) 单次插入、O(1)O(1)O(1) 比较，空间 O(n)O(n)O(n)。

原理

实现

（用一棵平衡树按字典序存所有后缀；比较两个后缀时可以用「哈希 + 二分」或者维护的「标签」。）

应用

在线比较后缀

用「哈希 + 二分」可以在 O(log⁡n)O(\log n)O(logn) 内比较两个后缀；配合平衡树就能维护「按字典序排序的后缀集合」。

后缀平衡树的核心：标签比较

维护「每个点的实数标签」，比较两个后缀时只要比较标签，就得到 O(1)O(1)O(1) 比较；失衡时重建整棵子树并重新分配标签。

回文自动机（PAM）

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你一个个字符往里加、建出回文自动机，数出其中本质不同的回文子串有多少个、每个回文子串出现了多少次。时间 O(n)O(n)O(n) 建机，空间 O(n)O(n)O(n)。

原理

实现

（两个根：长度 −1-1−1 的奇根和长度 000 的偶根；每个结点代表一个本质不同的回文串。）

应用

本质不同回文子串个数

除两个根以外的结点数就是答案。

每个回文子串出现次数

按 len 从大到小，把 cnt 累加到 fail 上（fail 树上的子树和）。

回文划分

fif_ifi​ 由「所有以 iii 结尾的回文串」转移，用 fail 链上的等差性质可以把 O(n2)O(n^2)O(n2) 降到 O(nlog⁡n)O(n\log n)O(nlogn)。

Burrows–Wheeler 变换（BWT）

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你把它所有循环位移排好序，取出每个位移的最后一个字符，再能从这一串字符还原回原串。时间 O(nlog⁡n)O(n\log n)O(nlogn)（用 SA）或 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

数据压缩

BWT 之后相同字符会聚集，再配合游程编码（RLE）与 MTF 就能大幅压缩。

逆变换的正确性

逆变换靠「L 列（排序后的第一列）与 F 列」的对应关系迭代还原。

Lyndon 分解

一句话

给一个长度为 nnn 的字符串（n≤106n\le 10^6n≤106），要你从左到右把它切成若干段，使每一段都严格小于自己的所有真后缀。时间 O(n)O(n)O(n)，空间 O(1)O(1)O(1) 额外。

原理

实现

（Duval 算法：维护「当前 Lyndon 串的周期」，逐字符扩张。）

应用

最小表示法

Lyndon 分解的最后一个 Lyndon 串的起点，就是最小表示的起点。

最小后缀

「最小后缀」指所有后缀中字典序最小的那个；它一定出现在 Lyndon 分解的最后一段。

字符串 DP

一句话

给两个长度不超过 nnn 的字符串（n≤5000n\le 5000n≤5000），要你逐位比较着往右扫，求出它们的最长公共子序列长度，并在单个串上找出最长回文子序列、判断带通配符的两个串能否匹配。时间 O(n2)O(n^2)O(n2)，空间 O(min⁡(n,m))O(\min(n,m))O(min(n,m))。

原理

实现

应用

最长回文子序列

区间 DP：两端字符相同时长度加 2，否则取「去掉一端」的较大值。

通配符 / 正则匹配

通配符问号匹配任意一个字符、星号匹配任意长度（含空），用二维 DP 递推；星号那一维可以只用一行滚动。

自动机上 DP

一句话

先给若干模式串建成 AC 自动机（状态数 S≤105S\le 10^5S≤105），再考虑所有长度为 LLL 的串（L≤1018L\le 10^{18}L≤1018），要你沿着自动机一位一位地走，数出其中不包含任何模式串的串有多少个。时间 O(SσL)O(S\sigma L)O(SσL)（LLL 大时用矩阵快速幂降到 O(S3log⁡L)O(S^3\log L)O(S3logL)），空间 O(S)O(S)O(S)。

原理

实现

应用

长度很大时用矩阵快速幂

L≤1018L\le 10^{18}L≤1018 时把转移写成 S×SS\times SS×S 的矩阵（SSS 是自动机状态数），用快速幂。

出现至少一次 / 恰好 kkk 次

把「命中次数」也放进状态（多一维 0..k0..k0..k），或者在自动机上标记「已经命中过」。

与 KMP 自动机的配合

只有一个模式串时用 KMP 自动机（状态数等于模式串长度），比 AC 自动机省时间空间。
