算法笔记 02｜数据结构进阶

并查集

一句话

一开始有 nnn 个互不相通的点和 mmm 次操作（n,m≤106n,m\le 10^6n,m≤106），每次操作是「在 aaa 与 bbb 之间加一条边」或「询问 aaa 与 bbb 现在是否连通」，两种操作交替出现。时间均摊 O(α(n))O(\alpha(n))O(α(n)) 每次，空间 O(n)O(n)O(n)。

原理

实现

合并时把大小相加、把连通块计数减一即可；数组 sz 只在根结点上有意义——size_of(x) 返回所在集合大小、components() 返回连通块个数。只想维护「集合大小」的话，上面这份模板已经够用，不需要额外结构。

合并时把大小相加、把连通块计数减一即可；数组 sz 只在根结点上有意义。

应用

带权并查集

数组 d 表示「点到父亲的权值」；路径压缩时一起累加，合并时按公式补上两个根之间的差。

扩展域并查集

把每个元素拆成 kkk 个「域」，用「合并域」来表达「xxx 属于哪一类」的约束；矛盾就是「两个不同的域落到了同一个集合」。

可撤销并查集

要支持撤销就只能按秩合并、不做路径压缩（否则撤销无法还原）；用栈把「被改动的点与旧值」记下来。

树状数组

一句话

给一个长度 n≤106n\le 10^6n≤106 的序列和 mmm 次操作，每次要么把 aia_iai​ 加上 xxx、要么询问 ∑i=lrai\sum_{i=l}^r a_i∑i=lr​ai​（也可以把区间 [l,r][l,r][l,r] 整体加 xxx 后问某个位置的值，或求第 kkk 小），修改与查询交替出现。时间单次操作 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

应用

区间修改与单点查询

把树状数组维护的数组设成差分数组：区间加变成两次单点修改，单点查就是前缀和。

区间修改与区间查询

维护两个树状数组：一个存差分 did_idi​，一个存 i dii\,d_iidi​；区间和可由这两个前缀和组合出来。

二维树状数组

把一维的 add 与 sum 各套一层循环，复杂度 O(log⁡2n)O(\log^2 n)O(log2n)，空间 O(n2)O(n^2)O(n2)（nnn 大时要另想办法）。

权值树状数组与树状数组上二分

把「值」当下标建树状数组，用倍增在 O(log⁡n)O(\log n)O(logn) 内找到第一个「前缀和不小于 kkk」的位置。

线段树

一句话

给一个长度 n≤106n\le 10^6n≤106 的序列和 mmm 次操作，每次要么把区间 [l,r][l,r][l,r] 整体加 xxx 或整体赋成 xxx，要么询问 [l,r][l,r][l,r] 的和与最值、或在树上二分找第一个满足条件的位置，修改与查询交替出现。时间单次操作 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

应用

标记永久化

修改时把标记留在结点上、不往下传；查询时把沿途的标记累加进答案。适合「可持久化」或「标记不好合并」的场景。

权值线段树与动态开点

把「值域」当下标建线段树；值域很大时只开用到的结点，单次操作 O(log⁡V)O(\log V)O(logV)、空间 O(mlog⁡V)O(m\log V)O(mlogV)。

zkw 线段树

把线段树按完全二叉树的下标建在数组里，自底向上做；区间操作时用左右两个指针往中间夹。

线段树二分

在线段树上「往左找、左边不够就往右走」，O(log⁡n)O(\log n)O(logn) 找到第一个满足条件的位置。

线段树合并与分裂

一句话

给若干棵动态开点的权值线段树（总共 O(nlog⁡V)O(n\log V)O(nlogV) 个结点），要你把两棵树对应位置上的信息并到一起、或把一棵树按排名 kkk 劈成两棵，合并与分裂交替出现。时间合并总复杂度 O(nlog⁡V)O(n\log V)O(nlogV)、单次分裂 O(log⁡V)O(\log V)O(logV)，空间 O(nlog⁡V)O(n\log V)O(nlogV)。

原理

实现

总的结点数怎么估
每插入一个元素开 O(log⁡V)O(\log V)O(logV) 个结点；合并不会新建结点（合并时有一边为空就直接接上），只有分裂会新建 O(log⁡V)O(\log V)O(logV) 个。

线段树合并（并入自 13 章）
每个点开一棵动态开点权值线段树，自底向上合并。每次合并时有一边为空就整棵接上，所以总复杂度 O(nlog⁡V)O(n\log V)O(nlogV)（每个结点最多被合并掉一次）。下面维护的是「权值出现次数」。

应用

按值域分裂（序列分裂）

把线段树当「可分裂的平衡树」用：按值域 [1,mid][1,mid][1,mid] 分成两棵，分别对应两段序列。

树上启发式合并统计子树信息

每个点一棵权值线段树，自底向上合并；合并后就能查任意子树的「第 kkk 小 / 值域计数」。

线段树分治

一句话

给一张动态图（nnn 个点 mmm 条边，每条边只在时间区间 [l,r][l,r][l,r] 内存在）和 q≤105q\le 10^5q≤105 次询问，每条边在自己的生存期里被挂到时间线段树上，你带着并查集一路 DFS、进结点时加边、回溯时撤销，问 aaa 与 bbb 每个时刻是否连通 / 是否是二分图，加边与撤销交替出现。时间 O((m+q)log⁡qlog⁡n)O((m+q)\log q\log n)O((m+q)logqlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（把「每条边存在的时间区间」挂到时间线段树上，DFS 一遍时间线段树，进入结点时加边、离开时撤销。）

应用

动态图连通性（离线）

每条边给出它的存在区间，按上面的流程跑一遍，每个时刻的连通块个数就是答案。

二分图判定（离线）

用「扩展域并查集」：把每个点拆成「左侧 / 右侧」两个域，一条边就把 u 的左与 v 的右、u 的右与 v 的左合并；若某次合并发现同侧，说明出现奇环、不是二分图。

李超树

一句话

一开始有一堆直线 y=kx+by=kx+by=kx+b，要你不断插入新的直线（或只在 [l,r][l,r][l,r] 内有效的线段），并询问某个横坐标 xxx 处所有直线的最大值 / 最小值，插入与查询交替出现，其中 CCC 是横坐标范围。时间单次操作 O(log⁡2C)O(\log^2 C)O(log2C)（线段插入）或 O(log⁡C)O(\log C)O(logC)（整条直线），空间 O(nlog⁡C)O(n\log C)O(nlogC)。

原理

实现

（在值域线段树的每个结点上存一条「可能最优」的直线；插入时逐层比较、把较劣的那条留在结点上。）

应用

求最小值

把每条直线取负后照常插入（查询时再取负），或者在比较函数里把符号全部反过来。

线段插入（只在 [l,r][l,r][l,r] 内有效）

把「线段」拆到 O(log⁡C)O(\log C)O(logC) 个结点上，每个结点插入整条直线即可。

斜率优化 DP

DP 转移形如 dpi=min⁡j(kjxi+bj)dp_i=\min_j(k_j x_i+b_j)dpi​=minj​(kj​xi​+bj​) 且 xix_ixi​ 单调时，不用单调队列，直接把每个 jjj 对应的直线插进李超树。

Segment Tree Beats

一句话

给一个序列和 mmm 次操作（n,m≤105n,m\le 10^5n,m≤105），每次要么把区间 [l,r][l,r][l,r] 对 xxx 取 min⁡\minmin / 取 max⁡\maxmax，要么询问 [l,r][l,r][l,r] 的和与最值，区间加还要和取 min 的标记按固定顺序一起下传，修改与查询交替出现。时间均摊 O(nlog⁡n)O(n\log n)O(nlogn) 内处理完 mmm 次操作，空间 O(n)O(n)O(n)。

原理

实现

（核心是「如果这个结点的最大值已经被取 min 取到不用再往下，就整体处理；否则递归」。）

应用

区间取 max

对称地再维护一份「最小值与次小值」，就能处理区间取 max。

区间加 + 区间取 min（务必对拍）

区间加要乘的是区间长度（作用到所有元素），不是最大值的个数——这一点极易写错：

这两条标记的下传顺序与相互影响比看上去微妙：区间加会同时改动 mx 与 se，而取 min 只压最大值，一旦顺序或乘的量写错，错误会在多次操作后以「数值整体偏移」的形式暴露出来。这一版请务必和暴力对拍（上面的 pushdown 已验证在「只有取 min」时正确；加入加法标记后要重新对拍）。

区间最值与历史最值

除了当前值，再维护「历史最大值」；下传时用「加法标记的历史最大值」去更新儿子的历史最大。

猫树

一句话

给一个不会改动的静态序列（n≤105n\le 10^5n≤105，运算可结合，如 max、gcd、矩阵乘）和 q≤105q\le 10^5q≤105 次区间查询，每次问 [l,r][l,r][l,r] 的区间信息，预处理时把以中点为界的两侧前缀 / 后缀结果都存下来，预处理与查询交替出现。时间预处理 O(nlog⁡n)O(n\log n)O(nlogn)、单次查询 O(1)O(1)O(1)，空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

（猫树：在每个分治区间里预处理「中点到两端的合并结果」，查询时取 lll、rrr 的 LCA 所在层直接合并。）

应用

区间 max

区间 gcd

把 cat 数组的合并运算换成 gcd、min 或矩阵乘法即可；要求运算是可结合的（不要求可减）。

平衡树

一句话

维护一个有序多重集（n≤105n\le 10^5n≤105，值域 ≤109\le 10^9≤109），要不断插入 xxx、删除 xxx、问 xxx 的排名、问第 kkk 小是谁、问 xxx 的前驱后继，或把一段区间整个翻转，插入与查询交替出现。时间单次操作均摊 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

（Fhq Treap：用随机优先级 + 分裂 / 合并实现所有操作，不需要旋转，天然支持可持久化与区间操作。）

应用

区间翻转（文艺平衡树）

把序列按位置放进平衡树，翻转区间就相当于「分裂出这段、打上翻转标记、再合回去」。

Treap

三种经典平衡树各有侧重：Treap 靠随机优先级旋转、Splay 靠「伸展」维护均摊复杂度、替罪羊树靠「重构不平衡子树」。

无旋 Treap（FHQ Treap）

本模块「实现」一节给出的就是无旋 Treap（FHQ Treap）：用随机优先级 + 分裂 / 合并完成全部操作，不需要旋转，因此天然支持可持久化与区间操作。

Splay

（把访问到的点一层层旋到根，靠均摊保证单次 O(log⁡n)O(\log n)O(logn)。）

替罪羊树

（不旋转。插入后沿路检查「子树是否太不平衡」，一旦超过阈值 α\alphaα 就把该子树中序拍平后重建；重建是均摊 O(1)O(1)O(1) 的。）

可持久化平衡树

Fhq Treap 的分裂 / 合并是「自顶向下、只改一条链」，把改动过的结点都复制一份就是可持久化。

可持久化数据结构

一句话

给一个序列和 mmm 次操作（n,m≤105n,m\le 10^5n,m≤105），每次要么基于历史版本把某个位置改成 xxx 得到新版本、之后还能回头查询旧版本，要么静态地问区间 [l,r][l,r][l,r] 内与 xxx 异或的最大值，修改与查询交替出现。时间单次操作 O(log⁡n)O(\log n)O(logn)，空间总共 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

原理

实现

只复制「被改动的那条链」，其余结点共用 —— 这就是全部思想。

应用

可持久化线段树（主席树）

（核心：只复制「被改动的那条链」，其余结点共用。）

可持久化数组

用可持久化线段树维护数组，每次修改新建 O(log⁡n)O(\log n)O(logn) 个结点，就能「回到任意历史版本」。

可持久化 Trie

对每个前缀建一棵 Trie，查询 [l,r][l,r][l,r] 时用「版本 r 的 Trie 减去版本 l-1 的 Trie」判断某条分支是否存在。

数列分块

一句话

给一个长度 n≤105n\le 10^5n≤105 的序列和 m≤105m\le 10^5m≤105 次操作，每次要么把区间 [l,r][l,r][l,r] 整体加上 xxx、要么询问 ∑i=lrai\sum_{i=l}^r a_i∑i=lr​ai​，整块一起处理、边角逐个改，修改与查询交替出现。时间单次操作 O(n)O(\sqrt n)O(n​)，空间 O(n)O(n)O(n)。

原理

实现

应用

值域分块

把值域分成 V\sqrt VV​ 块，先扫块找「第 kkk 小落在哪个块」，再在块内逐个找，O(V)O(\sqrt V)O(V​) 一次查询。

根号重构

（把「修改」先攒着，攒够 BBB 个就整体重构一次；查询时「查已重构的部分 + 暴力扫攒下来的部分」。）

根号重构

维护「插入数 + 查询第 kkk 小」：不每次插入都重建，而是攒够 BBB 个新元素就整体重建一次；查询时把「有序旧数组的二分」与「缓冲区暴力扫」合起来。总复杂度 O(nn)O(n\sqrt n)O(nn​)。

根号分治

一句话

给 n,q≤105n,q\le 10^5n,q≤105 个询问，拿阈值 n\sqrt nn​ 把对象分成两类：相关的量超过 n\sqrt nn​ 的按「重」的集中预处理、没超过的按「轻」的逐个暴力，预处理与暴力交替出现。时间总共 O(nn)O(n\sqrt n)O(nn​)，空间 O(n)O(n)O(n)。

原理

实现

按「某个量是否超过 n\sqrt nn​」分类：小的暴力枚举、大的预处理，两边合计 O(nn)O(n\sqrt n)O(nn​)。

根号分治（并入自 13 章）
按度数把点分成「大点」（度数大于 BBB，只有 O(m/B)O(m/B)O(m/B) 个）与「小点」：给每个大点预处理一份「邻点颜色计数」，小点询问时直接枚举邻居。取 B=mB=\sqrt mB=m​，两端都是 O(m)O(\sqrt m)O(m​)，总复杂度 O((n+q)m)O((n+q)\sqrt m)O((n+q)m​)。

应用

珂朵莉树（ODT）

一句话

维护一个序列的「颜色段」集合（n,m≤105n,m\le 10^5n,m≤105），每次把区间 [l,r][l,r][l,r] 整体赋成同一个值、或统计区间里的信息，赋值时把覆盖到的段并成一段，赋值与统计交替出现。时间随机数据下均摊 O(nlog⁡log⁡n)O(n\log\log n)O(nloglogn) 一次赋值，空间 O(n)O(n)O(n)；构造数据会退化。

原理

实现

维护「颜色相同的连续段」集合，区间赋值时把重叠段合并，随机数据下均摊很快（O(nlog⁡log⁡n)O(n\log\log n)O(nloglogn) 级别）。

应用

块状链表

一句话

维护一个序列（n,m≤105n,m\le 10^5n,m≤105），要不断在某个位置插入一个数、删除某个数、并把一段区间拿出来做查询，插入与查询交替出现。时间单次操作 O(n)O(\sqrt n)O(n​)，空间 O(n)O(n)O(n)。

原理

实现

（把序列切成 n\sqrt nn​ 块，每块存一个连续数组：定位 O(n)O(\sqrt n)O(n​)、块内插入 O(n)O(\sqrt n)O(n​)，块太大就裂开、块空了就删掉。）

应用

莫队

一句话

给 qqq 个区间询问（n,q≤105n,q\le 10^5n,q≤105），要你离线回答每个 [l,r][l,r][l,r] 的答案，而当前区间的左右端点每移动一格、就把一个元素加进统计或移出统计，加与删交替出现。时间总共 O(nq)O(n\sqrt q)O(nq​)（普通莫队）、O(n5/3)O(n^{5/3})O(n5/3)（带修）、O(nq)O(n\sqrt q)O(nq​)（回滚），空间 O(n)O(n)O(n)。

原理

实现

应用

普通莫队

本模块「实现」一节给出的 mo() 就是普通莫队：块长取 n\sqrt nn​，按左端点分块、右端点奇偶化排序。

带修莫队

把「时间」也当成一维，块长取 n2/3n^{2/3}n2/3，三个指针同时移动，总复杂度 O(n5/3)O(n^{5/3})O(n5/3)。

回滚莫队

只支持「加」不支持「删」时（例如维护最大值），把询问按左端点分块，右端点单调右移、左端点小范围回滚。

树上莫队

用欧拉序把树上的路径问题转成序列区间问题：每条路径对应欧拉序上的两段（或一段），出现两次的点表示「不在路径上」。

二次离线莫队

（把「指针移动时产生的贡献」拆成「前缀形式」，再用一次离线扫描回答所有前缀询问；代价是允许「O(1)O(1)O(1) 修改、O(1)O(1)O(1) 查前缀」，适用范围比普通莫队大得多。）

一句话

给 nnn 个带权三元组 (ai,bi,ci)(a_i,b_i,c_i)(ai​,bi​,ci​)（n≤105n\le 10^5n≤105），对每个 iii 要你数出有多少个 jjj 满足 aj≤ai, bj≤bi, cj≤cia_j\le a_i,\ b_j\le b_i,\ c_j\le c_iaj​≤ai​, bj​≤bi​, cj​≤ci​（三维偏序），做法是按 aaa 排序后对 bbb 归并、把 ccc 插进树状数组，归并与插入交替出现。时间 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)，空间 O(n)O(n)O(n)。

CDQ 分治

一句话

给你 nnn 个三元组 (ai,bi,ci)(a_i,b_i,c_i)(ai​,bi​,ci​)（n≤105n\le 10^5n≤105），要求出每个 iii 满足 aj≤aia_j\le a_iaj​≤ai​、bj≤bib_j\le b_ibj​≤bi​、cj≤cic_j\le c_icj​≤ci​ 的 jjj 的个数（三维偏序）；也用来处理「先单点修改、再区间询问」这类带时间维的离线问题。时间 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)，空间 O(n)O(n)O(n)。

原理

实现

CDQ 做「带时间维」的离线问题（并入自 13 章）
把每个修改和询问都编成一个事件 (t,p,v,ty)(t,p,v,ty)(t,p,v,ty)：修改是 ty=0ty=0ty=0、值为 vvv；询问是 ty=1ty=1ty=1、vvv 是正负号。分治按时间切，左半的修改去更新右半的询问，位置维用树状数组。

应用

整体二分

【说明】下面「实现」一节保留了两段：第一段是最小骨架，第二段是可直接套用的完整写法。

一句话

给 n,q≤105n,q\le 10^5n,q≤105 次操作 / 询问，要你离线回答每个询问的「第 kkk 小」或带时间维的偏序计数，做法是把所有询问和答案值域一起二分、每次把修改按值域分到左右两边再判定，分与判交替出现。时间 O((n+q)log⁡nlog⁡V)O((n+q)\log n\log V)O((n+q)lognlogV)，空间 O(n+q)O(n+q)O(n+q)。

原理

实现

把「二分答案」整体化：所有询问一起二分，用树状数组统一结算贡献，O((n+q)log⁡nlog⁡V)O((n+q)\log n\log V)O((n+q)lognlogV)。

应用

整体二分

一批询问一起二分答案：每次用 BIT 把「值落在左半」的位置标出来，按区间内计数把询问分流。下面是「静态区间第 kkk 小」，单次分治三层结构，总复杂度 O((n+q)log⁡Vlog⁡n)O((n+q)\log V\log n)O((n+q)logVlogn)。

树套树

一句话

给一个序列和 mmm 次操作（n,m≤105n,m\le 10^5n,m≤105），要你不断单点修改 aia_iai​，并询问 [l,r][l,r][l,r] 内小于 xxx 的个数、区间第 kkk 小或带修改的二维数点，外层线段树的每个结点里再挂一棵平衡树 / 值域结构，修改与查询交替出现。时间单次操作 O(log⁡2n)O(\log^2 n)O(log2n)，空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

（外层线段树维护位置区间，内层用权值结构维护「该区间内的值的集合」。）

应用

线段树套平衡树（区间内小于 xxx 的个数）

每个外层结点挂一棵平衡树 / 有序数组；后者是「静态」的，直接存有序 vector 并二分即可。

二维数点（静态）

把点按 xxx 排序、用可持久化线段树维护 yyy：「x≤Xx\le Xx≤X 且 y≤Yy\le Yy≤Y」的个数就是两个版本相减。

K-D 树

一句话

给 nnn 个 kkk 维点（n≤105n\le 10^5n≤105，kkk 通常 222 或 333），要你不断插入点，并询问离某个点最近 / 第 kkk 近的点是谁、或一个矩形里有多少个点，插入与查询交替出现。时间建树 O(nlog⁡n)O(n\log n)O(nlogn)、单次查询平均 O(n)O(\sqrt n)O(n​)，空间 O(n)O(n)O(n)。

原理

实现

（按维度轮换地取中位数分割，树上每个结点记录「子树内每个维度的坐标范围」用于剪枝。）

应用

最近点与第 kkk 近点

维护一个大小为 kkk 的大根堆（第 kkk 近），搜索时用「矩形最近距离」剪枝。

Link-Cut Tree

一句话

维护一片森林（nnn 个点，mmm 次操作，n,m≤105n,m\le 10^5n,m≤105），要不断在 uuu 与 vvv 之间连一条边、把某条边断开、问 uuu 到 vvv 路径上的和 / 最值、把根换成 xxx、并询问 uuu 与 vvv 现在是否连通，连边与查询交替出现。时间单次操作均摊 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

（用 Splay 维护「实链」，每个 Splay 的中序对应原树上一条从上到下的路径；核心操作是 access。）

应用

动态树上的路径查询与最小生成树

路径查询用 split(x,y) 之后直接读 y 的聚合值；动态 MST 用「每条边建一个点」的技巧。

维护连通性（带断边）

用 findroot 判断两点是否在同一棵树里；断边用 cut（前提是这条边确实存在）。

LCT 维护子树信息

普通的 LCT 只维护「实链」上的信息；要维护子树信息需要额外记录「虚儿子的聚合值」，并在 access 时同步更新。
