算法笔记 01｜基础

时间与空间复杂度

一句话

给你时限 111 秒、内存 256256256 MB 和一道题的数据范围（nnn 最大到 10710^7107），要你在动手写代码之前先估出「什么样的复杂度能过」，再据此挑算法。时间 O(1)O(1)O(1)（判断本身），空间按所选算法计。

原理

实现

（先估规模，再定复杂度：n≤20n\le 20n≤20 指状压、n≤500n\le 500n≤500 指 O(n3)O(n^3)O(n3)、n≤5000n\le 5000n≤5000 指 O(n2)O(n^2)O(n2)、n≤105n\le 10^5n≤105 指 O(nlog⁡n)O(n\log n)O(nlogn)、n≤107n\le 10^7n≤107 指 O(n)O(n)O(n)。）

应用

常见规模与可接受复杂度

把上面的表背下来（或者现场估），能避免「算法对了但复杂度超了」的常见翻车。

空间估算

整数数组 10710^7107 个 int 约 40 MB；二维 5000×50005000\times50005000×5000 的 long long 就是 200 MB，必须降维。

平摊分析与势能分析

一句话

给你一个「单次最坏很慢、但总量很快」的结构（如单调栈、并查集、双指针），要你说明它为什么总复杂度是线性的。时间摊还单次 O(1)O(1)O(1)（并查集为 O(α(n))O(\alpha(n))O(α(n))），空间 O(n)O(n)O(n)。

原理

实现

（用「势能」记账：定义势能 Φ\PhiΦ 为结构里「还没被消耗的余量」，把每次操作的「真实代价 +ΔΦ+\Delta\Phi+ΔΦ」累加起来，中间的项会两两抵消，只剩下首尾。）

应用

常数优化与快速读入

一句话

给你一份复杂度已经正确、却因为常数太大而 TLE 的代码（输入量到 10610^6106），要你把它压进时限。时间与空间都只在常数级别改变。

原理

实现

同样的复杂度，常数能差 5~10 倍：取模改条件减法、循环展开、减少函数调用、用数组代替 vector、快读。

应用

高精度运算

一句话

给两个十进制大整数 a,ba,ba,b，位数都不超过 10510^5105（位数 n≤105n\le 10^5n≤105），要你像竖式一样算出 a+ba+ba+b、a−ba-ba−b、a×ba\times ba×b、a÷ba\div ba÷b 并比较大小，低位对齐地从个位往上扫，加减、乘法、试商交替出现。时间 O(n)O(n)O(n)（加减、比较）、O(n2)O(n^2)O(n2)（朴素乘除）或 O(nlog⁡n)O(n\log n)O(nlogn)（FFT/NTT），空间 O(n)O(n)O(n)。

原理

实现

（用 int 数组倒着存每一位，低位在前；所有运算从低位往高位扫。）

应用

高精度除法

高精度比较与排序

折半枚举（Meet in the Middle）

一句话

给 n≤40n\le 40n≤40 个物品和一条「选出哪些才算合法」的规则（2n2^n2n 太大但 2n/22^{n/2}2n/2 可行），你要把物品均分成两半、各自枚举出所有子集，再在两半之间排序、二分或双指针配对，枚举与配对交替出现。时间 O(2n/2log⁡2n/2)O(2^{n/2}\log 2^{n/2})O(2n/2log2n/2)，空间 O(2n/2)O(2^{n/2})O(2n/2)。

子集计数 / 判存在

状态的位压缩

把「若干个 yes/no」压成一个整数，转移就是位运算；注意位宽上限（int 32 位、long long 64 位）。

x⊕x=0x\oplus x=0x⊕x=0、x⊕0=xx\oplus0=xx⊕0=x，所以「出现两次的抵消」类问题常用异或；配合前缀异或能做区间异或查询。

递推与递归

一句话

给一个能一项项往后算的问题（n≤106n\le 10^6n≤106），你要么从初值开始从小到大把每一项推出来、要么把原问题拆成同形状的更小子问题递归下去，推进与回溯交替出现。时间 O(n)O(n)O(n) 或 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)（或滚动后的 O(1)O(1)O(1)）。

原理

实现

应用

记忆化搜索

状态之间的依赖是 DAG 时，递归 + 记忆化能让「每个状态只算一次」，避免指数级重复。

全排列与子集枚举

O(n!)O(n!)O(n!) 的排列用 next_permutation；O(2n)O(2^n)O(2n) 的子集用位掩码。

递归深度与栈溢出

递归深度到 10510^5105 就可能爆栈；要么改成显式栈的迭代写法，要么开大栈（Windows 下可加大）。

分治

一句话

给一个规模为 nnn 的问题（n≤105n\le 10^5n≤105 或 n≤5×105n\le 5\times10^5n≤5×105），你要把区间从中间劈成两半、各自递归求解，再把左右两半的答案并起来，拆分与合并交替出现。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

实现

归并排序与逆序对

归并时「右边先出来」就说明右边这个数比左边剩下的都小，逆序对加上左边剩余个数。

快速幂 / 快速乘

O(log⁡b)O(\log b)O(logb) 的快速幂；模数到 101810^{18}1018 时用 __int128 或「倍增的快速乘」避免溢出。

平面最近点对

二维问题

二分与三分

一句话

给一个在整数上单调、或先增后减的函数 / 判定（n≤106n\le 10^6n≤106 或答案值域 ≤1018\le 10^{18}≤1018），要你在 [L,R][L,R][L,R] 上二分出最小的满足条件的位置，或在单峰函数上三分出极值点，每次判定后砍掉一段区间。时间 O(log⁡C)O(\log C)O(logC) 次判定 / 求值，空间 O(1)O(1)O(1)。

实现

0/1 分数规划

一句话

给 nnn 个「收益 aia_iai​、代价 bib_ibi​」对（n≤105n\le 10^5n≤105，bi>0b_i>0bi​>0），要你选一个子集 SSS 让 ∑i∈Sai∑i∈Sbi\dfrac{\sum_{i\in S}a_i}{\sum_{i\in S}b_i}∑i∈S​bi​∑i∈S​ai​​ 最大，做法是猜一个答案 xxx、把每项换成 ai−xbia_i-xb_iai​−xbi​ 再判定是否存在正和，猜测与判定交替出现。时间 O(nlog⁡C)O(n\log C)O(nlogC)（二分答案），空间 O(n)O(n)O(n)，精度 10−610^{-6}10−6 约 60 次迭代。

双指针与滑动窗口

一句话

给一个序列（n≤106n\le 10^6n≤106），要你数出有多少个连续子段满足某个性质、或求出其中最优的一段，做法是让左右指针只往右移：一边把右端点的元素收进窗口、一边把左端点往外放，收与放交替出现。时间 O(n)O(n)O(n) 总时间，空间 O(n)O(n)O(n) 或 O(1)O(1)O(1)。

原理

实现

（双指针的合法性：当右端点右移时，最小的合法左端点不会左移。）

应用

尺取法

「和不超过 / 不少于某值」的区间计数：右端点单调右移、左端点单调右移，总 O(n)O(n)O(n)。

滑动窗口

窗口大小固定为 kkk 时维护窗口内的和 / 计数 / 最值；最值用单调队列。

双指针判回文

左右指针向中间夹，比较字符；O(n)O(n)O(n) 且 O(1)O(1)O(1) 空间。

有序数组的两数之和

排序后左右夹逼；若要求「返回下标」则用哈希表。

倍增

一句话

给一个长度 n≤106n\le 10^6n≤106 的静态序列（n≤106n\le 10^6n≤106，值不会改），要你反复回答「[l,r][l,r][l,r] 的最大值 / gcd 是多少」，也可以在一棵树上反复问「从 uuu 往上跳 kkk 步到哪、uuu 与 vvv 的 LCA 是谁」，预处理与查询交替出现。时间预处理 O(nlog⁡n)O(n\log n)O(nlogn)、单次查询 O(1)O(1)O(1)，空间 O(nlog⁡n)O(n\log n)O(nlogn)；树上倍增预处理 O(nlog⁡n)O(n\log n)O(nlogn)、单次 O(log⁡n)O(\log n)O(logn)。

原理

实现

应用

可重复贡献

max⁡\maxmax、min⁡\minmin、gcd⁡\gcdgcd、按位或 / 与都满足「重叠不影响结果」；而「和」不满足（重叠会算两次），所以不能用 ST 表。

树上倍增与 LCA

预处理每个点向上 2j2^j2j 步的祖先，查询 LCA 时先跳到同一深度、再一起往上跳。

贪心

一句话

给 n≤105n\le 10^5n≤105 个物品或任务（n≤105n\le 10^5n≤105），要你按某个关键字从前往后一个个决定选不选，而且这一步选完不影响后面还能选什么，偶尔还要用堆把先前贪错的决定反悔回来，选择与反悔交替出现。时间 O(nlog⁡n)O(n\log n)O(nlogn)（通常瓶颈是排序）或 O(nlog⁡n)O(n\log n)O(nlogn)（反悔贪心用堆），空间 O(n)O(n)O(n)。

原理

实现

（贪心的两步：确定「按什么排序」，再证明「交换不会变差」。）

应用

交换论证

证明贪心正确性的标准套路：假设最优解与贪心解在某处不同，交换两个元素后不更差，从而可以逐步把最优解变成贪心解。

排序关键字的选择

「按比值排」「按差值排」「按右端点排」都是常见关键字；选错就会 WA，必须用交换论证确认。

反悔贪心

「当前选它最优、但以后可能后悔」时，用一个堆维护「已选」并支持「替换」，等价于把一个决策的收益拆成两半。

拟阵与拟阵交

一句话

给 n≤2×105n\le 2\times10^5n≤2×105 个带权元素和一个「哪些能一起选」的合法族（满足拟阵公理），要你选出权值和最大的子集，做法是把元素按权从大到小排好、每次问「加上它以后还合法吗」，加入与替换交替出现。时间 O(nlog⁡n)O(n\log n)O(nlogn)（拟阵贪心）或 O(n3)O(n^3)O(n3)（拟阵交），空间 O(n)O(n)O(n)。

原理

实现

（拟阵 = 独立集族 + 遗传性 + 交换性；拟阵上的贪心「按权从大到小、能加就加」就是最优解。）

应用

Kruskal 与图拟阵

「无环的边集」构成图拟阵，Kruskal 就是拟阵贪心：按边权从小到大，能加就加。

划分拟阵与匹配

「每个元素只能被选一次的」约束可以用划分拟阵描述；两个划分拟阵的交对应二分图匹配。

构造与交互

一句话

给一个问题（n≤105n\le 10^5n≤105，交互询问次数 ≤105\le 10^5≤105），要么让你输出任意一组满足条件的解，要么不给你数据、只能靠每次询问得到「是 / 否」来还原答案，询问与推理交替出现。时间构造本身 O(n)O(n)O(n) 或 O(nlog⁡n)O(n\log n)O(nlogn)、空间 O(n)O(n)O(n)，交互题则要在限定的询问次数（通常 O(log⁡n)O(\log n)O(logn) 或 O(n)O(n)O(n)）内还原答案。

原理

实现

（构造题先手玩小样例找规律，再写一个 checker 自测；交互题把「询问」封装成函数，本地用模拟器对拍。）

应用

构造的验证

写完构造一定要写一个 checker：检查输出是否合法（而不是是否正确），再对拍小数据。

数组与链表

一句话

给你一个要频繁在中间插入 / 删除的序列（长度到 10610^6106），要你选一种线性结构存它，并说清「随机访问」与「插入删除」的取舍。时间随机访问 O(1)O(1)O(1)、中间插入 O(n)O(n)O(n)（链表反之），空间 O(n)O(n)O(n)。

原理

实现

（数组和链表是最基础的两种线性结构，区别只有一条：内存连续还是不连续。）

应用

邻接表与链式前向星

一句话

给你一张 nnn 个点、mmm 条边的图（n,m≤106n,m\le 10^6n,m≤106），要你选一种存边的方式，使「把每个点的出边扫一遍」的总代价是线性的。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

vector 邻接表写起来方便、缓存略差；前向星（head + nxt 数组）内存紧凑、适合边数上百万。

应用

栈与单调栈

一句话

给你一个长度为 nnn 的序列（n≤106n\le 10^6n≤106），要你求出每个元素左边 / 右边第一个比它大（小）的位置。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

队列与双端队列

一句话

给你一个长度为 nnn 的序列（n≤106n\le 10^6n≤106），要你维护一个能两端进出的队列，或者做「边权只有 000 和 111 的图上最短路」。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

需要「两端都能插入 / 删除」时用 deque；0-1 BFS 用它（边权为 0 放队首、为 1 放队尾）。

应用

单调队列

一句话

给你一个长度为 nnn 的序列和一个窗口长度 kkk（n≤106n\le 10^6n≤106），要你求出每个窗口里的最大值 / 最小值。时间 O(n)O(n)O(n)，空间 O(k)O(k)O(k)。

原理

实现

滑动窗口最值：队首是窗口内最优、队尾弹出「更差且更晚」的；保证队列里下标单调、值单调。

应用

哈希表

一句话

给 nnn 个元素（n≤106n\le 10^6n≤106），要你反复做三件事：问某个值出现过没有、问它出现了几次、把值映射到它携带的信息，插入与查询交替出现。时间平均 O(1)O(1)O(1) 单次操作，空间 O(n)O(n)O(n)；被卡时用随机化或手写哈希。

原理

实现

应用

判重与计数

把「值」映射到「出现次数」；也可以用一个「时间戳」数组支持多组数据下的清零。

为什么 unordered_map 会被卡

标准库的哈希函数对某些输入会大量冲突；攻击者（或出题人）可以构造这些输入，让复杂度退化到 O(n2)O(n^2)O(n2)。

字符串 → 整数

把字符串用多项式哈希映射成整数；配合哈希值可以直接当哈希表的 key。

二叉堆与优先队列

一句话

给你 nnn 次「插入一个数」和「取出当前最小（大）的数」的操作（n≤106n\le 10^6n≤106），要你在 O(log⁡n)O(\log n)O(logn) 内完成每一次。时间单次 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

应用

对顶堆

一个大根堆放「较小的一半」、一个小根堆放「较大的一半」，随时取中位数；插入时调整两边大小。

堆优化 Dijkstra

每轮从堆里取当前距离最小的未确定点，用它松弛邻居；复杂度 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

可并堆（左偏树）

一句话

给你若干个堆（总共 n≤105n\le 10^5n≤105 个元素），要你不断把两个堆合并、并随时取出其中的最小值。时间合并与取最小值均 O(log⁡n)O(\log n)O(logn)，空间 O(n)O(n)O(n)。

原理

实现

需要「合并两个堆」时用左偏树（或配对堆）：合并 O(log⁡n)O(\log n)O(logn)，还支持「打标记整体加 / 整体乘」。

应用

二叉树与遍历

一句话

给你一棵二叉树，要你按先序 / 中序 / 后序 / 层序输出它的结点，或者由两种遍历序列还原出这棵树。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

完全二叉树的下标性质

用数组存完全二叉树时，结点 iii 的左右儿子是 2i2i2i、2i+12i+12i+1，父亲是 ⌊i/2⌋\lfloor i/2\rfloor⌊i/2⌋。

二叉搜索树

一句话

给你一个集合（n≤105n\le 10^5n≤105），要你支持插入、删除、查排名、查第 kkk 小、查前驱后继。时间平均单次 O(log⁡n)O(\log n)O(logn)、最坏 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

中序遍历有序是 BST 的核心性质；查询 / 插入是 O(树高)O(\text{树高})O(树高)，随机数据下 O(log⁡n)O(\log n)O(logn)，退化时 O(n)O(n)O(n)。

应用

哈夫曼树

一句话

给你 nnn 个带权叶子（n≤105n\le 10^5n≤105），要你构造一棵二叉树，使「每个叶子的权值乘上它到根的路径长度」之和最小。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

每次取权值最小的两个结点合并，用优先队列 O(nlog⁡n)O(n\log n)O(nlogn)；合并出来的树带权路径长度最小。

应用

深度优先搜索（DFS）

一句话

给你一张图或一个状态空间（规模 10510^5105），要你从某个点出发一路走到底再回溯，求出可达性、枚举所有方案或求连通块。时间 O(n+m)O(n+m)O(n+m)，空间 O(n)O(n)O(n)（递归栈也算）。

原理

实现

应用

广度优先搜索（BFS）

一句话

给你一张无权图（n,m≤106n,m\le 10^6n,m≤106）和一个起点，要你按层扩展，求出从起点到每个点的最少步数。时间 O(n+m)O(n+m)O(n+m)，空间 O(n)O(n)O(n)。

原理

实现

应用

八连通与特殊方向

格点图的方向数组要写全（4 / 8 连通），并仔细处理边界。

多源 BFS

把多个起点一起入队（初始距离都是 0），一次 BFS 就得到「到最近起点」的距离。

连通块计数

每次从一个未访问的点出发做一次 DFS / BFS，计数加一。

树与图的遍历

一句话

给你一棵树或一张图（n,m≤106n,m\le 10^6n,m≤106），要你在 O(n+m)O(n+m)O(n+m) 内走遍所有点，并顺便求出子树大小、深度、父亲等信息。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

说明：树与图的遍历本身没有额外技巧，核心代码就是 DFS / BFS；树上的用法见 06-树上算法 / 树的存储与遍历，图上的用法见 05-图论 / 图的存储与遍历。

应用

剪枝

一句话

给你一个状态空间很大的搜索（原始规模 10810^8108 以上），要你通过可行性剪枝与最优性剪枝把搜索树砍小到能跑完。时间取决于剪枝效果（最坏仍是指数级），空间 O(深度)O(\text{深度})O(深度)。

原理

实现

（剪枝的判断顺序：最便宜、最能砍掉分支的先判。）

应用

迭代加深（IDDFS）

一句话

给你一个「答案深度未知」的搜索，要你按深度 1,2,3,…1,2,3,\dots1,2,3,… 反复 DFS，把空间压到 O(深度)O(\text{深度})O(深度)。时间与最深那一次同阶，空间 O(深度)O(\text{深度})O(深度)。

原理

实现

答案深度未知时，按深度 1,2,3,…1,2,3,\dots1,2,3,… 反复 DFS；总代价与「最深一次」同阶，但空间只用 O(深度)O(\text{深度})O(深度)。

双向广搜

一句话

给你起点和终点（状态数 bdb^dbd 跑不动、但 bd/2b^{d/2}bd/2 可以），要你从两边各搜一半、在中点相遇。时间与空间都由 bd/2b^{d/2}bd/2 决定。

原理

实现

应用

双向 BFS（特殊搜索）

从起点和终点各 BFS 一半，任一侧扩展到对面访问过的点就相遇（见「搜索优化」一节）。

优先队列 BFS

一句话

给你一张边权不相等的隐式图，要你按「当前距离最小」的顺序扩展状态，第一次弹出终点即为最优。时间 O(mlog⁡n)O(m\log n)O(mlogn)，空间 O(n)O(n)O(n)。

原理

实现

（优先队列 BFS 就是「把 BFS 的队列换成小根堆」，用于边权不相等的隐式图。）

一句话

给你一张边权只有 000 和 111 的图和一个起点，要你在 O(n+m)O(n+m)O(n+m) 内求出到所有点的最短距离（000 边压队首、111 边压队尾）。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

应用

A* 与 IDA*

一句话

给你一个状态数巨大、但有「乐观下界」可估的最短路 / 最优化问题，要你用估价函数把搜索导向目标。时间取决于展开的状态数，空间 O(展开状态数)O(\text{展开状态数})O(展开状态数) 或 O(深度)O(\text{深度})O(深度)。

原理

实现

用「已走代价 + 估价函数 hhh」作为堆的键；只要 hhh 不高估（可采纳），第一次弹出终点就是最优解。

应用

IDA*

迭代加深 + 估价剪枝：限制 f=g+hf=g+hf=g+h 不超过当前阈值，超过就剪掉，并记下「被剪的最小 fff」作为下一轮阈值。
