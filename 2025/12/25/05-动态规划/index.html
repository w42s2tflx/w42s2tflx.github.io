算法笔记 05｜动态规划

DP 概念与编码方法

一句话

有一道规模 n≤105n\le 10^5n≤105 的最优化题：你选定状态、写出转移之后，要从初始状态把状态一个一个推出来，给出最优值，必要时把取到最优的那条方案也输出。时间最坏 O(n)O(n)O(n) 或 O(nlog⁡n)O(n\log n)O(nlogn)（视转移而定），空间 O(n)O(n)O(n)，滚动后为 O(1)O(1)O(1) 维。

原理

实现

（状态 + 转移 + 边界 + 答案，四件事写清楚；转移只依赖「已经算好的更小规模」。）

应用

记忆化搜索（自顶向下）

状态之间的依赖是 DAG 时，直接递归 + 记忆化最省心；注意「未计算」和「答案是 0」要用不同的标记区分。

滚动数组 / 降维

转移只依赖前一层时，把第一位丢掉、倒序（或正序）枚举即可；关键是判断「同一层内会不会读到本轮刚写的值」。

刷表法与填表法

填表法从「谁能转移到我」出发；刷表法从「我能转移到谁」出发。刷表法在转移较稀疏时更快。

输出方案

额外记一个「决策」数组，从答案状态倒推；如果空间紧张，就用「重新算一遍」的方式找决策。

线性 DP

一句话

给两个长度分别为 n,mn,mn,m 的序列（n,m≤5000n,m\le 5000n,m≤5000），要你逐位比较着往右扫：一边配出两个序列的最长公共子序列、算出把一个改成另一个所需的最少编辑次数，一边在单个序列上找出最长的上升子序列。时间 O(nm)O(nm)O(nm)，空间 O(min⁡(n,m))O(\min(n,m))O(min(n,m))。

原理

实现

应用

编辑距离

插入 / 删除 / 替换的代价都是 1 时，fi,j=min⁡(fi−1,j,fi,j−1,fi−1,j−1+[Ai≠Bj])+1f_{i,j}=\min(f_{i-1,j},f_{i,j-1},f_{i-1,j-1}+[A_i\ne B_j])+1fi,j​=min(fi−1,j​,fi,j−1​,fi−1,j−1​+[Ai​=Bj​])+1。

带权 LIS / 上升子序列计数

LIS 用「以 i 结尾的最长长度」，配合树状数组按值域维护最大值；带权版本把 max 换成权值和。

最长不降 / 下降子序列

把比较号反过来就行；用 upper_bound / lower_bound 的贪心解法可以做到 O(nlog⁡n)O(n\log n)O(nlogn)。

背包问题

一句话

有 nnn 件物品和容量为 WWW 的背包（n,W≤105n,W\le 10^5n,W≤105），每件物品有重量和价值，可以取一次、取有限次或取无限次，要你选出总重不超过 WWW 的取法使总价值最大，物品一件一件拿来考虑。时间 O(nW)O(nW)O(nW)（多重背包用单调队列同样 O(nW)O(nW)O(nW)），空间 O(W)O(W)O(W)。

原理

实现

应用

多重背包的单调队列优化

第 iii 件有 cic_ici​ 个时，按「模 wiw_iwi​ 的余数」分组，每组内是一个滑动窗口取最大值，用单调队列 O(W)O(W)O(W) 处理一种物品。

分组背包

每组最多选一个：外层枚举组，内层倒序枚举容量，再枚举组内物品。

树上背包

fu,jf_{u,j}fu,j​ 表示「uuu 的子树内选容量 jjj 的最大收益」；合并儿子时做卷积，用「子树大小」限制枚举上界就得到 O(n2)O(n^2)O(n2)。

求方案数 / 输出方案

把 max 换成加法就是方案数；要输出方案就额外记录转移来源。

区间 DP

一句话

给一个长度为 nnn 的序列（n≤500n\le 500n≤500，或 n≤5000n\le 5000n≤5000 配合四边形不等式），要你把相邻的两段反复合并成一段并算出合并的最优代价，靠由小区间推大区间，中间还要数出括号匹配方案数、找出最长的回文子序列。时间 O(n2)O(n^2)O(n2)（或 O(n3)O(n^3)O(n3)），空间 O(n2)O(n^2)O(n2)。

原理

实现

应用

四边形不等式优化

若代价函数满足「区间包含单调 + 四边形不等式」，则最优决策点单调，可以把 O(n3)O(n^3)O(n3) 降到 O(n2)O(n^2)O(n2)。

环形区间 DP

把环断开：要么「枚举断点」跑 nnn 次，要么把数组复制一倍、只取长度为 nnn 的区间。

括号序列 / 回文串

「区间内最多能匹配多少对括号」与「最长回文子序列」都是 O(n2)O(n^2)O(n2) 的经典区间 DP。

树形 DP

一句话

给一棵 nnn 个点的树（n≤105n\le 10^5n≤105，带权时 n≤2000n\le 2000n≤2000），要你从叶子往根逐点决定选或不选：选出最少的点盖住每条边、选出最多的两两不相邻的点，并依次把每个点拎起来当根重新算一遍。时间 O(n)O(n)O(n)（树上背包为 O(n2)O(n^2)O(n2)），空间 O(n)O(n)O(n)。

原理

实现

应用

最小点覆盖 / 最大匹配（树上）

树上最大匹配另开一维「这个点有没有被匹配」，转移时枚举「uuu 匹配给哪个儿子」。

换根 DP（rerooting）

先求「以 1 为根」的子树答案，再用「父亲那一边的答案」推出每个点为根时的答案。

依赖型背包（树上背包）

选儿子必须先选父亲：把「子树内选容量 j」的 DP 自底向上合并，复杂度 O(nW)O(nW)O(nW) 级别。

直径 / 最长链

维护「以 uuu 为端点向下延伸的最长路」，合并两个儿子时更新答案，O(n)O(n)O(n)。

DAG 上的 DP

一句话

给一个有 nnn 个点、mmm 条边的有向无环图（n,m≤106n,m\le 10^6n,m≤106），要你按拓扑序一个点一个点地推：算出从起点到终点的最长路与最短路、数出有多少条路径，并指出哪条是关键路径。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

应用

最长路 / 最短路（DAG）

按拓扑序递推：最长路取 max，最短路取 min。注意最短路要把初值设成 INF 并判可达。

路径计数

路径条数按拓扑序累加：cntvcnt_vcntv​ 加上所有入边的 cntucnt_ucntu​。

关键路径

「最早开始时间」按拓扑序正推，「最晚开始时间」按逆拓扑序倒推；两者相等的活动就是关键活动。

环形 DP 与后效性处理

一句话

给一个首尾相接的环（n≤105n\le 10^5n≤105，DP 状态 O(1)O(1)O(1) 维），要你沿着环一格一格做决策，还要处理某一步的转移会反过来依赖后面几步、或者首尾的状态互相牵制的情况。时间 O(n)O(n)O(n) 或 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(1)O(1)O(1) 维。

原理

实现

应用

环形区间 DP

把环复制一倍变成 2n2n2n 的链，再只统计长度为 nnn 的区间；或者枚举「第一个点的状态」跑两次。

状态里补一维

当转移需要知道「更早」的信息时，把那点信息放进状态：例如「连续选了几个」「上一个选的是谁」。

基环树 DP

先找环、把环上的点标出来，对每个环上点「挂着的子树」做树形 DP，再在环上做一次环形 DP。

悬线法

一句话

给一个 n×mn\times mn×m 的 01 矩阵（n,m≤2000n,m\le 2000n,m≤2000），要你一行一行往下扫，对每个格子算出以它为底能向上延伸多高的全 1 竖线，再向左右撑开找到最大的全 1 子矩形，并数出全 1 子矩形的个数。时间 O(nm)O(nm)O(nm)，空间 O(m)O(m)O(m)。

原理

实现

（对每个格子维护「向上能延伸多高」hhh、「向左 / 向右能延伸到哪」L,RL,RL,R，答案由 h×(R−L+1)h\times(R-L+1)h×(R−L+1) 给出。）

应用

最大全 1 矩形（单调栈版）

把每一行当成柱状图，用单调栈求最大矩形面积；与悬线法等价。

全 1 子矩形计数

用「以每个位置为右下角」的贡献法：对每行做单调栈，把不同高度的矩形个数累加。

状态压缩 DP

一句话

给一个规模 n≤20n\le 20n≤20 的集合问题（或 n×m≤100n\times m\le 100n×m≤100 的棋盘），把「选了哪些元素」压成一个二进制数，要你在这 2n2^n2n 个状态之间一个一个转移，选出最优的覆盖或划分方案。时间 O(2nn)O(2^nn)O(2nn) 或 O(3n)O(3^n)O(3n)，空间 O(2n)O(2^n)O(2n)。

原理

实现

应用

枚举子集（O(3n)O(3^n)O(3n)）

把「SSS 拆成两个不相交子集」的转移写成子集枚举；总循环次数是 3n3^n3n，不是 4n4^n4n。

状压 + 最短路 / 分层图

把「已经访问过的点集」作为最短路的状态，在状态图上跑 Dijkstra，复杂度 O(2nmlog⁡)O(2^n m\log)O(2nmlog)。

骨牌 / 棋盘覆盖的状态设计

按「行」压缩时，状态是「本行哪些位置被上一行伸下来的骨牌占用」；转移时枚举本行的摆放，判断不冲突。

插头 DP 与轮廓线 DP

一句话

给一个 n×mn\times mn×m 的网格（n,m≤12n,m\le 12n,m≤12，或 m≤30m\le 30m≤30 配合矩阵），要你一格一格地摆骨牌把整个网格铺满，或者从起点走到终点且中途必须经过指定的必经点，数出方案数。时间 O(nm⋅2m)O(nm\cdot 2^m)O(nm⋅2m)（轮廓线）或 O(nm⋅S)O(nm\cdot S)O(nm⋅S)（插头，SSS 是括号序列状态数），空间 O(2m)O(2^m)O(2m)。

原理

实现

（轮廓线 DP：逐格推进，状态是「当前格子前 mmm 个格子的占用情况」。）

应用

骨牌铺满的方案数

上面的写法；把 n、m 中的小者作为状态位数，复杂度是 O(nm2m)O(nm2^m)O(nm2m)。

带权 / 带限制的铺法

把方案数换成最大值（dp 取 max），或者给格子加「不能放」的限制（在枚举时跳过）。

数位 DP

一句话

给一个区间 [L,R][L,R][L,R]（R≤1018R\le 10^{18}R≤1018），要你从高位往低位一位一位地填数、同时卡住上界，数出区间里满足某条数位限制的数有多少个、或者它们的数位和是多少。时间 O(位数×状态数)O(\text{位数}\times\text{状态数})O(位数×状态数)，空间 O(状态数)O(\text{状态数})O(状态数)。

原理

实现

（记忆化搜索：pos 是当前位、limit 表示是否贴着上界、lead 表示是否还有前导零，再带上题目需要的额外状态。）

应用

前导零的处理

前导零会让「000123」和「123」被当成不同的数，所以必须用 lead 标记，且这一位不能计入「上一位是谁」等状态。

数字不降 / 不含某数字

「不降」把「上一位数字」放进状态；「不含 4」在枚举时直接跳过。

计数 + 求和

同时维护「个数」和「和」：每位数字 d 的贡献是 d 乘上这一位的位权再乘「后面有多少种填法」。

计数 DP

一句话

有一道规模 n≤106n\le 10^6n≤106 的计数题，要你把方案按最后一步拆开、把规模从小到大一个一个数出来，给出方案数。时间 O(n)O(n)O(n) 或 O(nlog⁡n)O(n\log n)O(nlogn)（含组合数预处理），空间 O(n)O(n)O(n)。

原理

实现

应用

加法原理与乘法原理

「或者」相加、「并且」相乘；DP 计数的每一步就是把这两个原理写成状态转移。

组合数预处理

O(n)O(n)O(n) 预处理阶乘与逆阶乘后，单次询问组合数是 O(1)O(1)O(1)；范围小的时候也可以直接用杨辉三角。

容斥 + 计数

「至少有 k 个位置重合」这类问题先按「钦定」计数，再用二项式系数容斥修正。

概率与期望 DP

一句话

有一个状态数为 nnn 的随机过程（n≤105n\le 10^5n≤105，需要解方程时 n≤500n\le 500n≤500），每一步按给定概率从一个状态跳到另一个状态，要你算出到达目标状态的概率或期望步数。时间 O(n)O(n)O(n)（递推）或 O(n3)O(n^3)O(n3)（高斯消元），空间 O(n)O(n)O(n)。

原理

实现

（期望的线性性：E[X+Y]=E[X]+E[Y]E[X+Y]=E[X]+E[Y]E[X+Y]=E[X]+E[Y]，无论是否独立，这是把复杂期望拆开的关键。）

应用

期望的线性性

把「总期望」拆成「每个元素贡献的期望之和」，常常能把 O(n2)O(n^2)O(n2) 变成 O(n)O(n)O(n)。

概率 DP（正推 / 倒推）

求「到终态的概率」通常倒推（f[i] = 从 i 出发的成功率），求「从起点到达各状态的概率」则正推。

高斯消元解期望方程

转移有环时，列出「E_i 减去所有后继的 p 倍」的线性方程组，用高斯消元 O(n3)O(n^3)O(n3) 解出。

动态 DP

一句话

给一棵树或一个序列，每个点带权，另有 mmm 次操作（n,m≤105n,m\le 10^5n,m≤105），每次操作是「把某个点的权值改成 vvv」，改完后立刻询问当前的全局最优值，两种操作交替出现。时间 O(log⁡2n)O(\log^2 n)O(log2n) 或 O(log⁡n)O(\log n)O(logn) 每次修改，空间 O(n)O(n)O(n)。

原理

实现

（把 DP 的转移写成矩阵（或广义矩阵），用线段树 / 树链剖分维护「一串转移的复合」。）

应用

带修改的序列 DP

把「每个位置的转移」看成一个矩阵，线段树维护矩阵乘积；单次修改就是把一个叶子的矩阵换掉。

带修改的树形 DP

树上用「树链剖分 + 线段树维护矩阵」：每个点的矩阵用它的轻儿子的贡献拼出来，重链上的转移交给线段树。

与矩阵快速幂的关系

「带修改的 DP」是「矩阵快速幂」的局部版本：矩阵快速幂求的是「固定转移重复 n 次」，线段树维护的是「转移逐个不同」。

前缀和优化

一句话

有一道 n≤106n\le 10^6n≤106 的 DP，每一步都要把前面一整段状态的和拿来做转移，老老实实从头加一遍就会退化成 O(n2)O(n^2)O(n2)。时间 O(n)O(n)O(n)（每步 O(1)O(1)O(1) 求和），空间 O(n)O(n)O(n)。

原理

实现

应用

区间和型转移

转移里出现 sum(j,i)sum(j,i)sum(j,i) 时，先用前缀和把它拆成 prei−prej−1pre_i-pre_{j-1}prei​−prej−1​，把与 iii 有关的部分提到 min/max 外面。

二维前缀和

转移依赖「矩形内的和」时，用二维前缀和（容斥）把它变成 O(1)O(1)O(1)。

单调队列优化 DP

一句话

有一道 n≤106n\le 10^6n≤106 的 DP，递推式是 dpi=min⁡j∈[i−m, i−1](dpj)+widp_i=\min_{j\in[i-m,\,i-1]}\big(dp_j\big)+w_idpi​=minj∈[i−m,i−1]​(dpj​)+wi​，也就是每步要从前面长度为 mmm 的滑动窗口里取最小值来往后推。时间 O(n)O(n)O(n)，空间 O(m)O(m)O(m)。

原理

实现

（队列里存下标，值单调；先弹过期、再弹更差的、最后取队首。）

应用

滑动窗口最值型转移

只要「候选集合是一个定长滑动窗口」，就能用单调队列把 O(nm)O(nm)O(nm) 降到 O(n)O(n)O(n)。

多重背包（单调队列）

把每种物品按「模重量 www 的余数」分组，组内是一个滑动窗口取最大值，每种物品 O(W)O(W)O(W)。

斜率优化与凸壳优化

一句话

有一道 n≤105n\le 10^5n≤105 的 DP，递推式是 dpi=min⁡j(ajbi+dpj)+cidp_i=\min_j\big(a_jb_i+dp_j\big)+c_idpi​=minj​(aj​bi​+dpj​)+ci​，每一步都要在若干个一次函数里挑出在 bib_ibi​ 处取值最小的那个。时间 O(n)O(n)O(n)（bib_ibi​ 单调时，单调栈加指针）或 O(nlog⁡n)O(n\log n)O(nlogn)（bib_ibi​ 不单调时，凸壳上二分），空间 O(n)O(n)O(n)。

原理

实现

（把每个 jjj 看成「斜率 aja_jaj​、截距 dpjdp_jdpj​ 的直线」，维护下凸壳。）

应用

凸壳维护

插入一条直线时，若它让「中间的直线永远不可能最优」就把中间那条弹掉；斜率相等时保留截距更优的那条。

查询：xxx 单调用指针、否则二分

bib_ibi​ 单调时，最优决策点在凸壳上只会朝一个方向移动，用一个指针即可；否则在凸壳上二分。

方向要按约定数清楚：斜率递增 + 下凸壳时，xxx 增大则最优直线的下标从右往左移（斜率越小越适合大的 xxx）；把方向搞反会漏掉最优解。

Slope Trick

一句话

有一道 n≤105n\le 10^5n≤105 的 DP，它的 DP 函数是凸的，每次转移只是在函数上加一个绝对值、做一次前缀取 min 或者整体平移一下，于是用两个堆就能把这整条凸函数维护住。时间 O(log⁡n)O(\log n)O(logn) 每次转移、总 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（用两个堆维护「斜率变化的拐点」，堆是「左侧拐点（大根堆）」与「右侧拐点（小根堆）」。）

应用

前缀取 min

f(x)←min⁡y≤xf(y)f(x)\leftarrow\min_{y\le x}f(y)f(x)←miny≤x​f(y) 表示「右侧的拐点全部无效」，直接把右堆清空并把最小值加上去。

平移与整体加

「f(x)→f(x−Δ)f(x)\to f(x-\Delta)f(x)→f(x−Δ)」给两个堆整体打一个加法标记；「f(x)→f(x)+cf(x)\to f(x)+cf(x)→f(x)+c」只改最小值。

四边形不等式与决策单调性

一句话

有一道 n≤5000n\le 5000n≤5000 的 DP，递推式是 dpi=min⁡j<i(dpj+w(j,i))dp_i=\min_{j<i}\big(dp_j+w(j,i)\big)dpi​=minj<i​(dpj​+w(j,i))，每一步都要枚举前面的分界点 jjj，而最优的 jjj 会随着 iii 增大单调右移（区间 DP 同理）。时间 O(nlog⁡n)O(n\log n)O(nlogn)（分治）或 O(n)O(n)O(n)（单调队列），空间 O(n)O(n)O(n)。

原理

实现

（分治求决策：算出 midmidmid 的最优决策点后，左右两半的决策点范围就确定了。）

数据结构优化

一句话

有一道 n≤105n\le 10^5n≤105 的 DP，每一步可供转移的候选集合是一个随位置变化的区间，要你随时往集合里加入、删除状态并取出最值或和，用线段树 / 树状数组维护。时间 O(log⁡n)O(\log n)O(logn) 每次转移、总 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（把「dpj+cost(j)dp_j+cost(j)dpj​+cost(j)」放进数据结构，转移时查询区间最值。）

应用

线段树维护区间最值

转移候选是「值域 / 下标区间」时，按区间查询最值即可。

树状数组维护前缀最值

候选集合是「前缀」时用树状数组（常数更小），但要注意它只能做「可合并且可减」或「前缀」型操作。

倍增优化

一句话

有一道 n≤105n\le 10^5n≤105 的题，同一种转移要重复至多 10910^9109 次，一步步跳显然跑不完，改成先预处理出跳 2k2^k2k 步后的结果再按二进制把答案拼起来。时间 O(nlog⁡n)O(n\log n)O(nlogn) 预处理、O(log⁡n)O(\log n)O(logn) 单次查询，空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

（预处理「跳 2j2^j2j 次」的结果，查询时把次数按二进制拆开拼起来。）

应用

树上跳 kkk 步的聚合值

把「跳 kkk 步的点权和 / 边权最值」预处理成倍增表，单次 O(log⁡k)O(\log k)O(logk)。

倍增求 LCA / 第 kkk 个祖先

先跳到同一深度，再一起往上跳；求第 kkk 个祖先就是把 kkk 按二进制拆开。

WQS 二分

一句话

有一道 n≤105n\le 10^5n≤105 的最优化题，要求恰好选 kkk 个（k≤nk\le nk≤n），而最优值关于 kkk 是凸的；做法是给每件物品额外挂一个代价 λ\lambdaλ，先不限个数地求最优，再二分 λ\lambdaλ 把个数的约束逼到 kkk。时间 O(nlog⁡C)O(n\log C)O(nlogC)，空间 O(n)O(n)O(n)，其中 CCC 是权值范围。

原理

实现

（给每个「选」额外加一个代价 λ\lambdaλ，去掉「恰好 kkk 个」的限制做无限制 DP，再二分 λ\lambdaλ 使最优解恰好选 kkk 个。）

应用

恰好选 kkk 个

对「选」加一个权值 λ\lambdaλ（最大化和时减去 λ\lambdaλ，最小化和时加上 λ\lambdaλ），二分出使段数恰好为 kkk 的 λ\lambdaλ。

恰好 kkk 段 / 恰好 kkk 次操作

同一条思路可以用来做「恰好分成 kkk 段」「恰好执行 kkk 次操作」「恰好选 kkk 个不相交区间」。

凸性的判定与陷阱

WQS 二分成立的前提是「答案关于 kkk 是凸的」；做题时先用 O(nk)O(nk)O(nk) 的暴力打表看相邻差值是否单调，再决定用不用。
