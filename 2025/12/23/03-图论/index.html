算法笔记 03｜图论

图的存储与遍历

一句话

给定一张 nnn 个点、mmm 条边的图（n,m≤106n,m\le 10^6n,m≤106），要求从任意一个点出发沿着边把所有能走到的点都访问一遍，同时回答这三个问题：图里有多少个互不相通的块、能不能把每个点染成黑白两色使每条边的两端颜色不同、图中是否存在环。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

应用

无向图连通块计数

每个未访问的点启动一次遍历，计数加一，O(n+m)O(n+m)O(n+m)。

二分图判定（顺带）

在 DFS / BFS 里给点染 0/1 两色；若遇到一条边的两端同色，就不是二分图。

拓扑排序与 DAG

一句话

给定一张 nnn 个点、mmm 条边的有向图（n,m≤106n,m\le 10^6n,m≤106），要求把点排成一列，使每条有向边都从列中靠前的点指向靠后的点，或者判定这样的排列不存在。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Kahn 算法：每次取入度为 0 的点；若最后编号不足 nnn 个，说明有环。）

应用

判有向环

拓扑序长度不足 nnn 就有环；也可以用「DFS 三色标记」（白 / 灰 / 黑）判。

DAG 上 DP（最长路 / 路径计数）

按拓扑序递推即可；最长路取 max、路径计数取加法。

字典序最小的拓扑序

把队列换成优先队列（小根堆），每次取编号最小的入度为 0 的点。

Dijkstra

一句话

给你一张 nnn 个点、mmm 条边的带权图（n,m≤106n,m\le 10^6n,m≤106，边权非负）和一个源点 sss，要你求出 sss 到其余每个点的最短距离。时间 O(mlog⁡n)O(m\log n)O(mlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Dijkstra：每次取出距离最小的未确定点，松弛它的出边；不允许负权。）

应用

最短路计数

Dijkstra 时顺便维护「到该点的最短路条数」：距离更短就覆盖，相等就累加。

负环与差分约束

Bellman-Ford / SPFA 判负环：某个点被松弛了 nnn 次以上说明有负环。

Floyd

0-1 BFS

一句话

给你一张 nnn 个点、mmm 条边的图（每条边权只有 000 或 111）和一个源点 sss，要你求出 sss 到其余点的最短距离。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（边权只有 000 和 111 时，Dijkstra 的优先队列可以退化成双端队列：000 边压队首、111 边压队尾，队列里就自动保持了「距离单调」。）

应用

差分约束

一句话

给定 nnn 个变量和 mmm 条形如 xv−xu≤wx_v-x_u\le wxv​−xu​≤w 的限制（n,m≤105n,m\le 10^5n,m≤105），要求给每个变量定一个取值使这些不等式同时成立，或者判定不可能。时间 O(nm)O(nm)O(nm)（Bellman-Ford）或 O(mlog⁡n)O(m\log n)O(mlogn)（Dijkstra，权非负时），空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（把 xv−xu≤wx_v-x_u\le wxv​−xu​≤w 变成边 u→vu\to vu→v 权 www；跑最短路，distdistdist 就是一组解；有负环则无解。）

最短路树与最短路 DAG

一句话

给定一张 nnn 个点、mmm 条边的带权图和一个源点 sss（n,m≤105n,m\le 10^5n,m≤105），要求把所有从 sss 出发的最短路径保留下来，整理成一棵树或一张有向无环图。时间 O(mlog⁡n+nlog⁡n)O(m\log n + n\log n)O(mlogn+nlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（最短路 DAG：只保留满足 distu+w=distvdist_u+w=dist_vdistu​+w=distv​ 的边；它一定无环。）

应用

最短路计数

在最短路 DAG 上按拓扑序把路径条数累加即可（无环，所以不会重复计数）。

最短路径的必经点 / 必经边

在最短路上「必经」等价于「删掉它之后 sss 到 ttt 的最短路变长」；用支配树或「正反两遍最短路 + 路径计数」判断。

最短路树的性质

任取每个点的一条「最短入边」就构成一棵以 sss 为根的最短路树；树上 s→us\to us→u 的路径就是一条最短路。

分层图与拆点

一句话

给定一张 nnn 个点、mmm 条边的带权图（n≤105n\le 10^5n≤105），其中最多允许 k≤20k\le 20k≤20 条边免费或打折通过，要求从起点走到终点使总代价最小。时间 O(kmlog⁡(kn))O(km\log (kn))O(kmlog(kn))，空间 O(kn+m)O(kn+m)O(kn+m)。

原理

实现

（把状态扩成 (u,已用次数)(u,\text{已用次数})(u,已用次数)，每个原状态复制 k+1k+1k+1 份，形成分层图。）

应用

免费 / 打折边

每条边可以选择「正常花 www」或「用掉一次机会花 w/2w/2w/2」；分层后跑一次 Dijkstra。

状态最短路（状压 + 最短路）

状态里再带上「已经拿到哪些钥匙 / 访问了哪些特殊点」，用 (u,S)(u, S)(u,S) 跑最短路。

Prim

一句话

给你一张 nnn 个点、mmm 条边的连通无向图，每条边有一个权值，要你求出一棵总权最小的生成树；它与 Kruskal 的区别是「每次从已选的集合往外扩一条最小的边」。时间 O(mlog⁡n)O(m\log n)O(mlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（从任意一个点开始，每次从「已选的集合」往外接一条最小的边，把新的点并进来；用优先队列维护这条「最小出边」。）

应用

Boruvka

一句话

给你一张 nnn 个点、mmm 条边的连通无向图，每条边有一个权值，要你求出一棵总权最小的生成树。时间 O(mlog⁡n)O(m\log n)O(mlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（每轮给每个连通块找一条最小的出边，然后把它们合并；连通块数每轮至少减半，所以最多 log⁡n\log nlogn 轮。）

Kruskal 重构树

一句话

给定一张 nnn 个点、mmm 条边的带权图和 qqq 次询问（n,m≤3×105n,m\le 3\times10^5n,m≤3×105），每次询问是「只走边权不超过 WWW 的边，从 uuu 出发能到达多少个点」或「两点之间所有路径中最大边权的最小值是多少」，两种询问交替出现。时间 O(mlog⁡m+qlog⁡n)O(m\log m + q\log n)O(mlogm+qlogn)，空间 O(n)O(n)O(n)。

原理

实现

（按边权从小到大加边；每次合并两个连通块时新建一个点，点权是这条边的权值。）

应用

区间可达点计数

「只走边权 ≤W\le W≤W 的边，uuu 能到达哪些点」= 在重构树上从 uuu 往上跳到「点权 ≤W\le W≤W 的最高祖先」，该子树内的原图点数就是答案。

最小瓶颈路

两点间「路径上最大边权的最小值」= 重构树上两点的 LCA 的点权。

最小树形图（朱刘算法）

一句话

给定一张 nnn 个点、mmm 条边的带权有向图和一个根 rrr（n≤100n\le 100n≤100、m≤104m\le 10^4m≤104），要求选出一些有向边，使 rrr 能沿这些边到达每个点、每个非根点的入度恰为 111，且选出的边权和最小。时间 O(nm)O(nm)O(nm)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（朱刘算法：给每个非根点选一条最小的入边，若成环就把环缩成一个点、调整边权后递归。）

应用

定根最小树形图

直接调用上面的算法；注意根必须能到达所有点，否则返回 -1。

不定根

枚举每个点作为根、分别跑一次，取最小值；复杂度 O(n2m)O(n^2m)O(n2m)，nnn 小时可用。

给定一张 nnn 个点、mmm 条边的带权图和 kkk 个关键点（n≤100n\le 100n≤100、k≤10k\le 10k≤10），要求选出一个连通子图把所有关键点连在一起，使子图的边权和最小。时间 O(3kn+2kmlog⁡n)O(3^k n + 2^k m\log n)O(3kn+2kmlogn)，空间 O(2kn)O(2^k n)O(2kn)。

原理

实现

（dp[S][u]dp[S][u]dp[S][u] 表示「已连接集合 SSS 且以 uuu 为根的树的最小代价」；先做子集合并，再跑一次最短路松弛。）

应用

最小斯坦纳树

见上面的实现；kkk 个关键点的最小连通子图，复杂度 O(3kn+2k(n+m)log⁡n)O(3^kn + 2^k(n+m)\log n)O(3kn+2k(n+m)logn)。

最小斯坦纳森林

如果要求「每组关键点各自连通」（组与组之间不必连通），在最后对 DP 做一次「分组子集枚举」即可。

Tarjan 算法

一句话

给你一张 nnn 个点、mmm 条边的图（n,m≤106n,m\le 10^6n,m≤106），要你用一遍 DFS 求出每个点的 dfndfndfn 与 lowlowlow，并据此回答割点、桥、双连通分量等问题。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Tarjan：dfn 记录访问时间、low 记录「能回到的最早祖先」。）

应用

割点、桥与双连通分量

一句话

给你一张 nnn 个点、mmm 条边的无向图，要你求出所有割点、所有桥，以及图被分成哪些点双 / 边双连通分量。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

说明：割点与桥的判定见 Tarjan 算法 一节的代码；双连通分量的求法见下面的「应用」一节。

应用

边双连通分量

删掉所有桥后，每个连通块就是一个边双；把边双缩点后图变成一棵树。

点双连通分量

在 Tarjan 的过程中用栈记录点，每当 low[v] >= dfn[u] 成立就弹出一整个点双。

强连通分量与缩点

一句话

给你一张 nnn 个点、mmm 条边的有向图，要你求出所有强连通分量，把每个分量缩成一个点，并在缩点后的 DAG 上做 DP。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

说明：缩点后的 DP 见下面的「应用」一节。求 SCC 只要把 Tarjan 算法 的框架改成「出栈时给同一 SCC 的点打同一个编号」即可。

应用

缩点后 DP

强连通分量缩点后有向图变 DAG，可以按拓扑序做 DP（最长路、方案数、最大权路径）。

圆方树

一句话

给定一张 nnn 个点、mmm 条边的无向图（n,m≤105n,m\le 10^5n,m≤105），要求对多次给出的点对分别回答「从其中一点走到另一点，哪些点是无论怎么走都必须经过的」，以及「这两点之间某条路径上的点权和」，多次询问交替出现。时间 O(n+m)O(n+m)O(n+m) 建树、O(log⁡n)O(\log n)O(logn)（倍增 LCA）单次询问，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（对每个点双新建一个「方点」，把点双内的所有「圆点」（原图的点）连到它上面，得到一棵树。）

应用

两点间的必经点

在圆方树上，「uuu 到 vvv 的路径上的圆点」就是原图中「uuu 到 vvv 的所有路径都必经的点」。

路径并集 / 点权和

把「圆点的点权」放在圆点上（方点为 0），则「u→vu\to vu→v 路径上的点权和」就是圆方树上路径和。

2-SAT

一句话

给定 nnn 个布尔变量和 mmm 条形如「若 aaa 为真则 bbb 为真」的限制（n≤105n\le 10^5n≤105），要求给每个变量取真或假使所有限制同时成立，或者判定做不到。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（每个变量拆成「真 / 假」两个点；a⇒ba\Rightarrow ba⇒b 连边 a→ba\to ba→b 与 ¬b→¬a\neg b\to\neg a¬b→¬a；同一 SCC 内则无解。）

应用

变量取值的判定

求完 SCC 后逐个变量比较两个点所属 SCC 的编号（Tarjan 编号小的对应「后出栈」，即拓扑序更靠后）。

区间 / 前缀约束

「区间内至少选一个」这类约束可以用前缀和 / 线段树优化建图，把边数从 O(n2)O(n^2)O(n2) 降到 O(nlog⁡n)O(n\log n)O(nlogn)。

欧拉路与欧拉回路

一句话

给定一张 nnn 个点、mmm 条边的图（n,m≤105n,m\le 10^5n,m≤105），要求找出一条依次走过每条边、且每条边恰好经过一次的路径，或一个首尾相接的回路。时间 O(n+m)O(n+m)O(n+m)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Hierholzer：DFS 到无路可走时把点压栈，回溯时加入答案，最后逆序输出。）

应用

欧拉回路（有向 / 无向）

无向图：所有点度数为偶数；有向图：所有点入度等于出度。满足条件就从任意点跑 Hierholzer。

欧拉路（指定起点）

无向图恰好有两个奇度点（起点和终点）；有向图恰好一个点出度比入度大 1、一个点入度比出度大 1。

哈密顿路与哈密顿回路

一句话

给定一张 nnn 个点的图（状压做法要求 n≤20n\le 20n≤20），要求判断能否找到一条依次经过每个点、且每个点恰好经过一次的路径。时间 O(2nn2)O(2^nn^2)O(2nn2)，空间 O(2nn)O(2^nn)O(2nn)（状压版）。

原理

实现

（dp[S][u]dp[S][u]dp[S][u] 表示「已访问集合 SSS、当前在 uuu」是否可行；这是 TSP 的判定版本。）

应用

状压 DP（n≤20n\le 20n≤20）

上面的写法；求「最小代价」就是 TSP，把 bool 换成代价取 min。

竞赛图一定有哈密顿路

「任意两点之间恰有一条有向边」的竞赛图一定存在哈密顿路；可以 O(n2)O(n^2)O(n2) 插入式构造。

平面图

一句话

给你一张平面图（或它的对偶图），要你判断平面性，或者利用「平面图的最小割 = 对偶图的最短路」求最小割。时间 O(mlog⁡m)O(m\log m)O(mlogm)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（平面图最好用的性质：最小割 = 对偶图的最短路。每个「面」在对偶图里是一个点，原图的每条边在对偶图里连一条「横穿它」的边，边权就是原边的容量。）

应用

支配树（Lengauer–Tarjan）

一句话

给定一张 nnn 个点、mmm 条边的有向图和一个起点 sss（n,m≤105n,m\le 10^5n,m≤105），要求对每个点求出「从 sss 出发无论怎么走都必须经过的那些点」，并把这种必经关系组织成一棵树。时间 O(mlog⁡n)O(m\log n)O(mlogn) 或 O(mα(n))O(m\alpha(n))O(mα(n))，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（先 DFS 求出 DFS 树与 dfs 序，再按 dfn 逆序计算半支配点（semi），最后把 semi 相同的点合并成一棵树。）

应用

最短路径的必经点

在「最短路 DAG」上建支配树，sss 到 ttt 路径上的支配点就是所有最短路都必经的点。

删除点后的可达性

删掉一个点后 sss 是否还能到达 ttt，取决于该点是否为 ttt 的支配点——直接用支配树判断。

Havel–Hakimi 序列判定

一句话

给你一个非负整数序列（n≤105n\le 10^5n≤105），要你判断它是不是某张简单图的度序列；如果是，还要构造出一张图。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（每次取出度数最大的点，让它与「剩下度数最大的 ddd 个点」连边，再把它们的度数各减 111；中途出现负数就说明这个序列不可图。）

应用

二分图

一句话

给定一个二分图（左部 nnn 个点、右部 mmm 个点、边数 E≤106E\le 10^6E≤106），要求选出尽可能多的边，使任何两条被选中的边都不共用端点；若边带权，则要求选出一组两两不共端点、且覆盖左右两侧每个点的边使权值和最大。时间 O(Emin⁡(n,m))O(E\sqrt{\min(n,m)})O(Emin(n,m)​)（Hopcroft–Karp）或 O(n3)O(n^3)O(n3)（KM，带权），空间 O(n+E)O(n+E)O(n+E)。

原理

实现

（匈牙利算法 O(nE)O(nE)O(nE)；Hopcroft–Karp 用 BFS 分层 + DFS 多路增广降到 O(EV)O(E\sqrt V)O(EV​)。）

应用

Hopcroft–Karp：O(En)O(E\sqrt n)O(En​)

用 BFS 把「到增广路径的距离」分层，再在每层里用 DFS 一次找多条不相交增广路。

KM 算法与最大权匹配

求「边权和最大的完美匹配」用 KM（二分图上 O(n3)O(n^3)O(n3)）；也可以转成最小费用流。

最小点覆盖 / 最大独立集 / 最大团

二分图上：最小点覆盖 = 最大匹配（König 定理）；最大独立集 = 顶点数 - 最大匹配。

稳定匹配与指派问题

一句话

给定 nnn 个男生和 nnn 个女生各自对对方的偏好排序（n≤500n\le 500n≤500），要求把男女一一配对，使不存在一对男女彼此都更喜欢对方胜过自己当前的伴侣。时间 O(n2)O(n^2)O(n2)，空间 O(n2)O(n^2)O(n2)。

原理

实现

（Gale–Shapley：男生按偏好从高到低依次求婚，女生在已有对象与追求者中选更喜欢的。）

应用

指派问题（最小费用）

nnn 个任务给 nnn 个人，代价矩阵 cijc_{ij}cij​，求最小总代价的完美匹配；用 KM 或最小费用流。

最大流（Dinic、ISAP、HLPP）

一句话

给定一张 nnn 个点、mmm 条边的有向图，每条边有容量上限，并指定源点与汇点（容量 ≤109\le 10^9≤109，n≤104n\le 10^4n≤104、m≤105m\le 10^5m≤105），要求从源点往汇点尽量多地推送流量，使每条边上的流量不超过容量、除源汇外每个点的流入等于流出。时间 O(n2m)O(n^2m)O(n2m)（Dinic，实际远快），空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Dinic：BFS 分层 -> DFS 多路增广 + 当前弧优化；单位容量图上复杂度是 O(mm)O(m\sqrt m)O(mm​)。）

应用

二分图最大匹配（转网络流）

超级源连左部（容量 1）、左部连右部（容量 1）、右部连超级汇（容量 1），最大流就是最大匹配。

拆点限流

「每个点只能经过 kkk 次」把点拆成入点 / 出点，中间连容量 kkk 的边。

最小割

一句话

给定一张 nnn 个点、mmm 条边的容量网络（n≤104n\le 10^4n≤104、m≤105m\le 10^5m≤105），要求把点分成含源点和含汇点的两部分，使两端分属不同部分的边的容量之和最小。时间 O(n2m)O(n^2m)O(n2m)（Dinic），空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（最大流最小割定理：最小割的容量等于最大流。求完最大流后，从 sss 沿残量边可达的点集就是一个最小割的划分。）

应用

最大权闭合子图

「选了一个点就必须选它的所有后继」的图，求最大权点集：正权连源、负权连汇，答案 = 正权和 - 最小割。

二者选其一 / 冲突建模

每个元素有两种归属，收益 / 代价写在两侧；「两个元素不能同时属于某侧」用 INF 边强制。

最小点权覆盖

点权非负时，最小点覆盖 = 最小割；建图方式与「最小割」一致（把点拆成入 / 出，容量是点权）。

最小割树

一句话

给定一张 nnn 个点、mmm 条边的无向带权图（n≤500n\le 500n≤500、m≤5000m\le 5000m≤5000），要求对多次给出的点对回答「至少要删掉总权多大的边才能把它们分开」。时间 O(n2m)O(n^2m)O(n2m) 预处理、O(log⁡n)O(\log n)O(logn) 单次查询，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（Gomory–Hu 树：每次在当前的连通块里任取两点求最小割，把块分成两部分并递归。）

应用

多次最小割询问

建好最小割树后，每次询问就是「树上路径的最小边权」，用倍增或直接 DFS 都能 O(n)O(n)O(n) / O(log⁡n)O(\log n)O(logn)。

全局最小割

全局最小割 = 最小割树上最小的边权；也可以用 Stoer–Wagner 算法 O(n3)O(n^3)O(n3) 直接求。

费用流

一句话

给定一张 nnn 个点、mmm 条边的网络，每条边除容量外还有一个单位费用（n≤104n\le 10^4n≤104、m≤105m\le 10^5m≤105，费用 ≥0\ge 0≥0），要求从源点到汇点推送最大的流量，并在所有最大流中使费用总和最小。时间 O(流量⋅mlog⁡n)O(\text{流量}\cdot m\log n)O(流量⋅mlogn)，空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（SPFA 版最容易写；用 Dijkstra + 势能可以在非负费用下更快。）

应用

二分图最大权匹配

左部连源（容量 1、费用 0）、左连右（容量 1、费用 −w-w−w）、右部连汇（容量 1、费用 0），跑费用流。

Dijkstra + 势能

把每条边的费用改成 w+hu−hvw + h_u - h_vw+hu​−hv​（hhh 是上一轮的势能），就变成非负，可以用 Dijkstra。

上下界网络流

一句话

给定一张 nnn 个点、mmm 条边的网络，每条边的流量既有下界也有上界（n≤104n\le 10^4n≤104、m≤105m\le 10^5m≤105），要求判断是否存在满足所有边界的流，并在有源汇时求出流量的最大值与最小值。时间 O(n2m)O(n^2m)O(n2m)（Dinic），空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（先把每条边 (u,v,[L,R])(u,v,[L,R])(u,v,[L,R]) 拆成「必须流 L」+「可选流量 R−LR-LR−L」，用超级源 / 汇平衡节点的流量差。）

应用

可行流判定

加超级源 S′S'S′、超级汇 T′T'T′ 后跑最大流；若 S′S'S′ 的所有出边都满流，则存在可行流。

有源汇最大流

先加边 t→st\to st→s（容量 ∞\infty∞）把有源汇问题转成无源汇，判可行；再去掉这条边、在原图上从 sss 到 ttt 再跑一次最大流。

有源汇最小流

与最大流对称：先按无源汇判可行，再去掉 t→st\to st→s、在残量网络的反图上从 ttt 到 sss 跑最大流，减掉。

最大权闭合子图

一句话

给定一张 nnn 个点、mmm 条边的有向依赖图，每个点带一个可正可负的权值（n≤104n\le 10^4n≤104、m≤105m\le 10^5m≤105），要求选出一个点集，使「只要选了某个点就必须把它的所有后继也选上」成立，且选中点的权值之和最大。时间 O(n2m)O(n^2m)O(n2m)（Dinic），空间 O(n+m)O(n+m)O(n+m)。

原理

实现

（正权点连源、负权点连汇，依赖边容量 ∞\infty∞；答案 = 正权总和 - 最小割。）

应用

项目选择 / 依赖决策

「做项目 iii 得收益 pip_ipi​，但需要先买设备 jjj（花费 cjc_jcj​）」是典型的最大权闭合子图。

变体：带「必须同时选」的约束

把「aaa 与 bbb 必须同时选」拆成两条单向依赖（a→ba\to ba→b 与 b→ab\to ab→a），仍然是最小割模型。
