算法笔记 04｜树上算法

树的存储与遍历

原理

实现

应用

按深度分层（BFS 序）

BFS 得到的层序可以直接当「从上到下的 DP 顺序」用；每层的点放在一起，也方便做分层统计。

换根 DP（rerooting）

先以 111 为根算出一遍「子树内的贡献」，再顺着边把根换过去。下面求的是「每个点到其余所有点的距离之和」。

树的直径

一句话

给你一棵 nnn 个点的带权树（n≤105n\le 10^5n≤105），要你求出树上最长路径的长度，以及这条路径的两个端点。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

直径的端点性质（两遍 DFS）

任取一点 AAA 求最远点 BBB，再从 BBB 求最远点 CCC，BCBCBC 就是直径；无权时两遍 BFS 更省事。

树的重心

一句话

给你一棵 nnn 个点的树，要你求出一个点，使删掉它之后剩下的最大连通块最小。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

重心的性质与合并

两棵树用一条边连起来后，新重心一定在原来两个重心之间的路径上；从重心出发，每个子树大小不超过 n/2n/2n/2。

树的中心

一句话

给你一棵 nnn 个点的带权树，要你求出一个点，使它到最远点的距离最小。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

应用

树的中心

树的中心（到最远点距离最小的点）一定在直径的中点上：从直径端点跑一遍 BFS 记录前驱，回溯到中点即可。

树上差分

一句话

给定一棵 nnn 个点的树和 mmm 条路径（n,m≤105n,m\le 10^5n,m≤105），要求统计每条边被多少条路径经过，或每个点被多少条路径经过。时间 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)，空间 O(n)O(n)O(n)。

原理

实现

（把路径的贡献拆到两个端点与 LCA 上，最后自底向上累加一次即可。）

应用

点差分

路径上的点加一：两个端点 +1，LCA 与 LCA 的父亲各 −1，最后自底向上累加。

子树加、单点查

把树拍成 DFS 序后，子树是一段连续区间，「子树加」就是区间加、「单点查」就是单点求值，用差分数组 O(1)O(1)O(1) 修改、O(n)O(n)O(n) 还原。

单点加、子树查

反过来：单点加就是差分数组上的一次区间修改，子树查就是求子树区间和，用树状数组即可。

树上倍增

一句话

给你一棵 nnn 个点的树和 qqq 次询问（n,q≤105n,q\le 10^5n,q≤105），每次问「从某个点往上跳 kkk 步到哪个点」或者「路径上的最值与和」。时间 O(nlog⁡n)O(n\log n)O(nlogn) 预处理、O(log⁡n)O(\log n)O(logn) 单次，空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

应用

维护路径上的最值 / 异或和

把「uuu 到根的路径」上的信息用倍增表存下来，询问时拆成两段再合并。

最近公共祖先（LCA）

一句话

给你一棵 nnn 个点的树和 qqq 次询问，每次给你两个点，问它们的最近公共祖先是谁、以及两点之间的距离。时间 O(nlog⁡n)O(n\log n)O(nlogn) 预处理、O(log⁡n)O(\log n)O(logn) 单次（欧拉序 + ST 表可做到 O(1)O(1)O(1)），空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

应用

两点距离

dist(u,v)=dep(u)+dep(v)−2 dep(lca(u,v))\mathrm{dist}(u,v)=\mathrm{dep}(u)+\mathrm{dep}(v)-2\,\mathrm{dep}(\mathrm{lca}(u,v))dist(u,v)=dep(u)+dep(v)−2dep(lca(u,v))；注意这里 dep\mathrm{dep}dep 从根开始数（根为 111）。

O(1) LCA（欧拉序 + ST 表）

在欧拉序上，lca(u,v)\mathrm{lca}(u,v)lca(u,v) 就是「uuu、vvv 第一次出现位置之间」深度最小的那个点；用 ST 表维护区间最小值下标即可 O(1)O(1)O(1) 查询。

路径上第 kkk 个点

把 u→vu\to vu→v 的路径拆成「uuu 到 LCA」和「LCA 到 vvv」两段，比较 kkk 与上半段长度决定往哪边走。

重链剖分

一句话

给你一棵 nnn 个点的树和 qqq 次操作，每次操作是「把一条路径上所有点的权值改成同一个值」或「询问一条路径上点权的最大值 / 和」，两种操作交替出现。时间 O(n)O(n)O(n) 预处理、单次 O(log⁡2n)O(\log^2 n)O(log2n)，空间 O(n)O(n)O(n)。

原理

实现

（重链剖分：两次 DFS 求出重儿子、链顶与 DFS 序；剖分后每条路径被拆成 O(log⁡n)O(\log n)O(logn) 条「DFS 序上的连续区间」。）

应用

路径赋值（区间覆盖）

把线段树换成「支持区间赋值的懒标记线段树」，O(log⁡2n)O(\log^2 n)O(log2n) 就能整段路径覆盖。

求 LCA（顺带）

轻重链剖分后求 LCA 只要不断地「把链顶更深的那个点跳到它父亲」，O(log⁡n)O(\log n)O(logn)。

长链剖分

一句话

给你一棵 nnn 个点的树，要你支持「O(1)O(1)O(1) 求出某个点的 kkk 级祖先」，或者优化与深度有关的树形 DP。时间 O(nlog⁡n)O(n\log n)O(nlogn) 预处理、O(1)O(1)O(1) 单次，空间 O(n)O(n)O(n)。

原理

实现

说明：本模块的具体做法与代码见下面的「应用」一节。

应用

长链剖分（O(1)O(1)O(1) 求 kkk 级祖先、优化深度相关 DP）

按「子树内最深深度」定重儿子；求 kkk 级祖先时先跳 2⌊log⁡k⌋2^{\lfloor\log k\rfloor}2⌊logk⌋ 步再查表，O(1)O(1)O(1)；优化 DP 时每个点直接继承重儿子的数组（指针偏移），总空间 O(n)O(n)O(n)。

点分治

一句话

给你一棵 nnn 个点的带权树（n≤105n\le 10^5n≤105），要你统计满足「两点距离恰好等于 / 不超过 KKK」的点对个数。时间 O(nlog⁡n)O(n\log n)O(nlogn) 或 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)，空间 O(n)O(n)O(n)。

原理

实现

（点分治：每次找出当前连通块的重心，统计过重心的路径，再递归到各个子树；每一层的总规模是 O(n)O(n)O(n)，共 O(log⁡n)O(\log n)O(logn) 层。另有「边分治」：每次取一条边把连通块分成两半，但要先把每个点的度数三度化（加虚点把度数降到 333），否则菊花图会把复杂度卡到 O(n2)O(n^2)O(n2)。）

应用

排序 + 双指针统计

把一层里所有点的深度收集起来排序，再用双指针数「两端深度和不超过 KKK」的有序位置对；同一个子树内部的贡献先减去。单层 O(nlog⁡n)O(n\log n)O(nlogn)。

点分治 + 桶统计

把「距离恰好为 ddd 的点数」装进桶，每加入一个点就查桶配对，单层 O(n)O(n)O(n)（不用排序）。

点分治 + 数据结构

若统计的不是「条数」而是「长度恰好为 ddd 的最短边权」这类信息，可以在每层用一个桶 / 树状数组维护，把统计从 O(nlog⁡n)O(n\log n)O(nlogn) 降到 O(n)O(n)O(n)。

边分治

一句话

给你一棵 nnn 个点的带权树，同样是统计满足距离条件的点对；当树退化成链或者度数很大时，点分治会变慢，这时改用边分治。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（先把树「三度化」，保证每个点的度数不超过 333；再每次选一条「两侧大小最接近」的边把树分成两半，处理跨过这条边的路径，然后递归。）

应用

点分树（动态点分治）

一句话

给定一棵 nnn 个点的带权树（n≤105n\le 10^5n≤105）和 q≤105q\le 10^5q≤105 次操作，每次操作是「把某个点的权值改成新值」或「询问所有点到 uuu 的距离乘以各自权值后的总和」，两种操作交替出现。时间单次操作 O(log⁡2n)O(\log^2 n)O(log2n)，空间 O(n)O(n)O(n)。

原理

实现

（点分树：把点分治每层的重心按父子关系连起来，深度是 O(log⁡n)O(\log n)O(logn)；改动一个点就沿点分树往上跳 O(log⁡n)O(\log n)O(logn) 个结点更新。）

应用

沿点分树二分的「距离 ≤K\le K≤K 的点数」

把每个点 xxx 在点分树里管辖的点的距离收集成一个有序数组，询问「离 uuu 不超过 KKK 的点数」时沿点分树跳，每层二分一次。O(log⁡2n)O(\log^2 n)O(log2n) 一次询问。

动态「距离 ≤K\le K≤K 的点权和」

把「距离和」换成「按距离排序的树状数组」，就能回答带阈值的权值和；每层用距离二分把问题压到「前缀和」，再用容斥减掉重复。

DSU on tree（树上启发式合并）

一句话

给定一棵 nnn 个点的树，每个点有一个颜色 cic_ici​（n≤2×105n\le 2\times10^5n≤2×105），要求对每个点 uuu 回答：以 uuu 为根的子树里出现次数最多的那种颜色出现了多少次，以及子树里共有多少种不同的颜色。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（每个点只保留重儿子的统计结果，轻儿子暴力重算；每个点最多被搬动 O(log⁡n)O(\log n)O(logn) 次。）

应用

子树内「深度为 ddd 的点数」

把颜色换成深度即可：cnt[d]cnt[d]cnt[d] 记录深度为 ddd 的点数；对每个 uuu 求「子树内和 uuu 距离恰好为 kkk 的点数」就是 cnt[depu+k]cnt[dep_u+k]cnt[depu​+k]。

子树内权值落在 [L,R][L,R][L,R] 的点数（DSU + 树状数组）

把计数数组换成树状数组，加/删子树时就做单点加减，询问时区间求和。

虚树

一句话

给定一棵 nnn 个点的树（n≤5×105n\le 5\times10^5n≤5×105）和 qqq 组询问（所有组的关键点总数 ≤5×105\le 5\times10^5≤5×105），每组询问给出若干关键点，要求只保留这些关键点，再补上它们之间两两的最近公共祖先，在这张缩小后的树上做树形 DP。时间预处理 O(nlog⁡n)O(n\log n)O(nlogn) 后每组 O(klog⁡k)O(k\log k)O(klogk)（kkk 是该组关键点数），空间 O(nlog⁡n)O(n\log n)O(nlogn)。

原理

实现

（虚树：把关键点按 DFS 序排序，相邻两点求 LCA 后一起建一棵只含关键点与它们 LCA 的树；总点数 O(∑k)O(\sum k)O(∑k)。）

应用

树上「关键点」DP

虚树建好后，在虚树上跑普通的树形 DP；虚边上要补上「原树这条边上的信息」（例如边权是原树上两点距离）。

虚树上的「最少删边使关键点互不连通」

经典用法：f[u]f[u]f[u] 表示「uuu 子树里的关键点已经互相隔开」的最小代价，分「uuu 本身是不是关键点」两类转移。

清空虚树

虚树的结点是所有关键点加上它们的 LCA，共 O(∑k)O(\sum k)O(∑k) 个；但不能每次 memset 整张表，要记录「这次动过哪些点」再逐个清空，或者用时间戳。

基环树

一句话

给定一张 nnn 个点、nnn 条边的连通无向图（n≤106n\le 10^6n≤106），要求求出图中相距最远的一对点之间的距离。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（先把环找出来：拓扑排序删掉所有度数为 111 的点，剩下的就是环。）

应用

环上 DP（断开环）

基环树的 DP 通常「先对每棵挂着的子树做树形 DP，再把环上的结果拼起来」；环上问题可以枚举「第一个点选 / 不选」断成两次链式 DP。

基环树直径

直径要么完全在某一棵子树里，要么跨过环上的两个点；后者要把环上的「挂子树的最深深度」排成一个环，求「两两之间距离 + 各自深度」的最大值。

不止一个环（基环森林）

nnn 个点 nnn 条边时可能不连通，每个连通块都是一棵基环树；一次拓扑排序能把所有连通块的环一起标出来，再按连通块分别处理。

树哈希与 AHU 算法

一句话

给定两棵各 nnn 个点的树（n≤105n\le 10^5n≤105），要求判断它们的结构是否完全相同——即忽略点的编号后，能否把一棵树的点与另一棵树的点一一对应起来，使边也一一对应。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（有根树：把儿子的哈希值排序后滚动组合；无根树再对每个点求一次「以它为根」的哈希，取最小值当指纹。）

应用

判断两棵树是否同构

无根树的指纹 = 「所有点作为根时哈希的最小值」；两棵树的指纹相等则同构（碰撞概率可忽略）。

AHU 算法（同构的规范编号）

最直观的办法是把「儿子子树」的规范形式递归拼成一个字符串；AHU 则把它优化到 O(nlog⁡n)O(n\log n)O(nlogn)（每轮用 map 把「儿子标签的多重集」映射成新标签）。

多重集哈希 / 随机权

把「排序后滚动」换成「异或随机权」可以做到 O(n)O(n)O(n)（不用排序），代价是哈希强度略低。
