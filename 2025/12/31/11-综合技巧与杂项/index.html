Erdős–Szekeres 定理与一维中位数

一句话

给你一个长度为 nnn 的序列（n≤105n\le 10^5n≤105），要你求一个数 xxx，使 ∑i∣ai−x∣\sum_i |a_i-x|∑i​∣ai​−x∣ 最小；或利用 Erdős–Szekeres 定理把二维偏序问题降到一维。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

任意长度 (r−1)(s−1)+1(r-1)(s-1)+1(r−1)(s−1)+1 的序列必含长 rrr 的上升或长 sss 的下降子序列；而 ∑∣ai−x∣\sum|a_i-x|∑∣ai​−x∣ 在 xxx 取中位数时最小，后者可以 O(n)O(n)O(n) 直接算。

应用

启发式合并

一句话

给你 nnn 个集合（n≤105n\le 10^5n≤105），要你不断把两个集合合并、并随时查询合并后的信息（如最大值、不同元素个数）。时间总计 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（DSU on tree / 树上启发式合并：每个点只保留「重儿子」的统计结果，轻儿子暴力重算。）

应用

小并大（启发式合并集合）

每次把小的集合合并进大的，每个元素最多被搬 O(log⁡n)O(\log n)O(logn) 次，所以合并总代价 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)（集合本身还带一层内部查找）。

二进制分组

一句话

给你 qqq 次「插入一个元素」和「查询整体信息」的操作（q≤105q\le 10^5q≤105），要求在线回答，或者对若干个静态块分别预处理后合并答案。时间单次 O(log⁡q)O(\log q)O(logq)，空间 O(qlog⁡q)O(q\log q)O(qlogq)。

原理

实现

把「在线插入」按二进制拆成 O(log⁡n)O(\log n)O(logn) 个块，每块大小是 222 的幂；新插入就按进位合并，均摊每次 O(log⁡n)O(\log n)O(logn) 次重建。下面支持「插入数字 + 查询总体第 kkk 小」。

应用

离线处理

一句话

给你一张有 qqq 次询问的题（q≤105q\le 10^5q≤105），允许先把所有询问读进来再做（离线），要你按某种顺序处理它们以减少重复计算。时间 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)，空间 O(n+q)O(n+q)O(n+q)。

原理

实现

（CDQ 分治：按第一维排序后不再动它，递归时用第二维归并、第三维用树状数组统计。）

应用

二维偏序 / 逆序对

只有两维时不需要分治：把值离散化当第二维，从右往左扫，用树状数组问「已经出现过且比我小的有几个」，累加就是逆序对数。

随机化技巧与随机化哈希

一句话

给你两棵树的括号序列或两个结构（n≤105n\le 10^5n≤105），要你判断它们是否同构；或者用随机权值把「判定」变成「比较哈希值」。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（随机化哈希：给每个元素一个随机的 646464 位权值，集合的哈希取这些权值的异或和。）

应用

树哈希与同构判定

有根树：把儿子的哈希值排序（消除顺序影响）后用多项式滚动组合。无根树再对每个点求一次「以它为根」的哈希，取最小值作为整棵树的指纹。

模拟退火与爬山

一句话

给你一个「状态空间很大、目标函数没有单调性」的最优化问题，要你在时限内找一个尽量好的解。时间按迭代次数计 O(T)O(T)O(T)，空间 O(1)O(1)O(1)。

原理

实现

从初始解出发不断小扰动，按温度决定是否接受更差的解。下面是「平面上找一个点使得到所有给定点的距离之和最小」。

应用

打表与找规律

一句话

给你一道看不出递推式的题，要你先写暴力跑出前若干项、观察规律或用 BM 拟合出线性递推，再求远处的项。时间 O(n)O(n)O(n) 打表 + O(k2log⁡n)O(k^2\log n)O(k2logn) 求项，空间 O(n)O(n)O(n)。

原理

实现

小规模先暴力打表，再用 Berlekamp–Massey 恢复递推（见「线性代数与多项式」一章）；复杂度对了仍 TLE 就上快读、关同步、位运算代替取模。

应用

对拍与调试

一句话

给你一份自己写的解法和一份暴力，要你随机生成小数据、跑两边比答案，从而在交题之前把 bug 找出来。时间每次 O(生成+两个解法)O(\text{生成}+\text{两个解法})O(生成+两个解法)，空间 O(数据规模)O(\text{数据规模})O(数据规模)。

原理

实现

（三个程序：gen 随机造数据、brute 慢但对、mine 你要交的解法。用一个循环反复跑，第一次不同就停下来把数据留下。）

应用
