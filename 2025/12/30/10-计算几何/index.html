算法笔记 10｜计算几何

向量、点积与叉积

一句话

给定平面上的点与向量（坐标绝对值 ≤109\le 10^9≤109），要你对它们做点积、叉积、模长与模长平方、单位化、绕原点旋转和极角排序，这些运算会在后面的算法里被反复调用。时间 O(1)O(1)O(1) 每次，空间 O(1)O(1)O(1)。

原理

实现

应用

极角排序

按 atan2 排序最简单；要求严格无精度误差时，用「先按象限、再按叉积」的比较函数。

向量旋转

逆时针转 ttt 弧度用旋转矩阵；转 90∘90^\circ90∘ 可以直接写成 (x,y)→(−y,x)(x,y)\to(-y,x)(x,y)→(−y,x)，不用三角函数。

叉积的符号（左转 / 右转）

叉积大于 0 表示 a→b→ca\to b\to ca→b→c 是逆时针（左转），小于 0 是右转，等于 0 三点共线。

浮点比较与去重

浮点点集的去重要用 sgn 判定「距离小于 eps」，不能直接比较坐标；整数点集可以直接排序去重。

线段相交判定

一句话

给定平面上的点与线段（整数坐标，绝对值 ≤109\le 10^9≤109），要你判断一个点是否落在线段上、两条线段是否相交，并求出点到直线的距离与两条直线的交点，这些判定会交替出现。时间 O(1)O(1)O(1) 每次，空间 O(1)O(1)O(1)。

原理

实现

（沿用上一节的 P 与 sgn / dot / cross。）

应用

跨立实验

两个叉积符号相反（或其中一个为 0）表示 c、d 在直线 ab 的两侧；两个跨立条件同时满足才相交。

直线与线段的交点

先判断线段的两个端点是否在直线两侧（叉积异号），再套 line_inter。

共线判定

三点共线就是叉积为 0；再用点积确认「落在两个端点之间」才能判断点在线段上。

整数几何版

坐标都是整数时，把所有判定改成 __int128 的叉积比较，完全避开浮点。

多边形

一句话

给定一个按顺序给出 nnn 个顶点的简单多边形（坐标是整数，n≤105n\le 10^5n≤105），要你求出它的面积与重心，并判断某个点是否落在多边形内部，多边形的顶点顺序已经排好。时间 O(n)O(n)O(n)（凸多边形的内点判定为 O(log⁡n)O(\log n)O(logn)），空间 O(1)O(1)O(1)。

原理

实现

应用

鞋带公式

面积等于 12∣∑i(xiyi+1−xi+1yi)∣\dfrac12\left|\sum_i(x_iy_{i+1}-x_{i+1}y_i)\right|21​∣∑i​(xi​yi+1​−xi+1​yi​)∣；逆时针为正、顺时针为负。

射线法判定

从待判点向一侧引射线，数它与多边形的交点个数；奇数在内、偶数在外；关键是「半开区间」处理，避免顶点被重复计数。

凸多边形的内点判定

凸多边形可以用「叉积同号」或者「先二分找扇形、再判」做到 O(log⁡n)O(\log n)O(logn)。

多边形面积与皮克定理

顶点都在整点上时，S=I+B2−1S=I+\dfrac B2-1S=I+2B​−1，于是 I=2S−B2+1I=\dfrac{2S-B}2+1I=22S−B​+1；边上整点数用 ∑gcd⁡(∣Δx∣,∣Δy∣)\sum\gcd(|\Delta x|,|\Delta y|)∑gcd(∣Δx∣,∣Δy∣)。

凸包（Andrew、Graham）

一句话

给定 nnn 个点（整数坐标，n≤105n\le 10^5n≤105），要你求出包住它们的凸包并按逆时针输出顶点，点一次全给出来。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（Andrew 单调链：按横坐标排序后分别求上下凸壳。）

应用

凸包周长与面积

周长是相邻顶点距离之和；面积用鞋带公式，都是 O(n)O(n)O(n)。

凸包上的判定

判断点是否在凸包内：O(log⁡n)O(\log n)O(logn) 二分，或者检查「所有边叉积非负」。

保留共线点

把弹栈条件从「叉积小于等于 0」改成「小于 0」，就能把边上的点也留在凸包上。

旋转卡壳

一句话

给定一个凸包（顶点数 n≤105n\le 10^5n≤105，顶点按逆时针排好），要你求出它的直径（最远点对距离）、最小宽度与最大面积内接三角形。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（用一对「对踵点」沿凸包旋转，每条边只推进一次。）

应用

最远点对

点集的最远点对一定在凸包上，所以先求凸包再卡壳；返回平方可以避免开根号的精度损失。

最小宽度

最小宽度就是「最小外接矩形的短边」，可以用三对对踵点维护投影最左/最右/最远来求。

最大面积三角形

固定一条底边 i→ji\to ji→j，第三个点满足决策单调性，可以 O(n2)O(n^2)O(n2) 或更优地求出。

半平面交

一句话

给定 nnn 个半平面（n≤105n\le 10^5n≤105，每个用一条有向直线表示「它的左侧」），要你求出这些半平面的交集（可能为空、也可能无界）并算出交集的面积，半平面一次给全。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（把直线按极角排序、用双端队列维护，逐个加入并弹掉两端不合法的交点。）

应用

二维线性规划

「在若干线性约束下最大化 ax+byax+byax+by」可以二分答案转成半平面交，也可以直接在半平面交的顶点上枚举。

多边形的核

判断一个多边形是否存在能看见全部顶点的点（内核非空），就是求「所有边的内侧半平面」的交。

面积与无界处理

求出交集顶点后直接用鞋带公式；无界时通常补一个大矩形把范围框住。

三角剖分

一句话

给定一个 nnn 个顶点的多边形（n≤105n\le 10^5n≤105），要你把它剖分成若干三角形并给出剖分方案，多边形的顶点按顺序给出。时间 O(nlog⁡n)O(n\log n)O(nlogn) 或 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（耳切法：每次找一个「耳朵」——连续三个顶点构成的三角形完全落在多边形内部——把它切掉，直到只剩一个三角形。）

应用

凸多边形的三角剖分数

顶点数为 mmm 的凸多边形，三角剖分方案数是 Catm−2\mathrm{Cat}_{m-2}Catm−2​，用区间 DP 也能算出来。

点在三角形内

对三条边分别做叉积，符号一致即在内部（含边界时改成非严格）。

一般多边形的耳切法

每次找一个「耳朵」三角形（对角线完全在多边形内部）切掉，O(n2)O(n^2)O(n2)，用于把任意简单多边形剖分。

圆

一句话

给定圆（圆心与半径）、一条直线与另一个圆，要你求出圆与直线的交点、圆与圆的交点，并判断两圆的位置关系，这些求交与判定会交替出现。时间 O(1)O(1)O(1) 每次，空间 O(1)O(1)O(1)。

原理

实现

应用

两圆位置关系

用 ddd 与 r1+r2r_1+r_2r1​+r2​、∣r1−r2∣|r_1-r_2|∣r1​−r2​∣ 的比较分成五种情形：相离、外切、相交、内切、内含。

圆的面积并

点数少时可以直接对每个圆算出「被其他圆覆盖掉的弧」，剩下的弧对应的扇形面积之和就是并集面积，O(n2log⁡n)O(n^2\log n)O(n2logn)。

精度与特殊情况

ddd 极小时要单独判断「重合」；开根号前必须把入参夹到非负，否则会出现 NaN。

最小圆覆盖

一句话

给定平面上 nnn 个点（n≤105n\le 10^5n≤105），要你找出一个半径最小的圆把所有点都盖住，输出它的圆心与半径，点一次给全。期望时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。

原理

实现

（随机增量法：把点随机打乱，逐个加入；若新点在当前圆外，就以它为基础重新确定圆。）

应用

二分半径 + 判定

二分半径 RRR，把问题转成「以每个点为圆心、半径 RRR 的圆是否有公共交点」。

平面最近点对

一句话

给定平面上 nnn 个点（n≤2×105n\le 2\times10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），要你找出距离最近的一对点并输出它们之间的距离，点一次全给出来。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（分治：按横坐标分成左右两半，递归求解后只检查「跨中线且横向距离小于当前答案」的点，并按纵坐标归并。）

应用

最近点对的整数版

坐标是整数时全程用模长平方比较，最后再开根号，完全避免浮点误差。

最远点对

最远点对一定在凸包上，先求凸包再旋转卡壳，O(nlog⁡n)O(n\log n)O(nlogn)。

曼哈顿距离最近点对

把曼哈顿距离转成切比雪夫距离（用 u=x+yu=x+yu=x+y、v=x−yv=x-yv=x−y 变换），再用排序 + 扫描。

最小矩形覆盖

一句话

给定 nnn 个点（n≤105n\le 10^5n≤105），要你找出一个能盖住所有点的矩形，使它的面积（或周长）最小，点一次全给出来。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（结论：最小面积矩形一定有一条边与凸包的一条边重合。于是枚举凸包的每条边作为矩形的一边，把其余点投影到「沿边」与「垂直边」两个方向，取包围盒。）

应用

扫描线与矩形面积并

一句话

给定 nnn 个轴对齐矩形（n≤105n\le 10^5n≤105，坐标绝对值 ≤109\le 10^9≤109），要你求出它们并集覆盖的总面积，矩形一次全给出来。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（扫描线：按横坐标切分，用线段树维护纵方向上「被覆盖至少一次」的总长度。）

应用

矩形周长并

对横竖两个方向分别做扫描线，累计「覆盖长度的变化量」就是这一段贡献的周长。

矩形面积交

面积交不容易直接扫描，常用「对每个矩形，求它与其它矩形的交被覆盖的次数」或者用扫描线维护「被覆盖至少 k 次」的长度。

离散化与整数坐标

坐标是整数时应当用整数离散化代替 double，彻底避免「相等的坐标去重不干净」；离散化后线段树的下标是段号。

计算几何常用技巧

一句话

给定坐标绝对值到 10910^9109 的几何判定题（例如「nnn 个点中是否存在三点共线」「点是否在多边形内」「两线段是否相交」），要你全程只用整数运算做出判定、不引入浮点误差，这些判定要反复询问。时间 O(1)O(1)O(1) 每次判定，空间 O(1)O(1)O(1)。

原理

实现

（核心思路：能用整数就绝不转 double；所有叉积、点积的比较都放在 __int128 里算。）

应用

整数几何优先

只要所有坐标都是整数，判定类问题就全部可以用 __int128 解决，不要碰 double。下面给出完整的「点在多边形内（整数版）」。

eps 的选取

必须用浮点时，相对误差比绝对误差更可靠：把 eps 取成与坐标量级相关的值。

避免开根号

比较距离时一律用距离的平方；只有真正需要输出长度时才开根号。

判等与去重

浮点点集的去重要用 sgn 判定「距离小于 eps」，而不是直接比较坐标是否相等。
