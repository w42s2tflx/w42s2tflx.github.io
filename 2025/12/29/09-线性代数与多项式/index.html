(1110)n\begin{pmatrix}1&1\\1&0\end{pmatrix}^n(11​10​)n 的右上角就是 FnF_nFn​；把状态向量取成 (Fn,Fn−1)(F_n,F_{n-1})(Fn​,Fn−1​)，转移矩阵第一行放递推系数、下面放一条斜对角即可。

高斯消元

一句话

给定一个 nnn 元线性方程组 Ax=bAx=bAx=b 和它的 nnn 阶系数方阵（n≤500n\le 500n≤500），要你判断这个方程组是有唯一解、无解还是有无穷多解并求出一组解，同时算出方阵的行列式与逆矩阵，围绕同一个矩阵的几个问题要一起回答。时间 O(n3)O(n^3)O(n3)，空间 O(n2)O(n^2)O(n2)。

原理

实现

应用

矩阵求逆（模意义）

在右边拼一个单位矩阵一起消元；模意义下主元用扩展欧几里得求逆。

求矩阵的秩

消元后非零行的行数就是秩；也可以用来判断向量组是否线性相关。

解异或方程组

把加减换成异或、系数取 0/1，用 bitset 压缩；秩为 rrr 时自由元有 n−rn-rn−r 个，解数就是 2n−r2^{n-r}2n−r。

线性基（异或空间）

一句话

给定 nnn 个非负整数（n≤105n\le 10^5n≤105，ai<260a_i<2^{60}ai​<260），要你把这些数一个个插进一个结构里，再询问它们异或能表示出的最大值、第 kkk 小值，以及某个数能否被表示，插入与询问交替出现。时间 O(60)O(60)O(60) 每次，空间 O(60)O(60)O(60)。

原理

实现

应用

最大异或和

从高位到低位贪心：能变大就异或上这一位的基。把两棵线性基「合并」时，把一棵的基逐个插进另一棵即可，这是线段树维护区间异或的基础。

异或第 kkk 小

把基化成最简形（每个基向量的最高位互不相同、且其他基在该位为 0），再按 k−1k-1k−1 的二进制挑基向量。

区间最大异或和（前缀线性基）

对每个前缀维护一份线性基，并让每个基向量的「位置」尽量靠右；查询 [l,r][l,r][l,r] 时只取位置 ≥l\ge l≥l 的基，O(60)O(60)O(60) 一次。

异或方程组的解数

nnn 个方程 mmm 个未知数，异或方程组消元后自由元有 m−rm-rm−r 个，解的个数就是 2m−r2^{m-r}2m−r。

矩阵树定理

一句话

给定一张 nnn 个点、mmm 条边的图（n≤500n\le 500n≤500，边可以带权），要你数出它一共有多少棵生成树（带权时数的是所有生成树的边权积之和），图一次给全。时间 O(n3)O(n^3)O(n3)，空间 O(n2)O(n^2)O(n2)。

原理

实现

（基尔霍夫矩阵 L=D−AL=D-AL=D−A；去掉任意一行一列后求行列式。）

应用

生成树计数（无向图）

边权全取 111，答案就是生成树个数。

带权生成树

边权 www 时，矩阵树定理给出的是「所有生成树的 ∏we\prod w_e∏we​ 之和」，也就是把边权当作「并联的条数」。

有向图的树形图

有向图用「入度矩阵 − 邻接矩阵」得到内向树（所有边指向根），去掉根所在的行列后求行列式。

快速傅里叶变换（FFT）

一句话

给定两个多项式 A(x),B(x)A(x),B(x)A(x),B(x)（次数 ≤106\le 10^6≤106，整数系数），要你把它们乘起来并求出 C(x)=A(x)B(x)C(x)=A(x)B(x)C(x)=A(x)B(x) 的每一项系数，系数大小可能撑满整型。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（把系数补零到 222 的幂，用单位根在「系数表示」与「点值表示」之间来回变换，点值相乘后再变回去。）

应用

拆位处理大系数

系数到 10910^9109 时 double 会丢精度：把一个系数拆成「高位 × 基数 + 低位」，做两次卷积再合并。

大整数乘法

把数字按位（或按 10410^4104 进制）拆成多项式系数，乘完再统一处理进位。

快速数论变换（NTT）

一句话

给定两个多项式（次数 ≤106\le 10^6≤106，系数是模 998244353998244353998244353 意义下的整数），要你求出它们的乘积的每一项系数，模数固定但卷积要反复做很多次。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（把 FFT 的单位根换成模意义下的原根，全程整数运算，没有精度误差。）

应用

任意模数 NTT（CRT 合并）

用三个 NTT 模数各做一次卷积，再用中国剩余定理合并，就能得到任意模数下的结果。

循环卷积

若把长度取成 nnn 而不补到 2n2n2n，得到的是「循环卷积」：下标对 nnn 取模。

多项式运算

一句话

给定多项式 A(x)A(x)A(x)（次数 <n<n<n，n≤105n\le 10^5n≤105，模 998244353998244353998244353），要你依次求出它的逆、ln⁡A\ln AlnA、exp⁡A\exp AexpA、A\sqrt AA​，以及 AAA 除以 BBB 的商与余数，同一个 AAA 上这些运算会挨个问一遍。时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)。

原理

实现

（核心是多项式求逆：牛顿迭代 B←B(2−AB)B\leftarrow B(2-AB)B←B(2−AB)，每次长度翻倍。）

应用

多项式求导与积分

求导：第 iii 项系数乘 i+1i+1i+1 后左移一位；积分：第 iii 项系数除以 i+1i+1i+1 后右移一位。两者都是 O(n)O(n)O(n)。

多项式 ln⁡\lnln 与快速幂

ln⁡A=∫A′A\ln A=\int\dfrac{A'}{A}lnA=∫AA′​（要求 a0=1a_0=1a0​=1）；Ak=exp⁡(kln⁡A)A^k=\exp(k\ln A)Ak=exp(klnA)，kkk 很大时要先对指数取模。

多项式 exp⁡\expexp 与开方

exp⁡\expexp 用牛顿迭代 B←B(1−ln⁡B+A)B\leftarrow B(1-\ln B+A)B←B(1−lnB+A)；开方用 B←B+A/B2B\leftarrow\frac{B+A/B}{2}B←2B+A/B​（要求 a0a_0a0​ 是二次剩余）。

拉格朗日插值

一句话

给定 n+1n+1n+1 个点 (xi,yi)(x_i,y_i)(xi​,yi​)（横坐标两两不同，n≤106n\le 10^6n≤106），要你找出过这些点的多项式并求出它在某个 x0x_0x0​ 处的值，询问可能有很多次。时间 O(n)O(n)O(n)（横坐标连续或等差时）或 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)（一般情况），空间 O(n)O(n)O(n)。

判断「是不是多项式」

插值只能用于「答案确实是 nnn 的多项式」的情形；先用暴力算前若干项、做差看第几阶差分变常数列。

常系数齐次线性递推

一句话

给定 kkk 阶常系数线性递推 fn=∑i=1kcifn−if_n=\sum_{i=1}^{k}c_if_{n-i}fn​=∑i=1k​ci​fn−i​ 与前 kkk 项（k≤2000k\le 2000k≤2000），要你求出第 nnn 项 fnf_nfn​（n≤1018n\le 10^{18}n≤1018），kkk 比矩阵做法能承受的更大而 nnn 仍是天文数字。时间 O(k2log⁡n)O(k^2\log n)O(k2logn)，空间 O(k)O(k)O(k)。

原理

实现

（Kitamasa：把递推写成特征多项式，用「多项式快速幂 + 多项式取模」把 xnx^nxn 化简。）

线性递推的通用求法（从 09 章并入）

应用

打表 + BM + Kitamasa

只给了前若干项、系数未知时，先用 Berlekamp–Massey 求出最短递推式，再套 Kitamasa 求远处项。

判定是否为线性递推

BM 返回的递推式拿去验算更多项：全部符合才说明是线性的，否则就是拟合过头了。

快速求第 nnn 项

Berlekamp–Massey 求递推式

只给了前若干项、系数未知时，用 BM 求出最短递推式，再套 linear_rec 求远处项。

任意模数与多项式取模

模数不固定时把 mulmod_k 里的乘法换成 __int128；kkk 很大（超过 10410^4104）时用 NTT 把多项式取模降到 O(klog⁡k)O(k\log k)O(klogk)。

快速沃尔什变换（FWT）

一句话

给定两个长度为 2k2^k2k 的数组 A,BA,BA,B（k≤20k\le 20k≤20，元素模 998244353998244353998244353），要你对下标按位求出它们的或 / 与 / 异或卷积 Ci=∑j⊕l=iAjBlC_i=\sum_{j\oplus l=i}A_jB_lCi​=∑j⊕l=i​Aj​Bl​，数组一次给全。时间 O(k2k)O(k2^k)O(k2k)，空间 O(2k)O(2^k)O(2k)。

原理

实现

应用

子集或 / 与卷积

ck=∑i∣j=kaibjc_k=\sum_{i\mid j=k}a_ib_jck​=∑i∣j=k​ai​bj​ 用 or 卷积，∑i&j=k\sum_{i\&j=k}∑i&j=k​ 用 and 卷积；长度必须是 222 的幂。

ck=∑i⊕j=kaibjc_k=\sum_{i\oplus j=k}a_ib_jck​=∑i⊕j=k​ai​bj​，与 or/and 的区别是逆变换要额外除以 nnn。

自卷积（求 ttt 次幂）

要求「选 ttt 个数的异或和为 kkk 的方案数」时，先 FWT，再逐点取 ttt 次幂，最后逆变换。

子集卷积

一句话

给定两个长度为 2k2^k2k 的数组 A,BA,BA,B（k≤20k\le 20k≤20，元素模 998244353998244353998244353），要你对每个集合 SSS 求出 CS=∑T⊆SAT BS∖TC_S=\sum_{T\subseteq S}A_T\,B_{S\setminus T}CS​=∑T⊆S​AT​BS∖T​，也就是下标取不相交并集的卷积，两个数组一次给全。时间 O(2kk2)O(2^kk^2)O(2kk2)，空间 O(2kk)O(2^kk)O(2kk)。

原理

实现

（把数组按 popcount 分层：第 iii 层只保留 ∣S∣=i|S|=i∣S∣=i 的元素，做 or 卷积后只取 i+j=∣S∣i+j=|S|i+j=∣S∣ 的项。）

应用

不相交并集的计数

很多「把集合拆成两部分」的计数都靠它：令 A[T]=1 表示子集 T 合法，则「把全集拆成两个不相交合法子集」的方案数就是子集卷积在全集处的取值。

恰好不相交的若干份

把子集卷积反复做 ttt 次就能求「把 SSS 拆成 ttt 份互不相交的子集」的方案数；也可以对层数做多项式幂。

与 SOS DP 的关系

只做 or 卷积、不要求「不相交」时，直接 SOS DP 更快（O(k2k)O(k2^k)O(k2k)）；两类结果在「存在有交集的下标对」时就会不同。

高维前缀和（SOS DP）

一句话

给定一个长度为 2k2^k2k 的数组 AAA（k≤20k\le 20k≤20），要你对每个集合 SSS 求出它所有子集的和与所有超集的和，数组一次给全。时间 O(k2k)O(k2^k)O(k2k)，空间 O(2k)O(2^k)O(2k)。

原理

实现

应用

逆变换（子集 / 超集差分）

把加法换成减法，顺序反过来，就得到「由子集和还原原数组」。

与 FWT(or) 的关系

正向的 fwt_or 得到的就是「子集和」；所以 SOS DP 可以看成「只做正变换、不做逆变换」的 FWT。

统计 gcd⁡\gcdgcd 之类的高维前缀和

把「是 ddd 的倍数」看成「下标是 ddd 的超集」，就得到倍数方向的高维前缀和；有了它再配合莫比乌斯反演即可求「gcd⁡\gcdgcd 恰好为 ddd」。

常见的「按位与为 0」计数

「有多少对 (i,j)(i,j)(i,j) 使 ai&aj=0a_i\&a_j=0ai​&aj​=0」这类问题：先对 aaa 做子集和，再对每个 iii 查 aia_iai​ 的补集。
