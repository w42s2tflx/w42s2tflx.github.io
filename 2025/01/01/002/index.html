Weird Algorithm

题目大意：给一个正整数 n，按下面的规则反复操作：n 是偶数就除以 2，是奇数就乘以 3 再加 1，直到 n 变成 1。按顺序输出迭代过程中经过的每一个 n。

解题思路：直接模拟即可：每次先把当前的 n 输出，再判断是否为 1——是就结束，否则按奇偶更新 n。迭代的中间值可能超出 int 的范围，所以用 ll 存。复杂度 O(迭代次数)。

Missing Number

题目大意：给出 1~n 中的 n-1 个互不相同的数，找出缺失的那一个。

解题思路：用布尔数组 seen 记录每个数有没有出现过：读入一个数就打上标记。全部读完后，扫描 1~n，第一个没被标记的下标就是缺失的数，复杂度 O(n)。（也可以用 1~n 的总和 n(n+1)/2n(n+1)/2n(n+1)/2 减去输入之和，一步算出答案，效果相同。）

Repetitions

题目大意：给一个只含 A、C、G、T 的字符串，求最长的一段"由同一个字符组成"的连续子串的长度。

解题思路：从左到右扫一遍，用 cur 记录当前连续相同字符的个数：遇到和上一个相同的字符就 cur+1，否则把 cur 重置为 1。每步用 cur 更新答案 res。复杂度 O(n)。

Increasing Array

题目大意：给一个长度为 n 的数组，每次操作可以把某个元素加 1。求至少多少次操作，能让数组变成不下降的（每个数都不小于前一个数）。

解题思路：从左到右贪心：如果 x[i] < x[i-1]，就把 x[i] 抬高到 x[i-1]，并把差值累加进答案。抬高 x[i] 只会让后面的数更容易满足条件，绝不会变差，所以贪心是最优的。复杂度 O(n)。

Permutations

题目大意：构造一个 1~n 的排列，使任意相邻两个数的差都不等于 1。做不到就输出 NO SOLUTION。

解题思路：n = 1 时直接输出 1；n = 2、3 时无解。其余情况有通用构造：先按升序输出所有偶数（2, 4, 6, …），再输出所有奇数（1, 3, 5, …）。偶数内部相邻差 2、奇数内部也差 2，而最后一个偶数与第一个奇数之差至少为 3，所以整个排列合法。复杂度 O(n)。

Number Spiral

题目大意：数字从 1 开始，沿逆时针方向一圈圈螺旋向外填进无限大的方格。给出若干询问，每组给一个格子（第 y 行第 x 列），求该格子上的数字。

解题思路：格子的位置决定了它所在的那一圈，设 m = max(y, x)：

  • 若 x >= y，格子在右边界（外圈号就是 x）。x 为奇数时，该列从右上角 (x,1) 的 (x−1)2+1(x-1)^2+1(x−1)2+1 开始向下递增，答案是 (x−1)2+y(x-1)^2 + y(x−1)2+y；x 为偶数时，从右下角 (x,x) 的 x2x^2x2 开始向上递增，答案是 x2−y+1x^2 - y + 1x2−y+1。
  • 若 y > x，格子在底边界（外圈号就是 y）。y 为奇数时答案是 y2−x+1y^2 - x + 1y2−x+1，y 为偶数时答案是 (y−1)2+x(y-1)^2 + x(y−1)2+x。

每个格子 O(1) 求出。注意 y、x 最大 10910^9109，要用 ll。

Two Knights

题目大意：对每个 k = 1..n，统计在一个 k×k 的棋盘上放两匹马、且它们互不攻击的方案数。

解题思路：两匹马一共有 (k22)\binom{k^2}{2}(2k2​) 种放法（任意两个格子）。两匹马互相攻击，当且仅当它们位于某个 2×3 或 3×2 矩形的对角上；每个这样的矩形恰好给出一种互相攻击的摆放。k×k 棋盘上 2×3 矩形有 (k−1)(k−2)(k-1)(k-2)(k−1)(k−2) 个、3×2 矩形同样有 (k−1)(k−2)(k-1)(k-2)(k−1)(k−2) 个，攻击方案共 4(k−1)(k−2)4(k-1)(k-2)4(k−1)(k−2) 种，所以答案：

(k22)−4(k−1)(k−2)=k2(k2−1)2−4(k−1)(k−2)\binom{k^2}{2} - 4(k-1)(k-2) = \frac{k^2(k^2-1)}{2} - 4(k-1)(k-2) (2k2​)−4(k−1)(k−2)=2k2(k2−1)​−4(k−1)(k−2)

这个公式对每个 k 都成立（k=1、2 时答案就是 0），对每个 k 分别 O(1) 算出即可。

Two Sets

题目大意：把 1~n 的所有数分成两组，使两组数字之和相等。可行就输出任意一种划分方案，否则输出 NO。

解题思路：两组和相等，说明总和 s=n(n+1)/2s = n(n+1)/2s=n(n+1)/2 必须是偶数，否则直接无解。目标是让第一组的和达到 s/2s/2s/2。用一个大根堆从大到小取数：每次取当前最大的 x，如果第一组还装得下（res >= x）就放进去并更新剩余目标，否则丢给第二组；取完后再把剩下的全部放进第二组。因为是从大到小取、剩余的数总能补满第二组，所以一定可行。复杂度 O(n log n)。

Trailing Zeros

题目大意：求 n!（n 的阶乘）写成十进制后，末尾连续有多少个 0。

解题思路：末尾一个 0 对应一个因子 10 = 2×5。n! 里因子 2 的个数总是远多于因子 5，所以 0 的个数只取决于因子 5 的总数：每 5 个数贡献一个因子 5，每 25 个数再额外贡献一个，依此类推，即 n/5+n/25+n/125+⋯n/5 + n/25 + n/125 + \cdotsn/5+n/25+n/125+⋯。复杂度 O(log n)。

Coin Piles

题目大意：有两堆硬币，个数分别是 a、b。每次操作要么从第一堆拿 1 个、第二堆拿 2 个，要么从第一堆拿 2 个、第二堆拿 1 个。问能否通过若干次操作把两堆都拿空。

解题思路：设第一种操作做 x 次、第二种做 y 次，则

a=x+2y,b=2x+ya = x + 2y,\qquad b = 2x + y a=x+2y,b=2x+y

两式相加得 x+y=(a+b)/3x + y = (a+b)/3x+y=(a+b)/3，所以 a+b 必须能被 3 整除。再由 x, y >= 0 可推出 a≤2ba \le 2ba≤2b 且 b≤2ab \le 2ab≤2a（即多的一堆不能超过少的一堆的两倍）。代码里先交换使 a <= b，再检查 (a+b) % 3 == 0 且 b <= 2*a 即可。每组数据 O(1)。

Palindrome Reorder

题目大意：重排给定字符串的字符，拼成一个回文串（正着读、倒着读一样）。可行就输出任意一种，否则输出 NO SOLUTION。

解题思路：统计每个字符的出现次数。回文串里除了正中间可能有一个字符外，其余字符都必须成对出现，所以出现奇数次的字符超过 1 个就无解。构造：按字典序把每个字符的一半依次拼在左边，若存在奇数次字符就把它的最后一个放在正中间，再把另一半逆序拼在右边，即得答案。复杂度 O(n)。

Gray Code

题目大意：构造长度为 n 的格雷码：把所有 2n2^n2n 个长度为 n 的 01 串排成一列，要求任意相邻两个串恰好只有一位不同。

解题思路：递归构造。n 位格雷码 = 每个 n-1 位格雷码前加 0，再接上 n-1 位格雷码逆序后前加 1。前半部分内部相邻差一位、后半部分内部也差一位，而衔接处的两个串恰好只在最高位不同，所以整体满足相邻性。需要输出 2n2^n2n 个串，复杂度 O(2n2^n2n)。

Tower of Hanoi

题目大意：汉诺塔问题。有 3 根柱子，把 n 个圆盘从 1 号柱借助 2 号柱全部移到 3 号柱，输出最少移动步数和每一步的移动方案。

解题思路：经典递归。用 move(n, a, b, c) 表示"把 n 个盘从 a 柱移到 b 柱，c 柱作中转"：先把上面 n-1 个盘移到中转柱，再把最大的盘直接移到目标柱，最后把 n-1 个盘从中转柱移到目标柱。最少步数是 2n−12^n - 12n−1。

Creating Strings

题目大意：给一个由小写字母组成的字符串，用它的全部字符能排列出哪些不同的字符串，按字典序全部输出（第一行先输出个数）。

Chessboard and Queens

题目大意：在一个 8×8 棋盘上放 8 个皇后，使它们互不攻击（任意两个不在同一行、同一列、同一条对角线）。棋盘上标 * 的格子不能放。求合法方案的个数。

Raab Game I

题目大意：双人纸牌游戏。两人各有 1~n 的一整套牌，每轮同时各出一张，点数大的得 1 分，点数相同都不得分。给定 n 和两人的最终得分 a、b，判断这种结果是否可能，可能就构造一组出牌方案。

解题思路：每轮最多产生 1 分，所以必须满足 a + b <= n。另外，两人的得分不能一个为 0、一个不为 0：例如 a = 0 而 b > 0 时，第一人一局都不能赢，意味着每轮第一人的牌都不大于第二人，剩下不平局的轮次必须全部平局，而平局要求双方出相同的牌，第一人手里剩余的大牌无法安排，因此无解；b = 0 而 a > 0 同理。

构造：第一人按 v 的顺序出牌，第二人按 1, 2, …, n 出。把 v 分成三段：

  • 开头 n-a-b 个放 1..n-a-b，与第二人逐轮打平；
  • 接着 a 个放 n-a+1..n，都比第二人对应轮次的牌大，第一人赢 a 轮；
  • 最后 b 个放 n-a-b+1..n-a，都比第二人对应轮次的牌小，第二人赢 b 轮。

输出前代码还会实际比较一遍，确认 a、b 都恰好归零。复杂度 O(n)。

题目大意：构造一个 n×n 的网格。对每个格子，看它左边同一行已经填的数、以及正上方同一列已经填的数，把"没有在这些数里出现过的最小非负整数"（即 mex）填进去。

Grid Coloring I

题目大意：一个 n×m 网格，每个格子初始是 A、B、C、D 之一。现在要把每个格子改成 A~D 中的某一个颜色，要求：每个格子的颜色不能和它原来的颜色相同，且上下左右相邻格子的颜色互不相同。求一种方案，做不到就输出 IMPOSSIBLE。

String Reorder

题目大意：重排给定字符串的字符，使任意相邻两个字符都不相同，并在所有可行的排列中输出字典序最小的结果；如果做不到，输出 -1。

解题思路：先判断可行性。某个字符出现 cnt 次时，想让它和相邻字符都不同，至少需要 cnt-1 个其他字符来隔开，所以必须满足 2⋅cnt−1≤len2 \cdot cnt - 1 \le len2⋅cnt−1≤len；只要有一个字符违反这个条件就无解，直接输出 -1。

Apartments

题目大意：n 个申请者、m 套公寓。申请者接受面积在 [x−k,x+k][x-k, x+k][x−k,x+k] 之间的公寓（x 是他的期望面积）。求最多能有多少个申请者各分到一套合适的公寓（一套公寓只能给一个人）。

解题思路：把期望面积和公寓面积都从小到大排序，用双指针贪心。对每个申请者，把公寓指针一路移到"不小于 x-k"的第一个公寓：如果它还不超过 x+k，就分配给他并让指针后移；否则说明没有合适的公寓，跳过这个申请者。排序后每套公寓只会被考虑一次，贪心能取到最多匹配数。复杂度 O(n log n + m log m)。

题目大意：n 个孩子体重已知，每个座舱最多坐 2 人、总重不能超过 x。求最少需要多少个座舱。

解题思路：体重从小到大排序，用左右指针 i、j。若最轻的 a[i] 和最重的 a[j] 能一起坐（和不超过 x），就让他们同舱，两指针一起收拢；否则最重的只能单独坐，右指针左移。每次处理用掉一个座舱，能凑就凑，总数最少。复杂度 O(n log n)。

解题思路：按高度从高到低处理，统计"以每座山为终点（最后一站）的滑翔路径最多经过几座山"。一座山 p 的路径终点必然是某座比它高的山 q 延长一格得到的，而能直接连上 p 的更高山，只需看 p 左侧、右侧最近的已处理山即可——因为中间若有更高的山挡着，那座更高的山一定先被处理，且它到 p 的距离更近、作为"最近"被找到；它的路径也必然不短于被挡住的 q 的路径。所以有转移：

count(p)=1+max⁡(count(左邻),count(右邻))\text{count}(p) = 1 + \max(\text{count}(左邻), \text{count}(右邻)) count(p)=1+max(count(左邻),count(右邻))

实现时用 map<int,int> counts 维护已处理位置及其路径长度，先塞入哨兵 counts[0] = counts[n+1] = 0（没有更高山时按 0 处理，路径长度就是 1，即只访问自己这一座）。对每座山 pos，用 counts.upper_bound(pos) 找到右邻、再回退一位得到左邻，取两者中较大的 count 加 1。同高度的山彼此不能作为对方的前驱，所以新值不立即写回 counts，而是暂存在 updates 里，等扫到更矮的一批山时再统一写回（代码里用 prev_height 判断高度变化）。答案取所有 count 的最大值。复杂度 O(n log n)。

Increasing Subsequence

题目大意：求数组中最长严格递增子序列（LIS）的长度。

解题思路：设 g(k) 表示"以值不超过 k 的某个数结尾的 LIS 的最大长度"，用值域树状数组维护。先把所有值离散化到 1~cnt，再按原顺序扫每个元素 a[i]：

  • 以 a[i] 结尾的 LIS 长度 = g(a[i] - 1) + 1（前面比它小的所有值里最长的，再接上自己）；
  • 用这个长度更新树状数组中位置 a[i] 处的最大值。

因为只查询比 a[i] 小的值，天然满足"严格递增"；a[i] - 1 保证不把相等的值算进去。答案取所有元素的最大 LIS 长度。复杂度 O(n log n)。

Projects

题目大意：n 个项目，各有开始日期、结束日期和奖励。每天最多做一个项目，且一个项目进行期间不能做别的项目（即两个项目不能有时间重叠），求能获得的最大总奖励。

解题思路：把所有项目拆成"开始事件"和"结束事件"按时间排序扫描。记 result 为"所有已结束的项目能构成的最佳总奖励"，money[i] 为"以第 i 个项目结尾的最佳总奖励"：

  • 遇到结束事件：用 money[i] 更新全局 result；
  • 遇到开始事件：此时 result 已经包含了所有在它之前结束的项目，安排这个项目即可得 money[i] = result + p[i]。

同一时间点有开始也有结束时，排序规定结束事件排前面（is_end < other.is_end，false < true 表示结束在前），保证同一天结束的项目可以接上同一天开始的项目（不重叠）。因为事件按时间排，后一个项目只会参考更早结束的项目，result 定义正确。复杂度 O(n log n)。

Elevator Rides

题目大意：n 个人（n <= 20）体重已知，电梯一次最多载重 x，每次载一批人往返一趟，求把所有送到顶楼所需的最少趟数。

解题思路：状态压缩 DP。设 best[mask] 为二元组（趟数，最后一趟的剩余载重），表示把 mask 这组人全部送完的最优安排；min 按字典序比较，先比趟数再比剩余载重，即"趟数尽量少，同等趟数下最后一趟剩余载重尽量大"。

初始 best[0] = {1, 0}（空集 1 趟、剩 0）。对每个 mask，枚举最后上电梯的人 p（mask 中第 p 位为 1）：先去掉 p 得到 mask ^ (1 << p) 的最优值 (r, l)，若 l + w[p] <= x 说明 p 能塞进当前最后一趟，新状态 {r, l + w[p]}；否则必须新开一趟，新状态 {r + 1, w[p]}。对所有人取字典序最小。答案 best[(1 << n) - 1].first。复杂度 O(n·2^n)，可行。

Counting Tilings

题目大意：用 1×2 和 2×1 的骨牌铺满 n×m 网格，求方案数（n <= 10、m <= 1000），答案对 109+710^9+7109+7 取模。

解题思路：逐列 DP。每列的状态用一个 n 位二进制 mask 表示，某位为 1 表示该格已经被"上一列伸过来的横骨牌"占住了。先预处理相邻两列的合法转移 (left, right)，其中 left 表示当前列的占用状态（已被上一列横骨牌占住哪些格）、right 表示下一列的占用状态。generate(i, left, right) 逐格考虑第 i 行：

  • 横放一个骨牌横跨两列：当前列和下一列的第 i 格都被占，left、right 的第 i 位都置 1，跳到 i+1；
  • 竖放一个骨牌占当前列第 i, i+1 行：不涉及下一列，跳到 i+2。

递归到 i == n 时记下这一组转移。DP 时 prev[mask] 表示"到上一列为止，从上一列伸到当前列的横骨牌状态为 mask"的方案数，prev[0] = 1；对每一列，枚举所有转移 (x, y)，把 prev[x] 累加到 cur[y]（取模），再交换。处理完 m 列后，prev[0] 就是"最后一列没有骨牌伸出"的方案数，即答案。复杂度 O(m·3^n)（转移数最多约 3n3^n3n），n <= 10 可行。

Counting Numbers

题目大意：统计闭区间 [a, b] 内、十进制表示中没有两个相邻数字相同的整数个数。

解题思路：数位 DP，用"答案 = count(b) - count(a-1)"转化为前缀计数。递归函数 recurse(i, prev, equal, empty) 表示：从高到低处理到第 i 位，prev 是上一个已填数字，equal 表示前缀是否仍紧贴上界 s，empty 表示是否仍在处理前导零（即前面还没填过非零数字）：

  • 枚举当前位数字 d：若 equal && d > s[i] 会超过上界，break；若 !empty && d == prev 会构成相邻相同，continue；
  • 递归下一层：equal 更新为 equal && d == s[i]，empty 更新为 empty && d == 0。

前导零不参与相邻比较（empty 为真时跳过 d == prev 判断），所以 count(0) 返回 1、不会把 0 算漏。状态用 map<array<int,4>, ll> 记忆化。复杂度 O(位数×10)。

Increasing Subsequence II

题目大意：统计数组中严格递增子序列的总个数（值严格递增，不同位置组成的序列算不同），答案对 109+710^9+7109+7 取模。

解题思路：与"求 LIS 长度"类似，但这里要统计个数。设 f[x] 表示"以值为 x 的某个元素结尾的严格递增子序列个数"，用树状数组维护前缀和。先把值离散化，再按原顺序扫每个元素 b[i]：

  • 以 b[i] 结尾的子序列 = 单独一个元素自己（1 种）+ 接在任何"值小于 b[i] 的递增子序列"后面。用树状数组查 sum(b[i] - 1) 得到所有更小值的子序列个数之和，再加 1 就是 num；
  • 把 num 累加到树状数组的 b[i] 位置（取模），并累进总答案。

树状数组统计"值域前缀"总和，b[i] - 1 保证只取严格更小的值，因此每个合法递增子序列恰好被计入一次。复杂度 O(n log n)。
