Static Range Sum Queries

题目大意：给定一个长度为 n 的静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问：每次给出区间 [l, r]，求其中所有元素之和；询问之间不会修改数组。

解题思路：前缀和。读入后执行 a[i] += a[i - 1]，把 a[i] 变成前 i 个元素之和；区间 [l, r] 的和即 a[r] - a[l - 1]。数组静态、不需要支持修改，因此预处理一遍前缀和之后每次询问只做一次减法。预处理时间复杂度为 O(n)O(n)O(n)，每次询问的时间复杂度为 O(1)O(1)O(1)，总时间复杂度为 O(n+q)O(n+q)O(n+q)。

Static Range Minimum Queries

题目大意：给定一个长度为 n 的静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问：每次给出区间 [l, r]，求其中的最小值；询问之间不会修改数组。

解题思路：

  • 做法（稀疏表）：倍增预处理区间最小值：a[i][j] 表示从 i 开始、长度为 2j2^j2j 的区间的最小值，满足

    a[i][j]=min⁡(a[i][j−1],a[i+2j−1][j−1]).a[i][j]=\min\bigl(a[i][j-1],a[i+2^{j-1}][j-1]\bigr). a[i][j]=min(a[i][j−1],a[i+2j−1][j−1]).

Dynamic Range Sum Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的元素和。

解题思路：树状数组。修改操作读入的第二个参数（代码里变量名仍为 r）就是新值：位置 l 的旧值是 sum(l) - sum(l - 1)，所以只需向树状数组加入「新值 − 旧值」即 r - sum(l) + sum(l - 1)，之后所有前缀和自动跟着变，不必重建数组。区间 [l, r] 的和为 sum(r) - sum(l - 1)。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次修改或查询的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Dynamic Range Minimum Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的最小值。

解题思路：线段树（自底向上的写法）维护区间最小值。位置 i 对应叶子 TREE_SIZE + i（TREE_SIZE = 1 << 18）：change(i, x) 先把该叶子改成 x，再沿父链让每个祖先取两个孩子的最小值。get_min(l, r) 让 l、r 从叶子层同时上移：l 是右孩子（l % 2 == 1）时把 tree[l] 计入答案并令 l 右移一格，r 是左孩子（r % 2 == 0）时把 tree[r] 计入答案并令 r 左移一格，然后 l、r 各除以 2；这样取出的节点恰好不重不漏地覆盖 [l, r]。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Update Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持给区间 [l, r] 内的每个元素加上 u，以及查询位置 k 当前的值。

  • 做法：记差分数组 b[i]=a[i]−a[i−1]b[i]=a[i]-a[i-1]b[i]=a[i]−a[i−1]，则区间加等价于两个单点修改——b[l]b[l]b[l] 加 u、b[r+1]b[r+1]b[r+1] 减 u；而位置 k 的值正是差分的前缀和 a[k]=∑i≤kb[i]a[k]=\sum_{i\le k}b[i]a[k]=∑i≤k​b[i]。于是本题只需要「单点加」与「前缀和查询」两个操作，用树状数组或线段树维护差分都可以，代码用线段树：初始化时对每个元素 x 执行 change(i, x) 与 change(i + 1, -x) 写出差分，区间加执行 change(l, u) 与 change(r + 1, -u)，询问位置 k 输出 get_sum(1, k)。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Forest Queries

题目大意：给定一个 n×nn\times nn×n 的森林网格（n≤1000n \le 1000n≤1000，q≤2×105q \le 2 \times 10^5q≤2×105），其中 * 表示树、. 表示空地。回答 q 次矩形询问：求左上角为 (l, r)、右下角为 (x, y) 的矩形中有多少棵树；网格不会被修改。

解题思路：二维前缀和。a[i][j] 为矩形 (1,1) 到 (i,j) 内的树木数，按行列递推

a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+1[格子(i,j)是树].a[i][j]=a[i][j-1]+a[i-1][j]-a[i-1][j-1]+\mathbf{1}[\text{格子}(i,j)\text{是树}]. a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+1[格子(i,j)是树].

矩形询问用容斥：减去左上角为 (l, r) 的矩形上方与左方的区域，再补回被多减一次的左上角，答案为 a[x][y] + a[l-1][r-1] - a[x][r-1] - a[l-1][y]。预处理时间复杂度为 O(n2)O(n^2)O(n2)，每次询问的时间复杂度为 O(1)O(1)O(1)。

Hotel Queries

题目大意：有 n 家酒店（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），每家酒店有一定数量的空房。m 个团队依次到来，每个团队需要 x 间房：把团队安排到编号最小且空房数不少于 x 的酒店，并让该酒店的空房数减少 x；若不存在这样的酒店，则输出 0。

解题思路：

  • 做法：线段树维护区间最大空房数，叶子依次对应各酒店（叶子数取不小于 n 的最小二次幂，多出的叶子初值为 0）。若 t[1] < x 则没有任何酒店装得下，输出 0；否则 query(x) 从根 k = 1 向下走：左孩子的最大值不小于 x 就进入左孩子，否则进入右孩子，直到叶子，返回编号 k - n + 1；随后 update(id, -x) 把该叶子的空房数减去 x 并沿父链重算最大值。

  • 正确性：节点值就是它对应区间的最大空房数，因此「左孩子的最大值 ≥x\ge x≥x」等价于左孩子那一段编号里存在可行的酒店，而左孩子覆盖的编号全部小于右孩子覆盖的编号（区间按编号从左到右切分），先试左孩子得到的必定是编号最小的可行酒店；每一步进入的孩子最大值仍 ≥x\ge x≥x，所以不会走空。补齐的零值叶子永远不会被选中，因为 x≥1x \ge 1x≥1。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

List Removals

题目大意：给定一个包含 n 个元素的列表（n≤2×105n \le 2 \times 10^5n≤2×105），再依次给出 n 个位置 p。每次删除当前列表中从左往右第 p 个元素，并输出被删除元素的值。

解题思路：

  • 做法（线段树）：线段树维护各原始位置的存活状态（1 存活、0 已删），节点值为区间内存活元素的个数。query(k) 从根向下找当前第 k 个存活元素：左子树的存活数不小于 k 就进入左子树，否则先把 k 减去左子树的存活数再进入右子树；到达叶子即得该元素的原下标 pos，输出 x[pos] 并 change(pos, 0) 删除。左子树的位置全部小于右子树，所以「左子树存活数 ≥k\ge k≥k」说明第 k 个存活元素必在左子树，贪心下降定位正确；每次删除只把一条叶子到根的路径上的计数各减一。每次查找与删除的时间复杂度为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

  • 另解（PBDS）：顺序统计树用二元组 (原位置, 元素值) 保存未删元素——原位置互异，所以集合中的排序顺序就是列表顺序；find_by_order(x - 1) 取出当前第 x 个元素，输出它的值分量，再删除该元素。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Salary Queries

题目大意：维护 n 名员工的工资（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持修改员工 k 的工资，以及查询工资位于闭区间 [l, r] 内的员工人数。

解题思路：

  • 做法（离散化 + 值域线段树）：把可能出现过的工资收集起来排序去重——初始工资、每次查询的两个端点、每次修改后的新值（被改掉的旧值一定已经在初始工资里），再用 index(x)（即 lower_bound）把工资映射成离散下标；线段树的叶子记录各个工资值当前的人数。初始化后对每个员工执行 change(index(p[i]), +1)；修改员工 qa[i] 的工资时先 change(index(p[qa[i]]), -1)，再改掉 p[qa[i]] 并 change(index(p[qa[i]]), +1)；查询输出 query(index(qa[i]), index(qb[i]))。预处理时间复杂度为 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，每次操作的时间复杂度为 O(log⁡(n+q))O(\log(n+q))O(log(n+q))。

  • 另解（PBDS）：顺序统计树维护全部工资（重复的工资各占一份），order_of_key(r + 1) - order_of_key(l) 即工资落在 [l,r][l, r][l,r] 内的员工人数；修改时删除一份旧工资、插入新工资。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Prefix Sum Queries

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持单点修改，并查询区间 [l, r] 的最大前缀和。允许选择空前缀，因此答案不会小于 0。

解题思路：

  • 做法：线段树每个节点存二元组（区间和, 最大前缀和），即 first、second。位置 i 存在下标 i - 1；叶子对应值 x 时该二元组为 {x, max(x, 0)}，下界 0 正对应允许空前缀。合并左区间 x 与右区间 y 时，最大前缀要么整段落在左区间（x.second），要么包含整个左区间再续上右区间的前缀（x.first + y.second），故 combine 返回 {x.first + y.first, max(x.second, x.first + y.second)}。

  • 边界：combine 不满足交换律（前缀方向固定），所以迭代查询时两侧要分别按序累积：左侧取出的节点依次 resl = combine(resl, t[l++])，右侧取出的节点依次 resr = combine(t[--r], resr)，最后取 combine(resl, resr).second；查询区间用左闭右开的 [l - 1, r)，resl、resr 的初值 {0, 0} 是空区间的单位元。每次修改或查询的时间复杂度为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

题目大意：有 n 家披萨店（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），第 i 家店的披萨价格为 a[i]。从店 i 送到位置 k 的总花费为 a[i]+∣i−k∣a[i]+|i-k|a[i]+∣i−k∣。支持修改某家店的价格，以及查询送到位置 k 的最低总花费。

解题思路：

  • 观察：把 a[i]+∣i−k∣a[i]+|i-k|a[i]+∣i−k∣ 按店在位置 k 的哪一侧拆开：i<ki<ki<k 时为 (a[i]−i)+k(a[i]-i)+k(a[i]−i)+k，i>ki>ki>k 时为 (a[i]+i)−k(a[i]+i)-k(a[i]+i)−k，i=ki=ki=k 时为 a[k]。于是只需两棵线段树，分别维护 a[i] - i 与 a[i] + i 的区间最小值。

Visible Buildings Queries

题目大意：给定 n 栋楼的高度（n≤105n \le 10^5n≤105，q≤2×105q \le 2 \times 10^5q≤2×105）。每次询问一个区间 [a, b]：从位置 a 向右看，位置 a 的楼一定可见，之后一栋楼只有在高于此前所有可见楼时才可见。求区间内可见楼的数量。

解题思路：

  • 观察：从 a 向右看到的楼恰为 a, next(a), next(next(a)),…a,\ next(a),\ next(next(a)),\ldotsa, next(a), next(next(a)),…，其中 next(i)next(i)next(i) 是 i 右侧第一栋严格高于 heights[i] 的楼；这条链上的高度严格递增，可见楼数就是链上落在 [a, b] 内的位置个数。

  • 做法：在 n + 1 处放一栋高度 INF 的哨兵楼，保证任何位置都有后继。从右向左用单调栈求后继：弹出栈中所有高度不大于 heights[i] 的位置后，栈顶即 jump[0][i]。构造倍增表 jump[k][i] 表示从 i 连续跳 2k2^k2k 次后继后的位置，转移为 jump[k][i] = jump[k - 1][jump[k - 1][i]]（代码取 k≤16k \le 16k≤16，17 层足以覆盖 n≤105n \le 10^5n≤105）。询问 [a, b] 时令 pos = a、答案初值为 1（计入 a 自身），从高位到低位尝试 k：若 jump[k][pos] <= b，说明这 2k2^k2k 栋楼都落在区间内，答案累加 2k2^k2k 并把 pos 移到 jump[k][pos]。

  • 正确性：链上位置递增，能被计入的跳转恰好是从 a 出发、仍不越过 b 的最大步数，从高位到低位的贪心能凑出它，所以累加值就是区间内的可见楼数。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Interval Queries

题目大意：给定一个静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）。每次询问给出下标区间 [a, b] 和数值区间 [c, d]，求下标落在 [a, b] 且元素值落在 [c, d] 内的元素个数。

  • 观察：每条被选中的边占用两个端点，故任意节点至多与一个孩子相连。对每个节点 node 维护两个状态：dp[0] 为 node 不与任何孩子匹配时其子树内的最大匹配数，dp[1] 为 node 至多与一个孩子匹配时的最大匹配数。

题目大意：输入一棵以 1 为根的带权树：n、q（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）、各节点权值与 n−1n - 1n−1 条边。操作有两种：把节点 s 的权值改为 x；查询从根节点到节点 s 的路径权值和。

解题思路：

  • 观察：在 order_in[u] 处计入 value[u]、在 order_out[u] 处扣掉 value[u] 后，前缀和只受「进入位置不晚于 order_in[s]、且离开位置晚于 order_in[s]」的节点影响，即根到 s 路径上的节点。

  • 观察：最大矩形一定以窗口中某根柱子的高度为高。用单调栈求出每根柱子 i 的 L[i]（左边第一个高度严格小于 h[i] 的柱子，不存在时为 -1）与 R[i]（右边第一个高度不大于 h[i] 的柱子，不存在时为 n），于是 h[i] 可以作高的最长区间是 [L[i]+1, R[i]−1][L[i]+1,\ R[i]-1][L[i]+1, R[i]−1]——等高时统一归最左边那根柱子所有，不会重复计算。

  • 做法：每个窗口由起点 l 决定（0≤l≤X=n−k0 \le l \le X = n-k0≤l≤X=n−k）。柱子 i 能进入的窗口起点范围是 [max⁡(0, i−k+1), min⁡(i, X)][\max(0,\ i-k+1),\ \min(i,\ X)][max(0, i−k+1), min(i, X)]；在这个范围内，窗口与区间 [L[i]+1, R[i]−1][L[i]+1,\ R[i]-1][L[i]+1, R[i]−1] 的交宽 www 随 l 分段线性变化，按 l 与 L[i]、R[i]-k 的大小关系分成四段，斜率依次为 +1+1+1、000、000、−1-1−1，每段都是一条关于 l 的直线 h[i]⋅wh[i] \cdot wh[i]⋅w。把这四条直线用 Li Chao 树区间插入登记到对应的 l 区间上，最后对每个 l 单点查询所有直线的最大值即为该窗口的答案。

  • 正确性：任一窗口内的最大矩形必以某根柱子 i 为高，其宽度被窗口与 [L[i]+1, R[i]−1][L[i]+1,\ R[i]-1][L[i]+1, R[i]−1] 同时限制，就是 w(l)w(l)w(l)；四段划分覆盖了 l 的全部取值，因此查询取到的最大值就是该窗口的最大矩形面积。总时间复杂度为 O(nlog⁡2n)O(n \log^2 n)O(nlog2n)，空间复杂度为 O(n)O(n)O(n)。
