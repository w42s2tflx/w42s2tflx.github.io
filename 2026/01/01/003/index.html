Increasing Array

题目大意：给定一个长度为 n 的数组（n≤2×105n \le 2 \times 10^5n≤2×105，元素 ≤109\le 10^9≤109）。每次操作可以把任意元素加 1，求使数组变为不下降序列所需的最少操作次数。

解题思路：从左到右贪心。若 x[i] < x[i - 1]，为满足不下降，x[i] 至少需补到 x[i - 1]，把差值 x[i - 1] - x[i] 累加进答案并令 x[i] = x[i - 1]；多补只会浪费操作并抬高后续元素的下界，故恰好补到相等即最优。时间复杂度为 O(n)O(n)O(n)。

Permutations

题目大意：构造一个 111 到 n 的排列（n≤106n \le 10^6n≤106），使任意两个相邻数之差都不等于 1。若无法构造，输出 NO SOLUTION。

解题思路：n=2n=2n=2 时两数必相邻、n=3n=3n=3 时无论中间放哪个数都与 1 或 3 相差 1，均无解，输出 NO SOLUTION；n=1n=1n=1 直接输出 1。n≥4n \ge 4n≥4 时先按升序输出所有偶数、再按升序输出所有奇数：相邻两数同为偶数或同为奇数时差为 2，两段交界处是最大偶数与 1，差也不为 1，构造合法。时间复杂度为 O(n)O(n)O(n)。

Trailing Zeros

题目大意：求 n!n!n! 的十进制表示末尾有多少个连续的 0（n≤109n \le 10^9n≤109）。

解题思路：末尾 0 来自因子 10=2×510=2\times510=2×5，而 n!n!n! 中因子 2 多于因子 5，故只需统计因子 5 的个数：555 的倍数各贡献 1 个，252525 的倍数多贡献 1 个，依此类推，答案为

⌊n5⌋+⌊n25⌋+⌊n125⌋+⋯ .\left\lfloor\frac n5\right\rfloor+\left\lfloor\frac n{25}\right\rfloor+\left\lfloor\frac n{125}\right\rfloor+\cdots. ⌊5n​⌋+⌊25n​⌋+⌊125n​⌋+⋯.

代码循环累加 n / 5 并令 n /= 5，直到 n < 5。时间复杂度为 O(log⁡n)O(\log n)O(logn)。

String Reorder

题目大意：重新排列给定字符串的全部字符，使任意两个相邻字符都不同，并在所有合法排列中字典序最小。若无法做到，输出 -1。

解题思路：从左到右逐位构造。剩余长度为 length、字符 c 还剩 v[c] 个时，把这些相同字符彼此隔开至少需要 v[c]−1v[c]-1v[c]−1 个其它字符，故必须满足 2v[c]−1≤length2v[c]-1\le length2v[c]−1≤length；check(length) 检查所有字符的该条件，初始不满足则输出 -1。对每一位按 A 到 Z 尝试：跳过剩余数为 0 或等于上一位的字符；将候选字符计数减 1 后调用 check(剩余长度)，可行则选定并输出，否则恢复并尝试下一个。

Grid Path Description

题目大意：在 7×77\times77×7 网格中，从左上角出发，经过恰好 48 步到达左下角，并且不能重复经过格子。输入一个长度为 48 的路径描述串，其中 D、U、R、L 表示固定方向，? 可表示任意方向。求符合描述的合法路径数。

解题思路：直接 DFS 的搜索量最坏为 4484^{48}448，需要剪枝。dfs(sx, sy, id) 维护当前位置与已走步数，棋盘四周预置为已访问以统一处理越界；固定字符只沿规定方向走，? 则尝试四个方向。共三条剪枝：

  1. 到达终点 (7, 1) 但 id < 48 时返回——路径必须恰好走满 48 步。

  2. 上、下方向均不可走而左、右可行（或对称情形）时返回——此时未访问格被当前路径切成互不相通的两块，每块都含未走格子，无法全部走完。图示中 1 为当前位置，0 为未走格，# 为已走或不可走格：

  3. 如果路径创建了一个不是终点的死胡同，则路径将无法访问所有方格（路径可能在死胡同处停止或越过它，从而封闭一个方格）。因此，我们希望避免产生死胡同。例如，如果我们当前位置上方的方格三面被挡住（包括我们现在的位置），那么下一步必须往上，以避免造成死胡同

    用图来解释：如果两个 ? 中至少有一个是 # ，加上我们当前的位置，如果不往上走就会形成死胡同，其他方向的也是同理
