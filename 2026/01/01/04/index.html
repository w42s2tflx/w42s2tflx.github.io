Weird Algorithm

题目大意：给定一个正整数 n（n≤106n \le 10^6n≤106），反复执行以下操作：若 n 是偶数，则将它除以 2；若 n 是奇数，则将它乘以 3 再加 1。按顺序输出从初始值到 1 的整个变化过程。

解题思路：按规则逐步模拟：每轮输出当前 n，n == 1 时结束，否则 n 为偶数则执行 n = n / 2、为奇数则执行 n = 3 * n + 1。中途出现的项可能超过 32 位整数范围（n≤106n \le 10^6n≤106 时峰值约 5.7×10105.7\times10^{10}5.7×1010），故用 ll 存储。设序列长度为 TTT，时间复杂度为 O(T)O(T)O(T)，空间复杂度为 O(1)O(1)O(1)。

Increasing Array

题目大意：给定一个长度为 n 的数组（n≤2×105n \le 2 \times 10^5n≤2×105，元素 ≤109\le 10^9≤109）。每次操作可以把任意元素加 1，求使数组变为不下降序列所需的最少操作次数。

解题思路：从左到右贪心。若 x[i] < x[i - 1]，为满足不下降，x[i] 至少需补到 x[i - 1]，把差值 x[i - 1] - x[i] 累加进答案并令 x[i] = x[i - 1]；多补只会浪费操作并抬高后续元素的下界，故恰好补到相等即最优。时间复杂度为 O(n)O(n)O(n)。

  • 边界：前导零不参与相邻数字比较，位数更短的整数由补前导零的路径自然被统计；全前导零的路径对应整数 0，故 count(0) = 1。count(x) 在 x < 0 时直接返回 0，因此 a = 0 时 count(a-1) = 0。每次调用 count 先用 lookup.clear() 清空记忆化，不同上界之间不会串用结果。设位数为 LLL，状态数为 O(40L)O(40L)O(40L)、每个状态枚举 10 个数字，时间复杂度为 O(L)O(L)O(L) 量级，空间复杂度为 O(L)O(L)O(L)。

题目大意：统计数组（n≤2×105n \le 2 \times 10^5n≤2×105）中严格递增子序列的总个数（值严格递增，不同位置组成的序列算不同），答案对 109+710^9+7109+7 取模。

解题思路：先离散化，再用树状数组按值维护递增子序列数量的前缀和：sum(x) 查询末尾值 ≤x\le x≤x 的子序列总数，add(x, v) 把 v 累加到末尾值为 x 的位置。处理 b[i] 时，以它结尾的子序列为：单独自身（1 种）+ 接在任何末尾值 <b[i]< b[i]<b[i] 的递增子序列后（sum(b[i]-1) 种），即 num = sum(b[i]-1) + 1；再把 num 累加进 add(b[i], num) 并计入总答案。查询排除相等值，保证严格递增；不同位置结尾的子序列分别计数。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
