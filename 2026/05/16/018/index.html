Filled Subgrid Count I

题目大意：n×nn\times nn×n 的字母网格（n≤3000n \le 3000n≤3000），对字母表中前 k 个字母逐一统计"全为该字母的正方形子网格"的个数。

解题思路：逐字母处理（避免字母间互相干扰）。对固定字母 c，dp[i][j] 为以 (i,j) 为右下角的全 c 最大正方形边长：(i,j) 不是 c 则为 0；否则取左上、正上、正左三个位置 dp 的最小值加 1（向上/向左延伸的正方形受两条边共同限制）。以 (i,j) 为右下角的全 c 正方形个数恰为 dp[i][j]（边长 1..dp1..dp1..dp 均合法），累加即该字母答案。时间复杂度为 O(kn2)O(kn^2)O(kn2)。

Filled Subgrid Count II

题目大意：n×nn\times nn×n 的字母网格（n≤3000n \le 3000n≤3000），对字母表中前 k 个字母逐一统计"全为该字母的矩形子网格"的个数。

解题思路：

  • 观察：枚举行 r 作矩形底边，height[c] 为列 c 从 r 向上连续同字母的高度（与上一行同字母则 +1，否则 1）。把底边按字母相同的连续段切分，段内即一个直方图；"以某列为右端、任一列为左端、底边在 r"的矩形数 = 直方图所有子数组的最小值之和。

  • 做法：用单调栈（严格递增）求最小值之和：弹出一个下标 mid 时，它作为最小值的左端范围为 (prev,mid](prev, mid](prev,mid]、右端范围为 [mid,c)[mid, c)[mid,c)（prev 为栈中前驱、c 为触发弹出的位置），贡献 height[mid]×(mid−prev)×(c−mid)height[mid]\times(mid-prev)\times(c-mid)height[mid]×(mid−prev)×(c−mid)。每个字母累加其段内贡献。

  • 正确性：单调栈保证每个下标恰在其"作为最小值"的极大区间被统计一次，段内矩形按底边与左右端一一对应。总时间复杂度为 O(n2)O(n^2)O(n2)。

All Letter Subgrid Count I

题目大意：n×nn\times nn×n 网格上有 k 种字母（n≤3000n \le 3000n≤3000），统计包含全部 k 种字母的正方形子网格个数。

解题思路：

  • 观察：对每个可能的左上角 (i,j) 求"最小边长"：need[i*n+j] = 使以 (i,j) 为左上角的正方形包含全部字母的最小边长减 1，即到"右下区域中每个字母最近出现位置"的最大切比雪夫距离。

  • 做法：对每种字母 c 从右下角倒推：cur[j] = 从 (i,j) 到右下区域内最近 c 的距离（(i,j) 本身是 c 为 0，否则取下方、右方、右下方三值最小 +1，用 below/cur 两行滚动）。need 取所有字母的最大值。最后：以 (i,j) 为左上角、边长从 need+1need+1need+1 到 min⁡(n−i,n−j)\min(n-i,n-j)min(n−i,n−j) 的每个正方形都包含全部字母，共 mx - side + 1 个，累加。

  • 正确性：切比雪夫距离 ddd 使以 (i,j) 为左上角、边长 d+1d+1d+1 的正方形恰好覆盖所有字母的最远者；更大的边长必然仍包含。总时间复杂度为 O(kn2)O(kn^2)O(kn2)。

  • 正确性：容斥按"缺失字母集合"精确计数；枚举法由"所有字母最近出现位置的最大者"确定最右合法左端点。两种情形的时间复杂度为 O(2kn2)O(2^k n^2)O(2kn2) 与 O(n2k)O(n^2k)O(n2k)（常数优化版）。

Counting Permutations

题目大意：统计 1..n1..n1..n 的排列中不存在相邻元素差为 1 的排列数（n≤500n \le 500n≤500），对 109+710^9+7109+7 取模。

解题思路：

  • 做法：DP 状态 dp[j][b]：已插入 1..i1..i1..i 的排列中有 j 个"坏相邻对"（相邻差为 1），b 表示 i 与 i-1 是否相邻。插入新元素 i（相对 1..i−11..i-11..i−1）分类：

    • b = 1（i-1 与 i-2 相邻）：把 i 放 i-1 旁产生一个新坏对（两个位置）ndp[j+1][1] += v；把 i 插进 i-1 与 i-2 之间拆掉这个坏对 ndp[j][1] += v。
    • b = 0：把 i 放 i-1 左右两侧（2 个位置）都新产生一个坏对 ndp[j+1][1] += 2v。
    • 其余 i−2i-2i−2 个空隙中，badGaps = j - b 个是"坏空隙"（插入会拆掉一个坏对），插入得 ndp[j-1][0] += v * badGaps；剩余空隙 ndp[j][0] += v * (i - 2 - badGaps)。

  • 正确性：插入法的经典转移，每类空隙的计数由状态精确刻画；答案 dp[0][0]（0 个坏对）。总时间复杂度为 O(n2)O(n^2)O(n2)。

  • 观察：A 和 B 各自是一个排列（每行一个、每列一个），且不能占用同一格。

  • 做法：把 A 在自由行上的补全枚举为"自由行 → 自由列"的排列；对每个合法的 A（不占用已放的 B），B 的补全数用容斥统计：B 必须落在"既无已放 B 也无 A"的格子，若 A 占用了 t 个 B 的自由列，则 B 的方案数 =∑k(−1)k(tk)(∣FB∣−k)!=\sum_{k}(-1)^k\binom{t}{k}(|FB|-k)!=∑k​(−1)k(kt​)(∣FB∣−k)!（A 占的格子是 B 的禁格，形成偏排列计数）。

  • 正确性：A 的枚举不重不漏；B 的计数用"禁格恰好全避开"的标准容斥。此解法为指数级枚举（枚举自由行的全排列），时间复杂度为 O(r!⋅r)O(r!\cdot r)O(r!⋅r)（r 为自由行数），仅作思路参考，大规模输入需要更精细的组合计数。
