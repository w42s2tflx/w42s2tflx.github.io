Hidden Integer

题目大意：交互程序藏有一个整数 x，满足 1≤x≤1091 \le x \le 10^91≤x≤109。每次输出 ? y，可以询问命题 y < x 是否成立，并读入 YES 或 NO；最多询问 30 次。确定答案后输出 ! x。

解题思路：二分答案。维护闭区间 [l, r] 为 x 的可能取值，初始 [1, 10^9]；l < r 时取下取整中点 mid = (l + r) / 2 并 check(mid)（询问 mid < x）：返回 YES 说明 mid < x，令 l = mid + 1；否则 x <= mid，令 r = mid。两种更新都严格缩小区间且不遗漏答案；l == r 时该值即 x，输出 ! l。每次询问至少减半，109<23010^9<2^{30}109<230，最多 30 次询问。交互输出用 endl 立即刷新。总时间复杂度为 O(log⁡109)O(\log 10^9)O(log109)。

K-th Highest Score

题目大意：芬兰和瑞典各有 n 个分数，每国的分数都已从高到低排列。输出 F i 或 S i，可以查询芬兰或瑞典第 i 高的分数。需要在最多 100 次查询内求出两国共 2n 个分数中的第 k 大，并输出 ! 和答案。

Permuted Binary Strings

题目大意：交互程序藏有一个长度为 n 的排列 a。每次输出一个二进制串 b 后，会收到按该排列重排得到的串 c，其中 c[j] = b[a[j]]。需要在不超过 10 次询问内还原所有 a[j]，最后输出 ! 以及整个排列。

解题思路：

  • 观察：固定返回位置 j，收到的 c[j] 来自查询串的第 a[j]a[j]a[j] 位；给原串每个位置编码，再按位从同一位置 j 的多次回复恢复编码即得 a[j]a[j]a[j]。

  • 做法：用位置编号 1..n1..n1..n 本身的二进制作编码。取最小 bits 使 2bits≥n+12^{bits}\ge n+12bits≥n+1；第 t 次询问构造串 b：位置编号 i 的第 t 位为 1 则 b[i-1] = '1'。返回的 c[j] 恰是 a[j]a[j]a[j] 的第 t 位，存入 res[t][j]。全部询问后对每个 j 按位重建 v（res[t][j]=='1' 则 v |= 1 << t），v 即 1 起始编号的 a[j+1]a[j+1]a[j+1]。

  • 正确性：二进制编码在 bitsbitsbits 位内区分 1..n+11..n+11..n+1 的所有编号；每次询问同时传输所有位置的一位，bits 次询问覆盖全部位。n≤1000n\le1000n≤1000 时 bits 不超 10，满足询问限制。构造与解码的时间复杂度为 O(n⋅bits)O(n\cdot bits)O(n⋅bits)。

Colored Chairs

题目大意：n 为奇数，n 把椅子首尾相接围成一圈，每把椅子是红色或蓝色。输出 ? i 可以查询第 i 把椅子的颜色。需要在最多 20 次查询内找到一对相邻且同色的椅子，并输出 ! i，其中 i 表示这对椅子中的前一把；当 i = n 时，后一把是椅子 1。

解题思路：

  • 观察：先查椅子 1 颜色 c1，构造理想交替序列：奇数位期望 c1、偶数位期望异色（exp）。把虚拟位置 n+1n+1n+1 视为椅子 1（颜色即 c1，不额外查询）。n 为奇数使 n+1n+1n+1 为偶数位，理想交替要求它与 c1 异色，但实际就是 c1——故区间 [2,n+1][2, n+1][2,n+1] 中必存在实际颜色与 exp 失配的位置；相邻同色对恰出现于"失配状态变化"处。

  • 做法：在 [2,n+1][2, n+1][2,n+1] 二分找失配边界：查询 mid 处实际颜色（mid=n+1mid=n+1mid=n+1 时用 c1），若 cm != exp 则 hi = mid，否则 lo = mid + 1。

  • 正确性：从椅子 1 到某位置之间"实际与期望一致"时相邻同色出现偶数次、失配时奇数次（相邻位期望必异色，实际同色当且仅当其中之一失配），故二分两端始终夹着至少一处状态变化。最终 lo-1 与 lo 状态不同且相邻，其实际颜色必相同；lo≤nlo\le nlo≤n 时答案是相邻的 lo-1、lo，lo=n+1lo=n+1lo=n+1 时哨兵代表椅子 1，输出 n 即环边界上的椅子 n 与 1。总询问次数为 1+O(log⁡n)1+O(\log n)1+O(logn)，满足 20 次限制。
