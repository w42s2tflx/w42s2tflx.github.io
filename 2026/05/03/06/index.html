Counting Rooms

题目大意：给定一张 n×mn \times mn×m 的地图（n,m≤1000n, m \le 1000n,m≤1000），其中 # 表示墙，. 表示地板。只能在地板格之间上下左右移动，求地图中四方向连通的地板区域数量，也就是房间数。

解题思路：遍历地图，每遇到仍为 . 的 building[i][j] 就发现了一个新房间，n_rooms 加 1，并从该格 dfs：把访问到的地板改为 #（就地标记已访问）后向四个方向递归，直到整个连通块处理完。每个格子至多被访问一次。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)（递归栈最深可达地板格总数）。

Labyrinth

题目大意：给定一张 n×mn \times mn×m 的迷宫（n,m≤1000n, m \le 1000n,m≤1000），A 是起点，B 是终点，# 是墙。每一步可以上下左右移动到非墙格，要求判断能否从 A 到达 B；若可以，还要输出一条最短路径的长度及由 L、R、U、D 组成的移动序列。

解题思路：无权网格最短路用 BFS：从起点 a 入队逐层扩展，格子首次被访问时走过的步数就是到它的最少步数。visited[i][j] 标记已访问，previous[i][j] 记录该格的前驱，last_letter[i][j] 记录从前驱走到这里的移动方向（取自 moves 表）。若终点 b 未被访问则输出 NO；否则从 b 沿 previous 回溯到 a 收集 last_letter 并反转，得到正向路径，先输出长度 ans.size() 再输出方向串。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Building Roads

题目大意：有 n 个城市和 m 条双向道路（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105）。可以在任意两个城市之间新建道路，要求用最少的新道路使所有城市互相可达，并输出道路数量及一种具体方案。

解题思路：设原图有 k 个连通块。一条新路至多合并两个连通块，故至少需要 k−1k-1k−1 条；把各连通块的代表点依次连成一条链恰好用 k−1k-1k−1 条，下界可达。用并查集读入道路时执行 merge(u, v)，再把每个城市的根 get(i) 放入 set 去重；s.size() - 1 即最少道路数，把 set 中相邻的代表点依次相连即得方案。时间复杂度为 O((n+m)α(n)+nlog⁡n)O((n+m)\alpha(n)+n\log n)O((n+m)α(n)+nlogn)，空间复杂度为 O(n)O(n)O(n)。

Message Route

题目大意：n 台电脑、m 条双向网线连接（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105）。问能否从 1 号走到 n 号，若能输出最短路径上的电脑数量以及路径上的电脑编号，否则输出 IMPOSSIBLE。

解题思路：从 1 号做 BFS，某节点首次入队时对应的步数就是它到 1 号的最短距离，parent[y] 记录首次到达 y 的前驱。若 n 未被访问则输出 IMPOSSIBLE；否则从 n 沿 parent 回溯收集路径——parent[1] 保持全局初值 0，作为回溯的终止标记——反转后先输出城市数量 ans.size() 再输出编号序列。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Building Teams

题目大意：n 个学生、m 对朋友关系（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），朋友之间不能分到同一队。问能否把所有人分成两队，能则输出每个学生的队号（1 或 2），否则输出 IMPOSSIBLE。

解题思路：学生为顶点、朋友关系为边，问题等价于判定这张图是否二分图，用二染色判定。对每个未访问的连通块从起点染 0 开始 DFS：相邻点染相反色 color ^ 1，枚举邻居时检查 c[u] == c[v]，一旦某条边两端同色就置 f = 0。全部染完后若 f == 0 输出 IMPOSSIBLE，否则颜色非 0 的学生输出 1、颜色为 0 的输出 2。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Round Trip

题目大意：无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），找一条至少经过 3 个不同顶点、能回到起点的环，输出环上的顶点序列；不存在则输出 IMPOSSIBLE。

解题思路：

  • 做法：对每个未访问的连通块 DFS，p[v] 记录 DFS 树上 v 的父节点。搜索 u 的邻居 v 时跳过父节点；遇到其它已访问点就记录 s = v、t = u 并立即返回。还原环时先放入 s，再从 t 沿 p[i] 走回 s，末尾补一次 s 后反转，得到首尾相同的序列。

  • 正确性：无向图 DFS 中不存在横叉边，除父边外连向已访问点的边（返祖边）必连接当前点与它的某个 DFS 树祖先。由于父边被跳过，v 是 u 的真祖先，从 t 沿 p 走到 s 至少经过两条树边，因此围出的环至少含 3 个不同顶点，满足题目要求；回溯的每一步走的都是树边，路径必然存在。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Monsters

题目大意：给定一张 n×mn \times mn×m 的迷宫（n,m≤1000n, m \le 1000n,m≤1000），其中 A 是玩家，M 是怪物，# 是墙。玩家和所有怪物每轮都可以上下左右移动一步。要求判断玩家能否在不与怪物同时到达同一格或更晚到达该格的前提下走到边界，并输出一条逃生路径。

解题思路：玩家能安全进入一个格子，当且仅当到达该格的时刻严格早于任意怪物最早到达它的时刻。先做多源 BFS：所有 M 同时入队，tim[i][j] 记录怪物最早到达时间（初值 INF，怪物所在格为 0）；玩家的起点也置 0，使它不会被再次进入。再从 A 出发 BFS，只把满足 tim[nx][ny] > nt 的格子入队（nt 是玩家的到达时刻），并用 fa[nx][ny] 记录前驱；玩家的到达时刻直接覆盖这些格子的 tim，相当于顺带完成了访问标记。首次扩展到边界格即可沿 fa 回溯，按相邻坐标差翻译成 U/D/L/R 再反转输出；起点本身已在边界时直接输出 YES。总时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Shortest Routes I

题目大意：n 个城市、m 条单向航线（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），每条从 a 到 b、费用 c。求从 1 号城市出发到每个城市的最短距离（不可达的城市距离保持初始极大值）。

解题思路：边权全为正，用 Dijkstra：小根堆（代码里是 reverse_priority_queue）存 (距离, 节点)，先把 dist[1] = 0 与状态 (0, 1) 入堆；每次取出 (d, x)，若 dist[x] < d 说明这是更新前的旧状态，直接跳过，否则枚举 x 的出边 g[x]，用 d + len 尝试更新 dist[y] 并把新状态入堆。距离用 ll 并以 101810^{18}1018 初始化。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

High Score

题目大意：n 个房间、m 条单向隧道（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），每条隧道走过后分数变化可正可负，可以重复走同一条隧道。求从 1 号到 n 号能获得的最大分数；若分数可以无限增大（存在一个从 1 出发且能回到 n 路上的正权环）则输出 -1。

解题思路：

  • 观察：把边权 x 取反为 -x，最大得分问题就化为最小费用问题，原图中能无限增分的正环对应新图中的负环；只有位于「从 1 可达且还能到达 n」的路径上的负环才会影响答案。

  • 做法：分别在原图 g 与反图 rev_g 上从 1、n 做 BFS，两个可达集合按位与得到 included，即有效点集。Bellman-Ford 松弛 n 轮，每轮只松弛两端都在 included 中的边；distance 初值为 101810^{18}1018、distance[1] = 0，若第 n 轮仍有一条边被严格松弛，说明有效路线中存在负环，输出 -1，否则答案为 -distance[n]。

  • 正确性：从 1 到 n 的路径上每个点都能被前缀到达、又能沿后缀到达 n，所以必定属于 included，剔除无效点不会漏掉有效负环；反过来，included 内的边起点仍从 1 可达，第 n 轮还能松弛就等价于这个子图内存在负环，因此与答案无关的负环不会被误判。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Flight Discount

题目大意：给定一张带正权的有向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），从 1 号城市前往 n 号城市时可以对一张航班票使用折扣，使该边费用变为整数除法下的 c / 2。求最小总费用。

解题思路：

  • 观察：折扣「已用/未用」是一个二元状态，用分层图表示：第 1 层 1..n 表示尚未用掉折扣，第 2 层 n+1..2n 表示已经用过，两层的点一一对应。

  • 做法：对原边 a -> b（费用 c）加入三条边：两层内各一条原价边 a -> b 与 n+a -> n+b，以及从第 1 层跨到第 2 层的折扣边 a -> n+b（费用 c/2）。

  • 正确性：跨层边只从第 1 层指向第 2 层，任何路径至多用一次折扣；目标 2n 位于第 2 层，保证折扣已被使用，因此 distance[2n] 就是恰用一次折扣到达 n 的最小费用。用 Dijkstra 在该分层图上求最短路即可。时间复杂度为 O((n+m)log⁡(n+m))O((n+m)\log(n+m))O((n+m)log(n+m))，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Cycle Finding

题目大意：有向带权图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），判断是否存在负环（边权和为负的环），若存在则输出其中一个负环的顶点序列。

解题思路：

  • 做法：把所有 distance 初始化为 0，这等价于增设一个向所有节点连零权边的超级源点，因而能检测图中任意位置上的负环。Bellman-Ford 松弛 n 轮，每轮遍历所有边 edges：能严格变小就更新 distance[to] 并记 previous[to] = from；第 n 轮仍被更新的节点记为 path_end，它或位于负环上、或可由负环到达。从 path_end 沿 previous 回退并记录访问标记，首次遇到重复节点时即找到了环；反转后从首节点输出到它再次出现为止，得到首尾相同的负环序列。

  • 正确性：松弛 n 轮后仍能更新的边，其起点必可由某个负环到达（否则最短距离在第 n-1 轮前就已收敛），而前驱链上只有 n 个不同节点，回退 n 步内必然重复，重复点及其间的一段就是负环。反之，若第 n 轮没有任何更新，则所有边都满足 distance[to] <= distance[from] + len，沿任一环求和得环权和非负，故不存在负环。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Flight Routes

题目大意：求从 1 号到 n 号的前 k 条最短路长度（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105，k≤10k \le 10k≤10）。可以重复经过城市，走的路线不同就算不同（同一条边路径顺序不同也算不同）。

解题思路：

  • 观察：边权为正，小根堆弹出的顺序单调不减，节点第 c 次被有效弹出时，对应的路径长度就是到该节点的第 c 小路径长度。

  • 做法：不设布尔访问标记去重，而用 visited[x] 计数，限制每个节点至多扩展 k 次，已弹出 k 次的状态直接丢弃；起点状态 (0, 1) 入堆，弹到 n 时用 dist[visited[n]] = d 记下这一条（此时 visited[n] 还是自增前的值）。

  • 正确性：每条路径都以其终点状态入堆，弹出顺序递增，故节点第 c 次弹出对应第 c 短路径；每个节点只扩展前 k 次不影响前 k 短的发现——被丢弃的状态是该节点第 k+1 次及以后的弹出，由它们延伸出的路线都不短于已发现的那 k 条。至多扩展 knknkn 个状态、扫描 kmkmkm 条边，总时间复杂度为 O(kmlog⁡(kn+km))O(km\log(kn+km))O(kmlog(kn+km))，空间复杂度为 O(n+m+km)O(n+m+km)O(n+m+km)。

Course Schedule

题目大意：n 门课程、m 条先修关系（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），每条 a b 表示必须先修完 a 才能修 b。求一个合法的学习顺序；若不存在（先修关系成环）则输出 IMPOSSIBLE。

Longest Flight Route

题目大意：n 个城市、m 条单向航线（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），保证图是 DAG。求从 1 号到 n 号、经过城市最多的路径，输出经过的城市数和路径；若 1 号到不了 n 则输出 IMPOSSIBLE。

解题思路：DAG 上记忆化搜索。longest[x] 为从 x 到 n 的最长路径包含的城市数（含 x 本身），next_city[x] 记录最优后继，ready[x] 为记忆化标记，终点令 longest[n] = 1。求 f(x) 时枚举 x 的每条出边 x -> y：先递归求出 f(y)，若 longest[y] + 1 更大就更新 longest[x] 与 next_city[x]。DAG 无环使递归不会绕回自身；不能到达 n 的状态初值为 -INF、最终仍为负值，所以 f(1) < 0 时输出 IMPOSSIBLE，否则先输出 f(1)，再从 1 起沿 next_city 依次输出城市编号（走到默认值 0 为止）。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Game Routes

题目大意：n 个城市（n≤20n \le 20n≤20）、m 条单向航班（同一起终点的多条航班视为不同路线），求从 1 号出发、恰好经过每个城市一次、最后到达 n 号的路线数，对 109+710^9+7109+7 取模。

解题思路：ways[mask][last] 表示已访问城市集合为 mask、当前停在 last 的路线数（城市按 0 起编号，mask 的第 i 位对应城市 i + 1），初始 ways[1][0] = 1。对每个 mask 从小到大、对其中每个 last 枚举 mask 中的所有城市 prev 做转移：

ways[mask][last]=∑prev∈maskcount[prev][last]⋅ways[mask⊕2last][prev]ways[mask][last]=\sum_{prev\in mask}count[prev][last]\cdot ways[mask\oplus 2^{last}][prev] ways[mask][last]=prev∈mask∑​count[prev][last]⋅ways[mask⊕2last][prev]

其中 count[prev][last] 为 prev 到 last 的航班条数，乘进去就正确计入了重边形成的不同路线；每算完一个 ways[mask][last] 就对 109+710^9+7109+7 取模。答案为 ways[(1 << n) - 1][n - 1]。时间复杂度为 O(n22n)O(n^2 2^n)O(n22n)，空间复杂度为 O(n2n)O(n2^n)O(n2n)。

Knight’s Tour

题目大意：在 8×88 \times 88×8 的国际象棋棋盘上，从给定起点出发，寻找一条经过每个格子恰好一次的骑士巡游路径，并输出每个格子是第几步到达的。

解题思路：

  • 做法：DFS 回溯，grid[y][x] 存该格是第几步到达的（0 表示未访问），行列都从 0 起算。每走一步先枚举所有在棋盘内且尚未访问的落点，用 degree 统计每个候选点还能前往的未访问格数，按该值升序排序后依次尝试（Warnsdorff 启发式：优先进入后续出路最少的格子）。

  • 正确性：Warnsdorff 只改变候选的尝试顺序，不改变被搜索的解集合——某个候选走不通时回溯后仍会尝试其余候选，只有走满 64 格才输出并 exit；放弃当前分支时会把 grid[y][x] 复位为 0。最坏情况需要穷尽全部走法，时间复杂度为指数级，但该启发式让 8×88\times88×8 棋盘上的实际搜索规模足够小。

题目大意：n 台电脑、m 条单向连接（n≤500n \le 500n≤500，m≤1000m \le 1000m≤1000），每条连接有带宽上限，求从 1 号到 n 号最多能传输的带宽（即最大流）。

解题思路：

  • 观察：从源到汇的最大总流量可以用增广路求解：残余网络中只要还存在源到汇的路径，就还能继续增加流量。本题源为 1 号、汇为 n 号，每条连接建一条容量等于带宽的正向边和一条容量 0 的反向边（反向边用于撤销已经发送的流量）。

  • 做法：容量缩放增广。bit 从 2622^{62}262 起逐次减半；固定 bit 时反复调用 dfs(source, bit)，只沿残余容量不小于 bit 的边搜索，找到路径就沿路增流 bit（正向减、反向加），重置 seen 后再找，直到当前尺度下不存在可行路径，再缩小 bit。

题目大意：无向图（n≤500n \le 500n≤500，m≤1000m \le 1000m≤1000），问至少拆掉多少条边能让 1 号与 n 号不连通（即边权为 1 的最小割），并输出这些要拆的边。

解题思路：

  • 观察：拆掉最少的边使 1 与 n 不连通就是容量为 1 的最小割；由最大流最小割定理，最小割的容量等于最大流值。把每条无向路建成两个方向、容量各 1 的边后，最大流值就等于最小割容量，也就是要拆掉的边数。

  • 做法：Edmonds-Karp（每轮 BFS 找一条最短增广路，沿路修改正反向残余容量）求最大流 k 并输出。随后从 1 号起沿残余容量大于 0 的边 DFS，visited 集合就是从源出发仍可达的点集；枚举原始无向边，两端分属两侧的即为要拆的边。

  • 观察：每条边容量为 1，整数流下每个单位的流对应一条 1 到 n 的路径，不同单位的路径不共边，因此边不相交路径的最大数量等于最大流值。

题目大意：nnn 个城市、mmm 条双向道路，其中 kkk 个城市有动漫商店。对每个城市，求它到另一个有商店的城市的最短距离（住在有商店的城市当然熟悉本地商店，所以它要算的是别的城市的商店）。无解输出 −1-1−1。

解题思路：注意住在本地的商店不算，所以有商店的城市答案不是 000，而是到另一个商店的距离（只有一家店时为 −1-1−1）；没有商店的城市则就是到最近商店的距离。做法是「每个点保留两个不同起点的最近距离」的多源 BFS：把 kkk 个商店同时入队、距离 000、各自带自己的标号，出队时若该点还没记录过就记下当前标号的距离，若已有相同标号则跳过，否则记成第二个标号的距离；一个点最多记录两个不同标号。无商店的城市取第一个距离，有商店的城市取第二个距离（没有则为 −1-1−1）。正确性：若某个源 sss 的波在点 uuu 处被挡住，说明 uuu 已有两个比 sss 更近的不同源，那么 uuu 的邻居 vvv 也有两个比 sss 更近的源，sss 本来就不该是 vvv 的次近源。每个点最多入队两次，时间复杂度为 O(n+m)O(n+m)O(n+m)。

Prüfer Code

题目大意：第一行给出 nnn，随后给出 n−2n-2n−2 个整数，是一棵 nnn 个点的标号树的 Prüfer 序列。重建这棵树并输出它的 n−1n-1n−1 条边，每行一条，两个端点用空格分隔。

解题思路：

  • 观察：Prüfer 序列与标号树一一对应，且每个点在序列中出现的次数等于它在树中的度数减一——所以没在序列里出现过的点恰好是叶子。代码用 degree[i] 统计点 i 在 code 中的出现次数，把所有 degree[i] == 0 的点放进小根堆 leaves。

  • 做法：按 code[1..n-2] 依次解码：每次取出编号最小的点 leaves.top()，把它与 code[i] 连边输出；随后把 degree[code[i]] 减 1，减到 0 说明 code[i] 已经变成新叶子，压入堆。

  • 边界：处理完序列后堆里只剩两个点，最后一条边输出 leaves.top() 与 n，依据是 n 一定还留在堆里：只要还剩不少于 3 个点，剩下的树就至少有两片叶子，而 n 是最大标号，被取走的只会是编号更小的那片叶子。n=2n=2n=2 时序列为空，循环不执行，直接输出 1 2。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

  • 观察：目标是最小化位置向量 (pos(1),pos(2),…,pos(n))(pos(1), pos(2), \dots, pos(n))(pos(1),pos(2),…,pos(n)) 的字典序，它并不等于最小拓扑序字典序：正向小根堆每步取编号最小的可用课程，会为了取到小编号而在无关处先把小编号用掉。例如只有一条依赖「4 必须早于 1」（边 4→14\to14→1）时，正向小根堆给出 2,3,4,1，而 4,1,2,3 能让课程 1 更早完成。

  • 做法：等价地从后往前放：每一步在当前所有没有出边的课程里取编号最大的放到末尾。代码在反向图（把输入 a ba\ ba b 建成 b→ab\to ab→a）上用大根堆 pq 做拓扑排序，得到序列 order 后倒序输出；每步取的是反向图中编号最大的入度 0 点，正好是原图当前编号最大的无出边点。出队点数不足 n 说明有环，输出 IMPOSSIBLE。

Strongly Connected Edges

题目大意：给定 nnn 个点、mmm 条边的无向图，为每条边选定一个方向，使得到的有向图强连通；无解输出 IMPOSSIBLE。有解时输出 m 行，第 iii 行是第 iii 条边定向后的起点与终点。

解题思路：

  • 判据：有解当且仅当图连通且没有桥。桥无论朝哪个方向定，两侧之间都只剩单向通路，不可能双向可达，故有桥必无解；图不连通时更不可能强连通。

  • 做法：先用 Tarjan 求桥并数连通块（有桥或连通块多于 1 就输出 IMPOSSIBLE）；再做一遍 DFS 定向，用 from、to 记录每条边：未访问过的邻居对应树边，定成父→子；已访问的邻居只可能是祖先（该边第一次被检查时另一端已经访问，说明祖先那层递归还在栈上、还没轮到检查这条边），定成当前点→该祖先。

  • 正确性：树边父→子，故根可以沿树边走到每个点。反过来看任一点 ccc 与其父亲 ppp：树边 (p,c)(p,c)(p,c) 不是桥，所以割「ccc 的子树 / 其余点」上必有非树边，而跨出子树的那一端只能是 ccc 的祖先，按定向规则方向是从子树内指向祖先，于是 ccc 的子树中存在一点能一步跳到 ppp 的某个真祖先；先沿树边走到这一点再跳上去，重复即得 ccc 能到达根。根与每个点双向可达，图强连通。

  • 边界：求桥时只跳过 id == pe 这一条具体的父边，平行重边不会被误当成父边而漏判；n=1n=1n=1 不需要任何边就已经强连通。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Even Outdegree Edges

题目大意：给定 nnn 个点、mmm 条边的无向图，为每条边选定一个方向，使每个点的出度都是偶数；无解输出 IMPOSSIBLE。有解时输出 m 行，第 iii 行是第 iii 条边定向后的起点与终点。

解题思路：

  • 做法：初始定向规则是：树边父→子；其余边（当前点检查到它时另一端已访问，必为祖先）定成祖先→当前点。随后按后序（孩子先于父亲）逐个修正：若点 v 的 outdeg[v] 是奇数，就把它与父亲的那条树边 pe[v] 翻转成 v→父亲——v 的出度加 1 变成偶数，父亲的出度减 1（代码先 swap(from[id], to[id])，再 outdeg[from[id]]++、outdeg[to[id]]--）。

  • 正确性：按后序处理，轮到 v 时它的所有孩子都已处理完，而之后的翻转只会改变「被处理点与它父亲」的出度，不会波及 v，故每个非根点被处理后就永久是偶数。又所有点的出度之和等于边数，所以根节点的出度奇偶等于它所在连通块边数的奇偶；若某个根仍是奇数，说明该块边数为奇数，而此时全偶要求出度总和为偶数，确实无解，输出 IMPOSSIBLE。

  • 边界：各连通块互不影响，代码对每个满足 parent[i] == -1 的点调用 fix；孤立点出度为 0，天然合法。最后统一复查所有 outdeg 都是偶数才输出方案。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

题目大意：有向图（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），找出从 1 到 n 的每一条路径都必经的城市（含 1 与 n）：先输出城市个数，再按升序输出这些城市。

解题思路：

  • 观察：点 ddd 支配 vvv，当且仅当从起点 1 到 vvv 的每条路径都经过 ddd；支配关系构成一棵以 1 为根的树（支配树），vvv 的支配者恰是它在树上的祖先，最近的那个记作 idom[v]。于是「所有必经城市」就是从 n 沿 idom 一路走到根所经过的点。

  • 做法：Lengauer–Tarjan 求支配树。先对正向图从 1 做 DFS，得到 DFS 序 dfn 与按序排列的点 ord；半支配点 semi[v] 是「存在路径 w→⋯→vw\to\cdots\to vw→⋯→v 且中间点的 DFS 序都大于 dfn[v]」的所有 www 里 DFS 序最小的那个，idom[v] 必落在 DFS 树上 vvv 到 semi[v] 的链上。按 DFS 序倒序处理每个点：用带权并查集 uni/mn 维护「当前点到已处理祖先之间 semi 最小的点」（uni_query 在路径压缩时把 mn 合并成 semi 更小的一方），对 fst[u][1]（原图中指向 uuu 的边）里每个可达前驱求出 semi[u]；再把 u 挂进 semi[u] 的桶（fst[semi[u]][2]）并令 uni[u] = fth[u]；轮到 fth[u] 处理时，用它桶里的点定出 idom（u == semi[mn[v]] 取 u，否则取 mn[v]）。

题目大意：带权有向图（n≤105n \le 10^5n≤105），求从 1 到 n 的所有最短路径都一定经过的城市：先输出个数，再按编号升序输出这些城市。

解题思路：

  • 判据：点 u 必在所有最短路上，当且仅当下面两条同时成立：(1) dist[0][u] + dist[1][u] == dist[0][N]，即 u 至少落在一条最短路上（dist[0] 是从 1 在正向图上、dist[1] 是从 n 在反向图上的 Dijkstra 结果）；(2) 经过 u 的最短路条数等于最短路的总条数。

  • 做法：两次 Dijkstra 中顺带做双模路径计数，ways[t][j][v] 表示第 t 次 Dijkstra 里到 v 的最短路径条数模第 j 个模数（j = 0, 1 分别对应 MOD1、MOD2）：松弛时找到更短路径就把计数整体覆盖为前驱的计数，等长则累加。判定写成 ways[0][0][u] * ways[1][0][u] % MOD1 == tot1 && ways[0][1][u] * ways[1][1][u] % MOD2 == tot2 && dist[0][u] + dist[1][u] == dist[0][N]，其中 tot1、tot2 是最短路总数在两个模下的值。

  • 正确性：满足 (1) 时，经过 u 的最短路都可拆成「1 到 u 的最短路 + u 到 n 的最短路」，条数恰为两侧条数之积，所以它等于总条数当且仅当 u 出现在每条最短路上；Dijkstra 按距离非降出队，等长前驱的计数都会在 u 之前累加完毕，计数是完整的。

  • 边界：MOD1、MOD2 是 mt19937_64 在 [109,2×109)[10^9, 2\times 10^9)[109,2×109) 上均匀抽取的随机大数（用两个模数降低哈希冲突概率），两数乘积不超过 4×10184\times 10^{18}4×1018，仍在 64 位整数范围内；dist 初值取 BIG，不可达点的计数不会通过判定。总时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

解题思路：

  • 观察：边双连通要求每条边都至少落在一个环上。树上的瓶颈是叶子：叶子的唯一邻边必须在环上，而一条新边 (x,y)(x,y)(x,y) 只让 xxx–yyy 树上路径上的边进环，树中的一条路径至多含两片叶子，所以至少要 ⌈m/2⌉\lceil m/2\rceil⌈m/2⌉ 条新边（m 为叶子数）；把叶子两两配对就够。

  • 做法：先把所有叶子按 DFS 序 tim 排序，让第 i 个叶子与第 i+⌊m/2⌋i+\lfloor m/2\rfloori+⌊m/2⌋ 个配对（下标从 1 起），叶子数为奇数时再补上「第一个 ↔ 最后一个」这一对，共 ⌈m/2⌉\lceil m/2\rceil⌈m/2⌉ 条边。
