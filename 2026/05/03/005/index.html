Dice Combinations

题目大意：每次掷骰子可以得到 1 到 6 中的一个点数，求点数总和恰好为 n 的序列数量（n≤106n \le 10^6n≤106）。顺序不同视为不同方案，答案对 109+710^9+7109+7 取模。

解题思路：DP。设 ways[i] 为点数总和恰为 i 的方案数，ways[0] = 1（空序列）。枚举最后一次掷出的点数 v（1 到 6），此前需凑出 i−vi-vi−v，故

ways[i]=∑v=16ways[i−v].\text{ways}[i]=\sum_{v=1}^{6}\text{ways}[i-v]. ways[i]=v=1∑6​ways[i−v].

从小到大枚举 i，再枚举 v，当 i−v≥0i-v\ge0i−v≥0 时累加并取模。每个状态只枚举 6 个点数，时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Minimizing Coins

题目大意：给定 n 种面值不同的硬币（n≤100n \le 100n≤100，面值 ≤106\le 10^6≤106），每种硬币都可以使用任意次。求凑出总金额 x（x≤106x \le 10^6x≤106）至少需要多少枚硬币；若无法凑出，则输出 -1。

解题思路：完全背包（每种硬币可取任意次）求最小值。设 f[i] 为凑出金额 i 的最少硬币数，初值为 BIG，f[0] = 0。若最后一枚硬币面值为 a[j]（i≥a[j]i\ge a[j]i≥a[j]），则

f[i]=min⁡(f[i], f[i−a[j]]+1).f[i]=\min\bigl(f[i],\,f[i-a[j]]+1\bigr). f[i]=min(f[i],f[i−a[j]]+1).

按金额从小到大计算：更新 f[i] 时所有更小金额的最优值已确定，同一硬币可重复使用。最后 f[x] 仍为 BIG 则输出 -1。时间复杂度为 O(nx)O(nx)O(nx)，空间复杂度为 O(x)O(x)O(x)。

Coin Combinations I

题目大意：n 种硬币（n≤100n \le 100n≤100，每种无限），求凑出总额 x（x≤106x \le 10^6x≤106）的方案数（硬币出现的顺序不同算不同方案），答案对 109+710^9+7109+7 取模。

解题思路：有序计数。f[i] 为凑出金额 i 的有序方案数，固定最后一枚为 a[j]，前缀需凑出 i−a[j]i-a[j]i−a[j]，故

f[i]=∑jf[i−a[j]](mod109+7).f[i]=\sum_j f[i-a[j]] \pmod {10^9+7}. f[i]=j∑​f[i−a[j]](mod109+7).

代码先用 f[a[i]] = 1 计入单枚硬币的方案，再按金额从小到大、枚举最后一枚硬币更新。不同的排列因“最后一枚不同”或“前缀顺序不同”而分别计数。答案为 f[x]，时间复杂度为 O(nx)O(nx)O(nx)。

Coin Combinations II

题目大意：n 种硬币（n≤100n \le 100n≤100，每种无限），求凑出总额 x（x≤106x \le 10^6x≤106）的方案数（只关心每种硬币用了几个，顺序不同不算不同方案），答案对 109+710^9+7109+7 取模。

解题思路：组合计数（顺序无关）。f[i][j] 为只用前 i 种硬币凑出 j 的方案数。第 i 种硬币可以不用（f[i-1][j]），或至少用一枚（先取出一枚，剩余 j−a[i]j-a[i]j−a[i] 仍可用第 i 种，f[i][j-a[i]]）：

f[i][j]=f[i−1][j]+f[i][j−a[i]](mod109+7).f[i][j]=f[i-1][j]+f[i][j-a[i]] \pmod {10^9+7}. f[i][j]=f[i−1][j]+f[i][j−a[i]](mod109+7).

逐种引入硬币使每种组合恰在其所含硬币种类全部引入时形成一次，排列不被重复统计。答案为 f[n][x]，时间复杂度为 O(nx)O(nx)O(nx)。

Removing Digits

题目大意：给定整数 n（n≤106n \le 10^6n≤106），每次可以减去它十进制表示里的任意一个数字，求把 n 变成 0 所需的最少步数。

解题思路：steps[i] 为把 i 减到 0 的最少步数，steps[0] = 0。最后一步必减去 i 的某个数字 d，故

steps[i]=1+min⁡d∈digits(i)steps[i−d].\text{steps}[i]=1+\min_{d\in\text{digits}(i)}\text{steps}[i-d]. steps[i]=1+d∈digits(i)min​steps[i−d].

从 1 到 n 依次计算，用循环逐位取出 i 的数字。数字 0 对应的候选为 steps[i]+1，不影响最小值。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Grid Paths I

题目大意：给定一个 n×nn\times nn×n 网格（n≤1000n \le 1000n≤1000），部分格子有陷阱而不能经过。每一步只能向右或向下，求从左上角到右下角的路径数，答案对 109+710^9+7109+7 取模。

解题思路：f[i][j] 为从左上角走到 (i,j) 的路径数。只能向右、向下，故只能来自上方或左方：

f[i][j]=f[i−1][j]+f[i][j−1](mod109+7).f[i][j]=f[i-1][j]+f[i][j-1]\pmod{10^9+7}. f[i][j]=f[i−1][j]+f[i][j−1](mod109+7).

起点可通行时 f[1][1] = 1；按行、列顺序扫描，仅对 . 格累加左侧与上方的值，陷阱格保持 0。数组越界处为全局零值，不会误判为 .。时间复杂度为 O(n2)O(n^2)O(n2)，空间复杂度为 O(n2)O(n^2)O(n2)。

Book Shop

total[j]=max⁡(total[j], s[i]+total[j−h[i]]),total[j]=\max(total[j],\,s[i]+total[j-h[i]]), total[j]=max(total[j],s[i]+total[j−h[i]]),

题目大意：有一个长度为 n 的数组（n≤105n \le 10^5n≤105），每个元素都在 1 到 m 之间（m≤100m \le 100m≤100），相邻元素之差不超过 1。部分位置的值未知，用 0 表示，求满足条件的填法数量，答案对 109+710^9+7109+7 取模。

解题思路：dp[i][j] 为填好前 i 位且第 i 位为 j 的方案数。相邻差不超过 1，故

dp[i][j]=dp[i−1][j−1]+dp[i−1][j]+dp[i−1][j+1](mod109+7).dp[i][j]=dp[i-1][j-1]+dp[i-1][j]+dp[i-1][j+1]\pmod{10^9+7}. dp[i][j]=dp[i−1][j−1]+dp[i−1][j]+dp[i−1][j+1](mod109+7).

a[1] == 0 时令 dp[1][0..m] = 1（其中 dp[1][0] 无效，但转移只接受 1 到 m 的 k，不参与答案）；已知时只置 dp[1][a[1]] = 1。未知位置枚举所有 j，已知位置只更新 dp[i][a[i]]。答案为 ∑j=1mdp[n][j]\sum_{j=1}^{m}dp[n][j]∑j=1m​dp[n][j]。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Counting Towers

题目大意：用宽、高都为整数的方块搭建一座宽为 2、高为 n 的塔，问有多少种不同的搭建方式（左右对称的算不同），答案对 109+710^9+7109+7 取模（多组询问，n≤106n \le 10^6n≤106）。

解题思路：

  • 观察：块的长宽可取任意整数，塔的结构只取决于顶部两格是否属于同一块。设 towers[i][1] 为高 i 且顶部两格分属不同块（独立）的方案数，towers[i][0] 为顶部两格同属一块（连通）的方案数，高度 1 时各为 1。

  • 做法：向上加一行，枚举新行两格的覆盖方式（新放 1×11\times11×1、新放横跨两列的 1×21\times21×2、或把下方块的顶边上扩一格）：

    • 独立 →\to→ 独立 4 种：两列各新放 1×11\times11×1；左扩右新；左新右扩；两列各上扩一格。
    • 连通 →\to→ 独立 1 种：两列各新放 1×11\times11×1。
    • 连通 →\to→ 连通 2 种：整个块上扩一格；新放一个 1×21\times21×2 横块。
    • 独立 →\to→ 连通 1 种：新放一个 1×21\times21×2 横块。

    即

    towers[i][1]=4⋅towers[i−1][1]+towers[i−1][0],towers[i][0]=towers[i−1][1]+2⋅towers[i−1][0].\begin{aligned} \text{towers}[i][1]&=4\cdot\text{towers}[i-1][1]+\text{towers}[i-1][0],\\ \text{towers}[i][0]&=\text{towers}[i-1][1]+2\cdot\text{towers}[i-1][0]. \end{aligned} towers[i][1]towers[i][0]​=4⋅towers[i−1][1]+towers[i−1][0],=towers[i−1][1]+2⋅towers[i−1][0].​

  • 正确性：每种塔按顶部两格状态唯一归类，上述 8 种扩展方式两两互异且覆盖全部可能的加行方式，转移完备。预处理到 N-1 后每次询问输出两状态之和。预处理时间复杂度为 O(N)O(N)O(N)，每次询问的时间复杂度为 O(1)O(1)O(1)，空间复杂度为 O(N)O(N)O(N)。

Edit Distance

题目大意：求把字符串 a 变成字符串 b 的最少操作次数（长度均 ≤5000\le 5000≤5000），允许的操作是插入一个字符、删除一个字符、替换一个字符。

解题思路：编辑距离 DP（编辑距离：通过插入、删除、替换将一字符串变为另一字符串的最少操作数）。distance[i][j] 为把 a 前 i 个字符变成 b 前 j 个字符的最少操作数；边界 distance[i][0] = i（全删）、distance[0][j] = j（全插）。按末字符分类：删除 a[i-1]（distance[i-1][j] + 1）、插入 b[j-1]（distance[i][j-1] + 1）、或直接处理两个末字符（distance[i-1][j-1] 加 (a[i-1] != b[j-1])，不等时视为替换），取三者最小值。答案为 distance[n][m]。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Longest Common Subsequence

题目大意：给定两个整数数组，求它们的最长公共子序列（LCS）的长度，并输出一个具体的 LCS。

解题思路：最长公共子序列（两个序列共有的、相对顺序保持的最长子序列）。lcs[i][j] 为 a 前 i 个与 b 前 j 个元素的 LCS 长度：若 a[i] == b[j]，该元素可接到更短前缀的 LCS 之后，lcs[i][j] = lcs[i-1][j-1] + 1；否则取 max(lcs[i-1][j], lcs[i][j-1])。恢复序列时从 (n, m) 回退：相等则收录该元素并同时减一，否则朝 lcs 值不变的方向移动，最后反转。DP 的时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)，回溯的时间复杂度为 O(n+m)O(n+m)O(n+m)。

Removal Game

题目大意：n 个数（n≤5000n \le 5000n≤5000）排成一列，两人轮流从两端取走一个数并累加到自己的得分，双方都按最优策略行动，求先手最终能得到的最大得分。

解题思路：

  • 观察：零和博弈中只需记录当前玩家相对对手的最终分差。设 score[l] 为在区间 [l, r]（r = l + len - 1）上先手相对后手的最大分差：取左端得 x[l]x[l]x[l]，对手随后在 [l+1, r] 上相对我方的分差为 score[l+1]，净差 x[l]−score[l+1]x[l]-\text{score}[l+1]x[l]−score[l+1]；取右端同理，净差 x[r]−score[l]x[r]-\text{score}[l]x[r]−score[l]（区间 [l, r-1]）。

  • 做法：按区间长度从小到大、原地更新

    score[l]=max⁡(x[l]−score[l+1], x[r]−score[l]),\text{score}[l]=\max\bigl(x[l]-\text{score}[l+1],\,x[r]-\text{score}[l]\bigr), score[l]=max(x[l]−score[l+1],x[r]−score[l]),

    长度 1 时 score[i] = x[i]。

  • 正确性：转移即双方最优策略的收益方程。原地更新时右侧两个 score 仍是长度为 len-1 的旧值：l 从小到大处理，score[l+1] 属本层尚未覆盖，score[l] 同理。设总和 sum、先手得分 ppp，由 p+q=sump+q=\text{sum}p+q=sum、p−q=score[0]p-q=\text{score}[0]p−q=score[0] 得 p=(sum+score[0])/2p=(\text{sum}+\text{score}[0])/2p=(sum+score[0])/2。时间复杂度为 O(n2)O(n^2)O(n2)，空间复杂度为 O(n)O(n)O(n)。

Mountain Range

题目大意：n 座山排成一列，每座有高度。从一座山出发可以沿滑翔路径"跳到"一座更矮的山，要求它比起点矮、且比两座山之间的所有山都矮（即中间没有比终点更高的山挡路）。求从某一座山出发，一条路线最多能经过多少座山。

解题思路：

  • 观察：按高度从高到低处理，已处理的山都比当前高。能直接滑到 p 的前驱只可能是 p 左右两侧最近的已处理位置：更远的高山与 p 之间隔着这座最近的高山，而它比 p 高，不满足“终点比中间所有山都矮”，被挡住。

  • 做法：count(p) = 1 + max(count(左邻), count(右邻))。用 map<int,int> 保存已处理位置及其最长路线，哨兵 0、n+1 的值均为 0；upper_bound(pos) 得到右侧最近者，前移一位得左侧最近者。同高度的山不能互跳，故同一高度算出的结果先存入 updates，进入更低高度时才写入 counts；答案取所有 count 的最大值。

  • 正确性：由观察，转移只用最近已处理邻居即完备；同高度批次延迟写入保证同高之间不互相转移。排序与每次 map 操作均为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Increasing Subsequence

题目大意：求数组（n≤2×105n \le 2 \times 10^5n≤2×105）中最长严格递增子序列（LIS）的长度。

解题思路：树状数组（Fenwick 树：按二进制低位分解维护前缀信息的数组结构，单点更新与前缀查询均为 O(log⁡n)O(\log n)O(logn)）维护值域前缀中的最大 LIS 长度。先把值离散化（排序去重后映射为从 1 开始的排名）。g(p) 查询离散值 ≤p\le p≤p 的元素能形成的最长递增子序列，f(p, v) 用 v 更新位置 p。以 a[i] 结尾的 LIS 为 g(a[i]-1) + 1（接在值更小的子序列后），再用它更新位置 a[i]；查询排除相等值，保证严格递增。答案为所有新长度的最大值。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Projects

题目大意：给定 n 个项目（n≤2×105n \le 2 \times 10^5n≤2×105），每个项目都有开始日期、结束日期和奖励。选择的任意两个项目都不能在同一天进行，求能够获得的最大奖励总和。

解题思路：事件扫描 DP。把每个项目拆成开始事件与结束事件，按时间排序（同日时 is_end = false 的开始事件排在前）。result 为已结束项目能取得的最大奖励，money[i] 为选项目 i 后的最大奖励：开始事件时 money[i] = result + p[i]（此时 result 只含结束日期严格早于当前日期的项目）；结束事件时用 money[i] 更新 result。同日开始的事件排在结束之前，保证同日结束的项目不能接续同日开始的项目。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Elevator Rides

题目大意：n 个人（n≤20n \le 20n≤20）体重已知，电梯一次最多载重 x，每次载一批人往返一趟，求把所有送到顶楼所需的最少趟数。

解题思路：状态压缩 DP（用二进制掩码表示子集作为状态）。best[s] 为二元组（已用趟数, 最后一趟当前载重），表示送完集合 s 的最优安排；pair 字典序比较先最小化趟数、再最小化最后一趟载重（载重越小越利于继续载人）。初始 best[0] = {1, 0}（尚未载人的第一趟也计入）。对每个集合 s 枚举最后加入的人 p：若 best[s ^ (1 << p)] 的载重加 w[p] 不超过 x，则放入当前趟得 {r, l + w[p]}；否则新开一趟得 {r + 1, w[p]}；取字典序最小。答案为 best[(1 << n) - 1].first，时间复杂度为 O(n2n)O(n2^n)O(n2n)，空间复杂度为 O(2n)O(2^n)O(2n)。

Counting Tilings

题目大意：用 1×21\times21×2 和 2×12\times12×1 的骨牌铺满 n×mn\times mn×m 网格，求不同铺法的数量。其中 n≤10n \le 10n≤10、m≤1000m \le 1000m≤1000，答案对 109+710^9+7109+7 取模。

解题思路：

  • 观察：逐列转移，一列的状态只需记录哪些格被伸向下一列的横向骨牌占用，用 n 位掩码表示；n≤10n\le10n≤10 使状态数 2n2^n2n 可行。

  • 做法：generate(i, left, right) 枚举一列内的覆盖方式：left 第 i 位为 1 表示上一列有横向骨牌伸入本列（本格已覆盖），right 第 i 位为 1 表示本格放一块伸向右列的横向骨牌。递归时有三种选择：只在 left 放（本格被覆盖）、只在 right 放（骨牌伸向右列）、或放一块竖向骨牌覆盖本列第 i、i+1 行并跳过两行；到 i == n 时该列完整覆盖，(left, right) 是一组合法转移；竖向骨牌越过边界（i > n）则丢弃。DP 中 prev[x] 为处理完若干列后边界状态为 x 的方案数，初始 prev[0] = 1；每处理一列，对所有合法转移 (x, y) 执行 cur[y] += prev[x] 后交换。处理完 m 列后状态 0 表示无骨牌伸出网格，答案为 prev[0]。

  • 正确性：相邻两列的组合方式恰好由 (left, right) 描述，转移生成完备且互不重复，逐列推进即拼接出全部铺法。设合法转移数为 TTT，总时间复杂度为 O(mT)O(mT)O(mT)，空间复杂度为 O(2n+T)O(2^n+T)O(2n+T)。

Counting Numbers

题目大意：统计闭区间 [a, b] 内（a,b≤1018a, b \le 10^{18}a,b≤1018）、十进制表示中没有两个相邻数字相同的整数个数。

解题思路：数位 DP（从高位到低位逐位构造数字，用状态记录与上界的贴合程度及约束，记忆化计数）。将区间计数转化为 count(b) - count(a-1)，其中 count(x) 统计 0 到 x 内相邻数字不同的整数个数。

  • 做法：递归 recurse(i, prev, equal, empty)：正在填第 i 位，prev 为上一位数字，equal 表示当前前缀是否仍与上界 s 完全相同，empty 表示此前是否全为前导零。枚举当前位 d：equal 为真时 d 不能超过 s[i]；已出现非前导零数字时 d 不能等于 prev；下一层状态为 (equal && d == s[i] - '0', empty && d == 0)。填完所有位返回 1。

  • 边界：前导零不参与相邻比较，使位数更短的数自然被统计；全前导零的路径对应整数 0，故 count(0) = 1，而 count(a-1) 对 a = 0 特判返回 0。用 map 对四元组状态记忆化。设位数为 LLL，状态数为 O(40L)O(40L)O(40L)、每状态枚举 10 个数字，时间复杂度为 O(L)O(L)O(L) 量级，空间复杂度为 O(L)O(L)O(L)。

Increasing Subsequence II

题目大意：统计数组（n≤2×105n \le 2 \times 10^5n≤2×105）中严格递增子序列的总个数（值严格递增，不同位置组成的序列算不同），答案对 109+710^9+7109+7 取模。

解题思路：先离散化，再用树状数组按值维护递增子序列数量的前缀和：sum(x) 查询末尾值 ≤x\le x≤x 的子序列总数，add(x, v) 把 v 累加到末尾值为 x 的位置。处理 b[i] 时，以它结尾的子序列为：单独自身（1 种）+ 接在任何末尾值 <b[i]< b[i]<b[i] 的递增子序列后（sum(b[i]-1) 种），即 num = sum(b[i]-1) + 1；再把 num 累加进 add(b[i], num) 并计入总答案。查询排除相等值，保证严格递增；不同位置结尾的子序列分别计数。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
