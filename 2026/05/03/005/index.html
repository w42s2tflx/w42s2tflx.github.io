Dice Combinations

题目大意：每次掷骰子可以得到 1 到 6 中的一个点数，求点数总和恰好为 n 的序列数量。顺序不同视为不同方案，答案对 109+710^9+7109+7 取模。

解题思路：设 ways[i] 表示点数之和恰好为 i 的方案数，并令 ways[0] = 1。要得到总和 i，可以枚举最后一次掷出的点数 v（1 到 6），此前的点数总和应为 i - v，于是：

ways[i]=∑v=16ways[i−v]\text{ways}[i] = \sum_{v=1}^{6} \text{ways}[i - v] ways[i]=v=1∑6​ways[i−v]

代码使用 ways 保存状态，先令 ways[0] = 1，表示凑出总和 0 有一种空序列。随后从小到大枚举 i，再枚举最后一次掷出的点数 v；当 i - v >= 0 时，将 ways[i - v] 累加到 ways[i]。每个状态只枚举 6 个点数，因此时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Minimizing Coins

题目大意：给定 n 种面值不同的硬币，每种硬币都可以使用任意次。求凑出总金额 x 至少需要多少枚硬币；若无法凑出，则输出 -1。

解题思路：完全背包求最小值。设 f[i] 表示凑出金额 i 的最少硬币数，初始为无穷大（代码用 INF），f[0] = 0。凑出 i 时，若最后一枚用了面值 a[j] 的硬币（i >= a[j]），则 f[i] 可由 f[i - a[j]] + 1 更新：

f[i]=min⁡(f[i], f[i−a[j]]+1)f[i] = \min\bigl(f[i],\ f[i-a[j]]+1\bigr) f[i]=min(f[i], f[i−a[j]]+1)

状态按金额从小到大计算，因此更新 f[i] 时，所有较小金额的最优答案都已经得到，同一种硬币也可以被重复使用。最后若 f[x] 仍为 INF，说明无解；否则输出 f[x]。时间复杂度为 O(nx)O(nx)O(nx)，空间复杂度由数组 f 决定。

Coin Combinations I

题目大意：n 种硬币（每种无限），求凑出总额 x 的方案数（硬币出现的顺序不同算不同方案），答案对 109+710^9+7109+7 取模。

f[i]=∑jf[i−a[j]](mod109+7)f[i] = \sum_j f[i-a[j]] \pmod {10^9+7} f[i]=j∑​f[i−a[j]](mod109+7)

Coin Combinations II

题目大意：n 种硬币（每种无限），求凑出总额 x 的方案数（只关心每种硬币用了几个，顺序不同不算不同方案），答案对 109+710^9+7109+7 取模。

解题思路：设 f[i][j] 表示只使用前 i 种硬币凑出金额 j 的组合数。对于第 i 种硬币，可以一枚也不用，此时方案数为 f[i - 1][j]；也可以至少使用一枚，先拿出一枚 a[i]，剩余金额仍可使用第 i 种硬币，因此方案数为 f[i][j - a[i]]：

f[i][j]=f[i−1][j]+f[i][j−a[i]](mod109+7)f[i][j] = f[i-1][j] + f[i][j-a[i]] \pmod {10^9+7} f[i][j]=f[i−1][j]+f[i][j−a[i]](mod109+7)

代码逐种引入硬币，f[i][j] 先继承 f[i - 1][j]，当 j >= a[i] 时再加上 f[i][j - a[i]]。由于每种组合只会在其所用硬币种类被依次引入时形成一次，硬币的排列顺序不会被重复统计。答案为 f[n][x]，时间复杂度为 O(nx)O(nx)O(nx)。

解题思路：设 steps[i] 表示把 i 减到 0 的最少步数，steps[0] = 0。最后一步一定是减掉 i 的某一个数字 d，所以：

steps[i]=1+min⁡d∈digits(i)steps[i−d]\text{steps}[i] = 1 + \min_{d \in \text{digits}(i)} \text{steps}[i - d] steps[i]=1+d∈digits(i)min​steps[i−d]

实现时从 i = 1 到 n 依次计算状态，并用 while 逐位取出 i 的数字 digit。数字 0 不会改变当前值，对应的候选为 steps[i] + 1，不会影响最小值；其余数字都会转移到更小的状态。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

解题思路：设 f[i][j] 表示从左上角走到 (i, j) 的路径数。由于只能向右或向下，到达 (i, j) 只能来自上方 (i - 1, j) 或左方 (i, j - 1)，所以：

f[i][j]=f[i−1][j]+f[i][j−1](mod109+7)f[i][j] = f[i-1][j] + f[i][j-1] \pmod {10^9+7} f[i][j]=f[i−1][j]+f[i][j−1](mod109+7)

Book Shop

题目大意：n 本书，每本有价格 h[i] 和页数 s[i]，预算为 x（总花费不超过 x），每本最多买一次，求能买到的最大总页数。

解题思路：0-1 背包求最大值。设 total[j] 表示花费不超过 j 时能获得的最大页数，对每本书做一次"最多选一次"的更新。因为是 0-1 背包（每本书只能买一次），内层循环容量必须从大到小扫，保证 total[j - h[i]] 还是没考虑当前这本书时的旧值，避免同一本书被重复购买：

total[j]=max⁡(total[j],  s[i]+total[j−h[i]])total[j] = \max(total[j],\; s[i] + total[j - h[i]]) total[j]=max(total[j],s[i]+total[j−h[i]])

total 初始全为 0，表示一本书都不买时页数为 0。处理完所有书后，total[x] 就是在预算不超过 x 时可获得的最大页数。时间复杂度为 O(nx)O(nx)O(nx)，空间复杂度为 O(x)O(x)O(x)。

Array Description

题目大意：有一个长度为 n 的数组，每个元素都在 1 到 m 之间，相邻元素之差不超过 1。部分位置的值未知，用 0 表示，求满足条件的填法数量，答案对 109+710^9+7109+7 取模。

解题思路：设 dp[i][j] 表示填好前 i 个位置，且第 i 个位置恰好填 j 的方案数。相邻元素之差不超过 1，因此第 i - 1 个位置只能填 j - 1、j 或 j + 1：

dp[i][j]=dp[i−1][j−1]+dp[i−1][j]+dp[i−1][j+1](mod109+7)dp[i][j] = dp[i-1][j-1] + dp[i-1][j] + dp[i-1][j+1] \pmod {10^9+7} dp[i][j]=dp[i−1][j−1]+dp[i−1][j]+dp[i−1][j+1](mod109+7)

若 a[1] == 0，第一个位置可以填 1 到 m 中的任意值；代码还将无效状态 dp[1][0] 设为 1，但后续转移只接受 k 位于 1 到 m，因此它不会参与答案。若 a[1] 已知，则只令 dp[1][a[1]] = 1。之后，未知位置枚举所有可能的 j，已知位置只更新 dp[i][a[i]]。最终将 dp[n][1] 到 dp[n][m] 相加。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Counting Towers

题目大意：用宽、高都为整数的方块搭建一座宽为 2、高为 n 的塔，问有多少种不同的搭建方式（左右对称的算不同），答案对 109+710^9+7109+7 取模。

解题思路：从下往上考虑塔的分界线，只需记录顶部两列是否连成一个整体。设 towers[i][1] 表示高度为 i、顶部两列连通的方案数，towers[i][0] 表示顶部两列彼此独立的方案数。高度为 1 时，这两种状态各有一种基本拼法。

继续向上延伸时，顶部连通状态有 4 种保持连通的方式，也可以由顶部独立状态用 1 种方式转入；顶部独立状态有 2 种保持独立的方式，也可以由顶部连通状态用 1 种方式转入。因此：

towers[i][1]=4⋅towers[i−1][1]+towers[i−1][0],towers[i][0]=towers[i−1][1]+2⋅towers[i−1][0].\begin{aligned} \text{towers}[i][1] &= 4\cdot \text{towers}[i-1][1] + \text{towers}[i-1][0],\\ \text{towers}[i][0] &= \text{towers}[i-1][1] + 2\cdot \text{towers}[i-1][0]. \end{aligned} towers[i][1]towers[i][0]​=4⋅towers[i−1][1]+towers[i−1][0],=towers[i−1][1]+2⋅towers[i−1][0].​

代码预处理 towers[1] 到 towers[N - 1]，每次询问直接输出两个状态之和并取模。预处理时间复杂度为 O(N)O(N)O(N)，每次询问为 O(1)O(1)O(1)，空间复杂度为 O(N)O(N)O(N)。

Edit Distance

题目大意：求把字符串 a 变成字符串 b 的最少操作次数，允许的操作是插入一个字符、删除一个字符、替换一个字符。

解题思路：经典编辑距离 DP。设 distance[i][j] 表示把 a 的前 i 个字符变成 b 的前 j 个字符所需的最少操作数。边界：distance[i][0] = i（全删）、distance[0][j] = j（全插）。

对非空前缀，根据两个前缀的末尾字符考虑三类操作：

  • 删除 a[i - 1]：distance[i - 1][j] + 1；
  • 在末尾插入 b[j - 1]：distance[i][j - 1] + 1；
  • 处理两个末尾字符：若 a[i - 1] == b[j - 1]，不增加操作；否则将前者替换为后者，增加一次操作。

第三种情况在代码中合写为 distance[i - 1][j - 1] + (a[i - 1] != b[j - 1])。三者取最小值即可得到当前状态，答案为 distance[n][m]。时间复杂度和空间复杂度均为 O(nm)O(nm)O(nm)。

Longest Common Subsequence

题目大意：给定两个整数数组，求它们的最长公共子序列（LCS）的长度，并输出一个具体的 LCS。

解题思路：设 lcs[i][j] 表示 a 的前 i 个元素与 b 的前 j 个元素的 LCS 长度：

  • 若 a[i] == b[j]，这个相同元素可以接到前两个更短前缀的 LCS 后面，因此 lcs[i][j] = lcs[i - 1][j - 1] + 1；
  • 否则当前两个元素不能同时接入答案，只需取 lcs[i - 1][j] 与 lcs[i][j - 1] 的较大值。

长度为 lcs[n][m]。恢复序列时从状态 (n, m) 反向移动：若 a[n] == b[m]，将该元素加入答案，并同时减小 n、m；否则，若 lcs[n - 1][m] == lcs[n][m]，说明可以舍去 a[n]，只减小 n，反之减小 m。回溯得到的元素顺序相反，最后调用 reverse。DP 的时间复杂度和空间复杂度均为 O(nm)O(nm)O(nm)，回溯为 O(n+m)O(n+m)O(n+m)。

Rectangle Cutting

题目大意：a×b 的矩形，每次可以沿整数线把某个矩形水平或竖直切成两个，求把整块切成若干正方形所需的最少切割次数。

解题思路：区间状 DP。设 moves[i][j] 表示把 i×j 的矩形完全切成正方形所需的最少切割次数。若 i == j 它已经是正方形，moves[i][j] = 0；否则必须在某条整数线上切一刀，把矩形分成两块再各自处理：

  • 沿第一条边切：枚举 1 <= x < i，代价为 moves[x][j] + moves[i - x][j] + 1；
  • 沿第二条边切：枚举 1 <= y < j，代价为 moves[i][y] + moves[i][j - y] + 1。

取所有切法中的最小值。每次转移只依赖边长更小的矩形，因此按 i、j 从小到大计算即可。答案为 moves[a][b]，时间复杂度为 O(ab(a+b))O(ab(a+b))O(ab(a+b))，空间复杂度为 O(ab)O(ab)O(ab)。

解题思路：所有路径字符串的长度都是 2n−12n-12n−1，因此可以按位置逐字符贪心。做法是按步数逐层推进：

初始只有起点 (0, 0)，先输出 grid[0][0]。之后每一步从当前保留的所有格子出发，收集它们向右、向下能够到达的候选格子。找出候选中的最小字符，只保留字符等于该最小值的格子，并将这个字符接到答案末尾。因为当前层之前的前缀已经最小，所以本层选择尽可能小的字符一定能得到最小前缀；字符更大的候选之后无论怎样延伸，都不可能反超。

Removal Game

题目大意：n 个数排成一列，两人轮流从两端取走一个数并累加到自己的得分，双方都按最优策略行动，求先手最终能得到的最大得分。

解题思路：采用区间 DP，并记录当前玩家相对对手的最大分差。处理固定长度的区间 [l, r] 时，score[l] 表示当前玩家在这个区间上最终能比对手多得多少分。若取左端 x[l]，对手接下来在 [l + 1, r] 上能取得的相对分差为 score[l + 1]，所以当前玩家的净优势为 x[l] - score[l + 1]；取右端时同理：

Two Sets II

题目大意：将 1 到 n 的所有整数分成两个集合，使两个集合的元素和相等。交换两个集合不产生新的划分，求不同划分的数量，答案对 109+710^9+7109+7 取模。

解题思路：所有数字之和为 total = n * (n + 1) / 2。若 total 为奇数，不可能均分，答案为 0；否则每组的目标和为 half = total / 2。

直接统计 1 到 n 中和为 half 的子集会把每个划分计算两次。代码采用更直接的去重方式：只从 1 到 n - 1 中选择和为 half 的子集。任意合法划分中，n 恰好属于一组，另一组不含 n，且它唯一对应 {1, ..., n - 1} 中一个和为 half 的子集，因此每个划分恰好被计算一次。

设 sets[s] 表示从已经处理的数字中选出总和为 s 的子集数量，初始化 sets[0] = 1。依次加入 x = 1 到 n - 1，并让 s 从 half 倒序更新 sets[s] += sets[s - x]，从而保证每个数字最多使用一次。答案为 sets[half]。时间复杂度为 O(n⋅half)=O(n3)O(n\cdot \text{half})=O(n^3)O(n⋅half)=O(n3)，空间复杂度为 O(n2)O(n^2)O(n2)。

Mountain Range

题目大意：n 座山排成一列，每座有高度。从一座山出发可以沿滑翔路径"跳到"一座更矮的山，要求它比起点矮、且比两座山之间的所有山都矮（即中间没有比终点更高的山挡路）。求从某一座山出发，一条路线最多能经过多少座山。

解题思路：按高度从高到低处理山峰，令当前位置 p 的 count 表示一条以 p 为最后一站的最长路线长度。处理 p 时，已经加入数据结构的都是更高的山。能够直接滑到 p 的前驱只可能是 p 左右两侧最近的已处理位置：更远的高山会被这两个最近位置中的某一个挡住。因此有转移：

count(p)=1+max⁡(count(左邻),count(右邻))\text{count}(p) = 1 + \max(\text{count}(左邻), \text{count}(右邻)) count(p)=1+max(count(左邻),count(右邻))

代码用 map<int, int> counts 维护已经生效的位置及其路径长度，并加入 counts[0] = 0、counts[n + 1] = 0 两个哨兵。对位置 pos，upper_bound(pos) 找到右侧最近位置，向前一步则得到左侧最近位置，取两者路径长度的较大值再加 1。

同高度的山不能互相跳转，因此同一高度计算出的结果先存入 updates，直到开始处理更矮的高度时才统一写入 counts。最后一组更新无需再写入，因为其结果已经在计算时用于更新 result。排序和每次 map 操作的总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Increasing Subsequence

题目大意：求数组中最长严格递增子序列（LIS）的长度。

解题思路：用树状数组维护值域前缀中的 LIS 最大长度。先将数组值离散化为从 1 开始的排名，再按原顺序处理每个 a[i]。函数 g(p) 查询离散值不超过 p 的元素能够形成的最大 LIS 长度，函数 f(p, v) 则用最大值 v 更新位置 p 及其后继节点。

  • 以 a[i] 结尾的 LIS 长度 = g(a[i] - 1) + 1（前面比它小的所有值里最长的，再接上自己）；
  • 用这个长度更新树状数组中位置 a[i] 处的最大值。

查询 g(a[i] - 1) 排除了与 a[i] 相等的值，因此得到的是严格递增子序列。每个元素进行一次查询和一次更新，答案取所有新长度的最大值。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Projects

题目大意：给定 n 个项目，每个项目都有开始日期、结束日期和奖励。选择的任意两个项目都不能在同一天进行，求能够获得的最大奖励总和。

解题思路：将每个项目拆成开始事件和结束事件，并按时间排序扫描。result 表示只使用已经结束的项目能够获得的最大奖励，money[i] 表示选择第 i 个项目后能够获得的最大奖励：

  • 遇到开始事件：此时 result 只包含结束日期严格早于当前日期的项目，因此令 money[i] = result + p[i]；
  • 遇到结束事件：项目 i 此时可以成为后续项目的前驱，用 money[i] 更新 result。

同一日期内，开始事件的 is_end 为 false，结束事件为 true，因此开始事件会排在结束事件之前。这样，某天开始的项目不会接在同一天才结束的项目之后，符合两个项目不能共享日期的要求。排序复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，扫描复杂度为 O(n)O(n)O(n)，额外空间复杂度为 O(n)O(n)O(n)。

Elevator Rides

题目大意：n 个人（n <= 20）体重已知，电梯一次最多载重 x，每次载一批人往返一趟，求把所有送到顶楼所需的最少趟数。

解题思路：使用状态压缩 DP。设 best[s] 为二元组“已经使用的趟数、最后一趟的当前载重”，表示送走集合 s 中所有人的最优安排。pair 的字典序比较会先最小化趟数，再最小化最后一趟的当前载重；当前载重越小，剩余容量越大，越利于继续加入其他人。

代码令 best[0] = {1, 0}，把当前尚未装人的第一趟也计入状态。对每个非空集合 s，枚举最后加入的人 p，先查看子集 s ^ (1 << p) 的最优状态 (r, l)。若 l + w[p] <= x，则把 p 放入当前最后一趟，得到 {r, l + w[p]}；否则新开一趟，得到 {r + 1, w[p]}。对所有选择取字典序最小值。答案为 best[(1 << n) - 1].first，时间复杂度为 O(n2n)O(n2^n)O(n2n)，空间复杂度为 O(2n)O(2^n)O(2n)。

Counting Tilings

题目大意：用 1×21\times21×2 和 2×12\times12×1 的骨牌铺满 n×mn\times mn×m 网格，求不同铺法的数量。其中 n <= 10、m <= 1000，答案对 109+710^9+7109+7 取模。

解题思路：逐列进行状态压缩 DP。一个 n 位掩码表示某列中被横向骨牌占用的格子。代码先用 generate(i, left, right) 枚举一列内所有合法覆盖方式，并记录相邻两列的状态对 (left, right)。

递归处理第 i 行时有三种选择：只在 left 的第 i 位放置横向占用、只在 right 的第 i 位放置横向占用，或用一块竖向骨牌覆盖当前列的第 i、i + 1 行并跳过两行。到达 i == n 时，说明这一列已经被完整覆盖，当前 (left, right) 是一组合法转移。若竖向骨牌越过边界，递归会到达 i > n 并直接丢弃。

DP 中，prev[x] 表示处理完若干列后，边界处状态为 x 的方案数。初始 prev[0] = 1；每处理一列，就对所有合法转移 (x, y) 执行 cur[y] += prev[x]。处理完 m 列后，只有状态 0 表示没有骨牌伸出网格，因此答案为 prev[0]。时间复杂度为 O(mT)O(mT)O(mT)，其中 TTT 是预处理出的合法转移数量，空间复杂度为 O(2n+T)O(2^n+T)O(2n+T)。

Counting Numbers

题目大意：统计闭区间 [a, b] 内、十进制表示中没有两个相邻数字相同的整数个数。

解题思路：使用数位 DP，并将区间计数转化为 count(b) - count(a - 1)。函数 count(x) 统计 0 到 x 中满足条件的整数个数；递归状态 recurse(i, prev, equal, empty) 表示正在填写第 i 位，其中 prev 是上一位数字，equal 表示当前前缀是否仍与上界 s 相同，empty 表示此前是否全是前导零。

  • 若 equal 为真，当前数字 d 不能超过 s[i]；
  • 若已经出现过非前导零数字，即 empty 为假，则 d 不能等于 prev；
  • 下一层的两个布尔状态分别更新为 equal && d == s[i] - '0' 和 empty && d == 0。

前导零不参与相邻数字比较，所以较短的数字能够自然表示；全程保持 empty 的路径对应整数 0，因此 count(0) 返回 1。代码用 map<array<int, 4>, ll> 对状态记忆化。设十进制位数为 LLL，状态数量为 O(40L)O(40L)O(40L)，每个状态枚举 10 个数字，时间复杂度为 O(L)O(L)O(L) 量级，空间复杂度为 O(L)O(L)O(L)。

Increasing Subsequence II

题目大意：统计数组中严格递增子序列的总个数（值严格递增，不同位置组成的序列算不同），答案对 109+710^9+7109+7 取模。

解题思路：先将所有值离散化，再按原顺序处理元素 b[i]。树状数组 BIT 按离散后的值维护递增子序列数量的前缀和；sum(x) 查询末尾值不超过 x 的递增子序列总数，add(x, v) 则把数量 v 累加到末尾值为 x 的位置。

  • 以 b[i] 结尾的子序列 = 单独一个元素自己（1 种）+ 接在任何"值小于 b[i] 的递增子序列"后面。用树状数组查 sum(b[i] - 1) 得到所有更小值的子序列个数之和，再加 1 就是 num；
  • 把 num 累加到树状数组的 b[i] 位置（取模），并累进总答案。

查询 sum(b[i] - 1) 只统计末尾值严格小于当前值的子序列，再加上仅包含当前元素的一种方案，得到 num。随后将 num 更新到位置 b[i]，并累加到总答案。每个不同位置作为结尾产生的子序列会分别计数。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
