Nearest Shops*

题目大意：无向图（n,m≤105n, m \le 10^5n,m≤105），其中 k 个城市有动漫商店。对每个城市，求它到另一个有店城市的最短距离（不算它自己；若只有一家店则输出 -1）。

解题思路：多源 BFS（所有源点同时入队、距离 0，一次 BFS 得到每个点到最近源点的距离）。把所有有店城市入队、dist = 0，BFS 扩展得每个城市到最近店的距离 dist，逐城市输出（店城市自身为 0）。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Prüfer Code

题目大意：给定一棵树的 Prüfer 序列（n−2n - 2n−2 个数），重建原树并输出 n−1n - 1n−1 条边。

解题思路：Prüfer 序列（nnn 个节点标号树与长度 n−2n-2n−2 的序列一一对应；每个节点在序列中出现次数 = 其度数 − 1，故度数为 1 的叶子恰是序列中出现 0 次的节点）。用小根堆维护当前所有叶子：每次取出最小叶子与序列当前项 code[i] 连边（"删最小叶子"的逆过程），并把 code[i] 出现次数减 1，减到 0 说明它成为新叶子、入堆。处理完序列后堆里剩两个节点，连最后一条边。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Tree Traversals

题目大意：给定二叉树的先序遍历和中序遍历（值互不相同），输出后序遍历。

解题思路：递归（先序 = 根 + 左子树先序 + 右子树先序；中序 = 左子树中序 + 根 + 右子树中序；后序 = 左 + 右 + 根）。先序第一个元素是根，在中序中定位根的位置 m（pos 数组预存每个值在中序的下标），则中序 [il,m−1][il, m-1][il,m−1] 是左子树、[m+1,ir][m+1, ir][m+1,ir] 是右子树；左子树大小 leftLen = m - il，对应先序 [pl+1,pl+leftLen][pl+1, pl+leftLen][pl+1,pl+leftLen]。递归构造左右子树后再输出根（后序）。时间复杂度为 O(n)O(n)O(n)。

Course Schedule II

题目大意：课程有先后依赖，输出一个拓扑序，使得课程 1 尽可能早完成，其次课程 2 尽可能早，以此类推（满足"最小字典序"偏好的拓扑序）；有环输出 IMPOSSIBLE。

解题思路：

  • 观察：正向小根堆拓扑是错的（反例：2 依赖 1、3 依赖 1——正向最小堆输出 2,3,1，但 1 可以更早完成）。要求"字典序最小的拓扑序"，可转而求反图上"字典序最大的拓扑序"再倒序：倒序序列中编号大的尽量靠后，等价于编号小的尽量靠前。

  • 做法：建反向图做大根堆拓扑（每步取编号最大的可修课程），把得到的顺序倒过来输出；出队数不足 n 说明有环，输出 IMPOSSIBLE。

  • 正确性：反图的拓扑序倒置仍是原图的拓扑序；大根堆贪心使倒置后的序列字典序最小（标准对偶论证）。时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Acyclic Graph Edges

题目大意：给定无向图，给每条边定向，使得到的有向图无环，输出每条边的方向。

解题思路：把每条边从编号小的端点指向编号大的端点：所有边方向一致地从小编号指向大编号，任何有向路径上的编号都严格递增，不可能成环。时间复杂度为 O(m)O(m)O(m)。

Strongly Connected Edges

题目大意：给无向图（n,m≤105n, m \le 10^5n,m≤105）的每条边定向，使得到的有向图强连通；无解输出 IMPOSSIBLE。

解题思路：

  • 观察：有解当且仅当图连通且没有桥（桥无论怎么定向，两侧都不连通）。构造：对每个连通块做 DFS 生成树——树边按父→子定向，回边按"当前点→祖先"定向（DFS 中已访问的邻居必是祖先）。

  • 做法：先用 Tarjan 求桥判无解（有桥输出 IMPOSSIBLE），再数连通块（>1 也 IMPOSSIBLE）；随后 DFS 定向：未访问邻居是树边定向父→子，已访问邻居定向当前点→它（即子→祖）。

  • 正确性：每个点都能沿树边走到根、根沿树边到每个点；回边保证每个点还能"绕上去"，故定向后强连通。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Even Outdegree Edges

题目大意：给无向图（n,m≤105n, m \le 10^5n,m≤105）的每条边定向，使每个节点的出度为偶数；无解输出 IMPOSSIBLE。

解题思路：

  • 做法：初始把每条边"向下"定向：DFS 生成树边父→子，回边祖→孙（注意与「Strongly Connected Edges」相反）。然后按后序遍历调整：若节点 v 当前出度为奇数，就把它连向父亲的树边翻转（出度 −1、父亲出度 +1）——处理到根之前所有非根节点都被修正为偶数。

  • 正确性：出度和 = 边数，故根节点的出度奇偶 = 该连通块边数的奇偶；根出度仍为奇数说明该块边数为奇，无解（输出 IMPOSSIBLE）。最后验证全部偶数并输出。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Graph Girth

题目大意：无向图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），求最短环的长度（围长），无环输出 -1。

解题思路：对每个点 i 做 BFS 找经过它的最短环：把 i 的所有邻居按"来自哪个搜索分支"打 tree 标记并入队；BFS 中若遇到已访问点 nxt，且它与当前点分支不同、也不是 i 本身，则 dist[nxt] + dist[s] + 1 是一条经过 i 的环的长度（两分支分别走到 nxt、s，再加回边），取最小值。所有起点取最小即围长（无环输出 -1）。时间复杂度为 O(n(n+m))O(n(n+m))O(n(n+m))。

Fixed Length Walk Queries

题目大意：无向图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），q 次询问（q≤105q \le 10^5q≤105）：从 a 出发能否用恰好 x 步走到 b（可以重复经过节点和边）。

解题思路：

  • 观察：无向图上的 walk（可重复经过节点边）要么只能按固定奇偶到达某点（所在块为二分图），要么两种奇偶都可达（块内含奇环）。把询问按起点 a 分组离线，对每个起点做奇偶分层 BFS：dist0[v]/dist1[v] 分别为到 v 的偶数长度/奇数长度最短 walk（状态 (v, 奇偶) 的两层 BFS）。

  • 做法：询问 (b, k) 取与 k 同奇偶的 need（dist1[b] 或 dist0[b]），若 need != -1 且 k >= need 则 YES——比最短多出的步数可沿一条边来回走补足（奇环情形奇偶分层已自动处理）。

  • 正确性：任何合法 walk 长度 ≥ 同奇偶最短长度且差为偶数，来回走补足差值即得恰好 k 步。k 超过 10910^9109 与 10910^9109 等价。总时间复杂度为 O(n(n+m)+q)O(n(n+m)+q)O(n(n+m)+q)。

Transfer Speeds Sum

题目大意：一棵带权树（n≤2×105n \le 2 \times 10^5n≤2×105），两点之间的传输速度等于它们路径上边权的最小值。求所有点对传输速度之和。

解题思路：

  • 观察：按边权从大到小处理边，边 (a,b,w)(a,b,w)(a,b,w) 连接的两个连通块 A、B 中，任意跨块点对的路径最小边权恰为 w（更小的边尚未处理、路径上其余边或不在当前树中或权更大），贡献 ∣A∣×∣B∣×w|A|\times|B|\times w∣A∣×∣B∣×w。

  • 做法：边按权降序，并查集维护块大小；每处理一条边把贡献累加后合并两端块。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

MST Edge Check

题目大意：带权无向图（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），对每条边判断它能否出现在某个最小生成树中。

解题思路：

  • 观察：Kruskal 按权分组处理。一条边能出现在某个 MST 中，当且仅当把所有更小权的边加入后它的两端仍不连通（不会被 Kruskal 跳过）。

  • 做法：边按权排序，同权的一组先统一"检查"（看两端在只含更小权边的并查集中是否连通，不连通则 ans[id] = true），再统一"合并"。时间复杂度为 O(mlog⁡m)O(m\log m)O(mlogm)。

MST Edge Set Check*

题目大意：带权无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），q 个查询，每个查询给一个边集，判断这些边能否同时出现在某个最小生成树中（查询总边数不超过 mmm）。

解题思路：

  • 做法：对每个查询，把查询边按权排序，用可回滚并查集（只按大小合并、修改压入历史栈，rollback 弹栈恢复）模拟 Kruskal 到相应权重：先把全局所有权更小的边合并进去，再逐条检查查询边——两端已连通说明该边在 Kruskal 中会被跳过（成环），查询失败；否则把它也合并（同权边之间先检查后合并）。处理完一个查询回滚到快照恢复并查集。

  • 正确性：查询边能同时进 MST 当且仅当按 Kruskal 顺序逐条加入时没有一条被跳过；回滚使各查询互不影响。总时间复杂度为 O((m+∑q∣查询q∣)log⁡m⋅α)O((m+\sum_q|\text{查询}_q|)\log m\cdot\alpha)O((m+∑q​∣查询q​∣)logm⋅α)。

MST Edge Cost

题目大意：带权无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），对每条边求"强制包含这条边"的最小生成树的总代价。

解题思路：

  • 观察：先跑 Kruskal 建出一个 MST（总代价 mstW）。树边的答案即 mstW。非树边 (a,b,w)(a,b,w)(a,b,w)：加入 MST 会与树上 a→ba\to ba→b 路径成环，删掉环上最大权边（正是 Kruskal 选这条边时会跳过的那条）得新 MST，答案 =mstW−pathMax(a,b)+w=mstW-pathMax(a,b)+w=mstW−pathMax(a,b)+w。

解题思路：

  • 观察：多源 BFS 求出每个点 x 到最近硬币点的距离 d[x]。从 a 走到 b 必须经过硬币，最优是在路径上离硬币最近的点 x 处岔出去打来回（2d[x]2d[x]2d[x]），故答案 =dist(a,b)+2min⁡x∈path(a,b)d[x]=dist(a,b)+2\min_{x\in path(a,b)}d[x]=dist(a,b)+2minx∈path(a,b)​d[x]。

Tree Coin Collecting II*

题目大意：一棵树（n≤2×105n \le 2 \times 10^5n≤2×105），k 个节点有硬币。q 次询问：从 a 出发，访问所有硬币节点，最后到达 b，求最短路径长度。

解题思路：

  • 观察：答案是"硬币 + 两端点"的斯坦纳树（连通指定点集的最小边集）的欧拉回路长度减去 dist(a, b)：访问所有硬币的最优走法 = 沿斯坦纳树走一圈（每条边两次）再省去从 a 到 b 的一段单程。

  • 做法：多源 BFS 求每个点到最近硬币的距离 distCoin 与锚点 anchor（最近的硬币）。计算硬币集合的虚树边权和 S：把硬币按欧拉序 tin 排序，环上相邻点距离之和的一半即虚树边数。询问 (a, b)：设 ca = anchor[a]、cb = anchor[b]，答案 =2S−dist(ca,cb)+dist(a,ca)+dist(b,cb)=2S-dist(ca,cb)+dist(a,ca)+dist(b,cb)=2S−dist(ca,cb)+dist(a,ca)+dist(b,cb)——从 a 到最近硬币、沿虚树欧拉回路访问全部硬币（结尾在 cb，故省去 ca→cbca\to cbca→cb 一段）、再去 b。

  • 正确性：虚树回路覆盖所有硬币且每条虚树边恰走两次；首尾的锚点衔接使总长为最小。总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Tree Isomorphism I*

题目大意：t 组测试，判断两棵有根树（根均为节点 1）是否同构。

解题思路：AHU 算法（有根树同构的规范化编码：自底向上给每棵子树算一个字符串编码，两子树同构当且仅当编码相同）。节点 v 的编码 = ( + 所有孩子的子树编码排序后拼接 + )。归纳：根对应、子树多重集同构当且仅当排序后的编码序列相同。两棵树以各自根算编码比较即可。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)（每层排序）。

Flight Route Requests

题目大意：n 个城市（n≤105n \le 10^5n≤105），给出 m 条"请求"（希望从 a 能到达 b）。可以在任意城市间添加单向航线，求最少添加多少条航线，使所有请求都被满足。

解题思路：

  • 观察：把 m 条请求看成需求图 G 的边，我们只允许新加单向航线 H，要求 G 的每条请求边 (a,b) 在 H 中存在 aaa 到 bbb 的有向路径。若 a、b 在 G 的同一个强连通分量（SCC，两两互相可达的极大顶点集）内，则它们在 H 中必互相可达：请求链 a→x1→⋯→ba\to x_1\to\cdots\to ba→x1​→⋯→b 每段都要求 H 中一段向前可达，串起来得 a 在 H 中可达 b；反向同理。故 H 必须把每个大 SCC 的全部点放进 H 的同一个强连通分量里。

  • 做法：按 G 的弱连通分量（WCC，忽略方向后的连通块）独立计算。设某 WCC 有 N 个点：H 在其中的边数下界为 N−1+(#大小≥2 的 H-SCC)N-1+(\#\text{大小}\ge2\text{ 的 }H\text{-SCC})N−1+(#大小≥2 的 H-SCC)（每个大 H-SCC 内部强连通至少需其大小条边，H-SCC 之间沿请求方向连通至少需个数减一条边）；WCC 含大 SCC 时至少有一个大 H-SCC，下界为 N，全单点时下界为 N−1N-1N−1。两个下界均可达到：全单点时按拓扑序连成一条链（N−1N-1N−1 条边，所有请求在拓扑序中都向前）；含大 SCC 时按拓扑序首尾相接成环（NNN 条边，整块强连通）。

  • 正确性：综上 ans=n−w+bans=n-w+bans=n−w+b，其中 w 为 WCC 数、b 为含大 SCC 的 WCC 数；代码等价地写为 ans=(c−w)+∑∣SCC∣≥2(∣SCC∣−1)+bans=(c-w)+\sum_{|SCC|\ge2}(|SCC|-1)+bans=(c−w)+∑∣SCC∣≥2​(∣SCC∣−1)+b（c 为 SCC 数，由 n=c+∑∣SCC∣≥2(∣SCC∣−1)n=c+\sum_{|SCC|\ge2}(|SCC|-1)n=c+∑∣SCC∣≥2​(∣SCC∣−1)）。迭代 Kosaraju 求 SCC、并查集求 WCC。

  • 边界：迭代 DFS 避免深递归栈溢出；sz[i] > 1 判定大 SCC。总时间复杂度为 O(n+m)O(n+m)O(n+m)。

Critical Cities

题目大意：n 个点的有向图（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），找从 1 到 n 的所有路径都必经的城市（含 1 和 n），升序输出。

解题思路：

  • 观察：必经城市即支配树（dominator tree：点 d 支配 v 当且仅当从源到 v 的每条路径都经过 d；支配关系构成一棵树，idom[v] 是 v 的最近支配者）上从源 1 到 n 的祖先链——v 被 w 支配当且仅当 w 是支配树中 v 的祖先，故"支配 n 的所有点"即从 n 沿 idom 走到根经过的点（1 与 n 自身天然包含）。

  • 做法：Lengauer-Tarjan 算法建支配树：对正图 DFS 得 DFS 树与 DFS 序；semi[v]（半支配点）是最小的 w 使存在路径 w→x1→⋯→vw\to x_1\to\cdots\to vw→x1​→⋯→v 且中间所有点 DFS 序大于 v——“能绕过 v 的 DFS 树祖先、最早到达 v 的点”；idom[v] 必在 v 与 semi[v] 之间的 DFS 链上。按 DFS 序倒序处理：求 semi 用带权并查集维护"节点到当前已处理祖先之间 semi 最小的点"（uni_query 路径压缩时合并最小值）；随后沿 semi 链求 idom 并做最后修正。

  • 正确性：Lengauer-Tarjan 的正确性由半支配点的递归刻画保证；从 n 沿 idom 链走到 0 收集到的点升序输出即所有必经城市。时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

题目大意：带权有向图（n≤105n \le 10^5n≤105），求所有最短路径上一定经过的城市。

解题思路：

  • 观察：城市 u 必在所有最短路上当且仅当：(1) dist[0][u] + dist[1][u] == dist[0][n]（u 在至少一条最短路上，dist[0] 为从 1 正向、dist[1] 为从 n 反向的 Dijkstra 结果）；(2) 经过 u 的最短路径数 = 总最短路数。

解题思路：

  • 观察：能否分成两条路径等价于最小路径覆盖 ≤2\le2≤2。DAG 的最小路径覆盖（覆盖全部顶点的最少条点不相交路径数）= n − 最大匹配：拆点二分图中左边每个点匹配一个后继，匹配边把路径串起来，每匹配一条边路径数减 1。

  • 做法：Hopcroft-Karp 求最大匹配（bfs 分层 + dfs 增广，复杂度优于朴素匈牙利）。若 n − 匹配数 > 2 输出 NO；否则沿匹配边还原路径：nxt[u] = matchL[u]，从没有前驱的点出发走链得到若干条路径（少于 2 条时补空路径）。

  • 观察：树中唯一的"桥风险"来自叶子（度 1 的节点），把它们两两配对连边即可让每个叶子都处于环上；最少加边数 =⌈叶子数/2⌉=\lceil\text{叶子数}/2\rceil=⌈叶子数/2⌉。

题目大意：一棵树（n≤2×105n \le 2 \times 10^5n≤2×105），选一些节点建办公室，要求任意两个办公室距离至少为 d，求最多能建多少个并输出方案。

解题思路：自底向上的贪心树 DP。先把树排成从叶子到根的处理顺序（栈式 DFS），每个节点维护两个值：mx[u] = 子树中"最远的未被覆盖点到 u 的距离"（无未覆盖点记 -BIG，u 自身未覆盖时至少 0），mn[u] = 子树中"最近的已建办公室到 u 的距离"。

  • 做法：合并所有儿子后：若 mx[u]+mn[u]≤dmx[u]+mn[u]\le dmx[u]+mn[u]≤d，最远未覆盖点已被某办公室覆盖（它们隔着 u），置 mx[u] = -BIG；否则若 mx[u] == d，最远未覆盖点恰在距离上限，必须在 u 建办公室（再上传就超距），置 mn[u] = 0、mx[u] = -BIG。处理完根若仍有未覆盖点（mx[0] >= 0），在根补建。
