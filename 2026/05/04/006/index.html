Counting Rooms

题目大意：给定一张 n×mn \times mn×m 的地图（n,m≤1000n, m \le 1000n,m≤1000），其中 # 表示墙，. 表示地板。只能在地板格之间上下左右移动，求地图中四方向连通的地板区域数量，也就是房间数。

解题思路：遍历地图，每遇到仍为 . 的格子即发现一个新房间，答案加 1 并从该格 DFS：把访问到的地板改为 #（就地标记已访问）并向四个方向递归，直到整个连通块处理完。每个格子至多访问一次，时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)（递归栈最深可达地板格总数）。

Labyrinth

题目大意：给定一张 n×mn \times mn×m 的迷宫（n,m≤1000n, m \le 1000n,m≤1000），A 是起点，B 是终点，# 是墙。每一步可以上下左右移动到非墙格，要求判断能否从 A 到达 B；若可以，还要输出一条最短路径的长度及由 L、R、U、D 组成的移动序列。

解题思路：无权网格最短路用 BFS（按到起点的距离递增逐层扩展，格子第一次被访问时的步数即最少步数）。previous[i][j] 记录该格前驱，last_letter[i][j] 记录从前驱走到这里的方向。若终点 b 未被访问则输出 NO；否则从 b 沿 previous 回溯到 a 收集 last_letter，反转即正向路径。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)。

Building Roads

题目大意：有 n 个城市和 m 条双向道路（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105）。可以在任意两个城市之间新建道路，要求用最少的新道路使所有城市互相可达，并输出道路数量及一种具体方案。

解题思路：设原图有 k 个连通块。一条新路至多合并两个连通块，至少需 k−1k-1k−1 条；把各连通块的代表点依次连成链恰用 k−1k-1k−1 条，下界可达。用并查集（维护不相交集合的数据结构，支持查询元素所在集合的代表元与合并两个集合，单次操作近乎 O(1)O(1)O(1)）读入道路时执行 merge(u, v)，再把每个城市的根 get(i) 放入 set 去重；s.size() - 1 即最少道路数，依次连接 set 中相邻代表点即得方案。时间复杂度为 O((n+m)α(n)+nlog⁡n)O((n+m)\alpha(n)+n\log n)O((n+m)α(n)+nlogn)。

Message Route

题目大意：n 台电脑、m 条双向网线连接（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105）。问能否从 1 号走到 n 号，若能输出最短路径上的电脑数量以及路径上的电脑编号，否则输出 IMPOSSIBLE。

解题思路：从 1 号做 BFS，节点首次入队时即取得最短距离，parent[y] 记录首次到达 y 的前驱。若 n 未被访问则输出 IMPOSSIBLE；否则从 n 沿 parent 回溯——parent[1] 的全局初值 0 作为终止标记——再反转序列得 1 到 n 的最短路径。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Building Teams

题目大意：n 个学生、m 对朋友关系（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），朋友之间不能分到同一队。问能否把所有人分成两队，能则输出每个学生的队号（1 或 2），否则输出 IMPOSSIBLE。

解题思路：学生为顶点、朋友关系为边，问题等价于判定图是否二分图（顶点可分成两组使每条边跨组），可用二染色判定。对每个未访问连通块 DFS：起点染 0，相邻点染相反色 color ^ 1；若某边两端同色则图非二分，置 f = 0。最后把颜色 1 输出为队伍 1、颜色 0 输出为队伍 2。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Round Trip

题目大意：无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），找一条至少经过 3 个不同顶点、能回到起点的环，输出环上的顶点序列；不存在则输出 IMPOSSIBLE。

解题思路：

  • 做法：对每个连通块 DFS，p[v] 记录 DFS 树上 v 的父节点。搜索 u 的邻居时跳过父节点；遇到其它已访问点 v 时记录 s = v、t = u 并立即返回。还原环时先放入 s，再从 t 沿 p[i] 走回 s，补一次 s 后反转。

  • 正确性：无向图 DFS 中除父边外，任意一条连向已访问点的边（返祖边）都连接当前节点与其 DFS 树祖先，它与树上的父指针链恰好围成一个简单环，故首个被发现的这类边即可还原一个环。p、vis 与 dfs 需定义在 solve() 外。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Monsters

题目大意：给定一张 n×mn \times mn×m 的迷宫（n,m≤1000n, m \le 1000n,m≤1000），其中 A 是玩家，M 是怪物，# 是墙。玩家和所有怪物每轮都可以上下左右移动一步。要求判断玩家能否在不与怪物同时到达同一格或更晚到达该格的前提下走到边界，并输出一条逃生路径。

解题思路：玩家能安全进入格子当且仅当到达该格的时间严格早于任意怪物最早到达它的时间。先做多源 BFS（所有怪物同时入队），tim[i][j] 为怪物最早到达时间；再从玩家起点 BFS，只扩展满足 tim[nx][ny] > nt 的格子并用 fa[nx][ny] 记录前驱。首次到达边界即可沿 fa 回溯还原方向串；起点已在边界时直接输出 YES。两次 BFS 的时间复杂度均为 O(nm)O(nm)O(nm)，总空间复杂度为 O(nm)O(nm)O(nm)。

Shortest Routes I

题目大意：n 个城市、m 条单向航线（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），每条从 a 到 b、费用 c。求从 1 号城市出发到每个城市的最短距离（不可达的城市距离保持初始极大值）。

解题思路：边权全正，用 Dijkstra（正权图单源最短路：用小根堆每次取出当前距离最小的未确定节点并松弛其出边）。堆中存 (距离, 节点)；取出 (d, x) 后若 dist[x] < d 说明是更新前的旧状态，直接跳过；否则枚举 x 的出边用 d + len 尝试更新 dist[y] 并入堆。距离用 ll、以 101810^{18}1018 初始化。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

High Score

题目大意：n 个房间、m 条单向隧道（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），每条隧道走过后分数变化可正可负，可以重复走同一条隧道。求从 1 号到 n 号能获得的最大分数；若分数可以无限增大（存在一个从 1 出发且能回到 n 路上的正权环）则输出 -1。

解题思路：

  • 观察：把边权 x 取反为 -x，最大得分问题化为最短路；原图能无限增分的正环对应新图的负环。但只有位于“从 1 可达且能继续到达 n”的路径上的负环才影响答案。

  • 做法：分别在原图 g 与反图 rev_g 上从 1、n 做 BFS，两个可达集合的交集 included 即有效点集。Bellman-Ford（每轮松弛所有边、至多 n 轮）只松弛两端都在 included 中的边；若第 n 轮仍有边被严格更新，说明有效路线中存在负环，输出 -1；否则答案为 -distance[n]。

  • 正确性：任何 1 到 n 的路径上的点必属 included，剔除无效点不会漏判有效负环，也不会被无关负环误判。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Flight Discount

题目大意：给定一张带正权的有向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），从 1 号城市前往 n 号城市时可以对一张航班票使用折扣，使该边费用变为整数除法下的 c / 2。求最小总费用。

解题思路：

  • 观察：折扣“已用/未用”是二元状态，用分层图（把原图的节点复制若干份，每份对应一种状态，层内连原边、层间连状态转移边）表示：第 1 层 1..n 未用折扣，第 2 层 n+1..2n 已用。

  • 做法：对原边 a -> b（费用 c）加三条边：两层内各一条原价边 a -> b、n+a -> n+b，及跨层折扣边 a -> n+b（费用 c/2）。从 1 到 2n 的最短路即恰用一次折扣到 n 的最小费用。

  • 正确性：跨层边只从第 1 层指向第 2 层，任何路径至多用一次折扣；目标 2n 在第 2 层，保证折扣已使用。用 Dijkstra 求最短路。时间复杂度为 O((n+m)log⁡(n+m))O((n+m)\log(n+m))O((n+m)log(n+m))，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Cycle Finding

题目大意：有向带权图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），判断是否存在负环（边权和为负的环），若存在则输出其中一个负环的顶点序列。

解题思路：

  • 做法：把所有 distance 初始化为 0——等价于增设一个向所有节点连零权边的超级源点，能检测图中任意位置的负环（边权和为负的有向环）。Bellman-Ford 松弛 n 轮；第 n 轮仍能更新的节点记为 path_end，它必在负环上或可由负环到达。从 path_end 沿 previous 回退并记录，首次遇到重复节点时即找到环；反转后从首节点输出到其再次出现，得首尾相同的负环序列。

  • 正确性：松弛 n 轮后仍更新的边一定属于某负环或其可达路径；沿前驱链回退 n 步内必入环。无第 n 轮更新则无负环。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Flight Routes

题目大意：求从 1 号到 n 号的前 k 条最短路长度（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105，k≤10k \le 10k≤10）。可以重复经过城市，走的路线不同就算不同（同一条边路径顺序不同也算不同）。

解题思路：

  • 观察：边权为正，按小根堆弹出的顺序，节点第 c 次被有效弹出时对应的路径长度就是到该节点的第 c 小路径长度。

  • 做法：不用布尔访问标记去重，而用 visited[x] 限制每个节点至多扩展 k 次；终点 n 第 c 次被弹出时记录 dist[visited[n]] = d。

  • 正确性：任意路径都以其终点状态入堆，堆弹出顺序单调不减，节点第 c 次弹出对应第 c 短路径；限制扩展次数不影响前 k 短路径的发现。至多扩展 knknkn 个状态、扫描 kmkmkm 条边，总时间复杂度为 O(kmlog⁡(kn+km))O(km\log(kn+km))O(kmlog(kn+km))，空间复杂度为 O(n+m+km)O(n+m+km)O(n+m+km)。

Course Schedule

题目大意：n 门课程、m 条先修关系（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），每条 a b 表示必须先修完 a 才能修 b。求一个合法的学习顺序；若不存在（先修关系成环）则输出 IMPOSSIBLE。

Longest Flight Route

题目大意：n 个城市、m 条单向航线（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），保证图是 DAG。求从 1 号到 n 号、经过城市最多的路径，输出经过的城市数和路径；若 1 号到不了 n 则输出 IMPOSSIBLE。

解题思路：DAG 上记忆化搜索。longest[x] 为从 x 到 n 的最长路径包含的城市数（含 x），next_city[x] 记录最优后继；终点 longest[n] = 1。对每条边 x -> y 先求 f(y)，若 longest[y] + 1 更大则更新 longest[x] 与 next_city[x]。DAG 无环使递归不会循环；不可达 n 的状态保持负值，f(1) < 0 时输出 IMPOSSIBLE，否则沿 next_city 从 1 输出到 0。相关数组与 f 需定义在 solve() 外。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Planets Queries II

题目大意：n 个星球、每个星球指向一个传送目的地（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），q 次询问从 a 传送到 b 至少要多少次，不可达输出 -1。

解题思路：

解题思路：

  • 观察：每条边容量 1，整数流下每个流单位对应一条 1→n 的路径，不同单位不共边，故边不相交路径的最大数量等于最大流值。

  • 做法：Dinic（BFS 建分层图，DFS 沿层级递增的边发送阻塞流，反复直到无增广路）求最大流 k。随后分解：orig 区分原始边与反向边，原始边 e.cap == 0 表示其正承载 1 单位流；每轮从 1 BFS 找一条仅由这类边组成的路径，沿 parent 还原输出，再把该路径上的正向容量恢复 1、反向容量清 0（从总流中删去这条路径），重复 k 轮。

  • 正确性：残余网络中的流可分解为若干条简单路径（流量守恒），orig && cap == 0 的边恰好构成这些路径；逐条剥离后恰好输出 k 条边不相交路径。Dinic 在单位容量网络上的时间复杂度为 O(EE)O(E\sqrt E)O(EE​)，路径分解为 O(kE)O(kE)O(kE)，空间复杂度为 O(n+E)O(n+E)O(n+E)。
