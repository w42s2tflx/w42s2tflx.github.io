Counting Rooms

题目大意：给定一张 n×mn \times mn×m 的地图，其中 # 表示墙，. 表示地板。只能在地板格之间上下左右移动，求地图中四方向连通的地板区域数量，也就是房间数。

解题思路：遍历整张地图。每遇到一个仍为 . 的格子，就说明发现了一个尚未统计的新房间，答案加 1，再从该格开始 DFS。DFS 将访问到的地板改成 #，相当于标记已访问，并继续搜索四个相邻方向，直到整个连通块都被处理完。每个格子至多被访问一次，时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(nm)O(nm)O(nm)，其中递归栈最深可能达到地板格总数。

Labyrinth

题目大意：给定一张 n×mn \times mn×m 的迷宫，A 是起点，B 是终点，# 是墙。每一步可以上下左右移动到非墙格，要求判断能否从 A 到达 B；若可以，还要输出一条最短路径的长度及由 L、R、U、D 组成的移动序列。

解题思路：无权网格中的最短路使用 BFS。BFS 按到起点的距离递增扩展，因此一个格子第一次被访问时，对应的步数就是最少步数。代码用 previous[i][j] 记录该格子的前驱，用 last_letter[i][j] 记录从前驱走到这里所用的方向。搜索结束后，若终点 b 未被访问则无解；否则从 b 沿 previous 回溯到起点 a，收集 last_letter，最后反转字符串即可得到正向路径。时间复杂度和空间复杂度均为 O(nm)O(nm)O(nm)。

Building Roads

题目大意：有 n 个城市和 m 条双向道路。可以在任意两个城市之间新建道路，要求用最少的新道路使所有城市互相可达，并输出道路数量及一种具体方案。

解题思路：设原图有 k 个连通块。一条新路最多合并两个连通块，因此至少需要 k - 1 条路；把各连通块依次连成一条链也恰好只需 k - 1 条，所以该下界可以达到。代码读入道路时用并查集执行 merge(u, v)，随后把每个城市的根 get(i) 放入 set 去重。s.size() - 1 就是最少道路数，再连接 set 中相邻的两个代表点即可构造方案。时间复杂度约为 O((n+m)α(n)+nlog⁡n)O((n+m)\alpha(n)+n\log n)O((n+m)α(n)+nlogn)。

Message Route

题目大意：n 台电脑、m 条双向网线连接。问能否从 1 号走到 n 号，若能输出最短路径上的电脑数量以及路径上的电脑编号，否则输出 IMPOSSIBLE。

解题思路：在无权图中从 1 号点做 BFS，节点第一次入队时得到的就是最短距离，并用 parent[y] 记录首次到达 y 的前驱。若搜索结束后 n 未被访问，则不存在路线；否则从 n 沿 parent 回溯。由于全局数组初值为 0，parent[1] 的 0 可作为回溯终止标记，最后反转序列即可得到从 1 到 n 的最短路径。时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。

Building Teams

题目大意：n 个学生、m 对朋友关系，朋友之间不能分到同一队。问能否把所有人分成两队，能则输出每个学生的队号（1 或 2），否则输出 IMPOSSIBLE。

解题思路：把学生视为顶点、朋友关系视为边，问题就是判断无向图能否二染色。对每个尚未访问的连通块启动 DFS，将起点染为 0，并把相邻点染成相反颜色 color ^ 1。若检查到某条边两端颜色相同，就说明该连通块不是二分图，将 f 设为 0。全部染色完成后，代码把颜色 1 输出为队伍 1、颜色 0 输出为队伍 2。时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。

Round Trip

题目大意：无向图，找一条至少经过 3 个不同顶点、能回到起点的环，输出环上的顶点序列；不存在则输出 IMPOSSIBLE。

解题思路：对每个连通块做 DFS，并用 p[v] 记录 DFS 树中 v 的父节点。搜索 u 的邻居时跳过父节点；若遇到其他已经访问过的点 v，就记录 s = v、t = u 并立即结束搜索。按照这份代码的 DFS 返回方式，首次发现的这条非树边可与父指针链组成一个环。还原时先放入 s，再从 t 沿 p[i] 回到 s，补上一次 s 后反转序列。时间复杂度为 O(n+m)O(n+m)O(n+m)。p、vis 和递归函数 dfs 需要定义在 solve() 外。

Monsters

题目大意：给定一张 n×mn \times mn×m 的迷宫，其中 A 是玩家，M 是怪物，# 是墙。玩家和所有怪物每轮都可以上下左右移动一步。要求判断玩家能否在不与怪物同时到达同一格或更晚到达该格的前提下走到边界，并输出一条逃生路径。

解题思路：玩家能够安全进入格子 (i, j) 的条件是：玩家到达它的时间严格小于任意怪物最早到达它的时间。先把所有怪物同时加入队列，做多源 BFS，用 tim[i][j] 记录怪物到达每个格子的最早时间。然后从 (sx, sy) 再做一次 BFS，只扩展满足 tim[nx][ny] > nt 的格子，并用 fa[nx][ny] 记录前驱。第一次到达边界时即可沿 fa 回溯并还原方向串；若起点已经在边界，代码直接输出 YES，空路径无需额外输出。两次 BFS 的时间复杂度均为 O(nm)O(nm)O(nm)，总空间复杂度为 O(nm)O(nm)O(nm)。

Shortest Routes I

题目大意：n 个城市、m 条单向航线，每条从 a 到 b、费用 c。求从 1 号城市出发到每个城市的最短距离（不可达的城市距离保持初始极大值）。

解题思路：所有边权均为正，可以从 1 号点运行 Dijkstra。小根堆中保存 (距离, 节点)；取出 (d, x) 后，若 dist[x] < d，说明这是节点 x 更新前留下的旧状态，直接跳过。否则枚举 x 的所有出边，用 d + len 尝试更新 dist[y]，更新成功便将新状态压入堆。距离可能达到很大范围，因此用 ll 保存，并以 101810^{18}1018 初始化。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

High Score

题目大意：n 个房间、m 条单向隧道，每条隧道走过后分数变化可正可负，可以重复走同一条隧道。求从 1 号到 n 号能获得的最大分数；若分数可以无限增大（存在一个从 1 出发且能回到 n 路上的正权环）则输出 -1。

解题思路：把每条边的分数 x 改成 -x，最大得分就转化为最短路；原图中能让得分无限增大的正环，也对应新图中的负环。并非所有负环都会影响答案，只有既能从 1 到达、又能继续到达 n 的点才可能出现在有效路线中。代码分别在原图和反图上 BFS，取两个可达集合的交集 included，Bellman-Ford 只松弛两端都在该集合中的边。若第 n 轮仍能严格更新距离，说明有效路线中存在负环，输出 -1；否则最大得分为 -distance[n]。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Flight Discount

题目大意：给定一张带正权的有向图，从 1 号城市前往 n 号城市时可以对一张航班票使用折扣，使该边费用变为整数除法下的 c / 2。求最小总费用。

Cycle Finding

题目大意：有向带权图，判断是否存在负环（边权和为负的环），若存在则输出其中一个负环的顶点序列。

解题思路：将所有 distance 初始化为 0，相当于增加一个向所有节点连零权边的超级源点，因此可以检测图中任意位置的负环。Bellman-Ford 连续松弛 n 轮；若第 n 轮仍有边更新，就把最后更新到的节点记录为 path_end，它位于负环上或可由负环到达。随后沿 previous 不断回退并记录节点，第一次遇到重复节点时，重复部分就是一个环。反转记录后，从首个节点输出到它再次出现为止，即得到首尾相同的负环序列。时间复杂度为 O(nm)O(nm)O(nm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Game Routes

题目大意：DAG 上从 1 号到 n 号一共有多少条不同路径，答案对 109+710^9+7109+7 取模。

解题思路：使用拓扑序 DP。令 dp[u] 表示从 1 到 u 的路径数，初始化 dp[1] = 1。a[v] 保存节点 v 的入度，先把所有入度为 0 的节点加入队列。每取出一个节点 u，就对每条边 u -> v 执行 dp[v] = (dp[v] + dp[u]) % mod，再将 a[v] 减 1；当 a[v] 变为 0 时，将 v 入队。拓扑序保证处理 v 前，它的所有前驱贡献都已经累加完成。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。相关全局数组需要定义在 solve() 外。

Road Reparation

题目大意：n 个城市、m 条可以修复的道路，每条有修复费用。求让所有城市连通所需的最小总费用；无法连通则输出 IMPOSSIBLE。

解题思路：使用 Kruskal 算法求最小生成树。先将所有道路按费用 c 升序排序，再用并查集维护当前已经连通的城市集合。依次扫描边 (a, b, c)：若 a 和 b 已在同一集合，加入该边只会形成环，直接跳过；否则合并两个集合并把 c 加入总费用。处理完后，若 sz[find(1)] != n，说明仍有城市不在 1 号城市所在的连通块中，无法完成修复。时间复杂度为 O(mlog⁡m+mα(n))O(m\log m+m\alpha(n))O(mlogm+mα(n))，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Road Construction

题目大意：一开始 n 个城市两两不连通。之后 m 天每天会加入一条新的路（连接两个城市），输出每天之后的连通块个数以及最大连通块的大小。

解题思路：用并查集在线维护连通块。初始时每座城市单独成块，所以 n_components = n，最大块大小 largest_size = 1。每天加入道路 (a, b)：若两端根节点相同，连通关系没有变化；否则调用 unite(a, b) 按大小合并，连通块数减 1，再用合并后根的 sz[find(a)] 更新最大块大小。每次操作后立即输出两个统计量。时间复杂度为 O((n+m)α(n))O((n+m)\alpha(n))O((n+m)α(n))，空间复杂度为 O(n)O(n)O(n)。

Flight Routes Check

题目大意：有向图，判断是否任意两点都能互相到达（即整张图强连通）；否则输出任意一对不可达的 (a,b)。

解题思路：一张有向图强连通，当且仅当 1 号点能到达所有节点，并且所有节点也都能到达 1 号点。代码分别从 1 在原图 g 和反图 rev_g 上做 DFS。visited1[i] 表示原图中 1 能到达 i；visited2[i] 表示反图中 1 能到达 i，等价于原图中 i 能到达 1。若前者为假，输出 1 i；若后者为假，输出 i 1。两次 DFS 都覆盖所有点时才输出 YES。时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。

Planets and Kingdoms

题目大意：有向图中，两个点在同一"王国"当且仅当它们互相可达。求强连通分量（SCC）的个数，以及每个点所属的分量编号。

Giant Pizza

题目大意：有 n 个顾客和 m 种配料。每位顾客提出两个愿望，+ x 表示希望加入配料 x，- x 表示希望不加入配料 x；每位顾客的两个愿望至少要满足一个。求一种可行的配料方案，或判断无解。

解题思路：这是标准 2-SAT。对配料 x，编号 x 表示选择 + x，编号 x + m 表示选择 - x，二者互为否定。每位顾客的条件是子句 (A∨B)(A \lor B)(A∨B)，等价于两条蕴含边 ¬A→B\neg A \to B¬A→B 和 ¬B→A\neg B \to A¬B→A。建好蕴含图后用 Tarjan 求强连通分量：若 x 与 x + m 属于同一分量，说明选择与不选择可以互相推出，方案无解。Tarjan 在节点出栈时依次给 SCC 编号，这份代码据此用 sccno[x] < sccno[x + m] 选择 +，否则选择 -。时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。图、Tarjan 数组及递归函数需要定义在 solve() 外。

Coin Collector

题目大意：有向图里每个房间有一定数量金币，可以任选起点和终点、沿有向边前进，经过的房间金币都会被收集（每个房间至多收集一次）。求最多能收集多少金币。

解题思路：同一强连通分量中的节点可以互相到达，因此进入一个 SCC 后，可以收集其中所有房间的金币。先用 Tarjan 求 SCC，并把属于同一分量的金币累加到 res[sccno[i]]。再将不同 SCC 之间的原图边加入缩点图 g，它一定是 DAG。记忆化函数 f(u) 表示从分量 u 出发最多能获得的金币，先取所有后继 f(v) 的最大值，再加上当前分量的 res[u]。最终对所有分量取最大值。即使缩点图中存在重复边，也不会影响结果和渐进复杂度。总时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。相关数组与递归函数需要定义在 solve() 外。

Mail Delivery

题目大意：给定一张无向图，要求从 1 号城市出发，经过每条道路恰好一次并最终回到 1 号城市，输出对应的欧拉回路；不存在则输出 IMPOSSIBLE。

解题思路：无向图存在从 1 出发的欧拉回路，需要所有非零度节点与 1 位于同一连通部分，并且每个节点的度数为偶数。代码先检查偶数度，再用 Hierholzer 算法：在 find_cycle(node) 中不断取出 graph[node] 的一条边，同时从两个端点的 set 中删除它，然后递归走向另一端；当前节点没有剩余边时，将它加入 cycle。这种后序加入方式得到的序列本身就是一条欧拉回路。最后用 cycle.size() == m + 1 检查是否确实使用了全部道路，也同时兜底连通性。使用 set 删除边，时间复杂度为 O(mlog⁡n+n)O(m\log n+n)O(mlogn+n)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

De Bruijn Sequence

题目大意：构造一个最短的二进制串，使它的所有长度为 n 的连续子串互不相同（即包含全部 2n2^n2n 种 n 位二进制串）。

解题思路：把每个长度为 n−1n-1n−1 的二进制串看作一个节点。当前状态为 v 时，在末尾追加位 i 可形成长度为 n 的串 u = (v << 1) + i，并转移到 u 的后 n−1n-1n−1 位。于是每个长度为 n 的二进制串恰好对应一条有向边，而每个节点的入度和出度都为 2，可以求欧拉回路。used[u] 标记对应边是否已经使用；DFS 在递归返回时把该边追加的位 i 放入 ans。最后补上起始状态的 n - 1 个 0，得到长度 2n+n−12^n+n-12n+n−1 的序列。时间复杂度和空间复杂度均为 O(2n)O(2^n)O(2n)。相关变量与递归函数 dfs 需要定义在 solve() 外。

Teleporters Path

题目大意：有向图，求从 1 号出发、到 n 号结束、经过每条边恰好一次的路径（欧拉路径），输出经过的顶点序列；不存在则输出 IMPOSSIBLE。

解题思路：从 1 到 n 的有向欧拉路径要求：1 号点的出度比入度多 1，n 号点的入度比出度多 1，其余节点入度等于出度。代码执行 in_degree[1]++ 和 out_degree[n]++，相当于仅在度数检查中补上一条 n -> 1 的边，于是所有节点都应满足入度等于出度。通过检查后，从 1 运行 Hierholzer：不断从 graph[node] 末尾取出一条尚未使用的出边，递归处理后再把当前节点加入 cycle。后序得到的序列需要反转。最后检查 cycle.size() == m + 1，确保所有真实边均已使用。时间复杂度和空间复杂度均为 O(n+m)O(n+m)O(n+m)。

Hamiltonian Flights

题目大意：n 个城市、m 条单向航班（同一起终点的多条航班视为不同路线），求从 1 号出发、恰好经过每个城市一次、最后到达 n 号的路线数，对 109+710^9+7109+7 取模。

解题思路：使用状态压缩 DP，并将城市编号改为 0 到 n - 1。ways[mask][last] 表示已经访问的城市集合为 mask，且当前停在 last 的路线数。初始状态是 ways[1][0] = 1。若 last 属于 mask，上一个状态应删除 last，因此转移为

ways[mask][last]=∑prev∈maskcount[prev][last]⋅ways[mask⊕(1≪last)][prev].ways[mask][last] =\sum_{prev \in mask} count[prev][last]\cdot ways[mask\oplus(1\ll last)][prev]. ways[mask][last]=prev∈mask∑​count[prev][last]⋅ways[mask⊕(1≪last)][prev].

其中 count[prev][last] 是从 prev 到 last 的航班数量，能够正确计入重边形成的不同路线。代码对每次累加后取模，最终答案为 ways[(1 << n) - 1][n - 1]。时间复杂度为 O(n22n)O(n^2 2^n)O(n22n)，空间复杂度为 O(n2n)O(n2^n)O(n2n)。

Knight’s Tour

题目大意：在 8×88 \times 88×8 的国际象棋棋盘上，从给定起点出发，寻找一条经过每个格子恰好一次的骑士巡游路径，并输出每个格子是第几步到达的。

解题思路：采用 DFS 回溯，并使用 Warnsdorff 启发式决定搜索顺序。grid[y][x] 保存格子 (y, x) 的访问步数。每一步枚举所有尚未访问的合法落点，对每个候选调用 degree(new_y, new_x)，计算它下一步还能前往多少个未访问格子，再按该数量升序尝试。优先处理后续选择较少的格子，能显著减少走到末尾无路可走的情况；若某个选择失败，代码将当前格恢复为 0 并回溯。访问到第 64 个格子时直接输出答案并结束程序。最坏时间复杂度仍为指数级，但该启发式在本题固定棋盘上足够快。

Download Speed

题目大意：n 台电脑、m 条单向连接，每条连接有带宽上限，求从 1 号到 n 号最多能传输的带宽（即最大流）。

解题思路：将 1 号电脑设为源点，n 号电脑设为汇点，每条连接建立容量等于带宽的正向边，并建立容量为 0 的反向边。代码使用容量缩放增广：max_flow 从 2622^{62}262 开始逐次将 bit 减半；在固定的 bit 下，dfs(source, bit) 只经过残余容量至少为 bit 的边，若能到达汇点，就沿路径发送恰好 bit 的流量，并同步减少正向残余容量、增加反向残余容量。每次 DFS 前重置 seen，直到当前尺度无法继续增广，再进入下一尺度。该实现的时间复杂度上界可写为 O(E2log⁡C)O(E^2\log C)O(E2logC)，空间复杂度为 O(n+E)O(n+E)O(n+E)，其中 C 为容量上界。

Police Chase

题目大意：无向图，问至少拆掉多少条边能让 1 号与 n 号不连通（即边权为 1 的最小割），并输出这些要拆的边。

解题思路：把每条无向道路看成两个方向、容量均为 1 的连接，问题就转化为从 1 到 n 的最小割。根据最大流最小割定理，最少删除的道路数等于最大流。代码用 Edmonds-Karp：bfs 在残余网络中寻找最短增广路并返回瓶颈容量，parent 用于回溯路径和更新正反向残余容量。最大流结束后，从 1 沿残余容量大于 0 的边 DFS，visited 中的节点构成最小割的源点侧。枚举原始无向边，若两端恰好分属割的两侧，就输出该道路。Edmonds-Karp 的一般时间复杂度为 O(VE2)O(VE^2)O(VE2)，本题空间复杂度为 O(n2+m)O(n^2+m)O(n2+m)。

School Dance

题目大意：n 个男生、m 个女生、k 对"愿意搭档"的组合，同一对只能配对一次，求最多能配成多少对，并输出配对方案（二分图最大匹配）。

题目大意：有向图，每条边（传送器）最多使用一次。每天从 1 号出发沿有向边走一条路到 n 号，问最多能玩多少天，并输出每天的路线（即求边互不相交的路径的最大数量）。

解题思路：给每条有向边设置容量 1，则一个整数流单位对应一条从 1 到 n 的路线，不同流单位不会共用原边。因此边互不相交路径的最大数量等于最大流。代码先用 Dinic 求出最大流 k：BFS 构造分层图，DFS 沿层级递增的边发送阻塞流。随后分解流量。orig 用于区分原始边和反向边；原始边满足 e.cap == 0 时表示该边当前承载了 1 单位流。每轮从 1 BFS 找到一条仅由这类边组成的路径，沿 parent 还原并输出，再把路径上的正向容量恢复为 1、反向容量清为 0，相当于从总流中删去这一条路径。重复 k 次即可。Dinic 在单位容量网络上的时间复杂度为 O(EE)O(E\sqrt E)O(EE​)，路径分解额外需要 O(kE)O(kE)O(kE)，空间复杂度为 O(n+E)O(n+E)O(n+E)。
