Apartments

题目大意：有 n 位申请者和 m 套公寓（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105）。第 i 位申请者期望的面积为 wishes[i]，能够接受的实际面积范围是 [wishes[i]−k,wishes[i]+k][\text{wishes}[i]-k,\text{wishes}[i]+k][wishes[i]−k,wishes[i]+k]。每套公寓至多分给一人，求最多可以满足多少位申请者。

解题思路：双指针。将 wishes 与 sizes 升序排序，i 依次考察申请者，j 指向最小的未处理公寓。若 sizes[j] < wishes[i] - k，该公寓对当前及之后期望更大的申请者都过小，j 后移；跳过所有过小公寓后，若 sizes[j] <= wishes[i] + k，把它分给当前申请者并消耗，否则当前最小公寓已过大，跳过该申请者。把最小的可用公寓分给当前申请者不会占用更大的公寓，故配对数量最大。时间复杂度为 O(nlog⁡n+mlog⁡m)O(n\log n+m\log m)O(nlogn+mlogm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Ferris Wheel

题目大意：有 n 个孩子（n≤2×105n \le 2 \times 10^5n≤2×105），第 i 个孩子的体重为 a[i]。每个座舱最多坐两人，且总重量不能超过 x，求最少需要多少个座舱。

解题思路：排序后双指针，i 指向最轻者、j 指向最重者。最重者 a[j] 必占一个座舱：若能与最轻者 a[i] 同坐（a[i]+a[j]≤xa[i]+a[j]\le xa[i]+a[j]≤x）则配对，i、j 同时移动；否则它连最轻者都无法搭配，单独乘坐，只移动 j。最重者至多只能与最轻者配对，故该选择不影响剩余人的可行性，每轮恰好消耗一个座舱。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Concert Tickets

题目大意：有 n 张价格已知的门票和 m 位依次到来的顾客（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105）。每位顾客给出最高愿付价格 x，需要卖给他一张价格不超过 x 且尽可能贵的票；若没有合适的票则输出 -1。

解题思路：用 multiset（可含重复元素的有序集合）保存未售票价。对每个 x，upper_bound(x) 指向第一个严格大于 x 的票价；若它不在开头，前一个元素就是不超过 x 的最大票价，输出并删除；若在开头，则所有票价都大于 x，输出 -1。每次查询与删除均为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)，空间复杂度为 O(n)O(n)O(n)。

Movie Festival

题目大意：有 n 部电影（n≤2×105n \le 2 \times 10^5n≤2×105），每部电影给出开始时间和结束时间。一个人同一时刻只能观看一部电影，求他最多能完整观看多少部电影。

解题思路：按结束时间从早到晚贪心，end 为上一部已选电影的结束时间，当前电影开始时间 a >= end 时选择它。若最优解这一步选的是另一部结束更晚的电影，替换为当前电影后 end 不增大，后续选择不受影响，故选结束最早者最优。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Missing Coin Sum

题目大意：给定 n 枚面值为正整数的硬币（n≤2×105n \le 2 \times 10^5n≤2×105，面值 ≤109\le 10^9≤109），每枚硬币至多使用一次，求无法由某个硬币子集凑出的最小正整数金额。

解题思路：

  • 做法：排序后维护 largest——已有硬币能凑出 [1,largest][1,\text{largest}][1,largest] 的全部金额。若下一枚 values[i] <= largest + 1，与已有金额组合后区间扩展为 [1,largest+values[i]][1,\text{largest}+\text{values}[i]][1,largest+values[i]]；否则 largest + 1 无法凑出，直接输出。

  • 正确性：values[i] > largest + 1 时，已有硬币最多凑到 largest，后续硬币更大，均不能填补 largest + 1；values[i] <= largest + 1 时，[1,largest][1,\text{largest}][1,largest] 中各金额加上 values[i] 得 [values[i]+1,largest+values[i]][\text{values}[i]+1,\text{largest}+\text{values}[i]][values[i]+1,largest+values[i]]，与 [1,largest][1,\text{largest}][1,largest] 相接或重叠，并集为 [1,largest+values[i]][1,\text{largest}+\text{values}[i]][1,largest+values[i]]。归纳知 largest 始终是最大可凑连续上界。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Collecting Numbers

题目大意：数组是 1 到 n 的一个排列（n≤2×105n \le 2 \times 10^5n≤2×105）。每一轮只能从左到右扫描，并按 1,2,…,n1, 2, \ldots, n1,2,…,n 的顺序收集数字，求收集完所有数字至少需要多少轮。

解题思路：记 pos[x] 为值 x 的位置。一轮扫描只能按位置递增的顺序收集，若 pos[i] < pos[i - 1]，收集到 i - 1 时 i 已被错过，需新开一轮。答案为 111 加满足 pos[i] < pos[i - 1] 的 i 的个数。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Collecting Numbers II

题目大意：给定 1 到 n 的一个排列（n≤2×105n \le 2 \times 10^5n≤2×105），以及 m 次交换操作（m≤2×105m \le 2 \times 10^5m≤2×105）。每次交换位置 u、v 上的数后，输出按顺序收集 1,2,…,n1,2,\ldots,n1,2,…,n 所需的最少轮数。

解题思路：

  • 观察：轮数只取决于相邻值对 (i−1,i)(i-1,i)(i−1,i) 的位置顺序（id[i] < id[i - 1] 计 1），而交换位置 u、v 上的值只可能改变 (x−1,x)(x-1,x)(x−1,x)、(x,x+1)(x,x+1)(x,x+1)、(y−1,y)(y-1,y)(y−1,y)、(y,y+1)(y,y+1)(y,y+1) 至多四个值对的顺序。

  • 做法：把 x 从 u 移到 v 时：若 id[x-1] 在 u 之前（id[x-1] < id[x]）而目标位置 v <= id[x-1]，值对 (x−1,x)(x-1,x)(x−1,x) 由升序变逆序，res++；若 id[x-1] > id[x] 而 v >= id[x-1]，由逆序变升序，res--；对 (x,x+1)(x,x+1)(x,x+1) 同理。更新 id[x] = v 后，对 y 从 v 移到 u 重复同样调整。哨兵 id[0] = 0、id[n + 1] = n + 1 让边界值对无需特判。

  • 正确性：未被移动的值对两端位置均不变，顺序不变；被移动值对的顺序变化由跨越关系精确判定，故每次交换只调整常数个值对即得新轮数。预处理时间复杂度为 O(n)O(n)O(n)，每次交换的时间复杂度为 O(1)O(1)O(1)，总时间复杂度为 O(n+m)O(n+m)O(n+m)。

Josephus Problem II

题目大意：n 个编号为 1 到 n 的孩子（n≤2×105n \le 2 \times 10^5n≤2×105）围成一圈。每次跳过 k 个仍在圈中的孩子，再移除下一个，输出移除顺序。

解题思路：

  • 做法：用支持顺序统计的平衡树（PBDS 的 __gnu_pbds::tree）保存仍在圈中的编号：find_by_order(i) 返回当前第 i 小的元素（从 0 计数），单次 O(log⁡n)O(\log n)O(logn)。初始移除位置 i = k % n；删除后后继元素顺次前移一位，下一次移除位置为 (i + k) % (n - 1)，循环至只剩一人。

Nested Ranges Count

题目大意：给定 n 个区间 [l, r]（n≤2×105n \le 2 \times 10^5n≤2×105）。对每个区间分别统计它包含多少个其他区间，以及它被多少个其他区间包含，并按输入顺序输出两组答案。

解题思路：

  • 观察：区间 A 包含 B 当且仅当 lA≤lBl_A\le l_BlA​≤lB​ 且 rA≥rBr_A\ge r_BrA​≥rB​；扫描时用排序固定左端点关系，用有序集合查询右端点关系。

  • 做法：第一遍按 l 降序、同 l 按 r 升序排序（右端点小的先入集合，恰满足“先入者才可能被后入者包含”）。处理 a[i] 时集合中区间的左端点均 ≥a[i].l\ge a[i].l≥a[i].l，其中被它包含者满足右端点 ≤a[i].r\le a[i].r≤a[i].r，计数 order_of_key(a[i].r + 1) 存入 ans[id].first。第二遍按 l 升序、同 l 按 r 降序排序（右端点大的先入集合，恰满足“先入者才可能包含后入者”）。此时集合中区间的左端点均 ≤a[i].l\le a[i].l≤a[i].l，包含它者满足右端点 ≥a[i].r\ge a[i].r≥a[i].r，计数 s.size() - order_of_key(a[i].r) 存入 ans[id].second。

  • 正确性：PBDS 顺序统计树维护右端点有序集合，order_of_key(x) 返回严格小于 x 的元素个数，查询与插入均为 O(log⁡n)O(\log n)O(logn)；两遍扫描分别对每个区间统计满足“左端点在前”与“右端点条件”的区间数。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Room Allocation

题目大意：有 n 位顾客（n≤2×105n \le 2 \times 10^5n≤2×105），第 i 位顾客从到达日 a[i].in 到离开日 a[i].out 占用一个房间。若前一位顾客在某日离开，同一房间只能分给在更晚日期到达的顾客。求最少房间数，并按输入顺序输出每位顾客的房间编号。

解题思路：按到达时间升序处理，小根堆保存各房间的（离开时间, 房间编号），堆顶为最早离开的房间。若 a[i].in > q.top().time（严格大于：离开日与到达日相同仍视为重叠），复用堆顶房间号并更新离开时间；否则新开房间。最后按输入顺序输出各顾客的房间号。每次堆操作为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Reading Books

题目大意：两个人都要读完同样的 n 本书（n≤2×105n \le 2 \times 10^5n≤2×105），每本书的阅读时间已知；两人可以同时阅读，但不能在同一时刻读同一本书。求两人都读完所有书的最短总时间。

解题思路：每人须读完全部书，答案至少为 total；最长一本书两人必须错开阅读，答案至少为 2⋅longest2\cdot longest2⋅longest。两个下界均可达到：total >= 2 * longest 时，一人先读最长书、另一人先读完其余书再接最长书，总时间恰为 total；否则一人先读最长书，另一人读其余书后待最长书空出再读，总时间为 2⋅longest2\cdot longest2⋅longest。故答案为 max(total, 2 * longest)。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(1)O(1)O(1)。

Maximum Subarray Sum II

题目大意：给定长度为 n 的整数数组（n≤2×105n \le 2 \times 10^5n≤2×105，∣a[i]∣≤109|a[i]| \le 10^9∣a[i]∣≤109），求长度在 [l, r] 范围内的非空连续子数组的最大元素和。

解题思路：

  • 观察：设前缀和 c[i]，以 i 为右端点、左端前缀下标 j 的子数组和为 c[i]-c[j]，长度在 [l, r] 等价于 j∈[i−r,i−l]j\in[i-r, i-l]j∈[i−r,i−l]，故只需该窗口内的最小 c[j]。

  • 做法：用 multiset 维护窗口内前缀和。对 i = l..r，插入 c[i-l] 后集合恰为 [0,i−l][0, i-l][0,i−l]（此时 i−r≤0i-r\le0i−r≤0，与窗口 [i−r,i−l][i-r, i-l][i−r,i−l] 一致），用 c[i] - *s.begin() 更新答案；对 i = r+1..n，先插入新进入窗口的 c[i-l]，再删除滑出窗口的 c[i-r-1]（lower_bound 定位），集合恰为 [i−r,i−l][i-r, i-l][i−r,i−l]。s.begin() 即窗口最小值。

  • 正确性：窗口内容与 j 的合法范围一一对应，c[i] - min(c[j]) 是右端点 i 处的最优子数组和，取所有 i 的最大值即答案。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
