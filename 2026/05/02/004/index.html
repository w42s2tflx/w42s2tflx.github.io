Apartments

题目大意：有 n 位申请者和 m 套公寓。第 i 位申请者期望的面积为 wishes[i]，能够接受的实际面积范围是 [wishes[i]−k,wishes[i]+k][\text{wishes}[i]-k,\text{wishes}[i]+k][wishes[i]−k,wishes[i]+k]。每套公寓至多分给一人，求最多可以满足多少位申请者。

解题思路：先将 wishes 和 sizes 都按升序排序，再用 i 依次考察申请者，用 j 指向当前最小的未处理公寓。若 sizes[j] < wishes[i] - k，这套公寓对当前申请者太小，对后面期望面积更大的申请者也一定太小，因此可以直接让 j 后移。跳过所有过小公寓后，如果 sizes[j] <= wishes[i] + k，就把这套最小可用公寓分给当前申请者，并同时消耗它；否则当前最小公寓都太大，只能跳过当前申请者。这个选择不会浪费更大的公寓，因此得到最大匹配数。时间复杂度为 O(nlog⁡n+mlog⁡m)O(n\log n+m\log m)O(nlogn+mlogm)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Ferris Wheel

题目大意：有 n 个孩子，第 i 个孩子的体重为 a[i]。每个座舱最多坐两人，且总重量不能超过 x，求最少需要多少个座舱。

解题思路：将体重升序排序，用 i、j 分别指向当前最轻和最重的孩子。最重的 a[j] 一定要占用一个座舱：如果它能和最轻的 a[i] 同坐，就让两人配对并同时移动两个指针；否则它连最轻的人都无法搭配，只能单独乘坐，此时只移动 j。每轮恰好确定一个座舱，优先让最重者与可搭配的最轻者同坐不会影响剩余人的可行性。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Concert Tickets

Restaurant Customers

题目大意：给出 n 位顾客各自的到店时间 a 和离店时间 b，求餐厅中同时存在的顾客人数最大值。

解题思路：把每位顾客拆成两个事件：到店时记录 (a, 1)，离店时记录 (b, -1)。将所有 events 按二元组升序排序后扫描，count 表示当前店内人数，high 记录最大值。同一时刻既有人离店又有人到店时，因为 -1 < 1，离店事件会先处理，这与区间端点不同时占用餐厅的含义一致。共有 2n2n2n 个事件，时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Sum of Two Values

题目大意：给定长度为 n 的数组和目标值 x，寻找两个不同位置，使这两个位置上的数之和等于 x。输出任意一组下标；不存在时输出 IMPOSSIBLE。

解题思路：从左到右读入数组，用 map m 记录此前每个数值对应的下标。读到当前值 a 时，先检查 m[x - a] 是否非零；若是，说明补数 x - a 已在更早的位置出现，可直接输出两个不同下标。否则记录 m[a] = i，供后面的元素查询。代码使用 map，所以时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Maximum Subarray Sum

题目大意：给定一个整数数组，求所有非空连续子数组中的最大元素和。

解题思路：使用 Kadane 算法。扫描到当前值 x 时，sum 表示以 x 结尾的最大子数组和，它要么由前一段接上 x，要么从 x 重新开始，因此更新为 max(sum + x, x)。再用 sum 更新全局答案 best。初值设为负数可以正确处理数组全部为负数的情况。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(1)O(1)O(1)。

Collecting Numbers

题目大意：数组是 1 到 n 的一个排列。每一轮只能从左到右扫描，并按 1, 2, ..., n 的顺序收集数字，求收集完所有数字至少需要多少轮。

解题思路：记录每个值的位置 pos[x]。如果 pos[i] < pos[i - 1]，那么扫描到 i - 1 后，位置更靠左的 i 已经错过，必须在下一轮才能收集。因此初始需要一轮，每出现一个这样的相邻值逆序就多一轮，即答案为 1+#{i∣2≤i≤n, pos[i]<pos[i−1]}1+\#\{i\mid 2\le i\le n,\ \text{pos}[i]<\text{pos}[i-1]\}1+#{i∣2≤i≤n, pos[i]<pos[i−1]}。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Collecting Numbers II

题目大意：给定 1 到 n 的一个排列，以及 m 次交换操作。每次交换位置 u、v 上的数后，输出按顺序收集 1,2,\ldots,n 所需的最少轮数。

解题思路：id[x] 表示数值 x 当前所在的位置，轮数 res 等于 111 加上满足 id[i] < id[i - 1] 的相邻值对数量。交换位置 u、v 上的 x = a[u]、y = a[v] 时，只有相邻值对 (x - 1, x)、(x, x + 1)、(y - 1, y)、(y, y + 1) 的前后顺序可能改变。代码先根据 x 从 u 移到 v 是否跨过相邻值的位置调整 res，再令 id[x] = v；随后以同样方式处理 y 从 v 移到 u，最后更新 a[u]、a[v]。哨兵 id[0] = 0、id[n + 1] = n + 1 让边界值也能使用相同判断。每次交换只检查常数个受影响的相邻对，预处理为 O(n)O(n)O(n)，全部操作为 O(m)O(m)O(m)，空间复杂度为 O(n)O(n)O(n)。

Nested Ranges Count

题目大意：给定 n 个区间 [l, r]。对每个区间分别统计它包含多少个其他区间，以及它被多少个其他区间包含，并按输入顺序输出两组答案。

解题思路：区间 A 包含区间 B 的条件是 lA≤lBl_A\le l_BlA​≤lB​ 且 rA≥rBr_A\ge r_BrA​≥rB​。第一遍按 l 降序排序，若 l 相同则按 r 升序排序。处理 a[i] 时，此前区间的左端点都满足 l >= a[i].l；s.order_of_key(a[i].r + 1) 统计其中右端点不超过 a[i].r 的数量，也就是被 a[i] 包含的区间数，写入 ans[a[i].id].first。第二遍按 l 升序排序，若 l 相同则按 r 降序排序。此时此前区间都满足 l <= a[i].l，s.size() - s.order_of_key(a[i].r) 统计右端点不小于 a[i].r 的数量，也就是包含 a[i] 的区间数，写入 ans[a[i].id].second。两种同左端点时的次序保证具有包含关系的区间先进入 s。PBDS 的 order_of_key(x) 表示严格小于 x 的元素个数；本题区间互不相同，右端点也可作为有序集合键。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Reading Books

题目大意：两个人都要读完同样的 n 本书，每本书的阅读时间已知；两人可以同时阅读，但不能在同一时刻读同一本书。求两人都读完所有书的最短总时间。

解题思路：设所有书的阅读时间之和为 total，最长一本耗时为 longest。每个人都要读完全部书，所以答案至少为 total；最长的书必须由两个人分别阅读，且这两段时间不能重叠，所以答案也至少为 2 * longest。这两个下界中的较大者可以通过合理安排达到，因此答案是 max(total, 2 * longest)。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(1)O(1)O(1)。

Sum of Three Values

题目大意：给定长度为 n 的数组和目标值 x，寻找三个互不相同的下标，使对应元素之和等于 x。输出任意一组答案；不存在时输出 IMPOSSIBLE。

解题思路：把每个元素和原下标组成 (值, 下标) 并排序。枚举第一个元素 v[i] 后，在区间 [i + 1, n - 1] 中用双指针 a、b 寻找和为 x - v[i].first 的两个数。当前和过小就右移 a，过大就左移 b；相等时输出三个原下标。三个位置来自排序后不同位置，因此原下标也互不相同。时间复杂度为 O(n2)O(n^2)O(n2)，空间复杂度为 O(n)O(n)O(n)。

Sum of Four Values

题目大意：给定长度为 n 的数组和目标值 x，寻找四个互不相同的下标，使对应元素之和等于 x。输出任意一组答案；不存在时输出 IMPOSSIBLE。

解题思路：先把所有下标对 (i, j) 的两数和以及两个下标存入 sums。外层枚举 i 时，先删除所有以 i 为较小下标的组合；而以更小下标和 i 组成的组合已在之前轮次删除，所以此时 sums 中不含下标 i。随后枚举 j < i，查找两数和 diff = x - a[i] - a[j]。此时集合中的下标都大于 i，自然与 i、j 不同；若找到即可输出四个下标。共有 O(n2)O(n^2)O(n2) 个数对，时间复杂度为 O(n2log⁡n)O(n^2\log n)O(n2logn)，空间复杂度为 O(n2)O(n^2)O(n2)。

Nearest Smaller Values

题目大意：给定数组 a。对每个位置 i，寻找左侧距离它最近且满足值严格小于 a[i] 的位置；若不存在则输出 0。

解题思路：维护一个值严格递增的单调栈，栈中保存 (值, 下标)。读到 x 时，持续弹出栈顶中值不小于 x 的元素，因为它们既不能作为当前位置的答案，也会被更靠右且不更大的 x 挡住。弹出后，若栈非空，栈顶就是最近的更小值位置；最后把 (x, i) 入栈。每个元素至多入栈、出栈一次，时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Subarray Sums I

题目大意：给定一个只包含正整数的数组，统计元素和恰好等于 x 的连续子数组数量。

解题思路：代码用 j 表示当前窗口左端点，k 表示下一个要加入窗口的位置，sum 表示区间 [j, k - 1] 的元素和。若 sum <= x，先在 sum == x 时给 ans 加一，再将 a[k] 加入并右移 k；若 sum > x，则减去 a[j] 并右移 j。因为所有元素均为正，扩大窗口只会增大和，缩小窗口只会减小和，所以不会漏掉合法区间。a[n + 1] = 1e18 是哨兵：当 k 越过末尾时，它会让 sum 变大，随后推动 j 收缩直至循环结束。两个指针都只单向移动，时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Subarray Sums II

题目大意：给定一个可能包含负数的数组，统计元素和恰好等于 x 的连续子数组数量。

解题思路：设扫描到 i 时的前缀和为 res。子数组 [l, i] 的和为 x，等价于此前的前缀和满足 S[l−1]=res−xS[l-1]=\text{res}-xS[l−1]=res−x。m 记录每个已出现前缀和的次数，因此每轮把 m[res - x] 加入答案。代码没有预先放入前缀和 0，而是用 res == x 单独统计从位置 1 开始的子数组，含义等价。使用 map 时，时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Subarray Divisibility

题目大意：给定长度为 n 的整数数组，统计元素和能够被 n 整除的连续子数组数量。

解题思路：两个前缀和之差能被 n 整除，当且仅当它们除以 n 的余数相同。扫描数组时，sum = ((sum + x) % n + n) % n 把前缀和余数规范到 [0, n - 1]，并用 a[sum] 统计每个非空前缀的余数出现次数。对于余数 i，任选两个同余前缀可得到 (a[i]2)\binom{a[i]}{2}(2a[i]​) 个合法子数组；此外，每个余数为 0 的非空前缀都能与空前缀配对，代码用初始值 ans = a[0] 单独加入这部分。因此答案为

ans=a[0]+∑i=0n−1(a[i]2).\text{ans}=a[0]+\sum_{i=0}^{n-1}\binom{a[i]}{2}. ans=a[0]+i=0∑n−1​(2a[i]​).

时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Distinct Values Subarrays II

题目大意：给定长度为 n 的数组，统计包含不同数值种类不超过 k 的连续子数组数量。

解题思路：维护窗口 [beg, i - 1] 内各数值的出现次数 m。加入 a[i] 前，若它不在窗口中且 m.size() == k，就必须从左侧收缩。代码不断减少 m[a[beg]] 并右移 beg，直到某个数值的次数降为零，将它从 m 删除后停止；此时窗口空出了一种数值，可以加入 a[i]。若 a[i] 已在窗口内，或当前种类数小于 k，则无需收缩。加入后 [beg, i] 中至多有 k 种值，以 i 结尾的合法子数组共有 i - beg + 1 个。每个位置至多进入和离开窗口一次，map 操作需要 O(log⁡k)O(\log k)O(logk)，总时间复杂度为 O(nlog⁡k)O(n\log k)O(nlogk)，空间复杂度为 O(k)O(k)O(k)。

Array Division

题目大意：把长度为 n 的数组划分成 k 个非空连续段，使所有段中最大的元素和尽可能小，输出这个最小值。

解题思路：二分最大段和上限 x，函数 f(x) 判断能否用不超过 k 段完成划分。代码从左到右把 a[i] 加入当前段的和 res；若 a[i] > x，任何划分都无法容纳该元素，直接返回 false。若加入后 res > x，就结束上一段，令 ans++、res = 0，并用 i-- 让当前元素在下一轮重新作为新段首处理。扫描结束后，若 res 非零，再计入最后一段。该贪心让每一段尽量长，所以得到上限 x 下所需的最少段数；只要 ans <= k，就可以继续拆分成恰好 k 个非空段。可行性随 x 单调，二分最小可行值。时间复杂度为 O(nlog⁡1016)O(n\log 10^{16})O(nlog1016)，空间复杂度为 O(n)O(n)O(n)。

Movie Festival II

题目大意：有 n 部电影和 k 位观众，每部电影给出开始、结束时间。每位观众同一时刻只能看一部电影，求所有观众总共最多能完整观看多少部电影。

解题思路：代码把电影存为 (结束时间, 开始时间) 并按结束时间升序处理，用 multiset times 保存 k 位观众各自最早能看下一部电影的时间，初始均为 0。对电影 (a, b)，用 times.upper_bound(a) 找到第一个大于开始时间 a 的元素；它的前一个元素就是不超过 a 的最大空闲时间。若存在这样的观众，就让他观看当前电影，删除旧空闲时间并插入结束时间 b。在能观看的人中选择最晚空闲者，可以把更早空闲的观众留给开始更早的其他安排；同时按结束时间优先处理能为之后保留更多机会，因此贪心最优。时间复杂度为 O(nlog⁡n+nlog⁡k)O(n\log n+n\log k)O(nlogn+nlogk)，空间复杂度为 O(n+k)O(n+k)O(n+k)。

Maximum Subarray Sum II

题目大意：给定长度为 n 的整数数组，求长度在 [l, r] 范围内的非空连续子数组的最大元素和。

解题思路：令 c[i] 为前 i 个元素的前缀和，则以 i 为右端点、左侧前缀下标为 j 的子数组和是 c[i] - c[j]，长度条件等价于 i−r≤j≤i−li-r\le j\le i-li−r≤j≤i−l。因此需要维护该范围内最小的 c[j]。代码先对 i = l, ..., r 逐步插入 c[i - l]，此时所有已插入下标都在 [0, i - l]，也就是有效范围 [0, i-l]。从 i = r + 1 开始，每轮先插入新进入窗口的 c[i - l]，再删除刚滑出窗口的 c[i - r - 1]，于是 s 恰好保存下标 [i-r, i-l] 的前缀和。用 c[i] - *s.begin() 更新 ans 即可。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
