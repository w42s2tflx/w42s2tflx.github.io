Static Range Sum Queries

题目大意：给定一个长度为 n 的静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问。每次给出区间 [l, r]，求其中所有元素之和；询问之间不会修改数组。

解题思路：前缀和。读入后执行 a[i] += a[i - 1]，使 a[i] 变为前 i 个元素之和；区间 [l, r] 的和即 a[r] - a[l - 1]。数组静态，无需支持修改。预处理时间复杂度为 O(n)O(n)O(n)，每次询问的时间复杂度为 O(1)O(1)O(1)，总时间复杂度为 O(n+q)O(n+q)O(n+q)。

Static Range Minimum Queries

题目大意：给定一个长度为 n 的静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问。每次给出区间 [l, r]，求其中的最小值；询问之间不会修改数组。

解题思路：

  • 做法（稀疏表）：稀疏表（ST 表）用倍增预计算静态数组的区间最小值：a[i][j] 为从 i 开始长 2j2^j2j 的区间最小值，满足

    a[i][j]=min⁡(a[i][j−1],a[i+2j−1][j−1]).a[i][j]=\min\bigl(a[i][j-1],a[i+2^{j-1}][j-1]\bigr). a[i][j]=min(a[i][j−1],a[i+2j−1][j−1]).

    询问 [l, r] 时令 s=⌊log⁡2(r−l+1)⌋s=\lfloor\log_2(r-l+1)\rfloors=⌊log2​(r−l+1)⌋，用从左、右端点出发的两个长 2s2^s2s 区间覆盖 [l, r]（允许重叠，最小值不受影响），答案为 min(a[l][s], a[r - (1 << s) + 1][s])。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问的时间复杂度为 O(1)O(1)O(1)。

  • 另解（离线）：单调栈与并查集。按右端点 r 分组询问，从左到右扫描位置 i：单调栈维护"尚未被右侧更小或相等元素替代"的位置，当 a[st.top()] >= a[i] 时弹出栈顶并 s.merge(st.top(), i)（把该位置的并查集父节点指向 i）。处理后从任意左端点 l 沿并查集跳到的 s.get(l) 恰是 [l, i] 的最小值位置——被弹出的位置都满足"i 更靠右且值不更大"，链上最终指向者即最小值所在。每个位置至多入栈、出栈一次，总时间复杂度为 O((n+q)α(n))O((n+q)\alpha(n))O((n+q)α(n))。

Dynamic Range Sum Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的元素和。

解题思路：位置 l 的旧值为 sum(l) - sum(l-1)；修改操作读入的 r 实为新值，向树状数组加入"新值减旧值"即 r - sum(l) + sum(l-1)。区间 [l, r] 的和为 sum(r) - sum(l-1)。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次修改或查询的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Dynamic Range Minimum Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的最小值。

解题思路：位置 i 对应叶子 TREE_SIZE + i；change(i, x) 改叶子后沿父链重算两个孩子的最小值。get_min(l, r) 两端从叶子层同时上移：l 为右孩子时计入 tree[l] 并右移，r 为左孩子时计入 tree[r] 并左移，选出的节点恰好覆盖 [l, r]。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Xor Queries

Range Update Queries

题目大意：维护一个长度为 n 的数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持给区间 [l, r] 内的每个元素加上 u，以及查询位置 k 当前的值。

解题思路：差分数组（b[i]=a[i]−a[i−1]b[i]=a[i]-a[i-1]b[i]=a[i]−a[i−1]：区间加 u 等价于 b[l]b[l]b[l] 加 u、b[r+1]b[r+1]b[r+1] 减 u，原数组为差分的前缀和），用线段树维护差分并支持区间求和。给 [l, r] 加 u 即 change(l, u)、change(r+1, -u)；位置 k 的值为 get_sum(1, k)。初始化时每个元素 x 按 change(i, x)、change(i+1, -x) 加入。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Forest Queries

题目大意：给定一个 n×nn\times nn×n 的森林网格（n≤1000n \le 1000n≤1000，q≤2×105q \le 2 \times 10^5q≤2×105），其中 * 表示树、. 表示空地。回答 q 次矩形询问：求左上角为 (l, r)、右下角为 (x, y) 的矩形中有多少棵树；网格不会被修改。

解题思路：二维前缀和。a[i][j] 为矩形 (1,1) 到 (i,j) 的树木数，递推

a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+1[格子(i,j)是树].a[i][j]=a[i][j-1]+a[i-1][j]-a[i-1][j-1]+\mathbf{1}[\text{格子}(i,j)\text{是树}]. a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+1[格子(i,j)是树].

矩形询问用容斥：减去上方、左方区域，补回重复减去的左上角，答案为 a[x][y] + a[l-1][r-1] - a[x][r-1] - a[l-1][y]。预处理时间复杂度为 O(n2)O(n^2)O(n2)，每次询问的时间复杂度为 O(1)O(1)O(1)。

Hotel Queries

题目大意：有 n 家酒店（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），每家酒店有一定数量的空房。m 个团队依次到来，每个团队需要 x 间房。应将团队安排到编号最小且空房数不少于 x 的酒店，并将该酒店的空房数减少 x；若不存在这样的酒店，则输出 0。

解题思路：线段树维护区间最大空房数（叶子数补齐到 nnn 之上的最小二次幂）。若根节点 t[1] < x 则无酒店可容纳，输出 0；否则 query(x) 从根向下：左子树最大值 ≥x\ge x≥x 优先进左子树，否则进右子树，最终落在编号最小的可行酒店。update(id, -x) 减少空房并沿父链更新最大值。每组操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

List Removals

题目大意：给定一个包含 n 个元素的列表（n≤2×105n \le 2 \times 10^5n≤2×105），再依次给出 n 个位置 p。每次删除当前列表中从左往右第 p 个元素，并输出被删除元素的值。

解题思路：

  • 做法（线段树）：线段树维护各原始位置的存活状态（1 存活、0 已删），节点值为区间内存活数。query(k) 从根向下找当前第 k 个存活元素：左子树存活数 ≥k\ge k≥k 则进左子树，否则 k 减去左子树存活数进右子树；到叶子得原下标，输出 x[pos] 并 change(pos, 0) 删除。每次查找与删除均为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

  • 另解（PBDS）：顺序统计树 ordered_set 按 (原位置, 元素值) 保存未删元素，原位置互异故集合顺序即列表顺序；find_by_order(x - 1) 直接取当前第 x 个元素，输出后删除。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Salary Queries

题目大意：维护 n 名员工的工资（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持修改员工 k 的工资，以及查询工资位于闭区间 [l, r] 内的员工人数。

解题思路：

  • 做法（离散化 + 值域线段树）：把所有可能出现的工资（初始工资与所有操作涉及的数值）收集、排序、去重，index(x) 用 lower_bound 把工资映射为离散下标，线段树叶子维护各工资的人数。修改时旧工资位置减 1、新工资位置加 1；查询时对 index(l) 到 index(r) 求区间和。预处理时间复杂度为 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，每次操作的时间复杂度为 O(log⁡(n+q))O(\log(n+q))O(log(n+q))。

  • 另解（PBDS）：顺序统计树维护工资有序序列，order_of_key(r + 1) - order_of_key(l) 即工资在 [l, r] 内的人数；修改时删除一份旧工资、插入新工资。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Prefix Sum Queries

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持单点修改，并查询区间 [l, r] 的最大前缀和。允许选择空前缀，因此答案不会小于 0。

解题思路：线段树每个节点存二元组（区间和, 最大前缀和），即 first、second。叶子值 x 的最大前缀和为 max(x, 0)（允许空前缀，答案不小于 0）。合并左 x 右 y 时，最大前缀要么全在左区间（x.second），要么含整个左区间再接右区间前缀（x.first + y.second），故 combine 返回 {x.first + y.first, max(x.second, x.first + y.second)}。查询用左闭右开 [l-1, r)，左、右两侧分别按序合并。每次修改或查询的时间复杂度为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Pizzeria Queries

题目大意：有 n 家披萨店（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），第 i 家店的披萨价格为 p[i]。从店 i 送到位置 k 的总花费为 p[i]+∣i−k∣p[i]+|i-k|p[i]+∣i−k∣。支持修改某家店的价格，以及查询送到位置 k 的最低总花费。

解题思路：

  • 观察：把绝对值按店在查询位置 k 的哪一侧拆开：i<ki<ki<k 时花费为 (p[i]−i)+k(p[i]-i)+k(p[i]−i)+k，i>ki>ki>k 时为 (p[i]+i)−k(p[i]+i)-k(p[i]+i)−k，i=ki=ki=k 时为 p[k]p[k]p[k]。于是只需两棵线段树分别维护 p[i]−ip[i]-ip[i]−i 与 p[i]+ip[i]+ip[i]+i 的区间最小值。

Visible Buildings Queries

题目大意：给定 n 栋楼的高度（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）。每次询问一个区间 [a, b]，从位置 a 向右看：位置 a 的楼一定可见，之后一栋楼只有在高于此前所有可见楼时才可见。求区间内可见楼的数量。

解题思路：

  • 观察：从 a 向右看到的楼恰为序列 a, next(a), next(next(a)),…a,\ next(a),\ next(next(a)),\ldotsa, next(a), next(next(a)),…，其中 next(i) 为 i 右侧第一栋严格更高的楼，即高度递增的"可见链"。

  • 做法：从右向左维护单调栈：弹出所有高度 ≤heights[i]\le heights[i]≤heights[i] 的位置后，栈顶即 jump[0][i]（n+1 处放高度 INF 的哨兵保证后继存在）。构造倍增表 jump[k][i]：从 i 连续跳过 2k2^k2k 个"右侧第一栋更高楼"后的位置，转移 jump[k][i] = jump[k-1][jump[k-1][i]]。询问 [a, b]：pos = a、答案 1（计入 a 本身），自高位向低位尝试，若 jump[k][pos] <= b 则该 2k2^k2k 栋楼都在区间内，累加 2k2^k2k 并更新 pos。

  • 正确性：可见链即沿 next 跳转的序列，倍增把它拆成不超过 O(log⁡n)O(\log n)O(logn) 段，累加即可见楼数。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Interval Queries

题目大意：给定一个静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）。每次询问给出下标区间 [a, b] 和数值区间 [c, d]，求满足下标位于 [a, b] 且元素值位于 [c, d] 的元素个数。

解题思路：

  • 观察：答案 = 值 ≤d\le d≤d 且在 [a,b] 的元素数 − 值 <c< c<c 且在 [a,b] 的元素数，可离线扫描值域完成。

  • 做法：把数组元素记为事件 {值, 2, 下标}，询问拆为 {c, 1, a, b, id}（贡献取负）与 {d, 3, a, b, id}（贡献取正），按值升序、同值按类型 1 < 2 < 3 排序处理。线段树维护已加入元素的位置（set_val(pos) 置 1）。类型 1 处理时值等于 c 的元素尚未加入，get_sum(a,b) 为值 <c<c<c 的个数，从答案中减去；类型 3 处理时值等于 d 的元素已加入，get_sum(a,b) 为值 ≤d\le d≤d 的个数，加到答案中。

  • 正确性：事件顺序保证两类统计的边界严格正确，相减即值在 [c,d] 且下标在 [a,b] 的元素数。预处理时间复杂度为 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Subarray Sum Queries

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），每次将一个位置修改为新值，并在修改后输出整个数组的最大子段和。允许选择空子段，因此答案至少为 0。

解题思路：线段树节点维护四个量：区间和 val、最大前缀和 pre、最大后缀和 suf、最大子段和 t。合并左右子区间 LLL、RRR 时：

val=valL+valR,pre=max⁡(preL,valL+preR),suf=max⁡(sufR,sufL+valR),t=max⁡(tL,tR,sufL+preR).\begin{aligned} val &= val_L+val_R,\\ pre &= \max(pre_L,val_L+pre_R),\\ suf &= \max(suf_R,suf_L+val_R),\\ t &= \max(t_L,t_R,suf_L+pre_R). \end{aligned} valpresuft​=valL​+valR​,=max(preL​,valL​+preR​),=max(sufR​,sufL​+valR​),=max(tL​,tR​,sufL​+preR​).​

最大子段要么全在左侧、要么全在右侧、要么跨中点（左区间的最大后缀 + 右区间的最大前缀）。叶子处 pre、suf、t 均为 max(0ll, x)，允许空子段。f(k, x) 修改叶子并向上重算，根节点 t[1] 即答案。初始化和全部修改的总时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Subarray Sum Queries II

题目大意：给定一个静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问。每次求区间 [a, b] 内的最大子段和；允许选择空子段，因此答案至少为 0。

解题思路：线段树节点 Node 存 total_sum（区间和）、max_left（最大前缀和）、max_right（最大后缀和）、max_sum（最大子段和）。合并时区间和相加；最大前缀要么全在左侧、要么含整个左侧再延伸到右侧；最大后缀同理；最大子段取左、右、跨中点（left.max_right + right.max_left）三者最大。

  • 边界：合并不满足交换律，迭代查询必须保持顺序——左侧取出的节点依次接到 left 后面，右侧取出的节点依次接到 right 前面，最后 combine(left, right)；零初始化的节点表示空区间，对应允许空子段。预处理时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Distinct Values Queries

题目大意：给定一个静态数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问。每次求区间 [a, b] 内不同数值的数量。

解题思路：

  • 观察：固定左端点 i，区间 [i, r] 内不同值的数量 = "每个值的第一个 ≥i\ge i≥i 出现位置中 ≤r\le r≤r 者"的数量。若线段树中只把每个值当前最靠左的未处理出现位置标记 1，则 [i, r] 的区间和即为所求。

  • 做法：询问按左端点升序离线。occurrences 从右向左存每个值的出现位置，向量末尾即最靠左者，初始把每值的第一次出现位置标记 1。扫描到左端点 i 时回答该组询问；随后 i 出局——若 v[i] 还有更靠后的出现位置，就把下一次出现位置标记 1。

  • 正确性：一个值在 [i, r] 出现当且仅当其最靠左的 ≥i\ge i≥i 出现位置 ≤r\le r≤r，标记和恰为不同值个数。每次修改与查询均为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Distinct Values Queries II

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持单点修改，以及判断区间 [a, b] 内的所有元素是否互不相同。若没有重复值则输出 YES，否则输出 NO。

解题思路：

  • 观察：区间 [a, b] 无重复值当且仅当其中每个位置的"下一个同值位置"都 >b> b>b，即区间内后继位置的最小值 >b> b>b。

  • 做法：线段树在位置 i 存与 values[i] 相同的下一个位置（不存在记 INF），询问 [a, b] 查区间最小值：≤b\le b≤b 输出 NO，否则 YES。有序集合 pairs 存所有 (值, 位置) 二元组，find_prev/find_next 在 O(log⁡n)O(\log n)O(logn) 内定位同值链上的前驱后继。修改位置 k 为新值时：先从旧值链删除（旧前驱直接指向旧后继），再插入新值链（新前驱指向 k，k 指向新后继），每次只需更新常数个位置。

  • 正确性：维护的是"同值下一位置"的完整结构，查询条件与无重复等价。集合与线段树每次操作均为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Increasing Array Queries

题目大意：给定一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），回答 q 次询问。每次只考虑子数组 [l, r]，每次操作可以将某个元素加 1，求把该子数组变成不下降序列所需的最少操作次数。

解题思路：

  • 观察：固定区间的最优策略是从左到右把每个元素补到"此前最大值"（操作只能加、不能减）。若维护从 l 出发高度严格递增的关键位置链，相邻关键位置之间全部被补成该段左端关键位置的高度。

  • 做法：询问按左端点分组，从右向左枚举左端点 i。双端队列 st 维护从 i 向右的关键位置（下标递增、高度严格递增）；若 a[i] >= a[st.front()]，旧关键位置被 a[i] 覆盖，从树状数组删除其代价并弹出。设下一个关键位置为 st.front()，则 [i+1, st.front()-1] 全部补到 a[i] 的代价为

    v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i]),v[i]=(st.front()-1-i)\cdot a[i]-\bigl(pre[st.front()-1]-pre[i]\bigr), v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i]),

    加入树状数组。回答 [i, r]：upper_bound 找最后一个不超过 r 的关键位置 st[pos]，其左侧完整段的代价由树状数组区间和得到，末尾不完整段用前缀和直接算。

  • 正确性：关键位置链正是从左到右贪心补平后的"平台"分段，代价按段求和即最少操作数。每个位置至多进出队列一次，每次树状数组操作与二分为 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Movie Festival Queries

题目大意：有 n 部电影（n≤2×105n \le 2 \times 10^5n≤2×105），每部电影有开始时间和结束时间。每次询问给出时间段 [a, b]（q≤2×105q \le 2 \times 10^5q≤2×105），求在该时间段内最多能完整观看多少部互不重叠的电影。

解题思路：

  • 观察：单次询问用区间调度贪心（每步选当前能看且结束最早的电影），该选择由"开始时间"唯一决定——nxt[i][0] 为开始时间 ≥i\ge i≥i 的电影中的最小结束时间。于是贪心过程是时间轴上的确定性跳转，可用倍增加速。

  • 做法：先对相同开始时间取最小结束时间，再从右向左做后缀最小值得到 nxt[i][0]；倍增表 nxt[i][j] 为从时刻 i 连续贪心选 2j2^j2j 部电影后的结束时刻，转移 nxt[i][j] = nxt[nxt[i][j-1]][j-1]。询问 [a, b] 从高位到低位尝试：nxt[a][j] <= b 则累加 2j2^j2j 并更新 a。

  • 正确性：贪心过程只依赖当前开始时间，倍增拼接即连续执行贪心，累加数恰为能完整观看的最大电影数。时间值域为 M，预处理时间复杂度为 O(Mlog⁡M+n)O(M\log M+n)O(MlogM+n)，每次询问的时间复杂度为 O(log⁡M)O(\log M)O(logM)。

Forest Queries II

题目大意：维护一个 n×nn\times nn×n 的森林网格（n≤1000n \le 1000n≤1000，q≤2×105q \le 2 \times 10^5q≤2×105），支持翻转某个格子的状态（树与空地互换），以及查询任意矩形内的树木数量。

解题思路：二维树状数组（树状数组的二维推广，矩形前缀和查询与单点修改均为 O(log⁡2n)O(\log^2 n)O(log2n)）。add(x, y, v) 点加，sum(x, y) 返回 (1,1) 到 (x,y) 的和；初始化时树格加 1。翻转 (x, y) 前用四项容斥求单点当前值：sum(x,y) - sum(x,y-1) - sum(x-1,y) + sum(x-1,y-1)，为 1 则加 -1（删树），否则加 1（种树）。矩形询问同样容斥：sum(l,r) - sum(l,y-1) - sum(x-1,r) + sum(x-1,y-1)。每次更新和查询的时间复杂度为 O(log⁡2n)O(\log^2 n)O(log2n)。

Range Updates and Sums

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持三种操作：将区间 [l, r] 的每个元素加上 x，将区间 [l, r] 的每个元素赋值为 x，以及查询区间 [l, r] 的元素和。

解题思路：

  • 做法：懒标记线段树（把区间修改延迟记录在节点标记上，访问子节点时才下传），每个节点存区间和 sum、加法标记 lazy_inc、赋值标记 has_rev 与赋值内容 rev_val。increase 整段加 v：sum += len * v 并累加 lazy_inc；revise 整段赋值：sum = len * v、置 has_rev、清空 lazy_inc。

  • 边界：两种标记并存时顺序不能颠倒——先发生的赋值、后发生的加法。pushdown 先下传赋值再下传加法（孩子先被覆盖，再叠加增量），并清除父节点标记；递归修改/查询时不相交返回、完全覆盖就地更新，否则下传后递归、最后 pushup 合并。代码还维护了 Max、Min，本题只用 sum。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Polynomial Queries

题目大意：维护一个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持两种操作：对区间 [l, r] 依次加上 1,2,3,…,r−l+11,2,3,\ldots,r-l+11,2,3,…,r−l+1，以及查询区间 [l, r] 的元素和。

解题思路：

  • 观察：区间 [l, r] 加 1,2,…1,2,\ldots1,2,… 即位置 x 加 x−l+1x-l+1x−l+1，是关于 x 的线性函数；把 [1, r] 整体加该线性函数、再对 [1, l-1] 抵消，就可用差分思想实现区间更新。

  • 做法：三棵树状数组分别维护前缀和中关于位置 x 的常数项、一次项、二次项系数。更新用 modify(r, 1, 1-l) 与 modify(l-1, -1, l-1) 两次前缀贡献：前者对 [1, r] 加线性函数 1⋅x+(1−l)1\cdot x+(1-l)1⋅x+(1−l)，后者抵消 [1, l-1] 上不该出现的部分。query(x) 组合三系数并利用 ∑k=1xk=x(x+1)2\sum_{k=1}^{x}k=\frac{x(x+1)}2∑k=1x​k=2x(x+1)​ 得 a + b*x + c*x*(x+1)/2，即 [1, x] 的和；区间 [l, r] 答案为 query(r) - query(l-1)。

  • 正确性：任意位置 xxx 被贡献的次数恰为其应加的值。每次更新、查询只做常数次树状数组操作，每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Queries and Copies

题目大意：维护若干个数组（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），初始只有一个数组。支持修改指定数组 k 的某个位置、查询指定数组 k 的区间和，以及复制数组 k 并将副本作为一个新的数组加入集合。

解题思路：

  • 观察：多个版本共享绝大部分数据，用可持久化线段树（每次修改只新建被改动的"从根到叶子"路径上的节点，其余部分与旧版本共享）即可在 O(log⁡n)O(\log n)O(logn) 内完成复制与修改。

  • 做法：Node 存左右孩子指针与区间和 sum，trees[k] 为第 k 个数组的根。单点修改时 change 用 new Node(*p) 复制当前节点，只递归重建含目标位置的一侧，另一侧继续共享旧节点，然后 trees[k] 指向新根。复制数组只需 trees.push_back(trees[k])（两版本暂共享根），之后的修改通过路径复制自动分离。区间查询在指定根上递归求和。

  • 正确性：路径复制保证旧版本节点不被改写，各版本互不干扰。每次操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)，总空间复杂度为 O(n+qlog⁡n)O(n+q\log n)O(n+qlogn)。

Missing Coin Sum Queries

题目大意：给定 n 枚硬币（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），第 i 枚硬币的面值为 c[i]。每次询问只允许使用下标位于 [l, r] 的硬币，每枚硬币最多使用一次，求无法凑出的最小正整数金额。

解题思路：

  • 观察：经典结论——若当前硬币能凑出 [1,res][1, res][1,res]，下一枚面值 ≤res+1\le res+1≤res+1 时可扩展到 res+coinres+coinres+coin，否则 res+1res+1res+1 无法凑出。按最高二进制位 id = __lg(c[i]) 分组后，第 id 组面值都在 [2id,2id+1)[2^{id}, 2^{id+1})[2id,2id+1) 内；从低位组向高位组贪心时，只要 res+1res+1res+1 不小于该组最小面值，整组都能并入，故每组只需其区间最小值与总和。

  • 做法：询问按右端点离线，从左到右扫描右端点 i。对每个 id 用单调栈维护后缀最小值候选：新位置值更小时，被弹出位置的并查集父节点指向新位置，get(id, ls[k]) 即区间 [ls[k], i] 内该组最小值的位置。t[i][id] 为每组前缀和，O(1)O(1)O(1) 得区间总和。回答时按 id 升序：若 res+1res+1res+1 不小于该组区间最小值，则 res += 该组区间总和；否则停止，输出 res + 1。

  • 正确性：组内按升序并入时每枚硬币并入前都满足 res+1≥res+1\geres+1≥ 其面值——首枚由最小值条件保证；其后每枚前面至少已并入一枚 ≥2id\ge 2^{id}≥2id 的硬币，使 res+1≥2id+1res+1\ge 2^{id+1}res+1≥2id+1，超过组内任意面值。组最小值已超过 res+1res+1res+1 时无法继续。总时间复杂度为 O((n+q)log⁡C)O((n+q)\log C)O((n+q)logC)，其中 C 为面值上限。
