Static Range Sum Queries

题目大意：给定一个长度为 n 的静态数组，回答 q 次询问。每次给出区间 [l, r]，求其中所有元素之和；询问之间不会修改数组。

解题思路：使用前缀和。代码在读入后执行 a[i] += a[i - 1]，使 a[i] 表示前 i 个元素之和。区间 [l, r] 的元素和等于前 r 个元素之和减去前 l - 1 个元素之和，即 a[r] - a[l - 1]。预处理复杂度为 O(n)O(n)O(n)，每次询问为 O(1)O(1)O(1)，总复杂度为 O(n+q)O(n+q)O(n+q)。

Static Range Minimum Queries

题目大意：给定一个长度为 n 的静态数组，回答 q 次询问。每次给出区间 [l, r]，求其中的最小值；询问之间不会修改数组。

解题思路：题解一使用稀疏表（ST 表）。a[i][j] 表示从位置 i 开始、长度为 2j2^j2j 的区间最小值。长度为 2j2^j2j 的区间可以拆成两个长度为 2j−12^{j-1}2j−1 的区间，因此有

a[i][j]=min⁡(a[i][j−1],a[i+2j−1][j−1]).a[i][j]=\min\bigl(a[i][j-1],a[i+2^{j-1}][j-1]\bigr). a[i][j]=min(a[i][j−1],a[i+2j−1][j−1]).

询问 [l, r] 时，令 s=⌊log⁡2(r−l+1)⌋s=\lfloor\log_2(r-l+1)\rfloors=⌊log2​(r−l+1)⌋。区间 [l, r] 可以由从左端点和右端点出发的两个长度为 2s2^s2s 的区间覆盖；求最小值允许这两个区间重叠，因此答案为 min(a[l][s], a[r - (1 << s) + 1][s])。预处理复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问为 O(1)O(1)O(1)。

另解（题解二）：使用离线询问、单调栈和并查集。先按右端点 r 对询问分组，再从左到右扫描位置 i。单调栈维护尚未被右侧更小或相等元素替代的位置；当 a[st.top()] >= a[i] 时，弹出栈顶，并通过 s.merge(st.top(), i) 将该位置的并查集父节点指向 i。处理完位置 i 后，从任意左端点 l 沿并查集跳到的 s.get(l)，正是区间 [l, i] 中最小值所在的位置，所以答案为 a[s.get(l)]。每个位置至多入栈、出栈一次，并查集操作的均摊复杂度近似为常数，总复杂度为 O((n+q)α(n))O((n+q)\alpha(n))O((n+q)α(n))。

Dynamic Range Sum Queries

题目大意：维护一个长度为 n 的数组，支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的元素和。

解题思路：使用树状数组维护前缀和。sum(d) 返回区间 [1, d] 的和，因此位置 l 的旧值为 sum(l) - sum(l - 1)。修改操作读入的第三个数 r 实际表示新值，代码向树状数组加入“新值减旧值”，即 r - sum(l) + sum(l - 1)。区间 [l, r] 的和为 sum(r) - sum(l - 1)。建树复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次修改或查询为 O(log⁡n)O(\log n)O(logn)。

Dynamic Range Minimum Queries

题目大意：维护一个长度为 n 的数组，支持把位置 k 的值修改为 u，以及查询区间 [l, r] 的最小值。

解题思路：使用迭代式线段树，位置 i 对应叶子 TREE_SIZE + i。change(i, x) 修改叶子后沿父节点向上，重新计算每个节点两个孩子的最小值。查询 get_min(l, r) 时，左右端点从叶子层同时向上移动：若 l 是右孩子，就计入 tree[l] 并右移；若 r 是左孩子，就计入 tree[r] 并左移。这样选出的节点恰好将 [l, r] 分成若干个互不重叠的线段树区间。每次修改和查询的复杂度均为 O(log⁡n)O(\log n)O(logn)。

Range Xor Queries

题目大意：给定一个长度为 n 的静态数组，回答 q 次询问。每次给出区间 [l, r]，求其中所有元素的异或和。

解题思路：使用前缀异或。代码在读入每个元素后执行 a[i] ^= a[i - 1]，使 a[i] 表示前 i 个元素的异或和。由于同一个数异或两次会抵消，即 x⊕x=0x\oplus x=0x⊕x=0，区间 [l, r] 的异或和为 a[r] ^ a[l - 1]。预处理复杂度为 O(n)O(n)O(n)，每次询问为 O(1)O(1)O(1)，总复杂度为 O(n+q)O(n+q)O(n+q)。

Range Update Queries

题目大意：维护一个长度为 n 的数组，支持给区间 [l, r] 内的每个元素加上 u，以及查询位置 k 当前的值。

解题思路：使用差分数组思想，并用线段树维护差分值。给区间 [l, r] 加 u，等价于让差分数组的 l 位置加 u、r + 1 位置减 u。原数组位置 k 的值等于差分数组 [1, k] 的和，因此用 get_sum(1, k) 查询。初始化时，每个原数组元素 x 也按 change(i, x)、change(i + 1, -x) 的方式加入差分结构。每次更新或查询的复杂度均为 O(log⁡n)O(\log n)O(logn)。

Forest Queries

题目大意：给定一个 n×nn\times nn×n 的森林网格，其中 * 表示树、. 表示空地。回答 q 次矩形询问：求左上角为 (l, r)、右下角为 (x, y) 的矩形中有多少棵树；网格不会被修改。

解题思路：使用二维前缀和。读入后，a[i][j] 表示矩形 (1, 1) 到 (i, j) 中的树木数量，递推为

a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+[格子 (i,j) 是树].a[i][j]=a[i][j-1]+a[i-1][j]-a[i-1][j-1]+[\text{格子 }(i,j)\text{ 是树}]. a[i][j]=a[i][j−1]+a[i−1][j]−a[i−1][j−1]+[格子 (i,j) 是树].

询问矩形 (l, r) 到 (x, y) 时，用容斥减去上方和左方区域，再补回被重复减去的左上区域，答案为 a[x][y] + a[l - 1][r - 1] - a[x][r - 1] - a[l - 1][y]。预处理复杂度为 O(n2)O(n^2)O(n2)，每次询问为 O(1)O(1)O(1)。

Hotel Queries

题目大意：有 n 家酒店，每家酒店有一定数量的空房。m 个团队依次到来，每个团队需要 x 间房。应将团队安排到编号最小且空房数不少于 x 的酒店，并将该酒店的空房数减少 x；若不存在这样的酒店，则输出 0。

解题思路：使用线段树维护每个区间内的最大空房数。代码先将叶子数量补到不小于原 n 的最小二次幂，并把补齐后的大小重新赋给 n。若根节点 t[1] < x，说明所有酒店都无法容纳该团队，直接输出 0；否则调用 query(x) 从根向下查找。若左子树最大值不少于 x，就优先进入左子树，否则进入右子树，因此最终得到的一定是编号最小的可行酒店。随后用 update(id, -x) 减少其空房数，并沿父链更新区间最大值。每个团队的处理复杂度为 O(log⁡n)O(\log n)O(logn)。

List Removals

题目大意：给定一个包含 n 个元素的列表，再依次给出 n 个位置 p。每次删除当前列表中从左往右第 p 个元素，并输出被删除元素的值。

解题思路：题解一使用线段树维护每个原始位置是否仍在列表中：存活记为 1，已删除记为 0，节点值为区间内存活元素数量。query(k) 从根节点向下查找当前第 k 个存活元素。如果左子树的存活数不少于 k，目标在左子树；否则先令 k 减去左子树的存活数，再进入右子树。到达叶子后得到原数组下标，输出 x[pos]，并用 change(pos, 0) 将其删除。每次查找和删除均为 O(log⁡n)O(\log n)O(logn)，总复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

另解（题解二）：使用 PBDS 的 ordered_set，按 (原位置, 元素值) 保存仍未删除的元素。由于原位置互不相同，集合中的顺序与当前列表顺序一致。find_by_order(x - 1) 可以直接找到当前第 x 个元素，输出二元组的第二项后再将其删除。每次操作的复杂度为 O(log⁡n)O(\log n)O(logn)。

Salary Queries

题目大意：维护 n 名员工的工资，支持修改员工 k 的工资，以及查询工资位于闭区间 [l, r] 内的员工人数。

解题思路：题解一使用离散化和值域线段树。先收集所有初始工资，以及后续操作中可能成为查询边界或新工资的值，排序并去重；index(x) 通过 lower_bound 将实际工资映射为离散下标。线段树叶子维护对应工资的人数。修改员工工资时，先在旧工资位置减 1，再更新 p[k]，最后在新工资位置加 1；查询 [l, r] 时，对 index(l) 到 index(r) 求区间和。离散化复杂度为 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，每次操作为 O(log⁡(n+q))O(\log(n+q))O(log(n+q))。

另解（题解二）：使用 PBDS 的 ordered_set 维护工资的有序序列。order_of_key(r + 1) - order_of_key(l) 分别统计小于等于 r 和小于 l 的元素数量，相减即可得到 [l, r] 内的人数。修改时先定位并删除一份旧工资，再插入新工资。代码使用的 ordered_set 类型需支持重复值，或通过其既有定义为重复元素提供区分键。

Prefix Sum Queries

题目大意：维护一个数组，支持单点修改，并查询区间 [l, r] 的最大前缀和。允许选择空前缀，因此答案不会小于 0。

解题思路：线段树的每个节点用二元组保存区间和与最大前缀和，代码中分别是 first 和 second。叶子值为 x 时，最大前缀和设为 max(x, 0)，对应允许空前缀。合并左区间 x 和右区间 y 时，合并区间的最大前缀要么完全位于左区间，要么包含整个左区间并接上右区间的一个前缀，因此 combine 返回 {x.first + y.first, max(x.second, x.first + y.second)}。查询采用左闭右开区间 [l - 1, r)，并分别保持左右结果的合并顺序。每次修改或查询均为 O(log⁡n)O(\log n)O(logn)。

Pizzeria Queries

题目大意：有 n 家披萨店，第 i 家店的披萨价格为 p[i]。从店 i 送到位置 k 的总花费为 p[i]+∣i−k∣p[i]+|i-k|p[i]+∣i−k∣。支持修改某家店的价格，以及查询送到位置 k 的最低总花费。

解题思路：按披萨店在查询位置 k 的左侧还是右侧拆开绝对值：当 i < k 时，花费为 (p[i]−i)+k(p[i]-i)+k(p[i]−i)+k；当 i > k 时，花费为 (p[i]+i)−k(p[i]+i)-k(p[i]+i)−k；当 i=k 时，花费就是 p[k]。因此用两棵线段树分别维护 p[i] - i 和 p[i] + i 的区间最小值。代码将店 i 存在线段树下标 i - 1，查询位置为 x 时，左侧对应 [0, x - 1)，右侧对应 [x, n)，再与 a[x] 取最小值。修改价格时同步更新两棵树。每次操作的复杂度为 O(log⁡n)O(\log n)O(logn)。

Visible Buildings Queries

题目大意：给定 n 栋楼的高度。每次询问一个区间 [a, b]，从位置 a 向右看：位置 a 的楼一定可见，之后一栋楼只有在高于此前所有可见楼时才可见。求区间内可见楼的数量。

解题思路：先求每栋楼右侧第一栋严格更高的楼。代码从右向左维护单调栈，遇到位置 i 时弹出所有高度不超过 heights[i] 的位置，此时栈顶就是 jump[0][i]。在 n + 1 处放置高度为 INF 的哨兵，保证每个位置都有后继。随后构造倍增表：jump[k][i] 表示从 i 连续跳过 2k2^k2k 个“右侧第一栋更高楼”后到达的位置。

询问 [a, b] 时，从 pos = a 开始，自高位向低位尝试跳跃。若 jump[k][pos] <= b，说明这 2k2^k2k 栋楼仍在询问区间内，就更新位置并将答案增加 2k2^k2k。初始答案为 1，用来统计位置 a 本身。预处理复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问为 O(log⁡n)O(\log n)O(logn)。

Range Interval Queries

题目大意：给定一个静态数组。每次询问给出下标区间 [a, b] 和数值区间 [c, d]，求满足下标位于 [a, b] 且元素值位于 [c, d] 的元素个数。

解题思路：使用离线事件和线段树。将数组元素记为事件 {值, 2, 下标}，将每个询问拆为 {c, 1, a, b, id} 和 {d, 3, a, b, id}。所有事件按字典序排序，因此首先按值升序，同值时按类型 1 < 2 < 3 处理。线段树维护已经加入的元素位置，元素事件调用 set_val(pos) 将该位置置为 1。

处理类型 1 事件时，值等于 c 的元素尚未加入，get_sum(a, b) 统计的是区间内值小于 c 的元素数，将其从答案中减去。处理类型 3 事件时，值等于 d 的元素已经加入，此时统计的是值小于等于 d 的元素数，将其加到答案中。两者相减后恰好得到值位于 [c, d] 的元素数量。排序复杂度为 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，每个事件的处理复杂度为 O(log⁡n)O(\log n)O(logn)。

Subarray Sum Queries

题目大意：维护一个数组，每次将一个位置修改为新值，并在修改后输出整个数组的最大子段和。允许选择空子段，因此答案至少为 0。

解题思路：线段树节点维护四个量：区间和 val、最大前缀和 pre、最大后缀和 suf、最大子段和 t。设左右子区间分别为 LLL 和 RRR，合并关系为

val=valL+valR,pre=max⁡(preL,valL+preR),suf=max⁡(sufR,sufL+valR),t=max⁡(tL,tR,sufL+preR).\begin{aligned} val &= val_L+val_R,\\ pre &= \max(pre_L,val_L+pre_R),\\ suf &= \max(suf_R,suf_L+val_R),\\ t &= \max(t_L,t_R,suf_L+pre_R). \end{aligned} valpresuft​=valL​+valR​,=max(preL​,valL​+preR​),=max(sufR​,sufL​+valR​),=max(tL​,tR​,sufL​+preR​).​

最大子段要么完全位于左区间，要么完全位于右区间，要么跨过中点，由左区间的最大后缀和右区间的最大前缀组成。叶子处将 pre、suf、t 初始化为 max(0ll, x)，表示允许空子段。每次调用 f(k, x) 修改一个叶子并向上重算，根节点 t[1] 即为答案。初始化和全部修改的总复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Subarray Sum Queries II

题目大意：给定一个静态数组，回答 q 次询问。每次求区间 [a, b] 内的最大子段和；允许选择空子段，因此答案至少为 0。

解题思路：线段树节点 Node 保存 total_sum、max_left、max_right 和 max_sum，分别表示区间和、最大前缀和、最大后缀和与最大子段和。合并左右节点时，区间和直接相加；最大前缀可能完全在左侧，也可能包含整个左侧并延伸到右侧；最大后缀同理；最大子段则取左侧答案、右侧答案和跨越中点的 left.max_right + right.max_left 三者最大值。

区间合并不满足交换律，因此迭代查询时必须保持顺序。代码将左侧取出的节点依次接到 left 后面，将右侧取出的节点依次接到 right 前面，最后再执行 combine(left, right)。零初始化节点表示空区间，也对应题目允许空子段。建树复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，每次询问为 O(log⁡n)O(\log n)O(logn)。

Distinct Values Queries

题目大意：给定一个静态数组，回答 q 次询问。每次求区间 [a, b] 内不同数值的数量。

解题思路：将询问按左端点升序离线处理。对每一种值，occurrences 保存它尚未处理的出现位置；由于代码从右向左加入位置，向量末尾始终是当前最靠左的位置。线段树中，每个值只在“不小于当前左端点的第一次出现位置”标记 1，其余出现位置标记 0。

当扫描到左端点 i 时，区间 [i, r] 的标记和就是不同值数量：一个值在该区间出现，当且仅当它当前最靠左的出现位置不超过 r。回答所有左端点为 i 的询问后，位置 i 不再可能进入后续区间；若 v[i] 之后仍有出现位置，就将下一次出现位置标记为 1。每次标记修改和区间查询均为 O(log⁡n)O(\log n)O(logn)，总复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Distinct Values Queries II

题目大意：维护一个数组，支持单点修改，以及判断区间 [a, b] 内的所有元素是否互不相同。若没有重复值则输出 YES，否则输出 NO。

解题思路：对每个位置 i，在线段树中维护与 values[i] 相同的下一个位置；若不存在，则记为 INF。所有 (值, 位置) 二元组存入有序集合 pairs，因此 find_prev 和 find_next 可以在 O(log⁡n)O(\log n)O(logn) 时间内找到同值位置链中的前驱和后继。

对于询问 [a, b]，若区间内某个位置的下一次同值出现位置仍不超过 b，区间中就存在重复值。因此只需查询 [a, b] 内后继位置的最小值：结果不超过 b 时输出 NO，否则输出 YES。修改位置 k 时，先将它从旧值的位置链中删除，让旧前驱直接指向旧后继；再将它插入新值的位置链，让新前驱指向 k，并让 k 指向新后继。集合和线段树的每次操作均为 O(log⁡n)O(\log n)O(logn)。

Increasing Array Queries

题目大意：给定一个数组，回答 q 次询问。每次只考虑子数组 [l, r]，每次操作可以将某个元素加 1，求把该子数组变成不下降序列所需的最少操作次数。

解题思路：对固定区间，最优做法是从左向右扫描，维护此前的最大值；当前元素较小时，只能将它补到此前最大值，因为降低前面的元素不被允许。代码将询问按左端点分组，并从右向左枚举左端点 i。

双端队列 st 维护从 i 向右的若干关键位置，其下标递增、高度严格递增。若 a[i] >= a[st.front()]，原来的关键位置会被 a[i] 覆盖，其对应代价 v[st.front()] 失效，需要从树状数组中删除。设新的下一关键位置为 st.front()，则将区间 [i + 1, st.front() - 1] 全部补到 a[i] 的代价为

v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i]).v[i]=(st.front()-1-i)\cdot a[i]-\bigl(pre[st.front()-1]-pre[i]\bigr). v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i]).

该完整段代价加入树状数组。回答 [i, r] 时，用 upper_bound 找到最后一个不超过 r 的关键位置 st[pos]。此前完整关键段的代价由树状数组区间和得到，末尾未完整覆盖的部分再利用前缀和直接计算。每个位置只会进出队列一次，每次树状数组操作和二分为 O(log⁡n)O(\log n)O(logn)，总复杂度为 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。全局数组及 add、query 定义在 solve() 外。

Movie Festival Queries

题目大意：有 n 部电影，每部电影有开始时间和结束时间。每次询问给出时间段 [a, b]，求在该时间段内最多能完整观看多少部互不重叠的电影。

解题思路：对单次询问采用区间调度贪心：每次选择当前能够开始且结束时间最早的电影，才能为后续电影留下最多时间。nxt[i][0] 表示开始时间不早于 i 的电影中，最小的结束时间。代码先对相同开始时间取最小结束时间，再从右向左做后缀最小值，从而得到该定义。

随后构造倍增表 nxt[i][j]，表示从时刻 i 开始，连续按贪心选择 2j2^j2j 部电影后的结束时刻，转移为 nxt[nxt[i][j - 1]][j - 1]。回答 [a, b] 时从高位向低位尝试：若 nxt[a][j] <= b，说明还能完整观看 2j2^j2j 部电影，于是累加数量并把 a 更新为新的结束时刻。时间值域大小为 M，预处理复杂度为 O(Mlog⁡M+n)O(M\log M+n)O(MlogM+n)，每次询问为 O(log⁡M)O(\log M)O(logM)。

Forest Queries II

题目大意：维护一个 n×nn\times nn×n 的森林网格，支持翻转某个格子的状态（树与空地互换），以及查询任意矩形内的树木数量。

解题思路：使用二维树状数组。add(x, y, v) 在点 (x, y) 加上 v，sum(x, y) 返回矩形 (1, 1) 到 (x, y) 内的元素和。初始化时，遇到树就在对应位置加 1。

翻转位置 (x, y) 前，先用四项容斥求出该单点当前的值：sum(x, y) - sum(x, y - 1) - sum(x - 1, y) + sum(x - 1, y - 1)。若结果为 1，就加 -1 删除树；否则加 1 种下树。查询左上角 (x, y)、右下角 (l, r) 的矩形时，同样通过四个前缀矩形容斥得到答案。二维树状数组的每次更新和查询复杂度均为 O(log⁡2n)O(\log^2 n)O(log2n)。

Range Updates and Sums

题目大意：维护一个数组，支持三种操作：将区间 [l, r] 的每个元素加上 x，将区间 [l, r] 的每个元素赋值为 x，以及查询区间 [l, r] 的元素和。

解题思路：使用同时支持区间加和区间赋值的懒标记线段树。每个节点保存区间和 sum、加法标记 lazy_inc，以及赋值标记 has_rev 和赋值内容 rev_val。increase(rt, v) 将整个节点区间加 v，区间和增加“区间长度乘 v”；revise(rt, v) 将整个区间赋值为 v，并清空此前的加法标记。

两个标记同时存在时，操作顺序不能颠倒。pushdown 先下传赋值，再下传加法，表示孩子先被覆盖成指定值，再叠加之后发生的增量。递归修改或查询时，完全不相交就直接返回，完全覆盖就更新当前节点，否则先下传标记，再递归处理左右孩子，最后用 pushup 合并。代码还维护了 Max 和 Min，但本题实际只使用 sum。每次操作的复杂度为 O(log⁡n)O(\log n)O(logn)；tr 和相关递归函数定义在 solve() 外。

Polynomial Queries

题目大意：维护一个数组，支持两种操作：对区间 [l, r] 依次加上 1,2,3,…,r−l+11,2,3,\ldots,r-l+11,2,3,…,r−l+1，以及查询区间 [l, r] 的元素和。

解题思路：使用三棵树状数组维护前缀和关于位置 x 的常数项、一次项和二次项系数。对于一次更新 [l, r]，位置 x 应增加 x-l+1。代码将其拆成 modify(r, 1, 1 - l) 和 modify(l - 1, -1, l - 1) 两次前缀贡献：第一部分描述对 [1, r] 加上线性函数，第二部分抵消 [1, l - 1] 上不应出现的贡献。

query(x) 累加三棵树状数组中的系数，并利用

∑k=1xk=x(x+1)2\sum_{k=1}^{x}k=\frac{x(x+1)}2 k=1∑x​k=2x(x+1)​

组合为 a + b * x + c * x * (x + 1) / 2，得到原数组 [1, x] 的总和。于是区间 [l, r] 的答案为 query(r) - query(l - 1)。每次更新和查询都只进行常数次树状数组操作，复杂度为 O(log⁡n)O(\log n)O(logn)。

Range Queries and Copies

题目大意：维护若干个数组，初始只有一个数组。支持修改指定数组 k 的某个位置、查询指定数组 k 的区间和，以及复制数组 k 并将副本作为一个新的数组加入集合。

解题思路：使用可持久化线段树。每个 Node 保存左右孩子指针和区间和 sum，trees[k] 保存第 k 个数组对应的根节点。build 根据初始数组建立第一棵树。

单点修改时，change 先通过 new Node(*p) 复制当前节点，再只递归修改包含目标位置的一个孩子；另一侧孩子继续与旧版本共享。因此一次修改只新建从根到叶子的 O(log⁡n)O(\log n)O(logn) 个节点，并将 trees[k] 替换为新根。复制数组时无需复制整棵树，只需执行 trees.push_back(trees[k])，让新数组暂时与原数组共享根节点；以后任一数组发生修改时，再通过路径复制分离。区间查询在指定根节点上递归求和。每个操作的时间复杂度为 O(log⁡n)O(\log n)O(logn)，总空间复杂度为 O(n+qlog⁡n)O(n+q\log n)O(n+qlogn)。

Missing Coin Sum Queries

题目大意：给定 n 枚硬币，第 i 枚硬币的面值为 c[i]。每次询问只允许使用下标位于 [l, r] 的硬币，每枚硬币最多使用一次，求无法凑出的最小正整数金额。

解题思路：先回顾经典结论：若当前使用若干硬币能够组成 [1, res] 内的所有金额，下一枚硬币面值不超过 res + 1 时，将它加入后就能连续组成到 res + coin；若下一枚硬币大于 res + 1，那么 res + 1 无法组成。

代码按照最高二进制位 id = __lg(c[i]) 将硬币分组。第 id 组的面值都位于 [2id,2id+1)[2^{id},2^{id+1})[2id,2id+1)。按组从低到高处理时，只要当前 res + 1 不小于该组的最小面值，组内硬币就可以按从小到大的顺序全部并入，因此只需知道该组在询问区间内的最小值和总和。

询问按右端点离线分组，并从左到右扫描右端点 i。对每个 id，单调栈维护后缀最小值候选；当新位置的值更小时，将被弹出位置的并查集父节点指向新位置。因此 get(id, ls[k]) 能找到区间 [ls[k], i] 中该组最小面值的位置。数组 t 保存每组的前缀和，可在 O(1)O(1)O(1) 时间得到该组区间总和。回答时从低位组到高位组执行上述贪心，不能接入当前组时立即停止，最终输出 res + 1。总复杂度为 O((n+q)log⁡C)O((n+q)\log C)O((n+q)logC)，其中 C 为面值上限。
