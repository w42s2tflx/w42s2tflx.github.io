Word Combinations

题目大意：给定字符串 s（长度 n，n≤5000n \le 5000n≤5000）和 k 个单词组成的词典，求用词典中的单词（可重复使用）从左到右完整拼接出 s 的方案数，对 109+710^9+7109+7 取模。

解题思路：

  • 观察：一个单词能否接在已拼出的前缀后面，只取决于它是否为 s 当前位置左侧某一段的后缀；把词典建成 AC 自动机后，「以当前位置 i 结尾的词典单词」恰好对应自动机当前状态沿 fail 链能到达的那些终止节点。

  • 做法：建 trie 并在 BFS 求 fail 边时把 fail 祖先的单词长度并入 out[u]——逐层推进保证 fail 的 out 已经完整，于是 out[v] 就是「走到状态 v 时以当前位置结尾的全部单词长度」。dp[i] 为 s 前 i 个字符的拼接方案数，dp[0] = 1；沿 s 走自动机，每走到状态 v 就对 out[v] 中每个长度 len 执行 dp[i] += dp[i-len]，答案取 dp[n]。

  • 正确性：按「最后一段单词的长度」给方案分类。out[v] 枚举的正是所有以位置 i 结尾的词典单词长度，每个合法切分因此被唯一计数一次；dp[0] = 1 对应空前缀这一种空切分。

  • 边界：扫描 s 的代价是各访问状态 out 表大小之和，词典中若含大量互为后缀的单词（如 a、aa、aaa），out 表会明显膨胀。总时间复杂度为 O(n+总单词长度+T)O(n + \text{总单词长度} + T)O(n+总单词长度+T)，其中 TTT 为扫描 s 时访问过的各状态 out 表大小之和；空间复杂度为 O(n+总单词长度)O(n+\text{总单词长度})O(n+总单词长度)。

String Matching

题目大意：统计模式串 p 在文本串 s 中出现的次数（作为子串，可重叠），∣s∣,∣p∣≤106|s|, |p| \le 10^6∣s∣,∣p∣≤106。

解题思路：

  • 做法：把两串拼成 t = p + '$' + s（$ 是不在两串中出现的分隔符）并求 t 的 Z 函数。z[i] 是 t 与「从位置 i 开始的后缀」的最长公共前缀长度；扫描 t 统计满足 z[i] == m（m 为 p 的长度）的位置个数即答案。Z 算法维护已算出的最右匹配段 [l, r]：i < r 时先令 z[i] = min(z[i-l], r-i)（取镜像位置的值，并用它到 r 的距离封顶，保证不越过已知边界），再逐字符向右扩展；r 只在扩展成功时更新。

  • 正确性：$ 既不在 p 中也不在 s 中，比较一旦推进到 j = m 就会拿 t[m] = '$' 去比 s 中的字符（或已到串尾），必然停下。于是 s 段中的位置都有 z[i] <= m，z[i] >= m 与 z[i] == m 在该段等价，恰好说明 p 出现在位置 i - m - 1；p 段中的位置在 j = m - i < m 时就已失配，z[i] < m，不会被误计数。

  • 边界：r 单调不减，每次扩展成功都把比较边界推得更远，故全部扩展的总次数不超过 ∣t∣|t|∣t∣（摊还）。时间复杂度为 O(n+m)O(n+m)O(n+m)，空间复杂度为 O(n+m)O(n+m)O(n+m)。

Finding Borders

题目大意：输出字符串 s（∣s∣≤106|s| \le 10^6∣s∣≤106）的所有 border（既是前缀又是后缀、且不等于整串的子串）的长度，按升序排列。

解题思路：

  • 做法：求 s 的 Z 函数。长度 L 是否为 border 的判据是 z[n-L] == L；对 i = n-1, n-2, \ldots, 1 依次检查 z[i] == n-i，成立就输出 L = n - i。

  • 正确性：z[n-L] >= L 表示从位置 n-L 开始的后缀与原串的最长公共前缀覆盖了整个后缀，即 s[0..L-1] = s[n-L..n-1]，这正是「长度 L 既是前缀又是后缀」；另一方面该后缀本身只有 L 个字符，z[n-L] 不可能超过 L。故 z[n-L] == L 与「L 是 border」等价，判据不重不漏。

  • 边界：循环范围 1 <= i <= n-1 对应 1 <= L <= n-1，L = 0 与 L = n（整串）都不在其中；i 递减使 L = n - i 递增，输出天然升序。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Finding Periods

题目大意：输出字符串 s（∣s∣≤106|s| \le 10^6∣s∣≤106）的所有周期长度 L：用前缀 s[0..L-1] 重复拼接能覆盖整串，且最后一个周期允许只取一部分。

解题思路：

  • 做法：求 s 的 Z 函数，对每个 L = 1, 2, \ldots, n 检查 z[L] >= n - L，成立则输出 L。

  • 正确性：z[L] >= n - L 表示从位置 L 开始的后缀与原串的公共前缀一直覆盖到串尾，即对每个 j∈[L,n−1]j \in [L, n-1]j∈[L,n−1] 都有 s[j] = s[j-L]：每个位置都与它前面第 L 个字符相同，也就是前缀被平移 L 后与自身吻合；反过来，L 为周期时这些等式全部成立，必有 z[L] >= n - L。等价地，L 是周期当且仅当长度 n−Ln-Ln−L 的串既是前缀又是后缀。

  • 边界：L = n 时不等式右端为 0，条件恒成立，整串长度总会被输出；L = 1 只在 s 全部由同一字符组成时成立。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Minimal Rotation

题目大意：求字符串 s（∣s∣≤106|s| \le 10^6∣s∣≤106）的所有循环旋转中字典序最小的那个。

解题思路：

  • 做法：minimal_rotation 内部先把 s 复制拼接成 s + s，在其上在线比较所有旋转起点。k 是当前最优起点，f 是失败函数，f[j-k-1] 给出以 k 为起点时已经匹配的公共前缀长度；把位置 j 依次加入比较，失配时若 s[j] < s[k+i+1] 就把最优起点更新为 k = j - i - 1，再令 i = f[i] 沿失败函数回退；匹配成功则记 f[j-k] = i + 1。返回的 k 即最优起点，输出 s.substr(k) + s.substr(0, k)。

  • 正确性：循环中 k 始终是已比较过的起点里字典序最小的旋转起点；失败函数让公共前缀的比对结果被保留下来，失配后从 f[i] 继续，不必重新从头比较。已匹配长度的增长与回退相互抵消，整个循环的摊还代价为 O(n)O(n)O(n)。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Longest Palindrome

题目大意：求字符串 s 的最长回文子串（s 长度可达 10610^6106）。

解题思路：

  • 做法：在 s 的每个字符间插入分隔符 # 得到 t（如 #a#b#a#），奇数长度与偶数长度的回文就都化为「以 t 中某个字符为中心的奇回文」。d[i] 为以 i 为中心的回文半径（含中心），对应区间 [i−d[i]+1,i+d[i]−1][i-d[i]+1, i+d[i]-1][i−d[i]+1,i+d[i]−1]。扫描时维护已到达的最右边界 l = i - k、r = i + k：i < r 时取 k = min(d[l+r-i], r-i)，否则取 k = 1，再逐字符向外扩展。最后取 d 最大的中心 center，把 t[center-d+1 .. center+d-1] 中的非 # 字符依次接起来即答案。

  • 正确性：i < r 时以 i 为中心的回文与以镜像 l+r-i 为中心的回文在 [l, r] 内逐位对称：镜像半径小于 r-i 时 d[i] 与之相等（再往外比较必定失败），否则 d[i] 至少为 r-i，需要继续向外验证。因此初值取两者较小者既不遗漏也不越界，随后的暴力扩展恰好补上超出部分；右边界 r 只在扩展成功时变大，全部扩展的总次数为 O(∣t∣)=O(n)O(|t|) = O(n)O(∣t∣)=O(n)。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

All Palindromes

题目大意：对字符串 s 的每个位置 i（1 起始），输出以 i 为右端点的最长回文子串的长度。

解题思路：

  • 观察：用 Manacher 求出全部奇回文半径 d1、偶回文半径 d2 后，只需对每个右端点 i 找覆盖它的最长回文。以奇回文为例：中心 c 的回文覆盖右端点区间 [c,c+d1[c]−1][c, c+d1[c]-1][c,c+d1[c]−1]，对区间内的 i 给出的长度为 2(i−c)+12(i-c)+12(i−c)+1，它随 c 减小而增大，所以在所有覆盖 i 的中心里取 c 最小者即最优。

  • 做法：扫描 i 时把「中心为 i、右端点为 i + d1[i] - 1（偶回文则为 i + d2[i] - 1）」的区间按 (中心, 右端点) 压入小根堆；堆顶右端点小于 i 的中心已无法覆盖当前右端点，惰性弹出，此后堆顶的 first 就是覆盖 i 的最小中心 c：奇回文答案取 2(i−c)+12(i-c)+12(i−c)+1、偶回文取 2(i−c+1)2(i-c+1)2(i−c+1)，与初值取大。

  • 边界：ans 初值为 1（每个单字符本身是回文）；d2[i] 可以为 0，这类区间入堆后立即因右端点小于 i 而被弹出，不影响结果。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Required Substring

题目大意：求长度为 n（n≤1000n \le 1000n≤1000）、由大写字母 A~Z 组成、且包含给定模式串 p（长度 m，m≤100m \le 100m≤100）作为子串的字符串个数，对 109+710^9+7109+7 取模。

解题思路：

  • 观察：逐个字符构造时，判断「模式串是否已经出现」不需要记住整个串，只需记住当前后缀能匹配 p 的最长前缀长度：再追加一个字符后，新的匹配长度只由这个长度和该字符决定，因此它可以作为 DP 的状态。

  • 做法：先求 p 的前缀函数 pi，pi[i] 是前缀 p[0..i] 的最长真 border 长度。再预处理 nxt[st][c]：从已匹配 st 个字符的状态出发追加字符 c，沿 pi[st-1]、pi[pi[st-1]-1]、… 回退到第一个能接上 c 的位置，接上后新状态为 j + 1；st = m 表示 p 已经出现，那一行统一填 m，不参与转移。dp[i][st] 表示构造了 i 个字符、当前匹配长度为 st 的串数，转移枚举字符 c 并跳过 nxt[st][c] == m 的边。

  • 正确性：bad 定义为所有满足 st<mst < mst<m 的 dp[n][st]dp[n][st]dp[n][st] 之和，它恰好是所有长度为 n 且不含 p 的串——这类串在构造过程中匹配长度始终不超过 m-1，唯一对应一条 DP 路径，反过来每条 DP 路径拼出的串也都不含 p。答案为补集，即 26n−bad26^n - bad26n−bad。

  • 边界：取模后的 26n26^n26n 与 bad 的大小关系不定，代码用 ((total - bad) % MOD + MOD) % MOD 修正可能出现的负数。时间复杂度为 O(n⋅m⋅26)O(n \cdot m \cdot 26)O(n⋅m⋅26)，空间复杂度为 O(n⋅m)O(n \cdot m)O(n⋅m)。

Palindrome Queries

题目大意：长度为 n 的字符串（n≤2×105n \le 2 \times 10^5n≤2×105）与 m 次操作，操作分两种：单点修改一个字符；查询子串 [a, b] 是否为回文。

解题思路：

  • 做法：分别维护正序与逆序的多项式哈希，各用一棵树状数组求前缀和。取底数 B = 911382323、模数 109+910^9+9109+9，令 f[i] = s[i] * B^i、g[i] = s[n-i+1] * B^i（幂表 pw[i] = B^i）：f 按原序维护、g 把串反转后维护。修改 s[k] 为 x 时对 f 的位置 k、对 g 的位置 n-k+1 分别加上 (x - s[k]) * pw[k] 与 (x - s[k]) * pw[n-k+1]；查询 [a, b] 时取 h1 = f.qry(a, b) * pw[n-b]、h2 = g.qry(n-b+1, n-a+1) * pw[a-1]。

  • 正确性：对齐后 h1 中 s[j]s[j]s[j] 的指数为 n−b+jn-b+jn−b+j，h2 中来自位置 j' 的项指数为 n+a−j′n+a-j'n+a−j′；两式指数相同时 j′=a+b−jj' = a+b-jj′=a+b−j，即互为 [a, b] 中的对称位置。于是 h1 == h2 等价于对所有 a <= j <= b 都有 s[j]=s[a+b−j]s[j] = s[a+b-j]s[j]=s[a+b−j]，正是「子串是回文」（哈希冲突概率可忽略）。相等输出 YES，否则 NO。

  • 边界：树状数组下标从 1 起，位置 k 在逆序串中对应 n-k+1，修改与查询都按这一对应取区间；g 的前缀和本身按逆序存放，查询区间也要相应反转。时间复杂度为 O((n+m)log⁡n)O((n+m) \log n)O((n+m)logn)，空间复杂度为 O(n)O(n)O(n)。

Finding Patterns

题目大意：给定文本串 s（∣s∣≤105|s| \le 10^5∣s∣≤105）和 k 个模式串（总长度 ≤5×105\le 5 \times 10^5≤5×105），对每个模式串判断它是否在 s 中出现过。

解题思路：

  • 做法：把所有模式串建成 trie，从根 BFS 求 fail 边并补全转移（不存在的儿子直接指向 fail 的对应儿子，使自动机读入任意字符都不需要回溯），同时用 order 记下 BFS 访问顺序。扫一遍 s，把走到的每个状态的 vis 置真；再按 order 的逆序把 vis 沿 fail 边向上传播。最后查每个模式串终止节点 term[i] 的 vis，为真输出 YES，否则 NO。

  • 正确性：走到状态 v 并置 vis，表示「以该位置结尾、长度等于 v 在 trie 中深度的串」出现过；fail 链恰好枚举 v 的所有后缀，故向上传播后 vis[x] 为真当且仅当 x 代表的串真正出现过，终止于 x 的模式串因此被正确判定。fail 边总指向 BFS 序中更早访问的状态，逆序传播保证儿子先于父亲处理完，一遍即可收敛。时间复杂度为 O(∣s∣+总模式长度)O(|s|+\text{总模式长度})O(∣s∣+总模式长度)，空间复杂度为 O(总模式长度)O(\text{总模式长度})O(总模式长度)。

Counting Patterns

题目大意：给定文本串 s（∣s∣≤105|s| \le 10^5∣s∣≤105）和 k 个模式串（总长度 ≤5×105\le 5 \times 10^5≤5×105），对每个模式串输出它在 s 中出现的次数。

解题思路：

  • 做法：建 AC 自动机，构建 fail 边时顺便把每个状态登记为 fail 的儿子 ch，得到 fail 树。扫一遍 s，走到一个状态就把它的 cnt 加 1；随后从根对 fail 树 DFS，回溯时把子树内的 cnt 全部累加到父节点。每个模式串的答案就是它终止节点 term[i] 的 cnt。

  • 正确性：fail 树中状态 t 是 v 的祖先，当且仅当 t 代表的串是 v 代表串的后缀。一次出现会使「该结束位置走到的状态」的 cnt 加 1，而这恰好就是「模式串在该位置出现」的条件；每个模式串的每次出现都让它的子树内恰好一个状态加 1，故子树和就是出现次数，不重不漏。时间复杂度为 O(∣s∣+总模式长度)O(|s|+\text{总模式长度})O(∣s∣+总模式长度)，空间复杂度为 O(总模式长度)O(\text{总模式长度})O(总模式长度)。

Pattern Positions

题目大意：给定文本串 s（∣s∣≤105|s| \le 10^5∣s∣≤105）和 k 个模式串（总长度 ≤5×105\le 5 \times 10^5≤5×105），对每个模式串输出它在 s 中第一次出现的位置（1 起始），未出现输出 -1。

解题思路：

  • 做法：沿用 fail 树的框架，把计数换成最早位置：扫描 s 时对第 i 个字符（1 起始）走到的状态执行 pos = min(pos, i)，再对 fail 树自底向上取 min。此时 term[i] 处的 pos 就是该模式串最早出现的结束位置。

  • 正确性：状态 v 在位置 i 被走到，说明「以 i 结尾、长度等于 v 深度的串」出现；fail 链枚举 v 的全部后缀，故子树取 min 之后 term[i] 收到的是「以该模式串为后缀的某个结束位置」中最小的那个，正是它首次出现的结束位置。

  • 边界：起点为 pos - 长度 + 1（1 起始）；pos 保留初值 10910^9109 说明该状态从未被走到，输出 -1。时间复杂度为 O(∣s∣+总模式长度)O(|s|+\text{总模式长度})O(∣s∣+总模式长度)，空间复杂度为 O(总模式长度)O(\text{总模式长度})O(总模式长度)。

Distinct Substrings

题目大意：给定平面上 n 个互不相同的整点（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），输出最近两点欧氏距离的平方。

解题思路：

  • 观察：最近点对的条带结论——按 x 排序依次扫描，设已求得的最小距离平方为 best，则 x 坐标之差已超过 best\sqrt{best}best​ 的点不可能再更新答案，只需保留 x 差不超过 best\sqrt{best}best​ 的活跃点。经典分治写法在合并时按 y 序遍历中线条带；代码用扫描线加按 y 有序的集合实现同一结论。

  • 做法：把点按 (x, y) 排序。集合 s 以 {y, x} 为键维护活跃点，条带宽度取 d = floor(sqrt(best)) + 1。处理 p[i] 时先把 p[i].first - p[j].first > d 的旧点逐个从集合中删除，再在集合中取 y 落在 [p[i].second - d, p[i].second + d] 内的点，逐一用 dx * dx + dy * dy 更新 best，最后把当前点插入集合；best 初值为 LLONG_MAX。

  • 正确性：若 dx>d=⌊best⌋+1dx > d = \lfloor\sqrt{best}\rfloor+1dx>d=⌊best​⌋+1，则 dx≥d+1>bestdx \ge d+1 > \sqrt{best}dx≥d+1>best​，从而 dx2>bestdx^2 > bestdx2>best，这样的点对不可能更新答案；删除只会发生一次且后续点的 x 更大，best 只减不增使条带只会变窄，被删的点无需恢复。条带内每个点至多与常数个候选点比较（几何打包论证），总比较次数为 O(n)O(n)O(n)。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Convex Hull

题目大意：给定平面上的 n 个点（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），构造凸包并输出凸包上的所有点——落在凸包边内部的共线点也要输出，先输出点数，再按任意顺序输出这些点。

解题思路：

  • 观察：凸包是包含全部点的最小凸多边形。本题要求输出边界上的所有点，因此弹栈判据必须取严格右转（叉积 < 0）：叉积为 0 表示三点共线，共线点位于凸包边上、属于答案；若写成 <= 0，共线的中间点会被弹出，输出就少了这些点。

  • 做法：Andrew 单调链。先把点按 (x, y) 排序并 unique 去重，再从左到右构造下凸壳：向栈 h 压入点之前，只要栈顶两点与新点 q 构成严格右转（cr(h[h.size() - 2], h.back(), q) < 0）就弹出栈顶，栈内从左到右因此始终是下凸壳；接着从右到左构造上凸壳，弹栈条件中加入 (int)h.size() > low（low 为下凸壳结束时的栈大小），避免把已建好的下凸壳弹掉；最后 h.pop_back() 去掉重复的起点。

  • 边界：去重后点数不超过 2，或者全部点共线时，两遍扫描会把中间点重复压栈，故先用 cr(p[0], p[1], p[i]) != 0 判断是否全共线，这两种情形都直接把全部点原样输出。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Intersection Points

题目大意：给定 n 条水平或竖直线段（水平线段 x1<x2x_1 < x_2x1​<x2​，竖直线段 y1<y2y_1 < y_2y1​<y2​），保证任意两条同方向的线段不相交、且线段的端点都不是交点。求交点总数。

解题思路：

  • 观察：沿 x 轴扫描，维护与扫描线相交的「活跃」水平线段在 y 轴上的分布；遇到竖直线段时，活跃水平线段中 y 落在这条竖直线段 [y1,y2][y_1,y_2][y1​,y2​] 内的个数就是它与该竖直线段的交点数。

  • 做法：每条水平线段拆成左端点处的 ADD 与右端点处的 REMOVE 事件，每条竖直线段在它的 x 处产生一个 QUERY 事件，所有事件按 x 排序；enum { QUERY, ADD, REMOVE } 使同一 x 处 QUERY 排在最前。y 坐标先离散化，线段树 Tree 按 y 的下标维护活跃水平线段条数：水平线段的两个 y 相同，ADD/REMOVE 是单点 +1/-1；QUERY 对 [y1, y2] 的压缩下标区间求和并累加进 ans。

  • 正确性：处理某条竖直线段时，树中恰好是所有覆盖该 x 的水平线段，区间求和统计的是端点落在 [y1,y2][y_1,y_2][y1​,y2​] 内的那些；由「端点不是交点」可知端点处的退化相交不会出现，因此计数不重不漏。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Line Segments Trace I

题目大意：n 条线段，左端点 x 坐标均为 0、右端点均为 m，且斜率都是整数（坐标绝对值可达 10910^9109）。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出所有线段在该 x 处的最大 y 值。

解题思路：

  • 观察：每条线段在 [0,m][0,m][0,m] 上就是一条完整直线 y=kx+by=kx+by=kx+b（整数斜率 k = (y2 - y1) / m、截距 b = y1）。对每个 x 求直线族在该点的最大值，就是求上包络的逐点取值，用 Li Chao 树处理。

  • 做法：每个节点存一条「在该区间内可能取到最大值」的直线。插入 add(node, l, r, nw) 先把新直线 nw 与节点直线在中点 mid 处比较，若 f(tr[node], mid) < f(nw, mid) 则交换，使中点处较优的直线留在 tr[node]；两条直线最多相交一次，较劣的那条至多在交点所在的一侧仍可能更优，代码依次检查 f(lo, l) < f(hi, l) 与 f(lo, r) < f(hi, r)，把较劣直线递归下放到相应的儿子。查询 qry 从根走到叶子，路径上每个节点的直线都可能在该点最优，逐层取 f 的最大值即为答案；Line 的默认参数让空节点的取值为极小的 NEG，不影响取最大。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)。

Line Segments Trace II

题目大意：n 条线段，端点 x 坐标都在 [0,m][0, m][0,m] 内、斜率均为整数。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出覆盖该 x 的线段中的最大 y 值；没有任何线段覆盖时输出 -1。

解题思路：

  • 观察：每条线段只在一个 x 区间上有效——线段两端为 (x1,y1)(x_1,y_1)(x1​,y1​)、(x2,y2)(x_2,y_2)(x2​,y2​)，所在直线为 y=ax+by=ax+by=ax+b，其中 a = (y2 - y1) / (x2 - x1)、b = y1 - a * x1，但它只能在 [x1,x2][x_1,x_2][x1​,x2​] 上参与取最大值，对应 Li Chao 树的区间插入。

  • 做法：addRange(node, l, r, ql, qr, nw) 把 [ql,qr][ql,qr][ql,qr] 递归拆成 O(log⁡m)O(\log m)O(logm) 个被完全覆盖的节点，在每个这样的节点上对 nw 调用一次普通 add；add 比较区间中点处两条直线的取值，把较优者留在 tr[node]，再把较劣者下放——两直线最多相交一次，故按 f(lo, l) < f(hi, l) 或 f(lo, r) < f(hi, r) 决定下放到左儿子还是右儿子。点查询 qry 沿根到叶的路径，对路径上每个节点存的直线在 x 处取最大值。

  • 边界：Line 的默认参数使空节点取值为 NEG，若 qry 的结果仍是 NEG，说明该点没有任何线段覆盖，输出 -1。斜率为整数意味着不会出现 x1=x2x_1=x_2x1​=x2​ 的竖直线段（代码中的跳过只是防御性处理）。总时间复杂度为 O(nlog⁡2m+mlog⁡m)O(n\log^2 m + m\log m)O(nlog2m+mlogm)。

  • 观察：把并集面积化成扫描线问题——沿 x 逐列统计被覆盖的 y 格子数，累加起来就是面积。

Robot Path

题目大意：机器人从原点出发，依次执行 n 条指令（方向 U/D/L/R 加步数），沿网格行走；一旦某条指令的第一步会踩上已经过的格子，机器人立即停下、之后的指令不再执行。求机器人最终移动的总距离。

解题思路：

  • 观察：机器人停下等价于路径在行走过程中首次回到已经过的点，即轴对齐线段序列首次出现自交；「前缀无自交」对前缀长度单调，于是可以二分最长的无自交前缀。

  • 做法：读入时把连续同方向的指令合并为一条线段，遇到与上一条方向相反的指令直接停止读入（走回头路必然立刻踩上已访问的格子）。把折点坐标离散化后，第 i 段是轴对齐线段，其 x 范围 [xl[i], xr[i]]、y 范围 [yd[i], yu[i]]。check(k) 判定前 k 段是否无自交：按 y 从小到大扫描，水平线段是覆盖 x 区间的区间事件，用 r 记录同一 y 上已覆盖到的最右端点，出现 r >= v.l 的重叠即冲突；竖直线段在下端 yd 处向树状数组单点 +1+1+1、在上端 yu 处 −1-1−1，处理水平线段时用区间和得到与它相交的活跃竖直线段数并从预算 bound 中扣除，扣成负数即冲突；竖直线段下端入库前若该点已有活跃竖直线段，同样判冲突（query(v.l) - query(v.l - 1) != 0）。

  • 正确性：前缀 k 段恰有 k−1k-1k−1 个相邻线段的公共端点，每个端点贡献 1 个交点，预算 bound = k-1 正为它们预留，因此扣成负数当且仅当存在额外交点；二分定位到首个冲突段的下标 j = upper - 1，第 j 段的起点就是机器人停下前的位置。

  • 边界：下标 0..j−10..j-10..j−1 的 j 段完整走过，距离逐段累加；第 j 段只走到与前面线段的第一个交点处——对每个 i<j−1i<j-1i<j−1（跳过与之共享端点的上一段）取它与第 j 段包围盒的交叠矩形，非空时用交叠矩形的一对对角 (l,d)(l,d)(l,d)、(r,u)(r,u)(r,u) 到当前位置的曼哈顿距离更新 wj（两线段正交相交时交叠矩形退化为交点，该距离即首个交点处）。总时间复杂度为 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)。
