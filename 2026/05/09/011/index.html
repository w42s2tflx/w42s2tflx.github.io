Point Location Test

题目大意：t 组测试（t≤105t \le 10^5t≤105），每组给出两个点确定一条直线和第三个点，判断从 p1 看向 p2 时 p3 在直线左侧、右侧还是直线上。坐标绝对值可达 10910^9109。

解题思路：叉积（二维向量外积 u⃗×v⃗=uxvy−uyvx\vec{u}\times\vec{v}=u_xv_y-u_yv_xu×v=ux​vy​−uy​vx​，符号表示 v⃗\vec{v}v 相对 u⃗\vec{u}u 的逆时针方向）。cross = (x2-x1)*(y3-y1) - (y2-y1)*(x3-x1) 即 p1p2→×p1p3→\overrightarrow{p_1p_2}\times\overrightarrow{p_1p_3}p1​p2​​×p1​p3​​：大于 0 时 p3 在左侧（逆时针），小于 0 在右侧，等于 0 共线。坐标差最大 2×1092\times10^92×109，乘积不超过 4×10184\times10^{18}4×1018，ll 不溢出。每组的时间复杂度为 O(1)O(1)O(1)。

Line Segment Intersection

题目大意：t 组测试（t≤105t \le 10^5t≤105），判断两条线段是否有公共点（相交或端点相接都算）。坐标绝对值可达 10910^9109。

解题思路：叉积判定 + 共线特判。两线段有公共点的充要条件：要么一条线段的两端点在另一条线段所在直线的两侧（两组叉积严格异号，即"跨立"），要么存在端点在另一条线段上（叉积为 0 时用 onSeg 判断点是否落在线段范围内：先验共线，再检查 x、y 坐标都在两端点之间）。每组的时间复杂度为 O(1)O(1)O(1)。

Polygon Area

题目大意：给定简单多边形的 n 个顶点（n≤1000n \le 1000n≤1000，坐标绝对值 ≤109\le 10^9≤109），输出多边形面积的 2 倍（保证为整数）。

解题思路：鞋带公式（把多边形顶点按顺序两两叉积求和，绝对值的一半为面积）。2S=∣∑i(xi⋅yi+1−xi+1⋅yi)∣2S=\left|\sum_i(x_i\cdot y_{i+1}-x_{i+1}\cdot y_i)\right|2S=∣∑i​(xi​⋅yi+1​−xi+1​⋅yi​)∣（下标循环，j = (i+1) % n），累加值即有向面积的 2 倍，取绝对值输出。多边形落在 [−109,109]2[-10^9,10^9]^2[−109,109]2 内，2S≤8×10182S\le8\times10^{18}2S≤8×1018，ll 足够。时间复杂度为 O(n)O(n)O(n)。

Point in Polygon

题目大意：给定一个 n 顶点的多边形（n,m≤1000n, m \le 1000n,m≤1000）和 m 个询问点，对每个点判断它在多边形内部、边界上还是外部。

解题思路：

  • 观察：射线法（从点向右作水平射线，与多边形边界的交点数若为奇数则点在内部、偶数在外部）判定内外。

  • 做法：先逐边检查点是否落在边上（onSeg，含端点），是则输出 BOUNDARY。否则统计交点：只处理"跨越射线高度"的边（(y[i] > py) != (y[j] > py)，恰一个端点在射线上方，避免端点被重复计数）；交点是否在点右侧用叉积式乘法比较（lhs 与 rhs 的符号），不除避免截断误差。

  • 正确性：半开规则（恰好一个端点在上方）使每条边对计数的贡献恰为其与射线真交点的个数，奇偶性即内外。时间复杂度为 O(nm)O(nm)O(nm)。

Polygon Lattice Points

题目大意：给定一个顶点坐标均为整数的简单多边形（n≤1000n \le 1000n≤1000，坐标绝对值 ≤106\le 10^6≤106），统计其内部和边界上的格点数量。

解题思路：

  • 观察：Pick 定理（顶点均为整点的简单多边形：S=I+B2−1S=I+\frac{B}{2}-1S=I+2B​−1，I 为内部格点数、B 为边界格点数）。

Minimum Euclidean Distance

题目大意：给定平面上的 n 个点（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），求最近两点欧氏距离的平方。

解题思路：

  • 观察：最近点对的经典分治/条带结论——按 x 排序扫描，若当前最优距离为 best，只有与当前点 x 坐标差 ≤best\le\sqrt{best}≤best​ 的点才可能更新答案。

  • 做法：维护按 y 排序的活跃点集（set）。条带宽度取 d = floor(sqrt(best)) + 1，把 x 差大于 d 的旧点移出集合；在集合中取出 y 落在 [y-d, y+d] 内的点逐一计算距离并更新 best；best 初始 LLONG_MAX。

  • 正确性：两候选点距离平方 dx2+dy2≥dx2dx^2+dy^2\ge dx^2dx2+dy2≥dx2，dx>d≥bestdx>d\ge\sqrt{best}dx>d≥best​ 时不可能更优；条带内候选点期望为常数（几何打包论证）。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Convex Hull

题目大意：给定平面点集（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），构造凸包，输出凸包上的所有顶点（边界上的共线点也要输出）。

解题思路：Andrew 单调链算法（先按 x、y 排序，从左到右构造下链、从右到左构造上链，用叉积弹出"右转"的点）。排序并去重后：点数不超过 2 或全部共线时，所有点都在凸包边界上，直接输出；否则每次加入新点时，只要最后两个点与新点构成严格右转（叉积 < 0）就弹出倒数第二个点；叉积等于 0 的共线点保留（满足"输出共线边界点"的要求）。最后弹出重复的起点。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Maximum Manhattan Distances

题目大意：一个集合最初为空，依次加入 n 个点，每次加入后输出当前集合中任意两点的最大曼哈顿距离。

解题思路：曼哈顿距离的坐标变换：45° 旋转（u=x+yu=x+yu=x+y，v=x−yv=x-yv=x−y）后，∣x1−x2∣+∣y1−y2∣=max⁡(∣u1−u2∣,∣v1−v2∣)|x_1-x_2|+|y_1-y_2|=\max(|u_1-u_2|,|v_1-v_2|)∣x1​−x2​∣+∣y1​−y2​∣=max(∣u1​−u2​∣,∣v1​−v2​∣)。只需维护 x+yx+yx+y 与 x−yx-yx−y 的最大最小值（mxp/mnp 与 mxm/mnm），每加入一个点更新四个值，答案 =max⁡(mxp−mnp, mxm−mnm)=\max(mxp-mnp,\ mxm-mnm)=max(mxp−mnp, mxm−mnm)。时间复杂度为 O(n)O(n)O(n)。

All Manhattan Distances

题目大意：给定 n 个点，求所有点对曼哈顿距离之和。坐标绝对值可达 10910^9109，答案可能超出 64 位。

解题思路：曼哈顿距离的 x、y 分量相互独立，分别求和再相加。把 x 坐标排序后，第 i 小的元素在 i 个"它被减"的对与 n−1−in-1-in−1−i 个"它去减"的对中出现，故 x 分量总和 =∑ixi⋅(i−(n−1−i))=\sum_i x_i\cdot\bigl(i-(n-1-i)\bigr)=∑i​xi​⋅(i−(n−1−i))；y 同理。答案可超出 64 位，用 __int128 累加，最后手写十进制输出（__int128 不能直接流输出）。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Intersection Points

题目大意：给定 n 条水平或垂直线段（水平线段 x1<x2x_1 < x_2x1​<x2​，竖直线段 y1<y2y_1 < y_2y1​<y2​），保证任意两条同方向的线段不相交、交点不在端点处。求交点总数。

解题思路：

  • 观察：扫描线——沿 x 扫描，维护"当前活跃的水平线段"在 y 轴上的分布；遇到竖直线段时，活跃水平线段中 y 落在 [y1,y2][y_1,y_2][y1​,y2​] 内的个数即该竖直线段与水平线段的交点数。

  • 做法：每条水平线段拆成左端点 ADD、右端点 REMOVE 两个事件，竖直线段是 QUERY 事件，全部按 x 排序（同一 x 处 QUERY 最先处理；交点不在端点处，顺序不影响正确性）。y 坐标先离散化；线段树维护活跃水平线段的 y（单点 ±1），QUERY 时区间求和累加。总时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Line Segments Trace I

题目大意：n 条线段，左端点 x 坐标均为 0、右端点均为 m，且斜率都是整数（坐标绝对值可达 10910^9109）。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出所有线段在该 x 处的最大 y 值。

解题思路：

  • 观察：每条线段对应一条贯穿 [0,m][0,m][0,m] 的直线 y=kx+by=kx+by=kx+b（整数斜率 k = (y2-y1)/m、截距 b = y1），对每个 x 求全部直线在该点的最大值——即"直线族上包络求值"，用 Li Chao 树（每个节点存一条在该区间内可能成为最大值的直线）解决。

  • 做法：插入 add：新直线与节点直线在区间中点比大小，较优者留在节点；较劣者至多在某一侧仍可能更优（两条直线最多交一次），递归下放该侧。查询 qry：从根到叶子路径上所有节点直线都可能在某点最优，一路取最大值。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)。

Line Segments Trace II

题目大意：n 条线段，端点 x 坐标都在 [0,m][0, m][0,m] 内、斜率均为整数。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出覆盖该 x 的线段中的最大 y 值；没有任何线段覆盖时输出 -1。

解题思路：与上一题类似，但每条线段只在区间 [x1,x2][x_1,x_2][x1​,x2​] 上有效，需要 Li Chao 树的区间插入：addRange 递归找到被查询区间完全覆盖的节点，在这些节点上各做一次普通 add（一条直线最多被拆到 O(log⁡m)O(\log m)O(logm) 个节点）。点查询取根到叶子路径上所有节点直线在 x 处的最大值。初始所有节点为空直线 NEG，查询结果仍为 NEG 说明无线段覆盖，输出 -1。斜率为整数保证 x1=x2x_1=x_2x1​=x2​ 的竖直线不会出现（代码中的跳过为防御性处理）。时间复杂度为 O((n+m)log⁡m)O((n+m)\log m)O((n+m)logm)。

Lines and Queries I

题目大意：动态处理两类操作：加入一条直线 y=ax+by = ax + by=ax+b；查询给定 x 处所有直线中的最大 y 值。

解题思路：Li Chao 树的全局插入与单点查询（结构见「Line Segments Trace I」）。每个节点存一条直线：插入时新直线与节点直线在区间中点比大小，较优者留节点、较劣者递归下放一侧；查询时从根到叶子路径上所有直线都可能在某点最优，一路取最大值。所有查询 x 都在 [0,105][0,10^5][0,105] 内（XMAX），插入 add(1, 0, XMAX, Line(a, b))；Line 默认截距 NEG，空节点不影响取 max。时间复杂度为 O(nlog⁡XMAX)O(n\log XMAX)O(nlogXMAX)。

Lines and Queries II

题目大意：动态处理两类操作：加入一条只在区间 [l,r][l, r][l,r] 内有效的直线 y=ax+by = ax + by=ax+b；查询给定 x 处所有有效直线中的最大 y 值，没有有效直线输出 NO。

解题思路：Li Chao 树的区间插入 + 点查询（核心思想与全局插入相同：节点存一条可能最优的直线，中点比较、劣者下放）。addRange 把直线递归拆到完全覆盖的节点上各做一次 add（最多 O(log⁡XMAX)O(\log XMAX)O(logXMAX) 个节点）。点查询取根到叶子路径上所有节点直线在 x 处的最大值；仍为 NEG 表示该点没有任何直线有效，输出 NO。

  • 正确性：x 处的最优直线必在它被下放路径的某个节点上存着，路径查询不会遗漏。总时间复杂度为 O(nlog⁡2XMAX)O(n\log^2 XMAX)O(nlog2XMAX)。

Area of Rectangles

题目大意：给定 n 个矩形（边平行于坐标轴，坐标在 [−106,106][-10^6, 10^6][−106,106] 内），求它们并集的面积。

解题思路：

  • 观察：求矩形并集面积，可沿 x 轴扫描，把问题化为"维护一列 y 单元格的被覆盖次数，统计覆盖数 > 0 的格子数"。

  • 做法：把 y 坐标加偏移映射到 [3,2M+3][3, 2M+3][3,2M+3]，在 [1,N−2][1, N-2][1,N−2] 上建线段树，节点维护区间覆盖次数最小值 Min 与达到最小值的格子数 cnt（平移后两侧永远留有空闲格，全局最小值恒为 0，tr[1].cnt 即未覆盖格子数）。逐列 x 扫描：先对该列开始的矩形区间 +1（懒标记 increase），统计该列被覆盖的格子数 N−2−tr[1].cntN-2-tr[1].cntN−2−tr[1].cnt 累加进答案，再对该列结束的矩形区间 -1。区间修改带懒标记，pushdown 下传、pushup 合并最小值与计数。

  • 正确性：每个矩形在其 x 范围覆盖相应 y 区间，逐列累计覆盖格子数即并集面积。时间复杂度为 O((n+M)log⁡M)O((n+M)\log M)O((n+M)logM)。

Robot Path

题目大意：机器人从原点出发，按 n 条指令（方向 + 步数）在网格上行走，一旦下一步会踩上已访问过的格子就停下。求它最终访问的格子数。

解题思路：

  • 观察：路径撞上已访问格等价于线段序列首次出现自交；"首次"具有单调性，可二分最长无自交前缀。

  • 做法：读入时合并同方向连续段；与上一条方向相反（立即走回头路）则提前终止。把路径整理成轴对齐线段并离散化端点。check(k) 判断前 k 条线段是否无自交：按 y 扫描——水平线段作为覆盖 x 区间的区间事件（r 记录当前 y 层已覆盖的最右端点，重叠即冲突），竖直线段作为单点加入/移除事件（Fenwick 树统计水平线段与竖直线的交点数量）；交点预算 bound = k - 1 耗尽也判冲突。对 check 二分出最长合法前缀 j：前 j−1j-1j−1 段的完整长度直接累加；第 j 段只走到与前面某线段的首个交点处——wj 取所有与第 j 段相交（包围盒重叠）的线段到当前位置的最近曼哈顿距离（对交叠矩形的四个角取值）。

  • 正确性：前缀线段无自交当且仅当 check 通过；二分定位首次冲突段，交点距离取最小即机器人停下的位置。总时间复杂度为 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)。
