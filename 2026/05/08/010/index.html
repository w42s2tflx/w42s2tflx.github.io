Word Combinations

题目大意：给定字符串 s（长度 n，n≤5000n \le 5000n≤5000）和 k 个单词组成的词典，求用词典中的单词（可重复使用）从左到右完整拼接出 s 的方案数，对 109+710^9+7109+7 取模。

解题思路：dp[i] 为 s 前 i 个字符的拼接方案数，dp[0] = 1。建 trie 连 fail 边的同时，把每个状态"经 fail 链能到达的单词结尾长度"收集进 out（构建时从 fail 祖先继承）。从左到右扫 s：走到状态 v 后，对 out[v] 中每个单词长度 len 执行 dp[i] += dp[i-len]（该单词恰以位置 i 结尾）。答案 dp[n]。时间复杂度为 O(n+总单词长度)O(n+\text{总单词长度})O(n+总单词长度)。

String Matching

解题思路：Z 函数：z[i]z[i]z[i] 为串与从位置 i 开头的后缀的最长公共前缀长度。构造 p + '$' + s（$ 为不出现的分隔符），则 s 内每个位置 i 的 z[i] 恰为它与 p 的最长公共前缀长度，z[i] == m 即出现一次。Z 算法用 [l, r] 维护已算出的最右匹配段：z[i] 先用 min(z[i-l], r-i) 初始化（利用对称性），再暴力扩展；r 只在扩展成功时右移，保证总扩展次数为 O(n+m)O(n+m)O(n+m)。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Finding Borders

题目大意：输出字符串 s（∣s∣≤106|s| \le 10^6∣s∣≤106）的所有 border（既是前缀又是后缀、且不等于整串的子串）的长度，按升序排列。

解题思路：border（既是真前缀又是真后缀的子串）的长度 L 满足：以 n - L 开头的后缀与原串的最长公共前缀至少覆盖整个后缀，即 z[n - L] >= L；又因该后缀长恰为 L，z[n - L] <= L 恒成立，故判 z[n - L] == L 等价。从 i = n - 1 扫到 1（i = n 对应 L = 0，非 border），L = n - i 自然递增，输出即升序。时间复杂度为 O(n)O(n)O(n)。

Minimal Rotation

题目大意：求字符串 s（∣s∣≤106|s| \le 10^6∣s∣≤106）的所有循环旋转中字典序最小的那个。

解题思路：

  • 做法：在 s + s 上在线比较所有旋转起点。维护当前最优起点 k 与失败函数 f（f[j - k - 1] 为已匹配长度）；逐个位置 j 加入比较，失配时若新字符更小则更新最优起点 k = j - i - 1，否则沿失败函数回退；匹配成功则 f[j - k] = i + 1。

  • 正确性：失败函数使比较过程中已匹配的公共前缀不被重复比较，每个字符的摊还代价为 O(1)O(1)O(1)；循环结束 k 即最小旋转起点。输出 s.substr(k) + s.substr(0, k)。时间复杂度为 O(n)O(n)O(n)。

Longest Palindrome

题目大意：求字符串 s 的最长回文子串（s 长度可达 10610^6106）。

解题思路：把原串插入分隔符变成 #a#b#a#，奇偶长度回文统一为"以某字符为中心的奇回文"；d[i] 为变换串中以 i 为中心的回文半径（含中心）。利用回文对称性：i 落在已知最右回文区间 [l, r] 内时，d[i] 先用镜像位置 l + r - i 的值初始化，再暴力向外扩展；r 只在扩展成功时右移，总扩展次数为 O(m)O(m)O(m)。取 d 最大的中心，展开时跳过 # 即得答案。时间复杂度为 O(n)O(n)O(n)。

All Palindromes

题目大意：对字符串 s 的每个位置 i，输出以 i 为右端点的最长回文子串的长度。

解题思路：

  • 观察：Manacher 求出所有奇回文半径 d1、偶回文半径 d2 后，对每个右端点 i 找覆盖它的最长回文。以奇回文为例：中心 c 的回文覆盖右端点区间 [c,c+d1[c]−1][c, c+d1[c]-1][c,c+d1[c]−1]，对其中每个 i 回文长为 2(i−c)+12(i-c)+12(i−c)+1；要最大，等价于在所有覆盖 i 的中心里取 c 最小（离 i 最远）者。

  • 做法：扫描 i 时把"中心为 i、右端点为 i + d1[i] - 1"的区间按 (中心, 右端点) 压入小根堆；堆顶右端点 <i< i<i 的中心已失效，惰性弹出，堆顶即最优中心。偶回文同理，长度 2(i−c+1)2(i-c+1)2(i−c+1)。时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)。

Inverse Suffix Array

题目大意：给定一个 1…n 的排列作为后缀数组（sa[i] 表示字典序第 i 小的后缀的起点），构造一个能产生该后缀数组的小写字母串，不存在输出 -1。

解题思路：

  • 观察：后缀数组（所有后缀按字典序排序的起点序列）给出 rank[sa[i]] = i。依次比较相邻后缀 a = sa[i]、b = sa[i+1]：若首字符相同，两后缀的大小关系必须由去掉首字符后的后缀决定，即要求 rank[a+1] < rank[b+1]（某后缀已到末尾时视为空后缀，字典序最小）；若满足，s[b] 可取与 s[a] 相同的字符，否则 s[b] 必须严格更大（字母序号 +1）。

  • 做法：cur 记录当前字母序号，超过 25 即无解输出 -1。构造出的串按上述规则满足全部相邻关系，由传递性整个后缀数组合法。时间复杂度为 O(n)O(n)O(n)。

String Transform

解题思路：逆 BWT（Burrows-Wheeler 变换：把串的所有循环移位按字典序排成方阵，取最后一列；变换后相同字符聚集成段，便于压缩，且可由最后一列唯一还原）。变换串是最后一列 L，第一列 F 即 L 排序结果。用计数排序建立 LF 映射 next[i]：L[i] 在 F 中的位置（start[c] + 该字符已出现次数），再取逆映射 succ。从 F 中 # 所在行出发沿 succ 走 n 步，依次读出 F 列字符（去掉 #）即原串——方阵每一行是原串的一个循环移位，succ 把"当前行"接到"其循环前驱行"。时间复杂度为 O(n)O(n)O(n)。
