Meet in the Middle

题目大意：给 n 个数（n≤40n \le 40n≤40）和一个目标 x，统计和为 x 的子集个数。

解题思路：折半搜索（把 2n2^n2n 的枚举拆成两个 2n/22^{n/2}2n/2，枚举一半、排序另一半后二分/双指针合并）。把数组分成两半，分别枚举两半的所有子集和（各 2n/22^{n/2}2n/2 个），枚举时剪掉和超过 x 的子集。把后一半的子集和排序，对前一半的每个和 v，统计后一半里等于 x - v 的个数（upper_bound - lower_bound）。时间复杂度为 O(2n/2log⁡2n/2)O(2^{n/2}\log 2^{n/2})O(2n/2log2n/2)。

Hamming Distance

题目大意：给 n 个长度为 m 的 01 串（n≤104n \le 10^4n≤104，m≤30m \le 30m≤30），求两两之间的最小汉明距离。

解题思路：把每个串压成整数掩码（第 j 位对应第 j 个字符），两串的汉明距离（等长串中对应位不同的个数）即 popcount(mask[i] ^ mask[j])。两个优化：先用哈希表去重，出现重复串时答案直接为 0；枚举数对时若当前最优值已是 1（最小可能值）就提前退出。时间复杂度为 O(n2)O(n^2)O(n2)。

Corner Subgrid Check

题目大意：n×nn\times nn×n 的字母网格，对字母表中前 k 个字母逐一判断：是否存在一个宽高都至少为 2 的子矩形，其四个角都是该字母。

解题思路：

  • 观察：四角同字母的矩形等价于"存在两行，它们至少有两列同时是该字母"。按每行内"该字母列对"总数 pairs 的大小分两种策略。

  • 做法：对字母 c 预处理 cols[c][i]（第 i 行该字母所在列）与行 bitset bs[c][i]。出现总次数小于 4 直接 NO。pairs 较小时用稀疏桶法：枚举每行的列对 (x, y)，把 y 放入桶 bucket[x]，再用时间戳 mark 检查某桶内是否有重复 y（免去每次清空）；pairs 很大时列对总数超过 (n2)\binom{n}{2}(2n​)，由鸽巢原理必有两行共享同一列对，直接用 bitset 行对（bs[c][i] & bs[c][j] 的 popcount ≥2\ge 2≥2）找出一对。总时间复杂度为 O(k⋅n2/64)O(k\cdot n^2/64)O(k⋅n2/64) 级别。

Reachable Nodes

题目大意：DAG 上有 n 个节点（n≤5×104n \le 5 \times 10^4n≤5×104），求每个节点能到达的节点数（含自身）。

解题思路：

  • 观察：拓扑排序后逆序 DP：reach[v]={v}∪⋃c∈children⁡(v)reach[c]reach[v]=\{v\}\cup\bigcup_{c\in\operatorname{children}(v)} reach[c]reach[v]={v}∪⋃c∈children(v)​reach[c]。直接开 n 个 n 位 bitset 内存过大，改为分块：把目标节点按块大小 B = 4096 分块，每块内只用 B/64=64B/64=64B/64=64 个 ull 词做反向拓扑 DP。

  • 做法：先 Tarjan 缩点成 DAG 并拓扑排序；dp[v] 表示 v 能到达当前块内的哪些节点，沿 DAG 反向 OR 起来，再把块内节点自身置位；处理完一块后，对每个原节点把其所在 SCC 的 dp popcount 累加进答案。一次只占 c×64×8c\times64\times8c×64×8 字节。

  • 正确性：同 SCC 节点互相可达；DAG 反向拓扑序保证 dp 转移时所有后继已算完。总时间复杂度为 O((n+m)⋅n/64)O((n+m)\cdot n/64)O((n+m)⋅n/64)。

Reachability Queries

题目大意：有向图（n≤5×104n \le 5 \times 10^4n≤5×104），q 次询问点 a 能否到达点 b。

解题思路：

  • 观察：先 Tarjan 缩点成 DAG 并拓扑排序；询问 a → b 可转化为分量间的可达性，把询问按目标分量分组后，用"每块 64 个目标 + 一个 ull 词"的 bitset 批量回答。

  • 做法：对每块 64 个目标分量做一次反向拓扑 DP：dp[v] 为 v 能到达当前块内哪些目标（一个 ull 词），沿拓扑逆序 OR，块内每个目标 t 用自己的位掩码 1 << (t - blk) 置位；之后遍历挂在 t 上的询问，查起点分量的 dp 对应位。答案只有 0/1，一个 ull 承载 64 个目标。总时间复杂度为 O((n+m+q)⋅n/64)O((n+m+q)\cdot n/64)O((n+m+q)⋅n/64)。

Cut and Paste

题目大意：长度为 n 的字符串（n≤5×105n \le 5 \times 10^5n≤5×105），m 次操作（m≤2×105m \le 2 \times 10^5m≤2×105）：把子串 [a, b] 剪下并拼接到字符串末尾。输出最终字符串。

解题思路：fhq Treap（无旋 Treap：按子树大小分裂、按随机优先级合并的平衡二叉搜索树，支持 O(log⁡n)O(\log n)O(logn) 的序列切分与拼接）。每个节点存字符、随机优先级和子树大小；split(t, k) 把前 k 个字符分到左树，merge 按优先级合并。一次剪切粘贴 = 三次 split（分出 [a-1]、[a,b]、剩余）+ 两次 merge（把 [a,b] 接到最后）。最后中序遍历输出。时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Substring Reversals

题目大意：长度为 n 的字符串（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），m 次操作：反转子串 [l, r]。输出最终字符串。

解题思路：

  • 观察：区间翻转只需"整体翻转子树"的懒标记，无需逐元素操作，可用 Splay（通过伸展把任意节点旋转到根的平衡树）把区间整段"提出"后打标记。

  • 做法：把序列建成 Splay（首尾各放哨兵节点），RotateTo(l - 1, 0) 与 RotateTo(r + 1, root) 把 [l, r] 旋成根右子树的左子树（Key_Tree），对其打 flip 标记（交换左右儿子并下传）即完成翻转。输出时对每个位置做区间最小值查询 Min(i, i) 还原字符；minx[0] = INF 使空子树不干扰取 min。时间复杂度为 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Necessary Roads

题目大意：连通无向图（n,m≤105n, m \le 10^5n,m≤105），找出所有"必要道路"——删掉后图不再连通的边（割边/桥）。

解题思路：Tarjan 求桥（桥：删除后图不再连通的边）。DFS 给每个点记录发现时间 tin 与 low（不经过父边能回溯到的最早时间）：对树边 (v, to)，若 low[to] > tin[v]，说明 to 的子树没有任何回边绕到 v 或 v 的祖先，该边即桥。用边编号 id 跳过父边——有重边时只跳过同一条边，平行边会被当作回边处理，正确判定两条平行边都不是桥。时间复杂度为 O(n+m)O(n+m)O(n+m)。

Distinct Routes II

题目大意：有向图，每天需要一条从 1 到 n 的路径（kkk 天，n≤500n \le 500n≤500，k≤500k \le 500k≤500），每条边全程最多被用一次。求 k 天的最小总边数，并输出每天的路径；无法凑出 k 条路径输出 -1。

解题思路：

  • 观察：把"每天一条路径、边不重复使用"建模为每条边容量 1、费用 1 的最小费用流：从 1 到 n 发送 k 单位流量，总费用即最小总边数；某轮 SPFA 找不到增广路说明流不满 k，输出 -1。

  • 做法：fwd 记录所有正向边，容量用尽（cap == 0）说明该边在流中；把有流边组成邻接表 adj，从 1 出发做 k 次 DFS 找一条到 n 的路径，边用过后立即删除，输出路径（顶点数 + 顶点序列）。

  • 正确性：整数流分解为 k 条边不相交路径（流量守恒），每条路径费用为其边数，总费用最小即总边数最小。总时间复杂度为 O(k⋅n⋅m)O(k\cdot n\cdot m)O(k⋅n⋅m)。
