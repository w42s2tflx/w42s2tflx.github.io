Counting Bits

题目大意：求 1..n1..n1..n 的所有数的二进制表示中 1 的总个数（n≤1018n \le 10^{18}n≤1018）。

解题思路：逐位统计。考虑 0..n0..n0..n 共 n+1n+1n+1 个数：第 b 位以 2b+12^{b+1}2b+1 为周期，每个完整周期恰有 2b2^b2b 个数该位为 1；剩余不足一周期部分的前 2b2^b2b 个数该位为 0、之后为 1。故第 b 位贡献 = (n+1) / 2^(b+1) * 2^b + max(0, (n+1) % 2^(b+1) - 2^b)；0 的贡献为 0，不影响结果。时间复杂度为 O(log⁡n)O(\log n)O(logn)。

Maximum Xor Subarray

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），求异或和最大的连续子数组的异或和。

解题思路：前缀异或 + 二进制 Trie（按二进制位构建的字典树，支持插入数并查询"与给定数异或最大"的数）。子数组 [l, r] 的异或 = pref[r] ^ pref[l-1]。从左到右扫描，维护已见前缀的 Trie（add）；对当前前缀 sum 在 Trie 上贪心走"相反的位"（query）：每层尽量取与 sum 不同的分支使结果该位为 1，不存在才走相同分支。初始插入 0（空前缀）；答案取所有 query(sum) 的最大值。时间复杂度为 O(nlog⁡V)O(n\log V)O(nlogV)。

Maximum Xor Subset

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105，值可达 2602^{60}260 级别），求任意子集（可空）异或和的最大值。

解题思路：

  • 观察：线性基（异或意义下的基：用若干向量表示"可由原集合异或生成"的线性空间；插入时按最高位做高斯消元式规约，基向量最高位互不相同，故线性无关）。

  • 做法：按位从高到低插入每个数：若当前最高位 b 尚无基向量则存入 basis[b]，否则异或掉该位继续。插入完求最大异或：从高位到低位贪心，若 ans ^ basis[b] > ans 则异或上（高位优先，把该位变 1 一定更优）。

  • 正确性：贪心按最高位递减选择，每个基向量最高位互异，逐位决策无后效，得到生成空间中最大值。时间复杂度为 O(60n)O(60n)O(60n)。

Number of Subset Xors

题目大意：给 n 个数（值 <263< 2^{63}<263），求所有子集（含空集）异或能得到多少个不同的值。

解题思路：

  • 观察：所有子集异或构成一个对异或封闭的线性空间，大小为 2rank2^{rank}2rank（rank 为线性基的秩）。

  • 正确性：插入线性基即高斯消元，每个数可表示成基向量异或，故任意子集异或是基向量的线性组合，至多 2rank2^{rank}2rank 种；反之任意一组 0/1 系数把系数为 1 的基向量异或起来，就得到某个子集的异或（每个基向量本身是若干原数的异或），2rank2^{rank}2rank 种组合全部可达；基向量线性无关使不同系数组合结果必然不同。故答案恰为 2rank2^{rank}2rank。插入时每成功放置一个基向量 rank++，答案 1LL << rank。时间复杂度为 O(60n)O(60n)O(60n)。

K Subset Xors

题目大意：给 n 个整数（0≤xi≤1090 \le x_i \le 10^90≤xi​≤109），把所有 2n2^n2n 个子集的异或（含空集的 0，重复按多次计）从小到大排序，输出前 k 小的值。

解题思路：

  • 做法：建线性基后高斯消元成简化阶梯形（对每个基向量 basis[b]，用低位基消掉其低位 1，使各基向量最高位互不占用）。此时第 idx 小的不同异或值 = 把 idx 的二进制位映射到基向量上异或（简化基保证结果随 idx 严格递增）；每个不同值重复 2n−r2^{n-r}2n−r 次（r 为秩：那些"自由"元素进不进子集都不改变异或值）。故第 i 个输出 = 第 i / mult 个不同值（mult = 2^(n-r)）。

  • 边界：n−rn-rn−r 很大时 1LL << (n-r) 会溢出——但此时 mult 超过 k，前 k 个输出全为 0，i / mult 恒为 0，idx 计算安全（代码中 mult 用 1LL << ... 在题目范围下不触发，属实现细节）。总时间复杂度为 O(60n+k⋅r)O(60n+k\cdot r)O(60n+k⋅r)。

All Subarray Xors

题目大意：给 n 个数（0≤xi≤1060 \le x_i \le 10^60≤xi​≤106），找出所有能作为某个连续子数组异或和的整数，去重后升序输出（含个数）。

解题思路：

  • 观察：子数组异或 = 两个前缀异或的异或，故目标集合 = 前缀异或集合（含 0）两两异或的所有结果，即对前缀异或计数数组做异或卷积（f[v]=∑a⊕b=vA[a]B[b]f[v]=\sum_{a\oplus b=v}A[a]B[b]f[v]=∑a⊕b=v​A[a]B[b]）。

  • 做法：用快速 Walsh-Hadamard 变换（FWHT：异或卷积的"傅里叶变换"，每层蝴蝶 (u+v,u−v)(u+v, u-v)(u+v,u−v)；变换后逐点平方，再逆变换（每层除 2））。得 f[v] = 异或为 v 的有序前缀对数；f[0] -= (n+1) 排除"两个相同前缀"的对（来自空子数组与同起点，不对应非空子数组）。f[v] > 0 的 v 升序输出。

  • 正确性：FWHT 的蝴蝶变换把"按位异或的卷积"对角化，平方再逆变换即自卷积；去重后每个 v 恰对应一个可产生的子数组异或。值域 2202^{20}220，总时间复杂度为 O(220⋅20)O(2^{20}\cdot 20)O(220⋅20)。

题目大意：异或金字塔：每个数是其左下方、右下方两个数的异或。给定底层 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105，ai≤109a_i \le 10^9ai​≤109），求顶端那个数。

解题思路：

  • 观察：把每层每个数展开成底层的异或，底层 aia_iai​ 在顶端出现 (n−1i−1)\binom{n-1}{i-1}(i−1n−1​) 次（每向上一层，下标 i 和 i+1 合并一次，路径数即组合数），系数奇偶决定是否参与。由 Lucas 定理（(mk)\binom{m}{k}(km​) 为奇数当且仅当 k 的二进制位全部包含在 m 里，即 k⊆mk\subseteq mk⊆m），aia_iai​ 参与当且仅当 (i−1)⊆(n−1)(i-1)\subseteq(n-1)(i−1)⊆(n−1)。

  • 做法：不需枚举子集，用"步长合并"：对 mask = n - 1 的每个 1 位 b，执行 cur[j] ^= cur[j + 2^b]（把相距 2b2^b2b 的元素合并一次）；全部位处理完后 cur[0] 恰是所有满足 i−1⊆n−1i-1\subseteq n-1i−1⊆n−1 的 aia_iai​ 的异或（SOS 子集异或的原地实现）。时间复杂度为 O(n⋅popcount(n))O(n\cdot\text{popcount}(n))O(n⋅popcount(n))。

题目大意：给 n 个数（0≤ai≤n0 \le a_i \le n0≤ai​≤n），对每个 k = 0..n 统计"元素按位与恰好等于 k"的非空子集个数，对 109+710^9+7109+7 取模。

解题思路：

  • 观察：两步变换。先算 cnt[mask]cnt[mask]cnt[mask] = 满足 ai⊇maska_i\supseteq maskai​⊇mask 的元素个数（超集 SOS 求和）；由这些元素组成的任意非空子集，其 AND 都 ⊇mask\supseteq mask⊇mask，个数 f[mask]=2cnt[mask]−1f[mask]=2^{cnt[mask]}-1f[mask]=2cnt[mask]−1。此时 f[k]=∑mask⊇kg[mask]f[k]=\sum_{mask\supseteq k}g[mask]f[k]=∑mask⊇k​g[mask]（g 为 AND 恰好等于的值）。

  • 做法：从 f 反演 g：按位做超集莫比乌斯变换 g[mask] = f[mask] - g[mask | (1<<b)]（对每个位 b，mask 不含位 b 时依次相减），等价于对"超集前缀和"做差分。
