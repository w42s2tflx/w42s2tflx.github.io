Word Combinations

题目大意：给定字符串 s（长度 n，n≤5000n \le 5000n≤5000）和 k 个单词组成的词典，求用词典中的单词（可重复使用）从左到右完整拼接出 s 的方案数，对 109+710^9+7109+7 取模。

解题思路：DP + Aho-Corasick 自动机。dp[i] 表示 s 的前 i 个字符的拼接方案数，dp[0] = 1。把所有单词建成 trie 并连好 fail 边，同时把每个状态"经由 fail 链能到达的单词结尾长度"收集进 out 列表（构建 fail 时从 fail 祖先继承 out）。然后从左到右扫 s：走到状态 v 后，对 out[v] 里的每个单词长度 len，dp[i] += dp[i - len]（该单词恰好以位置 i 结尾）。答案 dp[n]。复杂度 O(n+总单词长度)O(n + \text{总单词长度})O(n+总单词长度)。

String Matching

题目大意：统计模式串 p 在文本串 s 中出现的次数（作为子串，可重叠）。

解题思路：Z 算法。构造 p + '$' + s（$ 是不出现的分隔符）求 Z 函数：对于 s 内的每个位置 i，z[i] 就是该位置与 p 的最长公共前缀长度，z[i] == m 说明出现一次。Z 算法用 [l, r] 维护已算出的最右匹配段，让每个字符的扩展摊还 O(1)O(1)O(1)。复杂度 O(n+m)O(n + m)O(n+m)。

Finding Borders

题目大意：输出字符串 s 的所有 border（既是前缀又是后缀、且不等于整串的子串）的长度，按升序排列。

解题思路：Z 函数。长度为 L 的前缀是 border 当且仅当它与以 n - L 开头（即结尾处）的后缀相同，也就是 z[n - L] == L。从 i = n - 1 向 1 扫，L = n - i 自然递增。复杂度 O(n)O(n)O(n)。

Finding Periods

题目大意：输出字符串 s 的所有周期长度 L：用前缀 s[0..L-1] 重复拼接能覆盖整串，且最后一个周期允许只取一部分。

解题思路：Z 函数。L 是周期当且仅当从位置 L 开始的后缀与前缀的公共前缀长度至少为 n - L，即 z[L] >= n - L（位置 L 起的每一格都与前缀对应位置相同，整串被前缀的循环覆盖）；L == n 平凡成立，单独输出。复杂度 O(n)O(n)O(n)。

Minimal Rotation

题目大意：求字符串 s 的所有循环旋转中字典序最小的那个。

解题思路：Booth 算法，在 s + s 上在线比较所有旋转起点。维护当前最优起点 k 和失败函数 f：逐个位置 j 加入比较，f[j - k - 1] 记录已匹配长度，失配时若新字符更小就更新最优起点 k = j - i - 1，否则按失败函数回退。最终 k 即最小旋转的起点，输出 s.substr(k) + s.substr(0, k)。复杂度 O(n)O(n)O(n)。

Longest Palindrome

题目大意：求字符串 s 的最长回文子串（s 长度可达 10610^6106）。

解题思路：Manacher 算法。把原串插入分隔符变成 #a#b#a# 的形式，这样奇偶长度的回文统一为"以某个字符为中心的奇回文"。d[i] 表示变换串中以 i 为中心的回文半径（含中心），利用回文的对称性：当 i 落在已知的最右回文区间 [l, r] 内时，d[i] 先用镜像位置 l + r - i 的值初始化，再暴力向外扩展；r 只在扩展成功时右移，保证总扩展次数 O(m)O(m)O(m)。取 d 最大的中心，展开时跳过 # 即得答案。复杂度 O(n)O(n)O(n)。

All Palindromes

题目大意：对字符串 s 的每个位置 i，输出以 i 为右端点的最长回文子串的长度。

解题思路：Manacher 求出所有奇回文半径 d1、偶回文半径 d2 后，对每个右端点找覆盖它的最长回文。以奇回文为例：中心 c 的回文覆盖右端点区间 [c, c + d1[c] - 1]，对其中每个位置 i，回文长度为 2 * (i - c) + 1。要最大，等价于在所有覆盖 i 的中心里取 c 最小（离 i 最远）的那个。扫描 i 时把"中心为 i、右端点为 i + d1[i] - 1"的区间按 (中心, 右端点) 压入最小堆，堆顶右端点小于 i 的中心已失效，惰性弹出；堆顶即最优中心。偶回文同理，长度为 2 * (i - c + 1)。复杂度 O(nlog⁡n)O(n \log n)O(nlogn)。

Required Substring

题目大意：求长度为 n（n≤1000n \le 1000n≤1000）、由大写字母 A~Z 组成、且包含给定模式串 p（长度 m，m≤100m \le 100m≤100）作为子串的字符串个数，对 109+710^9+7109+7 取模。

解题思路：KMP 自动机 + DP。先求 p 的前缀函数 pi，再预处理转移表 nxt[st][c]：当前已匹配 p 的前 st 个字符时，再读入字符 c 后最长能匹配到哪个前缀（在 pi 上回退）。dp[i][st] 表示构造了 i 个字符、匹配到状态 st < m（即尚未完整出现模式串）的方案数，转移时跳过 nxt[st][c] == m 的边。所有避免出现 p 的串数为 bad = Σ dp[n][st]，总串数为 26n26^n26n，答案 total - bad。复杂度 O(n⋅m⋅26)O(n \cdot m \cdot 26)O(n⋅m⋅26)。

Palindrome Queries

题目大意：长度为 n 的字符串（n≤2×105n \le 2 \times 10^5n≤2×105），支持两种操作：单点修改一个字符；查询子串 [a, b] 是否为回文。

解题思路：滚动哈希 + 树状数组。选大质数模数 109+910^9+9109+9 和底数 B = 911382323。正序串存 f[i] = s[i] * B^i，逆序串存 g[i] = s[n - i + 1] * B^i，各自用 BIT 维护前缀和，单点修改只需在两个 BIT 上加上差值。查询 [a, b]：正序哈希 h1 = Σ s[i]·B^{i} 乘 pw[n - b]；逆序对应区间是 [n - b + 1, n - a + 1]，哈希乘 pw[a - 1]。把 h1 的逐项展开并做下标代换后，若 s[a..b] 是回文（s[j]=s[a+b−j]s[j] = s[a+b-j]s[j]=s[a+b−j]），两项恰好相等，所以 h1 == h2 即判 YES。复杂度 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Finding Patterns

题目大意：给定文本串 s 和 k 个模式串，对每个模式串判断它是否在 s 中出现过。

解题思路：Aho-Corasick 自动机。把所有模式串建成 trie，BFS 连好 fail 边并补全转移。在文本串上走一遍自动机，标记所有访问到的状态 vis；一个模式串出现，当且仅当它的终止节点被访问过，或终止节点沿 fail 链能到达某个被访问状态（出现位置结尾对应的后缀链）。所以最后按 BFS 序逆序把 vis 沿 fail 边向上传播，再查每个模式串的终止节点。复杂度 O(∣s∣+总模式长度)O(|s| + \text{总模式长度})O(∣s∣+总模式长度)。

Counting Patterns

题目大意：给定文本串 s 和 k 个模式串，对每个模式串输出它在 s 中出现的次数。

解题思路：Aho-Corasick。扫文本串时，每走到一个状态就给它的计数 cnt 加 1——这表示"以当前字符结尾的最长匹配后缀"。一个模式串的出现次数等于它终止节点在 fail 树子树内的 cnt 总和（fail 树中父节点是对应后缀状态）。构建 fail 边时顺便记录 fail 树的儿子 ch，BFS 结束后对 fail 树做一遍 DFS 自底向上累加即可。复杂度 O(∣s∣+总模式长度)O(|s| + \text{总模式长度})O(∣s∣+总模式长度)。

Pattern Positions

题目大意：给定文本串 s 和 k 个模式串，对每个模式串输出它在 s 中第一次出现的位置（1 起始），未出现输出 -1。

Distinct Subsequences

题目大意：给定字符串 s，求它的不同子序列（按位置选出的序列，相同内容只算一次）的个数，对 109+710^9+7109+7 取模。

解题思路：DP。count[c] 表示以字符 c 结尾的不同子序列个数。从左到右扫 s：新字符 s[i] 可以作为新的单字符子序列，也可以接在之前任意一个子序列后面，所以 count[s[i]] = 1 + Σ_c count[c]——直接把 count[s[i]] 覆盖成这个值，正是"去重"的关键：同一字符结尾的子序列只在最后一次出现的位置更新，之前重复的都作废。答案 =∑ccount[c]= \sum_c count[c]=∑c​count[c]。复杂度 O(26n)O(26n)O(26n)。

Repeating Substring

题目大意：求字符串 s 中出现至少两次的最长子串（两次出现可重叠），不存在输出 -1。

解题思路：后缀自动机 + endpos 计数。建机后按 len 做计数排序得到拓扑序（长度越大越靠前），先把每个前缀对应的状态 occ = 1，再倒序把 occ 累加到 link 上，得到每个状态的真实出现次数；同时沿 link 传递每个状态的最早出现位置 minp。最后取 occ >= 2 且 len 最大的状态 best，答案子串为 s[minp - bestLen + 1 .. minp]。复杂度 O(n)O(n)O(n)。

String Functions

题目大意：输出字符串 s 的 Z 函数（z[0..n-1]）与 KMP 前缀函数（pi[0..n-1]），各占一行。

解题思路：直接实现两个经典算法。Z 函数用 [l, r] 表示已算出的最右匹配段：z[i] 先取 min(z[i - l], r - i) 再暴力扩展。前缀函数：pi[i] 为前缀 s[0..i] 的最长真 border，从 pi[i - 1] 回退找到能接上 s[i] 的位置。复杂度 O(n)O(n)O(n)。

Inverse Suffix Array

题目大意：给定一个 1…n 的排列作为后缀数组（sa[i] 表示字典序第 i 小的后缀的起点），构造一个能产生该后缀数组的小写字母串，不存在输出 -1。

解题思路：由后缀数组可知 rank[sa[i]] = i。依次比较相邻的两个后缀 a = sa[i]、b = sa[i + 1]：若 a 的当前字符与 b 相同，则两个后缀的大小关系必须由去掉首字符后的后缀决定，即要求 rank[a + 1] < rank[b + 1]（某个后缀已到末尾时视为空后缀，一定最小）；若满足，s[b] 可以取与 s[a] 相同的字符，否则 s[b] 必须严格更大（字母序号 +1）。用 cur 记录当前字母序号，超过 25 即无解输出 -1。复杂度 O(n)O(n)O(n)。

String Transform

题目大意：给定一个字符串经过 Burrows-Wheeler 变换后的结果（长度为 n，含一个哨兵字符 #，它是原串末尾的标记且字典序最小），还原出原字符串。

解题思路：逆 BWT。变换串是最后一列 L，第一列 F 就是 L 排好序的结果。用计数排序建立 LF 映射 next[i]：第 i 行最后一个字符 L[i] 在 F 中的位置（start[c] + 该字符已出现次数），取逆映射 succ。从 F 中 # 所在的行出发，沿 succ 走 n 步，依次读出的 F 列字符（去掉 #）就是原串——BWT 的每一行是原串的一个循环移位，succ 恰好把"当前行"接到"该行的循环前驱"。复杂度 O(n)O(n)O(n)。

Substring Order I

题目大意：把字符串 s 的所有不同子串按字典序排序，输出第 k 小的子串。

解题思路：后缀自动机上数路径。每个状态 v 表示一组子串，从 v 出发的所有转移边对应"后面再接一个字符"的选择。按 len 从大到小的拓扑序倒推 ways[v] = 1 + Σ ways[next[v][c]]：1 是"在这里停下"（当前状态代表的子串本身），其余是向后扩展。求第 k 小：从根开始贪心，按字符 a..z 尝试每条边，若 k > ways[u] 说明前 ways[u] 个子串都以这个字符开头，k -= ways[u] 跳过；否则选定该字符、k-- 并进入 u，直到 k == 0。复杂度 O(26n)O(26n)O(26n)。

Substring Order II

题目大意：把字符串 s 的所有子串（含重复，每个出现位置算一次）按字典序排序，输出第 k 小的子串。

解题思路：后缀自动机 + endpos 计数。先按长度拓扑序累加每个状态的 occ（该状态代表子串的出现次数）。ways[v] = occ[v] + Σ ways[next[v][c]]：occ[v] 是"在这个状态停下"的贡献——当前状态代表的子串在排序中的连续 occ[v] 个条目；其余是向后扩展。求第 k 小：在状态 v ≠ 0 时先判断 k <= occ[v]，是则答案就是当前串（不必再扩展），否则 k -= occ[v] 并继续沿字符边贪心；每次选定字符后不需要再 k--（第 k 条被 occ 计数吸收）。复杂度 O(26n)O(26n)O(26n)。

Substring Distribution

题目大意：对每个长度 L = 1..n，输出字符串 s 的长度为 L 的不同子串个数。

解题思路：后缀自动机。每个状态 v 贡献一组不同子串，长度为 len[link[v]] + 1 到 len[v] 的连续区间，恰好每个长度一个。用差分数组 diff：对每个状态做 diff[len[link[v]] + 1]++、diff[len[v] + 1]--，最后前缀和即每个长度的答案。复杂度 O(n)O(n)O(n)。
