Meet in the Middle

题目大意：给 n 个数（n≤40n \le 40n≤40）和一个目标 x，统计和为 x 的子集个数。

解题思路：折半搜索。把数组分成两半，分别枚举两半的所有子集和（各 2n/22^{n/2}2n/2 个），枚举时顺手把和超过 x 的子集剪掉（if (s <= x)）。把后一半的子集和排序，对前一半的每个和 v，统计后一半里等于 x - v 的个数（upper_bound - lower_bound）。时间复杂度为 O(2n/2log⁡2n/2)O(2^{n/2} \log 2^{n/2})O(2n/2log2n/2)。

Hamming Distance

题目大意：给 n 个长度为 m 的 01 串（n≤104n \le 10^4n≤104，m≤30m \le 30m≤30），求两两之间的最小汉明距离。

解题思路：把每个串压成一个整数掩码（第 j 位对应第 j 个字符），两个串的汉明距离就是 popcount(mask[i] ^ mask[j])。两个小优化：先用哈希表去重，出现重复串时答案直接为 0；枚举数对时若当前最优值已经是 1（最小可能）就提前退出。时间复杂度为 O(n2)O(n^2)O(n2)。

Corner Subgrid Check

题目大意：n×nn\times nn×n 的字母网格，对字母表中前 k 个字母逐一判断：是否存在一个宽高都至少为 2 的子矩形，其四个角都是该字母。

解题思路：一个四角同字母的矩形等价于"存在两行，它们有两列同时是该字母"。对每个字母 c 预处理 cols[c][i]（第 i 行该字母所在的列）和对应的 bitset bs[c][i]。统计该字母出现的总次数与"每行内列对"总数 pairs：出现次数小于 4 直接 NO。pairs 较小时用稀疏桶法：枚举每行的列对 (x, y)，把 y 放进桶 bucket[x]，之后检查每个桶里是否有重复的 y（用时间戳 mark 数组，避免每次清空）；pairs 很大时列对总数超过 C(n,2)C(n, 2)C(n,2)，由鸽巢原理必有两行共享同一列对，此时直接用 bitset 行对（bs[c][i] & bs[c][j] 的 popcount ≥2\ge 2≥2）找出一对即可。时间复杂度为 O(k⋅n2/64)O(k \cdot n^2 / 64)O(k⋅n2/64) 级别。

Corner Subgrid Count

题目大意：n×nn\times nn×n 的 01 网格（n≤3000n \le 3000n≤3000），统计四角全是 1 的子矩形（宽、高至少 2）的个数。

Reachable Nodes

题目大意：DAG 上有 n 个节点（n≤5×104n \le 5 \times 10^4n≤5×104），求每个节点能到达的节点数（含自身）。

解题思路：拓扑排序后逆序 DP：reach[v]={v}∪⋃reach[child]reach[v] = \{v\} \cup \bigcup reach[child]reach[v]={v}∪⋃reach[child]。直接开 n 个 n 位 bitset 内存过大，改成分块：把目标节点按块大小 B = 4096 分块，每块内只用 B/64 = 64 个 ull 词做反向拓扑 DP——dp[v] 表示 v 能到达当前块内的哪些节点，沿 DAG 反向 OR 起来，再把块内节点自身置位；处理完一块后，对每个原节点把其所在 SCC 的 dp popcount 累加进答案。这样一次只占 c×64×8c \times 64 \times 8c×64×8 字节。时间复杂度为 O((n+m)⋅n/64)O((n + m) \cdot n / 64)O((n+m)⋅n/64)。

Reachability Queries

题目大意：有向图（n≤5×104n \le 5 \times 10^4n≤5×104），q 次询问点 a 能否到达点 b。

解题思路：先 Tarjan 缩点成 DAG 并拓扑排序，把询问按目标分量分组。对每块 64 个目标分量做一次反向拓扑 DP：dp[v] 是 v 能到达当前块内哪些目标（一个 ull 词），沿拓扑逆序 OR；块内每个目标 t 用自己的位掩码 1 << (t - blk) 检查所有询问它的起点分量。因为答案只有 0/1，一个 ull 就能承载 64 个目标，全部块处理完总时间复杂度为 O((n+m+q)⋅n/64)O((n + m + q) \cdot n / 64)O((n+m+q)⋅n/64)。

Cut and Paste

题目大意：长度为 n 的字符串（n≤5×105n \le 5 \times 10^5n≤5×105），m 次操作（m≤2×105m \le 2 \times 10^5m≤2×105）：把子串 [a, b] 剪下并拼接到字符串末尾。输出最终字符串。

解题思路：fhq Treap（无旋 Treap）按位置维护字符序列。每个节点保存字符、随机优先级和子树大小，split(t, k) 把前 k 个字符分到左树，merge 按优先级合并。一次剪切粘贴 = 三次 split（分出 [a-1]、[a,b]、剩余部分）+ 两次 merge（把 [a,b] 接到最后）。最后中序遍历输出。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Substring Reversals

题目大意：长度为 n 的字符串（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），m 次操作：反转子串 [l, r]。输出最终字符串。

解题思路：区间翻转用带懒标记的 Splay 维护。把序列建成 Splay（首尾各放一个哨兵节点 INF），RotateTo(l - 1, 0) 和 RotateTo(r + 1, root) 把区间 [l, r] 旋转成根右子树的左子树（Key_Tree），对其打 flip 标记（交换左右儿子并下传）即可完成翻转，无需真正逐元素操作。输出时对每个位置做区间最小值查询 Min(i, i) 还原字符。minx[0] = INF 保证空子树不干扰取 min。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Necessary Roads

题目大意：连通无向图（n,m≤105n, m \le 10^5n,m≤105），找出所有"必要道路"——删掉后图不再连通的边（割边/桥）。

解题思路：Tarjan 求桥。DFS 时给每个点记录发现时间 tin 和 low（不经过父边能回溯到的最早时间）：对树边 (v, to)，若子树 to 的 low[to] > tin[v]，说明 to 子树没有任何回边绕到 v 或 v 的祖先，这条边就是桥。用边的编号 id 跳过父边（处理重边时只跳过同一条边，另一条平行边会被当作回边，正确判定它俩都不是桥）。时间复杂度为 O(n+m)O(n + m)O(n+m)。

Necessary Cities

Eulerian Subgraphs

题目大意：无向图（n,m≤105n, m \le 10^5n,m≤105），统计所有节点度数均为偶数的边子集（欧拉子图）个数，对 109+710^9+7109+7 取模。

Monster Game I

解题思路：DP。设 dp[i] 为"最后一次在 i 关击杀"的最小耗时，转移：要么从初始系数直接杀 i 关（耗时 x * s[i]），要么上一次在 j < i 关击杀（此后技能系数一直是 f[j]），耗时 dp[j] + s[i] * f[j]。即

dp[i]=min⁡(x⋅si, min⁡j<i(fj⋅si+dp[j]))dp[i] = \min\Big(x \cdot s_i,\ \min_{j < i} (f_j \cdot s_i + dp[j])\Big) dp[i]=min(x⋅si​, j<imin​(fj​⋅si​+dp[j]))

把每个 j 看成一条直线 y=fj⋅t+dp[j]y = f_j \cdot t + dp[j]y=fj​⋅t+dp[j]（斜率 fjf_jfj​、截距 dp[j]dp[j]dp[j]），每次在 t=sit = s_it=si​ 处求最小值——用维护最小值的 Li Chao 树：先插入初始直线 (x, 0)，每关先查询 qry(s[i]) 得 dp，再插入直线 (f[i], dp)。f 的单调性在此解法中不必要。时间复杂度为 O(nlog⁡M)O(n \log M)O(nlogM)。

dp[j][i]=min⁡p<i(dp[j−1][p]+(prefi−prefp)2)dp[j][i] = \min_{p < i} \big(dp[j-1][p] + (pref_i - pref_p)^2\big) dp[j][i]=p<imin​(dp[j−1][p]+(prefi​−prefp​)2)

dp[l][r]=min⁡l≤m<r(dp[l][m]+dp[m+1][r]+(prefr−prefl−1))dp[l][r] = \min_{l \le m < r} \big(dp[l][m] + dp[m+1][r] + (pref_r - pref_{l-1})\big) dp[l][r]=l≤m<rmin​(dp[l][m]+dp[m+1][r]+(prefr​−prefl−1​))

New Roads Queries

Dynamic Connectivity

题目大意：无向图（n≤105n \le 10^5n≤105），有 m 条初始边和 k 个操作（m,k≤105m, k \le 10^5m,k≤105）：加一条边、删一条边。输出初始状态以及每次操作后的连通分量数。

解题思路：离线线段树分治 + 可撤销并查集。每条边只在若干时间点存在，用 map 记录它出现的时间：删除时把存活区间 [出现, 删除前] 插入线段树节点，最后未删除的边存活到 k。DFS 线段树：进入节点时合并该节点存的所有边（并查集 unite 把修改压入历史栈），叶子处记录当前连通分量数，回溯时 rollback 撤销到进入前的状态。时间复杂度为 O((m+k)log⁡k⋅α)O((m + k) \log k \cdot \alpha)O((m+k)logk⋅α)。

Parcel Delivery

题目大意：从城市 1 向城市 n 送 k 件包裹（n≤500n \le 500n≤500，k≤50k \le 50k≤50）。每条边有容量 c 和单件成本 d，求最小总成本；不可能送完 k 件输出 -1。

解题思路：最小费用最大流。每条边容量 c、费用 d，加一条费用 -d 的反向边用于退流。用 SPFA 不断找从 1 到 n 的当前最短路（费用最小）增广，每次沿路径压入尽可能多的流量（瓶颈容量），直到流量达到 k；若最短路不可达说明无法送完，输出 -1。费用只在有容量的边上走（e.cap > 0）。时间复杂度为 O(k⋅n⋅m)O(k \cdot n \cdot m)O(k⋅n⋅m)。

Task Assignment

题目大意：n 个员工、n 个任务（n≤200n \le 200n≤200），每个员工做每个任务有成本，求总成本最小的分配方案，并输出每个员工分配的任务。

解题思路：匈牙利算法求最小权完美匹配（对偶变量的形式）。u[i]、v[j] 是行、列的势，minv[j] 记录当前增广中列 j 的最小松弛值，way[j] 记录松弛的来源。对每个员工做一轮增广：从未匹配列出发，在未用列中找最小松弛列，更新势并前进，最后沿 way 链翻转匹配。全部增广完后 p[j] 是列 j 匹配的行，员工 i 分配任务 assign[i] = p 的反函数。正确性来自势的互补松弛：势 u[i] + v[j] 保证缩减成本 c[i][j]−u[i]−v[j]c[i][j] - u[i] - v[j]c[i][j]−u[i]−v[j] 非负，而匹配边恰好落在缩减成本为 0 的边上；每轮增广的 delta 是"抬升整条零成本增广路径"所需的最小值，所有 delta 的和恰好等于匹配边的总成本。v[0] 在每轮更新时累加 -delta，所以最优总成本 =−v[0]= -v[0]=−v[0]；代码中直接按匹配结果累加 c[i][assign[i]-1] 得到同样的值。时间复杂度为 O(n3)O(n^3)O(n3)。

Distinct Routes II

题目大意：有向图，每天需要一条从 1 到 n 的路径（kkk 天，n≤500n \le 500n≤500，k≤500k \le 500k≤500），每条边全程最多被用一次。求 k 天的最小总边数，并输出每天的路径；无法凑出 k 条路径输出 -1。

解题思路：把"每天一条路径、边不重复使用"建模为每条边容量 1、费用 1 的最小费用流，从 1 到 n 发送 k 单位流量，总费用就是最小总边数；某轮 SPFA 找不到增广路说明流不满 k，输出 -1。最后还要把流量分解成路径：fwd 记录所有正向边，容量用尽（cap == 0）说明该边在流中，把有流边组成邻接表 adj，从 1 出发 k 次 DFS 找一条到 n 的路径，边用过后立即删除，输出路径（顶点数 + 顶点序列）。时间复杂度为 O(k⋅n⋅m)O(k \cdot n \cdot m)O(k⋅n⋅m)。
