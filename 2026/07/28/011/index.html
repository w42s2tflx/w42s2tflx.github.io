Point Location Test

题目大意：t 组测试（t≤105t \le 10^5t≤105），每组给出两个点确定一条直线和第三个点，判断从 p1 看向 p2 时 p3 在直线左侧、右侧还是直线上。坐标绝对值可达 10910^9109。

解题思路：叉积。cross = (x2 - x1) * (y3 - y1) - (y2 - y1) * (x3 - x1)：大于 0 说明 p3 在左侧（p1→p2 方向逆时针转到 p1→p3），小于 0 在右侧，等于 0 共线。坐标差最大 2×1092 \times 10^92×109，两项乘积各不超过 4×10184 \times 10^{18}4×1018，ll 不会溢出。每组时间复杂度为 O(1)O(1)O(1)。

Line Segment Intersection

题目大意：t 组测试（t≤105t \le 10^5t≤105），判断两条线段是否有公共点（相交或端点相接都算）。坐标绝对值可达 10910^9109。

解题思路：叉积判断 + 共线特判。两条线段相交的充要条件是：要么一条线段的两个端点在另一条线段所在直线的两侧（两组叉积异号），要么有端点在另一条线段上（共线时用 onSeg 判断点是否落在线段范围内）。onSeg 先验共线（叉积为 0），再检查 x、y 坐标都在两端点之间。每组时间复杂度为 O(1)O(1)O(1)。

Point in Polygon

题目大意：给定一个 n 顶点的多边形（n,m≤1000n, m \le 1000n,m≤1000）和 m 个询问点，对每个点判断它在多边形内部、边界上还是外部。

解题思路：先逐边检查询问点是否落在某条边上（onSeg，含端点），落在边上输出 BOUNDARY。否则用射线法：从点向右作水平射线，统计它与多边形边的交点数，奇数在内部、偶数在外部。计数时只处理"边跨越射线高度"的边（(y[i] > py) != (y[j] > py)，等价于恰好一个端点在射线上方，避免端点重复计数）；交点是否在点右侧用叉积式乘法比较（lhs 与 rhs），不除避免截断误差。时间复杂度为 O(nm)O(nm)O(nm)。

Polygon Lattice Points

题目大意：给定一个顶点坐标均为整数的简单多边形（n≤1000n \le 1000n≤1000，坐标绝对值 ≤106\le 10^6≤106），统计其内部和边界上的格点数量。

解题思路：Pick 定理：S=I+B/2−1S = I + B/2 - 1S=I+B/2−1，其中 III 是内部格点数，BBB 是边界格点数。边界格点数：一条连接两个整点的线段（坐标差 dx, dy）经过的格点数为 gcd⁡(∣dx∣,∣dy∣)\gcd(|dx|, |dy|)gcd(∣dx∣,∣dy∣)（线段端点之一不重复计数，逐边累加正好得到总边界格点数）。s 用鞋带公式得到 2S2S2S，则 I=(2S−B)/2+1I = (2S - B)/2 + 1I=(2S−B)/2+1，代码即 (s - B) / 2 + 1。时间复杂度为 O(n)O(n)O(n)。

Minimum Euclidean Distance

题目大意：给定平面上的 n 个点（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），求最近两点欧氏距离的平方。

解题思路：按 x 排序后扫描，维护一个按 y 排序的活跃点集（set）。当前最优距离为 best 时，只有与当前点 x 坐标差不超过 best\sqrt{best}best​ 的点才可能更新答案，所以维护条带宽度 d = floor(sqrt(best)) + 1，把 x 差大于 d 的旧点移出集合；在集合中取出 y 落在 [y - d, y + d] 内的点逐一计算距离。条带内的候选点数量期望为常数，best 初始为 LLONG_MAX。总时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Convex Hull

题目大意：给定平面点集（n≤2×105n \le 2 \times 10^5n≤2×105，坐标绝对值 ≤109\le 10^9≤109），构造凸包，输出凸包上的所有顶点（边界上的共线点也要输出）。

解题思路：Andrew 单调链算法。按 x、y 排序并去重。点数不超过 2 或全部共线时，所有点都在凸包边界上，直接输出。否则先从左到右构造下链，再从右到左构造上链：每次加入新点时，只要最后两个点与新点构成严格右转（叉积 < 0）就弹出倒数第二个点；叉积等于 0 的共线点保留（这正是"输出共线边界点"的要求）。最后弹出重复的起点。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Maximum Manhattan Distances

题目大意：一个集合最初为空，依次加入 n 个点，每次加入后输出当前集合中任意两点的最大曼哈顿距离。

解题思路：曼哈顿距离可以转成两种变换之差的最大值：

∣x1−x2∣+∣y1−y2∣=max⁡(∣(x1+y1)−(x2+y2)∣, ∣(x1−y1)−(x2−y2)∣)|x_1 - x_2| + |y_1 - y_2| = \max\big(|(x_1+y_1)-(x_2+y_2)|,\ |(x_1-y_1)-(x_2-y_2)|\big) ∣x1​−x2​∣+∣y1​−y2​∣=max(∣(x1​+y1​)−(x2​+y2​)∣, ∣(x1​−y1​)−(x2​−y2​)∣)

所以只需要维护 x+yx+yx+y 和 x−yx-yx−y 两种值的最大最小值（mxp/mnp 与 mxm/mnm），每加入一个点更新四个值，答案 =max⁡(mxp−mnp, mxm−mnm)= \max(mxp - mnp,\ mxm - mnm)=max(mxp−mnp, mxm−mnm)。时间复杂度为 O(n)O(n)O(n)。

All Manhattan Distances

题目大意：给定 n 个点，求所有点对曼哈顿距离之和。坐标绝对值可达 10910^9109，答案可能超出 64 位。

Intersection Points

题目大意：给定 n 条水平或垂直线段（水平线段 x1<x2x_1 < x_2x1​<x2​，竖直线段 y1<y2y_1 < y_2y1​<y2​），保证任意两条同方向的线段不相交、交点不在端点处。求交点总数。

解题思路：扫描线。把每条水平线段拆成两个事件：左端点 ADD、右端点 REMOVE；竖直线段是一个 QUERY 事件。所有事件按 x 排序（同一 x 处 QUERY 编号最小、最先处理，因为交点不在端点处，顺序不影响正确性）。扫描时用线段树维护"当前活跃水平线段"所在的 y 坐标（单点 +1/-1），遇到竖直线段就区间求和 [y1, y2] 内的活跃水平线段数，累加即交点总数。y 坐标先离散化。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Line Segments Trace I

题目大意：n 条线段，左端点 x 坐标均为 0、右端点均为 m，且斜率都是整数（坐标绝对值可达 10910^9109）。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出所有线段在该 x 处的最大 y 值。

解题思路：每条线段对应一条贯穿 [0,m][0, m][0,m] 的直线 y=kx+by = kx + by=kx+b，其中整数斜率 k = (y2 - y1) / m、截距 b = y1。把直线全部插入 Li Chao 树（值域 [0,m][0, m][0,m]），再对每个 x 查询最大值。Li Chao 树的插入：新直线与当前节点存的最优直线在中点比大小，较优者留在节点，较劣者只在某一侧还可能更优，递归下放一侧。时间复杂度为 O((n+m)log⁡m)O((n + m) \log m)O((n+m)logm)。

Line Segments Trace II

题目大意：n 条线段，端点 x 坐标都在 [0,m][0, m][0,m] 内、斜率均为整数。对每个整数 x∈[0,m]x \in [0, m]x∈[0,m]，输出覆盖该 x 的线段中的最大 y 值；没有任何线段覆盖时输出 -1。

解题思路：与上一题类似，但每条线段只在区间 [x1,x2][x_1, x_2][x1​,x2​] 上有效，需要 Li Chao 树的区间插入：addRange 递归地找到完全覆盖的节点，在该节点上做普通的 add（一条直线最多被拆到 O(log⁡m)O(\log m)O(logm) 个节点上）。点查询时取根到叶子路径上所有节点直线在 x 处的最大值。初始所有节点都是 NEG（空直线），查询结果仍为 NEG 说明无线段覆盖，输出 -1。斜率为整数保证了 x1 == x2 的竖直线不会出现，代码里的跳过是防御性的。时间复杂度为 O((n+m)log⁡m)O((n + m) \log m)O((n+m)logm)。

Lines and Queries I

题目大意：动态处理两类操作：加入一条直线 y=ax+by = ax + by=ax+b；查询给定 x 处所有直线中的最大 y 值。

解题思路：Li Chao 树的全局插入与单点查询。Li Chao 树每个节点存一条直线：插入时新直线与节点直线在区间中点比大小，较优者留在节点、较劣者递归下放一侧；查询时从根到叶子路径上所有直线都可能在某点最优，一路取最大值即可。所有查询的 x 都在 [0,105][0, 10^5][0,105] 内（XMAX），直线插入 add(1, 0, XMAX, Line(a, b))。Line 的默认截距是 NEG，保证空节点不影响取 max。时间复杂度为 O(nlog⁡XMAX)O(n \log XMAX)O(nlogXMAX)。

Lines and Queries II

题目大意：动态处理两类操作：加入一条只在区间 [l,r][l, r][l,r] 内有效的直线 y=ax+by = ax + by=ax+b；查询给定 x 处所有有效直线中的最大 y 值，没有有效直线输出 NO。

解题思路：Li Chao 树的核心思想是"每个节点存一条在该区间内可能成为最优的直线"：插入新直线时与节点当前直线在区间中点比较，中点处更大的留在节点，另一条只可能在左半或右半区间还更优，递归下放到对应子树。本题的区间插入：addRange 把直线递归拆到完全覆盖的节点上各做一次 add（一条直线最多拆到 O(log⁡XMAX)O(\log XMAX)O(logXMAX) 个节点）。点查询取根到叶子路径上所有节点直线在 x 处的最大直线值；仍为 NEG 表示该点没有任何直线有效，输出 NO。正确性：一个 x 处的最优直线必然在它被下放路径的某个节点上存着，路径查询不会漏。时间复杂度为 O(nlog⁡2XMAX)O(n \log^2 XMAX)O(nlog2XMAX)。

Area of Rectangles

题目大意：给定 n 个矩形（边平行于坐标轴，坐标在 [−106,106][-10^6, 10^6][−106,106] 内），求它们并集的面积。

解题思路：扫描线 + 线段树。把 y 坐标整体加偏移（+M 再加 1）映射到 [3,2M+3][3, 2M+3][3,2M+3]，在 [1,N−2][1, N-2][1,N−2] 上建树维护每个 y 单元格被覆盖的次数的最小值 Min 及达到最小值的格子数 cnt。逐列 x 扫描：先对该列开始的矩形区间 +1，再统计"未覆盖的 y 格子数"（因为平移后两侧永远留有空闲格，全局最小值恒为 0，tr[1].cnt 就是未被覆盖的格子数），该列被覆盖的格子数 =N−2−tr[1].cnt= N - 2 - tr[1].cnt=N−2−tr[1].cnt 累加到答案；处理完再对该列结束的矩形区间 -1。区间修改用懒标记，get_Min 查询全局最小值。时间复杂度为 O((n+M)log⁡M)O((n + M) \log M)O((n+M)logM)。

Robot Path

题目大意：机器人从原点出发，按 n 条指令（方向 + 步数）在网格上行走，一旦下一步会踩上已访问过的格子就停下。求它最终访问的格子数。

解题思路：参考 rainboy 的写法，核心是二分 + 扫描线。

  1. 读入指令时合并同方向连续段，若某条指令与上一条方向相反（会立刻走回头路）则提前终止；把路径整理成若干条轴对齐线段，端点坐标做离散化。
  2. check(k) 判断前 k 条线段构成的路径是否无自交：按 y 扫描，水平线段作为覆盖 x 区间的区间事件，竖直线段作为单点加入/移除事件，用 Fenwick 树统计水平线段与竖直线的交点数量；同一 y 上两条水平线段重叠、或交点预算（bound）耗尽都判定冲突。
  3. 对 check 二分出最长合法前缀 j，机器人就在第 j 段上第一次撞上已访问格。前 j - 1 段完整覆盖的格子数直接累加；第 j 段只走到与前面某条线段的首个交点处，wj 取所有与第 j 段相交的线段中"到当前点最近的交点距离"的最小值（对交叠矩形的四个角取曼哈顿距离）。

时间复杂度为 O(nlog⁡2n)O(n \log^2 n)O(nlog2n)。
