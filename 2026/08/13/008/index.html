Tree Algorithms

Subordinates

题目大意：公司关系构成一棵以 1 号员工为根的树（n≤2×105n \le 2 \times 10^5n≤2×105）。对每名员工，求其所有直接和间接下属的数量。

解题思路：从根节点开始做后序 DFS。进入节点 u 时先令 sz[u]++，把 u 自身计入；递归处理每个孩子 v 后，再把整棵子树的大小 sz[v] 累加到 sz[u]。因此 DFS 结束后，sz[u] 表示以 u 为根的子树节点数，答案需要输出 sz[u] - 1，减去员工 u 自己。叶子的 sz[u] 为 1，所以答案自然为 0。每条边只访问两次，时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Tree Matching

题目大意：在树（n≤2×105n \le 2 \times 10^5n≤2×105）中选择尽可能多的边，并要求任意两条被选边不能共享端点，求最多能选择多少条边。

解题思路：树上最大匹配用树形 DP。dfs(node, parent) 返回两个数：dp[0] 表示强制 node 不与任何孩子匹配时，node 子树内最多能选的边数；dp[1] 表示不限制 node 是否已与某个孩子匹配时的最大值。两个状态在逐个合并孩子 child 时同步更新（等式右侧都是合并前的旧值）：

  • 用边 (node, child) 匹配：要求 node 此前未匹配、child 也未与自己的孩子匹配，候选为 dp[0] + child_dp[0] + 1；
  • 不用这条边：孩子子树独立取最优，候选为 dp[1] + max(child_dp[0], child_dp[1])，而未匹配状态变为 dp[0] + max(child_dp[0], child_dp[1])。

代码把第一种与后两种一起写成 dp[1] = max(dp[0] + child_dp[0] + 1, dp[1] + child_dp[1], dp[1] + child_dp[0])，恰好覆盖"与当前孩子匹配 / 不与它匹配"的全部选择。node 至多与一个孩子匹配，而每个孩子只在其被合并时决策一次，因此不重不漏；归纳可知两个状态始终是各自定义下的最优值。叶子返回 {0, 0}，根节点答案为两个状态的较大值。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Tree Diameter

题目大意：求树上（n≤2×105n \le 2 \times 10^5n≤2×105）任意两个节点之间距离的最大值，即树的直径长度。距离按路径包含的边数计算。

解题思路：利用树的性质：从任意节点出发，距离最远的节点一定可以作为某条直径的端点。设从 x 出发最远到达 y，而任意取一条直径 (a, b)；由于树上任意两点的路径唯一，x 到 y 的路径与这条直径要么在某个点分叉，要么不相交，由"y 是 x 的最远点"可推出 dist(y, a) 与 dist(y, b) 中至少有一个不小于原直径长度，于是 y 可以作为一条（新的）直径的端点。因此两次 DFS 即可：第一次从 1 号出发得到端点 c，第二次从 c 出发得到另一个端点，距离即为直径。全局变量 c 始终记录当前 DFS 找到的最远节点，dep[u] 记录起点到 u 的距离；第二次搜索中同一个全局 c 会被更新为另一个直径端点，最终 dep[c] 就是直径长度。单节点树不会进入任何边，初始 c 和 dep[c] 均为 0，输出也正确。两次 DFS 的时间复杂度均为 O(n)O(n)O(n)，总时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Tree Distances I

题目大意：对树（n≤2×105n \le 2 \times 10^5n≤2×105）中的每个节点，求它到其他节点的最大距离。

解题思路：先用 dfs1 自底向上计算。max_dist[u][0] 和 max_dist[u][1] 分别保存从 u 出发的最大、次大距离，update 负责按大小插入候选值；每个孩子 v 提供 max_dist[v][0] + 1。再用 dfs2 换根，把经过父节点方向的距离传给孩子。若父节点的最大值恰好由当前孩子贡献，即 max_dist[node][0] == max_dist[child][0] + 1，就不能原路返回该孩子，必须传父节点的次大值加 1；否则传最大值加 1。即使多个孩子给出相同最大值，代码选择次大值仍然正确，因为 update 会把相等的另一份最大贡献保存在次大位置。两遍 DFS 后，max_dist[i][0] 已覆盖子树内和子树外所有方向，因此就是答案。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Tree Distances II

题目大意：对树（n≤2×105n \le 2 \times 10^5n≤2×105）中的每个节点，求它到其余所有节点的距离之和。

解题思路：第一次 DFS 以 1 为根，计算每个节点的子树大小 sz[u] 和深度 dep[u]。代码令 dep[u] = dep[fa] + 1，而全局数组初始为 0，所以根的 dep[1] 是 1；计算根的距离和时使用 dep[i] - 1，得到实际的边数距离。随后从父节点 u 换根到孩子 v：v 子树内的 sz[v] 个节点距离都减少 1，其余 n - sz[v] 个节点距离都增加 1，因此

ans[v]=ans[u]−sz[v]+(n−sz[v]).ans[v] = ans[u] - sz[v] + (n - sz[v]). ans[v]=ans[u]−sz[v]+(n−sz[v]).

fun 按此公式自顶向下求出全部答案。ans、sz 和 dep 使用 ll，可容纳距离总和。时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Company Queries I

题目大意：公司层级构成一棵以 1 号员工为根的树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）。每次询问员工 x 向上第 k 级的上级；若不存在，输出 -1。

解题思路：建立倍增表 jmp[i][j]，表示员工 i 向上 2j2^j2j 级后的节点。输入直接给出 jmp[i][0]；之后按 jmp[i][j + 1] = jmp[jmp[i][j]][j] 递推。代码在 (1 << j) <= n 时填写第 j + 1 列，而查询使用 j = 19...0，数组第二维为 20，覆盖题目中 k 可能用到的所有二进制位。全局数组的 0 号行默认为 0，因此不存在的祖先会沿表继续停在 0，0 同时充当哨兵。查询时枚举 k 的置位并跳跃，最终 x == 0 就输出 -1。预处理时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，每次查询为 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Company Queries II

题目大意：公司层级构成一棵以 1 号员工为根的树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105）。每次询问两名员工最近的共同上级，即最低公共祖先（LCA）。

解题思路：代码使用重链剖分求 LCA，而不是倍增。dfs1 计算父节点 fa[u]、深度 dep[u]、子树大小 sz[u]，并把子树最大的孩子记为重儿子 hson[u]；dfs2 为每个节点记录所在重链的链顶 top[u]，重儿子继承父亲的链顶，轻儿子以自身作为新链顶。查询时，只要 top[x] != top[y]，就让链顶更深的节点跳到 fa[top[x]]。每次跨过一条轻边，所在子树大小至少成倍增加，因此最多跳 O(log⁡n)O(\log n)O(logn) 次。两点进入同一条重链后，深度较小者就是 LCA。预处理时间复杂度为 O(n)O(n)O(n)，每次查询为 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(n)O(n)O(n)；单点与祖先关系也由同链阶段自然处理。

Distance Queries

题目大意：给定一棵树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），多次询问两个节点之间的距离，距离按路径上的边数计算。

解题思路：代码用欧拉序加 ST 表 RMQ 求 LCA，而不是倍增。DFS 每次进入节点以及从一个孩子返回时都把当前节点写入 dfn，故欧拉序长度为 2 * n - 1；pos[u] 记录 u 在序列中的位置，dep[u] 记录深度。两个节点 x、y 在 pos[x] 到 pos[y] 之间深度最小的节点就是 LCA。f[i][j] 保存从位置 i 开始、长度为 2j2^j2j 的区间中深度最小的节点，get 用两个重叠区间在 O(1)O(1)O(1) 时间完成 RMQ。得到 LCA 后，距离为

dep[x]+dep[y]−2×dep[lca⁡(x,y)].dep[x] + dep[y] - 2 \times dep[\operatorname{lca}(x,y)]. dep[x]+dep[y]−2×dep[lca(x,y)].

预处理时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，每次查询为 O(1)O(1)O(1)，空间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Counting Paths

题目大意：给定树上的若干条路径（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），求每个节点被多少条路径经过。路径的两个端点也算被经过。

解题思路：先与上一题相同，用欧拉序和 ST 表 RMQ 预处理 LCA；dfs_fa 另外记录每个节点的父亲 fa[u]。对路径 (x, y)，令 lca = get(x, y)，执行 val[x]++、val[y]++、val[lca]--、val[fa[lca]]--。随后后序 DFS，把每个孩子的 val[v] 累加到父节点。端点产生的两股贡献会沿树向上汇合：在 lca 处减一次，使 LCA 本身仍保留一次贡献；在 parent(lca) 处再减一次，阻止贡献继续传到路径之外。根的父节点是 0，写入 val[0] 不会参与输出和汇总，因此根作为 LCA 时也无需特判。LCA 预处理为 O(nlog⁡n)O(n \log n)O(nlogn)，每次路径处理为 O(1)O(1)O(1)，最终汇总为 O(n)O(n)O(n)，总时间复杂度为 O(nlog⁡n+q)O(n \log n + q)O(nlogn+q)，空间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Subtree Queries

题目大意：给定以 1 为根的带权树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持把单个节点 s 的权值改为 x，以及查询以 s 为根的整棵子树权值和。

解题思路：DFS 进入 u 时记录 in[u] = ++tim 和 dfn[tim] = u，处理完全部孩子后记录 out[u] = tim，因此 u 的子树恰好对应闭区间 [in[u], out[u]]。随后代码通过 id[dfn[i]] = i 建立节点到 DFS 序位置的反向映射，所以 id[u] 与 in[u] 等价。树状数组 BIT 按 DFS 序维护权值：子树和为 sum(out[x]) - sum(in[x] - 1)。修改节点 l 为 r 时，sum(id[l]) - sum(id[l] - 1) 是旧值，因此 r - sum(id[l]) + sum(id[l] - 1) 正是需要加入的差值，实现单点赋值而非累加。预处理时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，每次操作为 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(n)O(n)O(n)。

Path Queries

题目大意：给定以 1 为根的带权树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持修改单个节点的权值，以及查询从根节点到指定节点 s 的路径权值和。

解题思路：DFS 为每个节点记录进入时间 order_in[u] 和结束时间 order_out[u]。这里 order_out[u] 是处理完子树后的下一个位置，所以节点 u 对应半开区间 [order_in[u], order_out[u])。在树状数组中于 order_in[u] 加上 value[u]，于 order_out[u] 减去 value[u]；查询 order_in[s] 的前缀和时，恰好只有仍处于活动区间、也就是根到 s 路径上的节点保留贡献。修改时先在进入位置加 -value[s]、离开位置加 value[s] 撤销旧值，再以相反符号加入新值。order_out[root] 可能等于 n+1n+1n+1，而树状数组大小为 n，add 会自然忽略这个越界结束标记；所有有效查询位置均不超过 n，不影响答案。预处理和每次操作的时间复杂度分别为 O(nlog⁡n)O(n \log n)O(nlogn) 与 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(n)O(n)O(n)。

Path Queries II

题目大意：给定一棵带权树（n,q≤2×105n, q \le 2 \times 10^5n,q≤2×105），支持修改单个节点的权值，以及查询任意两个节点 a、b 之间路径上的最大权值。

解题思路：先做重链剖分。dfs1 计算 fa、dep、sz 和重儿子 hson，dfs2 让同一条重链上的节点获得连续编号 id，并用 top 记录链顶。ask(x, y) 在两点链顶不同时，始终处理链顶较深的一侧，查询从 top[x] 到 x 的整段后令 x = fa[top[x]]；最后两点处于同一重链，再查询它们之间的一段。底层是迭代线段树，query(l, r) 使用左闭右开区间 [l, r)，而 id 从 1 开始、线段树逻辑位置从 0 开始，所以节点闭区间 [id[a], id[b]] 要转换成 query(id[a] - 1, id[b])。修改同理使用 modify(id[l] - 1, r)。HLD 将路径拆成 O(log⁡n)O(\log n)O(logn) 段，每段线段树查询为 O(log⁡n)O(\log n)O(logn)，因此查询为 O(log⁡2n)O(\log^2 n)O(log2n)，修改为 O(log⁡n)O(\log n)O(logn)，空间复杂度为 O(n)O(n)O(n)。

Distinct Colors

题目大意：给定一棵以 1 为根、每个节点带有颜色的树（n≤2×105n \le 2 \times 10^5n≤2×105），求每个节点的子树中出现了多少种不同颜色。

解题思路：DFS 为每个节点返回一个 set<int>，其中保存该节点整棵子树的颜色。初始集合只含 color[node]；得到孩子的 child_colors 后，比较两个集合大小，必要时交换，始终把较小集合合并到较大集合中。set::merge 会转移尚未存在的元素，重复颜色留在源集合中但不影响当前大集合的不同颜色数，因此合并结束后 colors.size() 就是答案。small-to-large 保证一个元素每次被转移时所在目标集合至少翻倍，所以每个元素最多经历 O(log⁡n)O(\log n)O(logn) 次转移；每次红黑树操作还需 O(log⁡n)O(\log n)O(logn)，总时间复杂度为 O(nlog⁡2n)O(n \log^2 n)O(nlog2n)，空间复杂度为 O(n)O(n)O(n)。

Finding a Centroid

题目大意：求树（n≤2×105n \le 2 \times 10^5n≤2×105）的一个质心。删除质心及其相连的边后，剩余每个连通块的节点数都不超过 n/2n / 2n/2。

解题思路：先以 1 为根 DFS，计算子树大小 sz[u]，并令 max_child[u] 为所有孩子子树大小的最大值。考虑删除节点 i 后的连通块：每个孩子方向的大小是对应的 sz[child]，而父亲方向并不是一棵孩子子树，其大小为 n - sz[i]。因此最大连通块大小是 max(max_child[i], n - sz[i])；若它不超过 n/2n/2n/2，i 就是质心。树至少存在一个质心，代码找到第一个后输出并结束。DFS 和枚举各进行一次，时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(n)O(n)O(n)。

Fixed-Length Paths I

题目大意：统计树（n≤2×105n \le 2 \times 10^5n≤2×105）上长度恰好为 k 的简单路径数量，路径长度按边数计算。

解题思路：使用点分治。每次在当前未删除连通块中求质心 centroid，令 cnt[d] 表示已经处理过的方向中，到质心距离为 d 的节点数，并先放入质心自身 cnt[0] = 1。然后逐棵处理质心的邻接子树：get_dist 收集当前子树内不超过 k 的距离 d，并在加入这些距离之前查询 cnt[k - d]。这样配对的另一个端点只能是质心或此前处理过的子树，路径必经过质心；同一子树内的两个端点不会在当前质心重复统计，它们会留到该子树递归分治时处理。查询完当前子树后才把其距离加入 cnt。最后按 all_dists 清空本轮改动的计数，并递归处理删除质心后形成的各连通块。每条路径在其两端首次被某个分治质心分开的层次恰好统计一次。点分治深度为 O(log⁡n)O(\log n)O(logn)，每层总遍历节点数为 O(n)O(n)O(n)，时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。

Fixed-Length Paths II

题目大意：统计树（n≤2×105n \le 2 \times 10^5n≤2×105）上长度位于闭区间 [k1, k2] 内的简单路径数量，路径长度按边数计算。

解题思路：同样使用点分治，但代码用普通计数数组 cnt 和前缀和数组 pref，不是树状数组。对当前质心，先令 cnt[0] = pref[0] = 1，表示质心自身。逐棵处理邻接子树时，get_dists 收集其中不超过 k2 的深度；对深度为 d 的节点，另一个端点到质心的深度必须位于 [k1 - d, k2 - d]。代码把下界截到 0，并把查询范围限制在已加入的最大深度 max_d_total，通过 pref[R] - pref[L - 1] 得到数量。关键是先查询当前子树，再把它的所有深度加入 cnt 并重建 pref，所以只统计端点位于不同子树或一端为质心的路径，不会统计当前子树内部路径。处理完质心后，仅清空 [0, max_d_total] 中用过的 cnt、pref，再递归处理各剩余连通块；每条合法路径会在首次分开其两端的质心处恰好统计一次。点分治共有 O(log⁡n)O(\log n)O(logn) 层；每轮重建前缀和的长度不超过本连通块的有效深度，整体时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)，空间复杂度为 O(n)O(n)O(n)。
