Advanced Graph Problems

Nearest Shops*

题目大意：无向图（n,m≤105n, m \le 10^5n,m≤105），其中 k 个城市有动漫商店。对每个城市，求它到另一个有店城市的最短距离（不算它自己；若只有一家店则输出 -1）。

解题思路：多源 BFS。把所有有店城市同时入队、距离为 0，一遍 BFS 得到每个城市到最近店的距离 dist。对本身有店的城市 i，答案 = 它的邻居中 dist[v] + 1 的最小值（即"另一家最近的店"，因为最近店距离为 0 的只有它自己）。时间复杂度为 O(n+m)O(n + m)O(n+m)。

Prüfer Code

题目大意：给定一棵树的 Prüfer 序列（n−2n - 2n−2 个数），重建原树并输出 n−1n - 1n−1 条边。

解题思路：Prüfer 序列的性质：每个节点在序列中出现的次数 = 它的度数减 1，所以度数为 1（序列中出现 0 次）的节点就是叶子。用小根堆维护当前所有叶子：每次取出最小叶子，与序列当前项 code[i] 连边（这条边正是"删掉最小叶子"的过程逆推），并把 code[i] 的出现次数减 1，减到 0 说明它变成了新叶子、入堆。处理完序列后堆里剩两个节点，连上最后一条边。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Tree Traversals

题目大意：给定二叉树的先序遍历和中序遍历（值互不相同），输出后序遍历。

解题思路：递归。先序的第一个元素是根，在中序中定位根的位置 m，则中序的 [il,m−1][il, m-1][il,m−1] 是左子树、[m+1,ir][m+1, ir][m+1,ir] 是右子树（pos 数组预存每个值在中序里的下标）。左子树大小 leftLen = m - il，对应先序的 [pl+1,pl+leftLen][pl+1, pl+leftLen][pl+1,pl+leftLen]。递归构造左右子树后再输出根（后序）。时间复杂度为 O(n)O(n)O(n)。

Course Schedule II

题目大意：课程有先后依赖，输出一个拓扑序，使得课程 1 尽可能早完成，其次课程 2 尽可能早，以此类推（满足"最小字典序"偏好的拓扑序）；有环输出 IMPOSSIBLE。

解题思路：想直接用小根堆做正向拓扑是错的（反例：2 依赖 1，3 依赖 1——正向最小堆会输出 2,3,1，但 1 可以被放得更早）。正确做法：建反向图做"大根堆拓扑"（每步取当前可取的编号最大的课程），把得到的顺序倒过来输出。直观解释：倒序序列中编号大的尽量靠后，等价于编号小的尽量靠前。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Acyclic Graph Edges

题目大意：给定无向图，给每条边定向，使得到的有向图无环，输出每条边的方向。

解题思路：把每条边从编号小的端点指向编号大的端点即可：所有边方向一致地从小编号指向大编号，任何有向路径上的编号都严格递增，不可能成环。时间复杂度为 O(m)O(m)O(m)。

Strongly Connected Edges

题目大意：给无向图（n,m≤105n, m \le 10^5n,m≤105）的每条边定向，使得到的有向图强连通；无解输出 IMPOSSIBLE。

解题思路：有解当且仅当图连通且没有桥（边双连通）——桥无论怎么定向两个方向都不连通。构造：对每个连通块做 DFS 生成树：树边按父→子定向，回边按子→祖定向（DFS 过程中：未访问的邻居是树边，已访问的邻居一定是祖先，定向为"当前点→祖先"）。这样每个点都能沿树边走到根、根能沿树边到每个点，且回边保证每个点也能"绕上去"。时间复杂度为 O(n+m)O(n + m)O(n+m)。

Even Outdegree Edges

题目大意：给无向图（n,m≤105n, m \le 10^5n,m≤105）的每条边定向，使每个节点的出度为偶数；无解输出 IMPOSSIBLE。

解题思路：初始把每条边都"向下"定向：DFS 生成树边父→子，回边祖→孙（注意回边方向与上一题相反）。这样所有边的方向都指向 DFS 树深处。然后按后序遍历调整：若节点 v 当前出度为奇数，就把它连向父亲的树边翻转（出度 -1，父亲出度 +1）——处理到根之前所有非根节点都被修正成偶数；根节点的出度奇偶性 = 该连通块边数的奇偶性（因为出度和 = 边数），若根出度仍为奇数说明该块边数为奇，输出 IMPOSSIBLE。最后验证全部偶数并输出。时间复杂度为 O(n+m)O(n + m)O(n+m)。

Graph Girth

题目大意：无向图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），求最短环的长度（围长），无环输出 -1。

解题思路：对每个点 i 做 BFS 找经过它的最短环：把 i 的所有邻居按"来自哪个搜索分支"打上 tree 标记并入队，BFS 过程中若遇到一个已访问点 nxt，且它与当前点的分支不同、也不是 i 本身，则 dist[nxt] + dist[s] + 1 就是一条经过 i 的环的长度，取最小值。所有起点取最小即围长。时间复杂度为 O(n(n+m))O(n(n + m))O(n(n+m))。

Fixed Length Walk Queries

题目大意：无向图（n≤2500n \le 2500n≤2500，m≤5000m \le 5000m≤5000），q 次询问（q≤105q \le 10^5q≤105）：从 a 出发能否用恰好 x 步走到 b（可以重复经过节点和边）。

解题思路：把所有询问按起点 a 分组离线处理。对每个起点做奇偶分层 BFS：dist0[v]/dist1[v] 分别是从起点到 v 的偶数长度/奇数长度最短 walk。图的走法要么只能按某固定奇偶到达（二分图），要么两种奇偶都可达（含奇环）。对询问 (b, k)：取与 k 同奇偶的 need（dist1[b] 或 dist0[b]），若 need != -1 且 k >= need 则 YES——比最短多出的步数可以靠来回走一条边补足（奇环存在时也能调整奇偶，但奇偶分层已经自动处理了这种情况）。k 超过 10910^9109 时与 10910^9109 等价（距离不可能更大）。时间复杂度为 O(n(n+m)+q)O(n(n + m) + q)O(n(n+m)+q)。

Transfer Speeds Sum

题目大意：一棵带权树（n≤2×105n \le 2 \times 10^5n≤2×105），两点之间的传输速度等于它们路径上边权的最小值。求所有点对传输速度之和。

解题思路：按边权从大到小处理边。处理边 (a,b,w)(a, b, w)(a,b,w) 时，它连接的两个连通块 A、B 中，任意跨块点对的路径最小边权恰好是 w（更小的边都还没被处理，路径上其余边要么不在当前树中、要么权更大），贡献 ∣A∣×∣B∣×w|A| \times |B| \times w∣A∣×∣B∣×w。用并查集维护块大小，合并后继续。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

MST Edge Check

题目大意：带权无向图（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），对每条边判断它能否出现在某个最小生成树中。

解题思路：Kruskal 按权分组处理。一条边能出现在某个 MST 中，当且仅当把所有更小权的边加入后，它的两个端点仍不连通（它不会在 Kruskal 中被跳过）。实现：把边按权排序，同权的一组先统一"检查"（看两端在只含更小权边的并查集中是否连通），再统一"合并"。时间复杂度为 O(mlog⁡m)O(m \log m)O(mlogm)。

MST Edge Set Check*

题目大意：带权无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），q 个查询，每个查询给一个边集，判断这些边能否同时出现在某个最小生成树中（查询总边数不超过 mmm）。

解题思路：对每个查询：把查询的边按权排序，用一个可回滚并查集模拟 Kruskal 到相应权重——先把全局所有权更小的边合并进去，然后逐条检查查询边：两端已连通说明该边在 Kruskal 中会被跳过（成环），查询失败；否则把它也合并（同权边之间先检查后合并）。处理完一个查询后回滚到快照，恢复并查集。时间复杂度为 O((m+∑∣查询∣)log⁡m⋅α)O((m + \sum |查询|) \log m \cdot \alpha)O((m+∑∣查询∣)logm⋅α)。

MST Edge Cost

题目大意：带权无向图（n≤105n \le 10^5n≤105，m≤2×105m \le 2 \times 10^5m≤2×105），对每条边求"强制包含这条边"的最小生成树的总代价。

解题思路：先跑 Kruskal 建出一个 MST（总代价 mstW）。对树边，答案就是 mstW。对非树边 (a,b,w)(a, b, w)(a,b,w)：把它加入 MST 会与树上 a→ba\to ba→b 路径成环，删掉环上最大权的那条边（这就是 Kruskal 在选这条边时会跳过的那条）得到新 MST，答案 = mstW - pathMax(a, b) + w。用树上倍增（up/mx 数组）预处理每个点到祖先跳段的最大边权，pathMax 像 LCA 一样把路径拆成 O(log⁡n)O(\log n)O(logn) 段取 max。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Network Breakdown*

题目大意：无向图（n≤105n \le 10^5n≤105），按顺序删除 k 条边，每次删除后输出当前连通分量数。

Tree Coin Collecting II*

题目大意：一棵树（n≤2×105n \le 2 \times 10^5n≤2×105），k 个节点有硬币。q 次询问：从 a 出发，访问所有硬币节点，最后到达 b，求最短路径长度。

解题思路：答案是"硬币 + 两端点"的斯坦纳树的欧拉回路长度减去 dist(a, b)：访问所有硬币的最优走法等价于沿斯坦纳树走一圈（每条边两次）再减去一段从 a 到 b 的单程。具体地，先多源 BFS 求每个点到最近硬币的距离 distCoin 与锚点 anchor（最近的那个硬币），并计算硬币集合的虚树边权和 S：把硬币按欧拉序（tin）排序，环上相邻点距离之和的一半就是虚树边数。对询问 (a, b)：设 ca = anchor[a]、cb = anchor[b]，答案 =2S−dist(ca,cb)+dist(a,ca)+dist(b,cb)= 2S - dist(ca, cb) + dist(a, ca) + dist(b, cb)=2S−dist(ca,cb)+dist(a,ca)+dist(b,cb)——从 a 走到最近硬币、沿虚树欧拉回路访问所有硬币（结尾在 cb，所以省掉 ca→cbca\to cbca→cb 一段）、再去 b。时间复杂度为 O((n+q)log⁡n)O((n + q) \log n)O((n+q)logn)。

Tree Isomorphism I*

题目大意：t 组测试，判断两棵有根树（根均为节点 1）是否同构。

解题思路：AHU 算法。自底向上给每棵子树计算一个规范化编码：节点 v 的编码 = ( + 所有孩子的子树编码排序后拼接 + )。两个子树同构当且仅当它们的编码相同（归纳：根对应、子树多重集同构当且仅当排序后的编码序列相同）。两棵树以各自根算编码比较即可。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)（每层排序）。

Tree Isomorphism II*

题目大意：t 组测试，判断两棵无根树是否同构。

解题思路：无根树同构可以用树的"中心"固定根。每棵树有 1 或 2 个中心（findCenter 用叶子逐层剥离法：每轮删掉当前所有度 ≤1\le 1≤1 的点，剩余 ≤2\le 2≤2 个点时停止）。两棵无根树同构当且仅当存在根的选择（各取一个中心）使有根树同构——把每棵树以各中心为根分别做 AHU 编码，排序后得到编码集合，比较两个集合是否相等。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Flight Route Requests

题目大意：n 个城市（n≤105n \le 10^5n≤105），给出 m 条"请求"（希望从 a 能到达 b）。可以在任意城市间添加单向航线，求最少添加多少条航线，使所有请求都被满足。

解题思路：把 m 条请求看成一张需求图 G 的边，我们只能新加单向航线 H，要求 G 的每条请求边 (a, b) 在 H 中都存在从 a 到 b 的有向路径。

关键引理：若 a、b 在 G 的同一个 SCC 内，则它们在 H 中必须互相可达。证明：G 的 SCC 意味着存在请求链 a→x1→⋯→ba \to x_1 \to \cdots \to ba→x1​→⋯→b，每条请求都要求 H 中一段向前的可达性，串起来得到 a 在 H 中可达 b；反向同理。所以 H 必须把每个大 SCC 的所有点放进 H 的同一个强连通分量里。

因此按 G 的弱连通分量（WCC）独立计算。设某 WCC 有 N 个点，把 H 缩点成 H-SCC（大小 tjt_jtj​）：H 在 WCC 内的边数 ≥∑tj≥2tj+(#H-SCC−1)=N−1+(#大小≥2 的 H-SCC)\ge \sum_{t_j\ge2} t_j + (\#H\text{-SCC} - 1) = N - 1 + (\#\text{大小}\ge2\text{ 的 }H\text{-SCC})≥∑tj​≥2​tj​+(#H-SCC−1)=N−1+(#大小≥2 的 H-SCC)（每个大 H-SCC 内部要强连通至少需要其大小条边，H-SCC 之间要沿请求方向弱连通至少需要个数减一条边）。若 WCC 含有大 SCC，则至少有一个大 H-SCC，下界为 N；全是单点时下界为 N - 1。

下界都可达到：全单点时按拓扑序把 N 个点连成一条链（N - 1 条边），所有请求在拓扑序中都向前，全部满足；含大 SCC 时把 N 个点按拓扑序首尾相接成一个环（N 条边），整块强连通，所有请求都被满足。

综合公式：ans=n−w+bans = n - w + bans=n−w+b，其中 www 是弱连通分量数、bbb 是含大 SCC 的弱连通分量数。代码等价写成 ans=(c−w)+∑∣SCC∣≥2(∣SCC∣−1)+bans = (c - w) + \sum_{|SCC|\ge2}(|SCC|-1) + bans=(c−w)+∑∣SCC∣≥2​(∣SCC∣−1)+b（ccc 是 SCC 数，因为 n=c+∑∣SCC∣≥2(∣SCC∣−1)n = c + \sum_{|SCC|\ge2}(|SCC|-1)n=c+∑∣SCC∣≥2​(∣SCC∣−1)）。代码用迭代 Kosaraju 求 SCC、并查集求弱连通分量，时间复杂度为 O(n+m)O(n + m)O(n+m)。

Critical Cities

题目大意：n 个点的有向图（n,m≤2×105n, m \le 2 \times 10^5n,m≤2×105），找从 1 到 n 的所有路径都必经的城市（含 1 和 n），升序输出。

解题思路：必经城市就是支配树（dominator tree）上从源点 1 到 n 的祖先链。一个点 d 支配 v，当且仅当从 1 到 v 的每条路径都经过 d；支配关系构成一棵树，idom[v] 是 v 的最近支配者（支配 v 的其余点中离 v 最近的）。v 被 w 支配当且仅当 w 是支配树中 v 的祖先，所以"支配 n 的所有点"就是从 n 沿 idom 链走到根经过的点，正是所有必经城市（1 和 n 自身天然包含）。

建树用 Lengauer-Tarjan 算法：先对正图做 DFS 得到 DFS 树与每个点的 DFS 序；semi[v]（半支配点）是最小的 w，使得存在一条路径 w→x1→⋯→vw \to x_1 \to \cdots \to vw→x1​→⋯→v 且中间所有点的 DFS 序都大于 v——直觉上它是"能绕过 v 在 DFS 树上的祖先、最早到达 v 的点"，而 idom[v] 一定是 v 与 semi[v] 之间 DFS 链上的某个点。算法按 DFS 序倒序处理每个点：求 semi 时借助带权并查集，维护"节点到当前已处理祖先之间 semi 最小的点"（uni_query 路径压缩时合并最小值），即可把每条"先向上再沿横叉/回边向下"的路径的贡献 O(log⁡n)O(\log n)O(logn) 取到；随后利用 semi 链求出 idom 并做最后修正。答案：从 n 沿 idom 链走到 0，收集到的点升序输出。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Visiting Cities

题目大意：带权有向图（n≤105n \le 10^5n≤105），求所有最短路径上一定经过的城市。

解题思路：从 1 正向、从 n 反向各跑一次 Dijkstra，同时用两个随机大质数 MOD1、MOD2 做双模路径计数：ways[type][j][v] 记录到 v 的最短路径条数（模两个质数）。城市 u 必在最短路上当且仅当：(1) dist[0][u] + dist[1][u] == dist[0][n]（u 在至少一条最短路上）；(2) 经过 u 的最短路径数 = 总最短路数（两个模下 ways[0][u] * ways[1][u] == total）——随机模数使哈希冲突概率可忽略。时间复杂度为 O((n+m)log⁡n)O((n + m) \log n)O((n+m)logn)。

Graph Coloring

题目大意：n 个点的图（n≤16n \le 16n≤16），求最小着色数并输出一种着色方案。

解题思路：子集 DP 求色数。先预处理每个子集 mask 是否为独立集（内部无边）；dp[mask] 表示给 mask 中所有点着色的最少颜色数：枚举 mask 的一个独立集子集 sub（最后一种颜色），dp[mask] = min(dp[mask ^ sub] + 1)，同时记录 prev[mask] 是哪个子集。最后沿 prev 回溯给每类颜色赋值。时间复杂度为 O(3n)O(3^n)O(3n)。

Bus Companies

题目大意：n 个城市、m 家公交公司，公司 c 票价 price[c]，覆盖若干城市（买一张票可在其覆盖的城市间任意转移）。从城市 1 出发，求到每个城市的最少花费。

解题思路：Dijkstra 变体。维护城市距离 dist；从城市 u 松弛时，枚举覆盖 u 的尚未使用的公司 c，花 price[c] 买票后可达该公司的全部城市（dist[v] = min(dist[v], d + price[c])）。每家公司最多买一次（usedComp 标记）：第一次被某个已达城市"激活"时票价最小，之后没必要重复激活。优先队列按距离取最小。时间复杂度为 O((n+∑kc)log⁡n)O((n + \sum k_c) \log n)O((n+∑kc​)logn)。

Split into Two Paths

题目大意：DAG（n≤105n \le 10^5n≤105），判断能否把节点分成恰好两条路径（每条路径按 DAG 的边走，每个节点恰好属于一条路径），能则输出两条路径（空路径输出 0）。

解题思路：等价于最小路径覆盖 ≤2\le 2≤2。DAG 的最小路径覆盖 = n - 最大匹配（拆点二分图：左边每个点匹配一个后继，匹配边把路径串起来；每匹配一条边路径数减 1）。用 Hopcroft-Karp 求最大匹配（bfs 分层 + dfs 增广）。若 n - 匹配数 > 2 输出 NO；否则沿匹配边还原路径：nxt[u] = matchL[u]，从没有前驱的点出发走链，得到若干条路径（少于 2 条时补空路径）。时间复杂度为 O(En)O(E \sqrt{n})O(En​)。

Network Renovation

题目大意：给一棵树（n≤2×105n \le 2 \times 10^5n≤2×105）加最少的边，使任意一条边断开后图仍连通（即变成边双连通），输出加边方案。

解题思路：树中唯一的"桥风险"来自叶子（度为 1 的节点），把它们两两配对连边即可让每个叶子都处于环上。最少加边数 = ⌈叶子数/2⌉\lceil 叶子数 / 2 \rceil⌈叶子数/2⌉。配对方式：把所有叶子按 DFS 序（tim）排序，第 i 个与第 i + m/2 个配对（m 为叶子数）；叶子数为奇数时让最后一个与第一个配对。这样配对保证每条原树边两侧都有至少一个叶子跨越它，全部边都进入环。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Forbidden Cities*

题目大意：无向图（n≤105n \le 10^5n≤105），q 次询问：从 a 到 b 是否存在不经过城市 c 的路径。

解题思路：建圆方树（block-cut tree）：Tarjan 用边栈求所有点双连通分量，每个分量建一个"方点"，原节点是"圆点"，方点连接分量内所有圆点。若 c 不是割点，删掉它不影响连通性，答案恒 YES；若 c 是割点，删掉它后 a、b 不连通当且仅当 c 在圆方树上 a→ba\to ba→b 的路径上（onPath：lca(a, c) == c && lca(c, b) == lca(a, b) 或对称）。树上 LCA 用倍增。时间复杂度为 O((n+m+q)log⁡n)O((n + m + q) \log n)O((n+m+q)logn)。

Creating Offices*

题目大意：一棵树（n≤2×105n \le 2 \times 10^5n≤2×105），选一些节点建办公室，要求任意两个办公室距离至少为 d，求最多能建多少个并输出方案。

解题思路：自底向上的贪心 DP。先把树按 DFS 序排成从叶子到根的处理顺序，每个节点维护两个值：mx[u] = 子树中"最远的未被覆盖点到 u 的距离"（没有未覆盖点记为 -INF，点 u 自身未覆盖时至少是 0），mn[u] = 子树中"最近的已建办公室到 u 的距离"。合并所有儿子后：若 mx[u] + mn[u] <= d，说明最远未覆盖点已经能被某个办公室覆盖（它们中间隔着 u），整个子树都被覆盖，置 mx[u] = -INF；否则若 mx[u] == d，最远未覆盖点恰好在距离上限上，必须在 u 建办公室（再往上传就超距离了），置 mn[u] = 0、mx[u] = -INF。处理完根后若根还有未覆盖点（mx[0] >= 0），在根补建一个。这个贪心在树上最优。时间复杂度为 O(n)O(n)O(n)。

New Flight Routes*

题目大意：有向图（n,m≤105n, m \le 10^5n,m≤105），求最少添加多少条单向航线使整个图强连通，并输出添加方案。

解题思路：缩 SCC 得到 DAG。若只有一个 SCC，答案就是 0。否则设源点（入度 0 的 SCC）有 s 个、汇点（出度 0 的 SCC）有 t 个。

下界是 max⁡(s,t)\max(s, t)max(s,t)：加边后整图要强连通，每个源点都至少需要一条入边（否则没有任何点能到达它），每个汇点都至少需要一条出边（否则它到不了任何点），而一条新边最多同时为一个源点提供入边、为一个汇点提供出边，所以边数 ≥max⁡(s,t)\ge \max(s, t)≥max(s,t)。

构造恰好达到下界：把汇点与源点交错连成环，第 i 条边从 sink[i % t] 连到 src[(i + 1) % s]，共 max⁡(s,t)\max(s, t)max(s,t) 条。加完后每个源点都有了入边、每个汇点都有了出边，即新图的缩点 DAG 中每个节点入度、出度都不为 0；而非空 DAG 必存在入度为 0 的节点，矛盾，所以新缩点只能是单点——整图强连通。正确性由此闭环。

特例 s == t == 1：唯一源点与唯一汇点必然不同（若相同，该分量孤立，其余分量构成的非空子 DAG 必有另一个源点，与 s = 1 矛盾），此时一条从 sink[0] 到 src[0] 的边即可。代码对"源汇同点"仍做了防御性处理：用 2 条边经其他分量绕一圈兜底。时间复杂度为 O(n+m)O(n + m)O(n+m)。
