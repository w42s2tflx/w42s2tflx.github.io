Filled Subgrid Count I

题目大意：n×n 的字母网格（n≤3000n \le 3000n≤3000），对字母表中前 k 个字母逐一统计"全为该字母的正方形子网格"的个数。

解题思路：逐字母处理（避免不同字母互相干扰）。对固定字母 c，dp[i][j] 表示以 (i, j) 为右下角的全 c 最大正方形边长：若 (i, j) 不是 c 则为 0；否则取左上、正上、正左三个位置的 dp 最小值加 1（上方/左方的正方形延伸过来受两条边限制）。以 (i, j) 为右下角的全 c 正方形个数恰好等于 dp[i][j]（边长 1…dp 都合法），累加即该字母答案。复杂度 O(kn2)O(kn^2)O(kn2)。

Filled Subgrid Count II

题目大意：n×n 的字母网格（n≤3000n \le 3000n≤3000），对字母表中前 k 个字母逐一统计"全为该字母的矩形子网格"的个数。

解题思路：枚举行 r 作为矩形的底边，height[c] 是列 c 从 r 向上连续同字母的高度（与上一行相同则 +1，否则为 1）。把底边按字母相同的连续段切分，段内就是一个直方图，其中"以某列为右端、以任一列为左端、底边在 r"的矩形数 = 直方图所有子数组的最小值之和。用单调栈（严格递增）求这个和：弹出一个下标 mid 时，它作为最小值的左端范围是 (prev, mid]、右端范围是 [mid, c)，贡献 height[mid] × (mid - prev) × (c - mid)（prev 是栈中前一个元素，c 是当前弹出的触发位置）。每个字母累加其段内贡献。复杂度 O(n2)O(n^2)O(n2)。

All Letter Subgrid Count I

题目大意：n×n 网格上有 k 种字母（n≤3000n \le 3000n≤3000），统计包含全部 k 种字母的正方形子网格个数。

解题思路：对每个可能的左上角 (i, j) 求"最小边长"：need[i*n+j] = 使得以 (i, j) 为左上角的正方形包含全部字母的最小边长减 1（即到"右下区域中每个字母最近出现位置"的最大切比雪夫距离）。对每种字母 c 从右下角倒推：cur[j] = 从 (i, j) 到右下区域内最近的 c 的距离（(i,j) 本身是 c 则为 0，否则为下方、右方、右下方三个值的最小值 +1，用 below/cur 两行滚动）。need 取所有字母的最大值。最后：以 (i, j) 为左上角、边长 side = need + 1 到 min(n-i, n-j) 的每个正方形都包含全部字母，共 mx - side + 1 个，累加。复杂度 O(kn2)O(kn^2)O(kn2)。

All Letter Subgrid Count II

题目大意：n×n 网格上有 k 种字母，统计包含全部 k 种字母的矩形子网格个数。n 可达 3000、k 可达 26。

解题思路：根据 k 与 n 的关系选两种算法。

  • 2^k ≤ n（k 很小）：容斥。对每个字母子集 T，统计"只使用 T 中字母"的矩形数（直方图：height[c] 为列 c 向上连续"字母 ∈ T"的高度，单调栈求子数组最小值之和），按 (−1)k−∣T∣(-1)^{k - |T|}(−1)k−∣T∣ 累加——包含全部字母的矩形在容斥中恰好被计一次。
  • k 较大：枚举行对 (r1, r2)，把每列的字母集合按位或成 colMask，行对覆盖的字母并集 rowOr 不全就跳过。扫列时维护 gap[L] = 字母 L 距当前列最近一次出现的距离（8 路 SSE2 int16 并行维护：该列没出现 L 则 gap[L] +1，出现则清零）。当前列 c 的 mx = max gap[L]，则以 c 为右端点、左端点在 [0, c - mx + 1] 的矩形都包含全部字母，贡献 c - mx + 1。复杂度 O(n2k)O(n^2 k)O(n2k) 的常数优化版。

Border Subgrid Count I

题目大意：n×n 的字母网格（n≤3000n \le 3000n≤3000，k≤26k \le 26k≤26），对每个字母统计"四条边（上下两行 + 左右两列）全为该字母的正方形子网格"的个数。

解题思路：k=1k = 1k=1 时答案就是所有正方形个数 ∑h=1n(n−h+1)2\sum_{h=1}^{n}(n-h+1)^2∑h=1n​(n−h+1)2，直接输出。一般情况：预计算每行的同字母连续段（run），并把每行的 run 按长度降序排序；同时预计算三个 bitset 层：HQ[r]（第 r 行水平相邻同字母对）、VQ[r]（第 r、r+1 行垂直相邻同字母对）、BL[L][r]（第 r 行字母 L 出现的位置）。枚举正方形的下边行 r2 和上边行 r1（自下而上），高度 h = r2 - r1 + 1：

  • U 是"从 r1 到 r2 每相邻两行都垂直同字母"的列集合，随 r1 上移逐层与 VQ[r1] 求交（aliveU 词表维护非零词）；
  • C2 是第 r2 行"相距 h - 1 的两列同字母"（把 HQ[r2] 右移 h - 2 位后与之前的结果求交），保证正方形上下两条边各是一段同字母 run；
  • 对第 r1 行每个长度 ≥ h 的 run（按长度降序、指针 ptr 剪掉过短的），枚举左上角列 lo ∈ [s, e - h + 1]，用 BL[L][r2]（右下角列）与 U、C2、位移后的 U（左右两列垂直）求交并 popcount；按"存活词表"（alive，U&C2≠0U \& C2 \ne 0U&C2=0 的词）跳过死词，稠密时预计算位移 shU、稀疏时二分定位起点。

1×1 的正方形单独全部计入。复杂度 O(n3/64)O(n^3 / 64)O(n3/64) 级别。

Border Subgrid Count II

题目大意：n×n 的字母网格，对每个字母统计"四条边全为该字母的矩形子网格"的个数。

解题思路：枚举行对 (r1, r2)。一个合法的边框矩形要求：第 r1、r2 行的对应两列同字母，且这两条边之间的两列各自上下同字母。先预处理 up[r][c] = 列 c 从 r 向上连续同字母的长度。把第 r1 行按"与第 r2 行同字母"的连续段切分，段内扫描列：若 up[r2][c] >= len（len = r2 - r1 + 1），该列就是一根合法的"竖边柱"；以它为右端时，能配对的左端 = 段内之前的所有竖边柱个数，用前缀计数 pref 累加。每个字母单独统计。复杂度 O(n3)O(n^3)O(n3)。

Empty String

题目大意：给一个字符串（∣s∣≤500|s| \le 500∣s∣≤500），每次可以删除两个相邻且相同的字符，求把整个字符串删空的方案数（按删除步骤的顺序计数），对 109+710^9+7109+7 取模。

解题思路：区间 DP。dp[l][r] 表示把 s[l..r] 删空的方案数（长度必须为偶数）。s[l] 最终一定与某个 s[k]（k 与 l 同奇偶，s[k] == s[l]）作为一对被删除——这一对不一定要相邻，但删除它时中间的 [l+1, k-1] 必须已先删空，右边 [k+1, r] 之后删空。所以 dp[l][r] += dp[l+1][k-1] · dp[k+1][r] · C[total][a+1]：中间段有 a = (k-l-1)/2 对，加上 (l,k) 这一对共 a+1 对"先完成"，与右边 total-(a+1) 对交错排列，交错方式 (totala+1)\binom{total}{a+1}(a+1total​) 种。复杂度 O(n3)O(n^3)O(n3)。

Permutation Inversions

题目大意：统计 1..n1..n1..n 的排列中恰好有 k 个逆序对的个数（n≤500n \le 500n≤500，k≤n(n−1)/2k \le n(n-1)/2k≤n(n−1)/2），对 109+710^9+7109+7 取模。

解题思路：DP。把数从小到大插入：插入第 i 个数时，它可以插在已排好的 i - 1 个数形成的 i 个空隙中，若插在倒数第 t 个空隙则新增 t 个逆序（t = 0..i-1）。所以 dp[i][j] = Σ_{t=0}^{i-1} dp[i-1][j-t]，即 dp[i-1] 的滑动窗口和（窗口长 i），滚动数组 + 前缀和做到每次 O(1)O(1)O(1) 转移。k 超过最大可能时答案直接 0。复杂度 O(nk)O(nk)O(nk)。

Counting Bishops*

题目大意：在 n×n 棋盘（n≤500n \le 500n≤500）上放 k 个互不攻击的象，求方案数，对 109+710^9+7109+7 取模。

解题思路：象沿对角线攻击，把对角线按格子的 (i+j) 奇偶分成两组（不同奇偶的对角线不相交，两组的象互不攻击），分别 DP 后卷积合并。对一组：它的对角线条数按长度升序为 1,1,3,3,5,5,…1, 1, 3, 3, 5, 5, \ldots1,1,3,3,5,5,…（n 为奇数时最后是 n,nn, nn,n；偶数时是 n−1,n−1n-1, n-1n−1,n−1）。dp[i][j] = 前 i 条斜线放 j 个象的方案数，转移：第 i 条（长 len）不放：dp[i-1][j]；放：前面 j-1 个象占掉了 j-1 条格子，剩 len - (j-1) 个格子可选，即 dp[i-1][j-1] × (len - j + 1)。最后 ans = Σ_a dpW[a] · dpB[k-a]。复杂度 O(nk)O(nk)O(nk)。

Counting Permutations

题目大意：统计 1..n1..n1..n 的排列中不存在相邻元素差为 1 的排列数（n≤500n \le 500n≤500），对 109+710^9+7109+7 取模。

解题思路：DP 状态 dp[j][b]：已插入 1..i1..i1..i 的排列中，有 j 个"坏相邻对"（相邻差为 1），且 b 表示 i 与 i - 1 是否相邻。插入新元素 i（相对 1..i−11..i-11..i−1）时分类：

  • 若 b = 1（i-1 与 i-2 相邻），把 i 放在 i-1 旁边会产生一个新坏对（两个位置）：ndp[j+1][1] += v；把 i 插进 i-1 与 i-2 之间会拆掉这个坏对：ndp[j][1] += v。
  • 若 b = 0，把 i 放在 i-1 的左右两侧（2 个位置）都新产生一个坏对：ndp[j+1][1] += 2v。
  • 其余 i - 2 个位置（i - 2 个旧元素之间的空隙）中，有 badGaps = j - b 个是"坏空隙"（插进去会拆掉一个坏对），插进去：ndp[j-1][0] += v × badGaps；剩余空隙：ndp[j][0] += v × (i - 2 - badGaps)。

答案 dp[0][0]（0 个坏对）。复杂度 O(n2)O(n^2)O(n2)。

题目大意：n 个点的函数图（每个点恰有一条出边，即 f:[n]→[n]f: [n] \to [n]f:[n]→[n]，共 nnn^nnn 个），统计恰好有 k 个连通分量的个数（n≤5000n \le 5000n≤5000），对每个 k = 1..n 输出，对 109+710^9+7109+7 取模。
