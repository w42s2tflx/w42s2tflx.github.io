Inverse Inversions

题目大意：构造一个 1..n1..n1..n 的排列，使它恰好有 k 个逆序对（n≤106n \le 10^6n≤106，k 可达 n(n−1)/2n(n-1)/2n(n−1)/2）。

解题思路：贪心逐个确定排列的每一位。用双指针 l = 1（最小可用值）、r = n（最大可用值）：当前还剩 left = n - i 个位置没填。若把 r 放在当前位置，它会与后面所有 left 个数（都比它小）构成 left 个逆序对；所以当 left <= k 时就放 r（消耗掉 left 个逆序对、k -= left），否则放 l（不产生逆序对，为后面的位置保留"制造逆序对"的空间）。两种选择覆盖了 0 到 C(n,2)C(n,2)C(n,2) 的全部 k 值，贪心必然成功。复杂度 O(n)O(n)O(n)。

Monotone Subsequences

题目大意：构造一个 1..n1..n1..n 的排列，使它的最长单调子序列（递增或递减取更长者）长度恰好为 k；无解输出 IMPOSSIBLE。

解题思路：由 Erdős–Szekeres 定理，任意 n>k2n > k^2n>k2 个互异实数必含长度 k+1k+1k+1 的单调子序列，所以 n>k2n > k^2n>k2 时无解。构造：把 1..n1..n1..n 切成若干块，每块长 k（最后一块可残缺），块内从大到小输出，块间从小到大排列。这样每个块内部是递减序列（LDS 恰为 k），跨块只能取递增序列（LIS = 块数 ⌈n/k⌉≤k\lceil n/k \rceil \le k⌈n/k⌉≤k），最长单调子序列恰好为 k。复杂度 O(n)O(n)O(n)。

Third Permutation

题目大意：给两个排列 a、b（保证每个位置 ai≠bia_i \ne b_iai​=bi​），构造排列 c 满足每个位置 ci≠aic_i \ne a_ici​=ai​ 且 ci≠bic_i \ne b_ici​=bi​；无解输出 IMPOSSIBLE。

解题思路：按值贪心。对值 v = 1..n，把它放到"最小的可用位置"上，且该位置不能是 pa[v]（v 在 a 中的位置）或 pb[v]。若某个值卡住（可用位置只剩 pa[v] 和 pb[v] 两个禁位），就"夺位修复"：任取一个禁位 p1（它还是空的），再找一个已占的位置 q（放的是值 w）使得 w 可以合法移到 p1（p1 ∉ {pa[w], pb[w]}），然后把 w 移到 p1、把 v 放到 q。最后整体验证一遍每个位置都合法，不合法输出 IMPOSSIBLE。复杂度 O(n2)O(n^2)O(n2)（找位置和找 q 各是 O(n)O(n)O(n) 扫描）。

Permutation Prime Sums

题目大意：构造两个 1..n1..n1..n 的排列 a、b，使每个位置 ai+bia_i + b_iai​+bi​ 都是质数；无解输出 IMPOSSIBLE。

解题思路：质数中只有 1+1=21 + 1 = 21+1=2 是偶数，其余都是奇数 = 奇数 + 偶数，所以除了可能存在的 1-1 配对，每个奇数必须与一个偶数配对、每个偶数必须与一个奇数配对。n 为奇数时 1 配 1（两个排列该位置都放 1），其余 n−1n-1n−1 个数里奇数、偶数各半，两两配对；n 为偶数时奇数与偶数直接两两配对。配对用贪心：奇数从大到小处理，为每个奇数 o 找"最大的可用偶数 e 使 o + e 为质数"（先检查最大的 200 个候选，找不到再全扫描——小质数密集，几乎总是前几个就命中）。把配对 (o, e) 同时写入两个排列：a[o] = o, b[o] = e 且 a[e] = e, b[e] = o（即 a 是顺序排列，b 在每个配对里交换两数）。最后验证所有 ai+bia_i + b_iai​+bi​ 都是质数再输出。复杂度 O(nn+n)O(n \sqrt{n} + n)O(nn​+n)（筛法 + 贪心）。

Chess Tournament

题目大意：n 位棋手，第 i 位想下恰好 xix_ixi​ 盘棋，任意两人最多对弈一盘。判断能否满足所有人的需求，能则输出比赛安排。

解题思路：贪心（Havel-Hakimi 风格）：用大根堆按剩余需求排序，每次取出需求最大的棋手 s（还差 d 盘），让他与当前需求最大的 d 位棋手各下一盘（若剩余人数不足 d 则 IMPOSSIBLE），对手需求减 1（减到 0 就出堆）。需求最大者优先被匹配，保证不会出现"只剩一位对手却需求 > 1"的死局。输出每场对弈。复杂度 O((n+∑xi)log⁡n)O((n + \sum x_i) \log n)O((n+∑xi​)logn)。

Distinct Sums Grid*

题目大意：构造 n×n 网格，使每个整数 1..n1..n1..n 恰好出现 n 次，且所有 n 个行和与 n 个列和共 2n2n2n 个值互不相同。无解输出 IMPOSSIBLE。

解题思路：小情况（n≤3n \le 3n≤3）无解。先构造拉丁方 g[i][j] = 1 + (i + j) % n：每个值恰好出现 n 次，但所有行列和相等。然后用局部搜索逐步消除重复的行列和：随机交换两个不同值的位置（值计数不变），若交换后"不同行列和的数量"不减就保留，否则回退。重复若干轮直到 2n2n2n 个和全部互异；达到迭代上限仍失败则输出 IMPOSSIBLE。复杂度 O(迭代次数⋅n)O(\text{迭代次数} \cdot n)O(迭代次数⋅n)。

Filling Trominos

题目大意：t 组测试，判断 n×m 网格能否用 L 形三格骨牌铺满（每块覆盖 3 格、形状为 2×2 缺一角），能则输出平铺方案——同一骨牌的 3 个格用同一个字母表示。

解题思路：无解条件：面积不能被 3 整除、最短边小于 2、或一边为 3 另一边为奇数（3×3、3×5…都无法铺满，角落处必空）。构造分四种情形（必要时先转置使 m % 3 == 0）：

  • n == 3：此时必有 m % 6 == 0（m % 6 == 3 已判 NO），横铺 3×2 块；
  • n 为偶数：2 行一组，每组用 2×3 块横铺；
  • n 为奇数（≥ 5）：底部用 1 个 5 行组，其余 2 行一组。5 行组里，m % 6 == 0 时上面 3 行用 3×2 块、下面 2 行用 2×3 块；m % 6 == 3 时先放一个固定的 5×9 模板（15 个 L 骨牌），之后每 6 列重复"3×2 + 3×2 + 3×2 / 2×3 + 2×3"的组合。

每个 L 块放置时，place 会检查四个方向的相邻格，选一个不与已放骨牌冲突的字母。全部放完验证网格无空位后输出（转置过的再转回来）。复杂度每组 O(nm)O(nm)O(nm)。

Grid Path Construction*

题目大意：t 组测试，每组给 n×m 网格与起点 a、终点 b，构造一条从 a 到 b、恰好访问每个格子一次的路径（沿四方向移动），输出方向串；无解输出 NO。

解题思路：先用奇偶着色判断可行性：路径每步颜色交替，所以格数为偶数时两端点必须异色、格数为奇数时两端点必须同色（1×11 \times 11×1 的网格单独处理为 YES）。构造用 Warnsdorff 启发式 DFS：每一步把所有未访问邻居按"剩余度数"升序排序，优先走度数最小的（容易堵死的）方向；同时维护动态度数——进入新格子后把其未访问邻居的度数各减 1，若出现度数为 0 的孤立格（不是终点，或终点但还剩不止一步），立即剪枝回溯。这样在网格上几乎总能很快找到解。找到终点且步数满即输出方向串。复杂度取决于搜索（实践上 O(nm)O(nm)O(nm) 级别）。
