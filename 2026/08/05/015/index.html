Bitwise Operations

Counting Bits

题目大意：求 1..n1..n1..n 的所有数的二进制表示中 1 的总个数（n≤1018n \le 10^{18}n≤1018）。

解题思路：逐位统计。考虑 0..n0..n0..n 共 n + 1 个数：第 b 位的取值以 2b+12^{b+1}2b+1 为周期，每个完整周期里恰有 2b2^b2b 个数该位为 1，剩余不足一个周期的部分，前 2b2^b2b 个数该位为 0、之后为 1。所以第 b 位的贡献 = (n+1) / 2^(b+1) * 2^b + max(0, (n+1) % 2^(b+1) - 2^b)。0 的贡献为 0，不影响结果。复杂度 O(log⁡n)O(\log n)O(logn)。

Maximum Xor Subarray

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），求异或和最大的连续子数组的异或和。

解题思路：前缀异或。子数组 [l, r] 的异或 = pref[r] ^ pref[l-1]（前缀异或数组 sum）。从左到右扫描，维护已见过前缀的二进制 Trie（add），对当前前缀 sum 在 Trie 上贪心地按"相反的位"走（query）：每一位尽量取与 sum 不同的分支，使异或结果该位为 1；某分支不存在才走相同分支。初始把 0 插入（空前缀）。答案取所有 query(sum) 的最大值。复杂度 O(nlog⁡V)O(n \log V)O(nlogV)。

Maximum Xor Subset

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105，值可达 2602^{60}260 级别），求任意子集（可空）异或和的最大值。

解题思路：线性基。把每个数按位从高到低插入：若当前最高位 b 还没有基向量就把它存入 basis[b]，否则用它异或掉这一位继续往下（类似高斯消元）。插入完后求最大异或：从高位到低位贪心，若 ans ^ basis[b] > ans 就异或上（把该位变成 1 一定更优，且高位优先）。复杂度 O(60n)O(60n)O(60n)。

Number of Subset Xors

题目大意：给 n 个数，求所有子集（含空集）异或能得到多少个不同的值。

解题思路：所有子集异或恰好张成一个线性空间（每个线性组合都可达），其大小是 2rank2^{rank}2rank，rank 为线性基的秩。插入线性基时每成功放一个基向量 rank++，答案 1LL << rank。复杂度 O(60n)O(60n)O(60n)。

K Subset Xors

题目大意：给 n 个整数（0≤xi≤1090 \le x_i \le 10^90≤xi​≤109），把所有 2n2^n2n 个子集的异或（含空集的 0，重复按多次计）从小到大排序，输出前 k 小的值。

解题思路：先建线性基并高斯消元成简化阶梯形（对每个基向量 basis[b]，用低位的基消掉它的低位 1，使每个基向量的最高位互不占用）。此时不同异或值共有 2r2^r2r 个（r 为秩），第 idx 小的不同值就是把 idx 的二进制位映射到基向量上异或；每个不同值重复 2n−r2^{n-r}2n−r 次（那些"自由"元素进不进子集都不改变异或结果）。所以第 i 个输出 = 第 i / mult 个不同值（mult = 2^(n-r)；n-r 很大时前 k 个全是 0）。复杂度 O(60n+k⋅r)O(60n + k \cdot r)O(60n+k⋅r)。

All Subarray Xors

题目大意：给 n 个数（0≤xi≤1060 \le x_i \le 10^60≤xi​≤106），找出所有能作为某个连续子数组异或和的整数，去重后升序输出（含个数）。

解题思路：子数组异或 = 两个前缀异或的异或，所以目标集合 = 前缀异或集合（含 0）两两异或的所有结果。用快速 Walsh-Hadamard 变换（FWHT）对前缀异或的计数数组做异或卷积：FWHT 是每层蝴蝶 (u+v, u-v)，变换后逐点平方再逆变换（每层除以 2），得到 f[v] = 异或为 v 的有序前缀对数。f[0] -= (n + 1) 排除"两个相同前缀"的对（它们来自空子数组/同起点，不代表非空子数组）。最后 f[v] > 0 的 v 升序输出。值域 2202^{20}220，复杂度 O(220⋅20)O(2^{20} \cdot 20)O(220⋅20)。

Xor Pyramid Peak

题目大意：异或金字塔：每个数是其左下方、右下方两个数的异或。给定底层 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105，ai≤109a_i \le 10^9ai​≤109），求顶端那个数。

解题思路：把每层的每个数展开成底层的异或，发现底层的 aia_iai​ 在顶端出现 C(n−1,i−1)C(n-1, i-1)C(n−1,i−1) 次（系数奇偶决定是否参与）。由 Lucas 定理，组合数为奇数当且仅当 (i−1)(i-1)(i−1) 的二进制位全部包含在 n−1n-1n−1 里，即 (i−1)⊆(n−1)(i-1) \subseteq (n-1)(i−1)⊆(n−1)。不需要枚举所有子集：用"步长合并"——对 mask = n - 1 的每个 1 位 b，执行 cur[j] ^= cur[j + 2^b]（把相距 2b2^b2b 的元素合并一次），全部位处理完后 cur[0] 就是所有满足 i−1⊆n−1i-1 \subseteq n-1i−1⊆n−1 的 aia_iai​ 的异或。复杂度 O(n⋅popcount(n))O(n \cdot \text{popcount}(n))O(n⋅popcount(n))。

Xor Pyramid Diagonal

题目大意：异或金字塔，给定底层 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每一行（自底向上）最左边的那个数。

解题思路：第 r 行（自底向上数，r = 1..n）最左边的数 = 底层中满足 (i−1)⊆(r−1)(i-1) \subseteq (r-1)(i−1)⊆(r−1) 的所有 aia_iai​ 的异或（与上一题相同的 Lucas 推导）。对每个 mask = r - 1 求"所有子集的异或和"正是 SOS（子集）DP：dp[mask] 初值为 a[mask]（空位补 0），对每个位 b 做 dp[mask] ^= dp[mask ^ (1<<b)]（mask 含位 b 时），处理完 dp[mask] = ⊕_{sub ⊆ mask} a[sub]。输出 dp[r - 1]。复杂度 O(2⌈log⁡n⌉log⁡n)O(2^{\lceil \log n \rceil} \log n)O(2⌈logn⌉logn)。

Xor Pyramid Row

题目大意：异或金字塔，给定底层 n 个数，输出从顶端数第 k 行的所有数（该行有 k 个数）。

解题思路：从顶端数第 k 行就是从底端数第 r = n - k 行（0 起始）。该行第 j 个数 = 底层中满足 t⊆rt \subseteq rt⊆r 的所有 aj+ta_{j+t}aj+t​ 的异或（Lucas 推导同上，平移了 j）。用"步长合并"就地计算整行：cur = a，对 r 的每个 1 位 b 执行 cur[i] ^= cur[i + 2^b]，处理完后 cur[0..k-1] 就是答案。复杂度 O(n⋅popcount(r))O(n \cdot \text{popcount}(r))O(n⋅popcount(r))。

SOS Bit Problem

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105，ai<220a_i < 2^{20}ai​<220），对每个数 x 输出三个计数：满足 x | y == x 的 y 个数、满足 x & y == x 的 y 个数、满足 x & y != 0 的 y 个数。

解题思路：SOS（子集和/超集和）DP。F[v] 初始为值为 v 的元素个数，做子集和（对每个位 b：F[mask] += F[mask ^ (1<<b)]，mask 含位 b 时）后，F[x] = 所有 y ⊆ x 的个数，即第一问答案（y | x == x ⟺ y 是 x 的子集）。G[v] 做超集和后，G[x] = 所有 y ⊇ x 的个数，即第二问。第三问：x & y != 0 的补集是 x & y == 0，即 y ⊆ ~x（~x = ma - 1 - x，ma = 2^20），个数为 F[ma - 1 - x]，所以答案为 n - F[ma - 1 - x]。复杂度 O(n+220⋅20)O(n + 2^{20} \cdot 20)O(n+220⋅20)。

And Subset Count

题目大意：给 n 个数（0≤ai≤n0 \le a_i \le n0≤ai​≤n），对每个 k = 0..n 统计"元素按位与恰好等于 k"的非空子集个数，对 109+710^9+7109+7 取模。

解题思路：两步变换。先算 cnt[mask] = 满足 ai⊇maska_i \supseteq maskai​⊇mask 的元素个数（mask 的 1 位都在 aia_iai​ 里），用超集 SOS 求和；由这些元素组成的任意非空子集，其 AND 都 ⊇mask\supseteq mask⊇mask，个数为 f[mask] = 2^cnt[mask] - 1。现在 f[k] = Σ_{mask ⊇ k} g[mask]（g 是 AND 恰好等于的值），从 f 反演 g：按位做超集莫比乌斯变换 g[mask] = f[mask] - g[mask | (1<<b)]（对每个位 b，mask 不含位 b 时依次相减）。输出 g[0..n]。复杂度 O(n+2⌈log⁡n⌉log⁡n)O(n + 2^{\lceil \log n \rceil} \log n)O(n+2⌈logn⌉logn)。
