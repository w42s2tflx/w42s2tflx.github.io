Bouncing Ball Steps

题目大意：在 n×mn\times mn×m 的网格中，球沿对角线方向移动，碰到边界就反弹。给定步数 k，求 k 步后球所在的位置以及总共改变方向的次数。

解题思路：行、列方向的运动相互独立，各自在区间 [1,n][1, n][1,n]、[1,m][1, m][1,m] 上往返，周期为 2(n−1)2(n-1)2(n−1)、2(m−1)2(m-1)2(m−1)。fold(t, L) 计算沿长度为 L 的坐标轴走 t 步后的位置：r=t mod 2(L−1)r = t \bmod 2(L-1)r=tmod2(L−1)，r≤L−1r \le L-1r≤L−1 时位置为 r+1r+1r+1，否则为 2L−1−r2L-1-r2L−1−r。球在行方向上每 n−1n-1n−1 步撞一次上下边界（方向反转），在列方向上每 m−1m-1m−1 步撞一次左右边界；撞四角时两个方向同时反转，只算一次改变方向。所以前 k 步内改变方向的次数 = k/(n-1) + k/(m-1) - k/lcm(n-1, m-1)（减去同时撞两边、被重复计数的步数）。每组时间复杂度为 O(1)O(1)O(1)。

Increasing Array II

题目大意：给长度为 n 的数组（n≤2×105n \le 2 \times 10^5n≤2×105），每次操作把任意一个元素加 1 或减 1，求使数组变为非下降序列的最少操作次数。

Swap Round Sorting

题目大意：给一个 1..n1..n1..n 的排列，每轮可以同时交换任意多对互不相交的元素（每个元素每轮至多参与一次交换），求把它排成升序的最少轮数，并输出每轮的交换方案。

解题思路：一轮交换等价于右乘一个"对合"（不相交对换之积）。经典结论：任意排列都能写成两个对合的乘积，所以任意排列至多 2 轮；1 轮可行当且仅当排列本身是对合（所有环长 ≤2\le 2≤2）。答案：已排好 → 0；所有环长 ≤2\le 2≤2 → 1；否则 → 2。构造：对每个环 (c0…cL−1)(c_0 \ldots c_{L-1})(c0​…cL−1​)，第 1 轮交换 (ci,cL−1−i)(c_i, c_{L-1-i})(ci​,cL−1−i​)（反射）；若 L≥3L \ge 3L≥3，第 2 轮交换 (ci,cL−i)(c_i, c_{L-i})(ci​,cL−i​)。时间复杂度为 O(n)O(n)O(n)。

Binary Subsequences

题目大意：构造一个最短的二进制串，使它恰好有 n 个不同的非空子序列（n≤109n \le 10^9n≤109）。

解题思路：记 a = 以 0 结尾的不同子序列数、b = 以 1 结尾的，总数 = a+ba+ba+b。在串尾追加 0：新串中 (a,b)(a, b)(a,b) 变为 (a+b+1,b)(a + b + 1, b)(a+b+1,b)；追加 1 变为 (a,a+b+1)(a, a + b + 1)(a,a+b+1)。于是给定目标 (a,b)(a, b)(a,b)，最后一个字符被唯一确定：a > b 时必为 0（回溯为 (a - b - 1, b)），b > a 时必为 1；a = b 时只能等于 (0, 0)（空串）。对每个拆分 (i, n - i) 用欧几里得式递归判断该数对是否可达，可达则反向构造串，取长度最短的；若都不可达，全 1 串恰好有 n 个不同子序列（子序列数 = 1 的个数）。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Grid Coloring II

题目大意：n×mn\times mn×m 网格，每个格子原字符为 A/B/C 之一。要求把每个格子改成 A/B/C 中另一个字符（必须与原字符不同），且任意相邻格子字符不同。输出任一方案或 IMPOSSIBLE。

题目大意：n×nn\times nn×n 网格（n≤100n \le 100n≤100），第 i 行要选恰好 a[i] 个格子、第 j 列恰好 b[j] 个格子（∑a=∑b\sum a = \sum b∑a=∑b），输出一种选择方案或 -1。

解题思路：0-1 矩阵行和/列和构造的经典贪心：把行按需求降序处理，每行一次性选取当前剩余需求最大的 a[i] 个列（用 multiset 按 -b[j] 维护）并各减 1；过程中剩余列不足则该行无法完成，输出 -1。优先消耗需求大的列，能最大程度避免"需求被分得太碎而无法凑整"。时间复杂度为 O(n2log⁡n)O(n^2 \log n)O(n2logn)。

Minimum Cost Pairs

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），对每个 k=1..⌊n/2⌋k = 1..\lfloor n/2\rfloork=1..⌊n/2⌋ 求"配成 k 对（每对代价 = ∣a−b∣|a-b|∣a−b∣）"的最小总代价。

解题思路：排序后最优配对必然都是相邻元素（跨过未配对的元素只会更大）。贪心：用最小堆反复取最小的相邻差 val[i] = a[i+1] - a[i]，选它作为一对后，该对两侧的元素变成新的相邻，合并出新差 a[r] - a[l]（链表 L/R 维护邻居，removed 标记）；堆中弹出过期的（与当前 val[i] 不一致的）项。每次配对累积总代价，输出前缀。这是"配对问题"的经典贪心，时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Two Stacks Sorting

题目大意：给一个 1..n1..n1..n 的排列，用两个栈把它排序（输入流 → 两个栈 → 输出流，每个数依次进入其中一个栈，最终按 1…n 顺序输出），输出每个数进入哪个栈（1 或 2）；无解输出 IMPOSSIBLE。

解题思路：先推冲突条件。同一栈中先入者在后入者下方；若 i<ji < ji<j 且 ai<aja_i < a_jai​<aj​ 同栈，则 aja_jaj​ 在 aia_iai​ 上方、必须先弹出，违反从小到大的输出顺序，唯一挽救办法是 aja_jaj​ 入栈前 aia_iai​ 已弹出——这要求所有小于 aia_iai​ 的值都出现在位置 jjj 之前。所以 aia_iai​ 与 aja_jaj​（i<ji < ji<j，ai<aja_i < a_jai​<aj​）不能同栈，当且仅当存在 k>jk > jk>j 使 ak<aia_k < a_iak​<ai​（位置 i<j<ki < j < ki<j<k、值 ak<ai<aja_k < a_i < a_jak​<ai​<aj​，即 231 模式）。值递减的同栈对（ai>aja_i > a_jai​>aj​）永远相容：aja_jaj​ 先弹、顺序正确。因此"可双栈排序当且仅当按 231 模式连边的冲突图可以二染色"，矛盾则输出 IMPOSSIBLE。

代码把冲突边批量化添加：按"下一个待输出值"的出现时刻把时间轴切成块（读到值 x 时记录它的到达序 st[x]，每当下一个待输出值 nx 已经出现，就把 (st[nx], 当前时刻) 划成一个块存入 w）。块按起点排序后，用线段树维护每个块起点处的已处理块列表：query(a, b) 收集与当前块 [a, b] 相交的已处理块，用带权并查集 unite 把它们与当前块连成"异色"约束（edge 记录每个分量的异色对象）；若发现当前块与父端已在同一分量（find(parent) == find(A)），说明冲突图出现奇环，输出 IMPOSSIBLE。全部块处理完后按并查集给各分量染 1/2 色（相邻异色），输出每个元素所在栈。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。
