Sliding Window Problems

Sliding Window Sum

题目大意：用线性同余生成器 x, a, b, c 生成 n 个数（n≤105n \le 10^5n≤105）：第一个数为 x，之后每个数 =(a⋅prev+b) mod c= (a \cdot prev + b) \bmod c=(a⋅prev+b)modc。对每个长度为 k 的窗口求和，输出所有窗口和的异或。

解题思路：滑动维护窗口和。先累加前 k 个数作为第一个窗口的和（答案初始化为它），然后每次右移一格：加上新进来的 arr[i]、减去离开的 arr[i - k]，把新的窗口和异或进答案。时间复杂度为 O(n)O(n)O(n)。

Sliding Window Minimum

题目大意：同上生成 n 个数，对每个长度为 k 的窗口求最小值，输出所有最小值的异或。

解题思路：单调队列维护窗口最小值。队列存下标，保持队内元素值单调递增：加入 i 前把队尾所有 arr[...] >= arr[i] 的下标弹出（它们既大又先过期，永远不会成为最小值），再把过期的队首（下标 <= i - k）弹出，队首即当前窗口最小值。时间复杂度为 O(n)O(n)O(n)。

Sliding Window Xor

题目大意：同上生成 n 个数，对每个长度为 k 的窗口求窗口内所有数的异或，再输出所有窗口异或值的异或。

解题思路：异或两次等于抵消，所以窗口右移时只需 cur ^= arr[i] ^ arr[i - k]（新元素进一次、旧元素再异或一次移除）。第一个窗口单独初始化。时间复杂度为 O(n)O(n)O(n)。

Sliding Window Or

题目大意：同上生成 n 个数（值不超过 2302^{30}230），对每个长度为 k 的窗口求窗口内所有数按位或，再输出所有窗口或值的异或。

解题思路：逐位独立处理。对第 b 位，窗口的 OR 在该位为 0 当且仅当窗口内所有数该位都是 0——也就是"连续 0 段"长度至少为 k。扫描时维护当前 0 段长度 len0（遇到该位为 1 的数就清零），每处统计 len0 >= k 的窗口数 zeroWin；总窗口数减去它得到该位为 1 的窗口数 oneWin，若为奇数就在答案里置上第 b 位（最终是异或，所以只看奇偶）。清零操作 len0 = (len0 + 1) & mask 用掩码技巧写成无分支（该位为 0 时 mask = ~0，为 1 时 mask = 0）。时间复杂度为 O(30n)O(30n)O(30n)。

Sliding Window Distinct Values

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每个长度为 k 的窗口中不同值的个数。

解题思路：先把值离散化（坐标压缩），用 cnt[idx] 记录窗口内每个值出现的次数。右移时新元素计数 +1（从 0 变 1 时 distinct++），离开元素计数 -1（减到 0 时 distinct--）。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Sliding Window Mode

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每个长度为 k 的窗口的众数（出现次数最多的值；并列时取最小的值）。

解题思路：值离散化后维护 cnt[idx]（出现次数）和"按频率分桶"的集合 freqSet[f]（当前频率为 f 的所有值）。加入元素：把它从旧频率桶移到新频率桶，更新 maxf；移除元素：降频移桶，若最大频率的桶空了就 maxf--（每次移除最多掉一级）。窗口众数 = freqSet[maxf] 中的最小值，输出 vals[*freqSet[maxf].begin()]。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Sliding Window Mex

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每个长度为 k 的窗口的 mex（窗口内未出现的最小非负整数）。

解题思路：窗口大小只有 k，所以 mex 一定不超过 k≤nk \le nk≤n，值大于 n 的数可以忽略。维护 cnt[0..n] 和一个"缺失值集合" missing（初始 0..n+10..n+10..n+1 全在）：加入值 x≤nx \le nx≤n 时若 cnt[x] 从 0 变 1 就从 missing 删掉，移除时若减到 0 就插回。窗口的 mex 即 *missing.begin()。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Sliding Window Median

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每个长度为 k 的窗口中位数（k 为偶数时取较小者，即第 (k-1)/2 小、0 起始）。

解题思路：用 PBDS 的红黑树（支持 find_by_order 查询第 t 小）维护窗口。值可能有重复，所以集合元素用 pair<int, int>（值 + 下标），下标保证唯一。滑动时 insert({x[i], i})，离开窗口的元素 erase({x[i-k], i-k})，每个窗口输出 find_by_order((k-1)/2) 的值分量。时间复杂度为 O(nlog⁡k)O(n \log k)O(nlogk)。

Sliding Window Cost

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），对每个长度为 k 的窗口，输出把窗口内所有元素变成同一个数所需的最小总代价（每个元素的代价 = 改变量）。

解题思路：最优目标值取窗口的中位数。总代价是 ∑∣xi−t∣\sum |x_i - t|∑∣xi​−t∣：把目标 t 向右移动 Δ\DeltaΔ 时，比 t 小的元素（左半）代价各增加 Δ\DeltaΔ，比 t 大的元素（右半）各减少 Δ\DeltaΔ，净变化为 Δ⋅(左半个数−右半个数)\Delta \cdot (\text{左半个数} - \text{右半个数})Δ⋅(左半个数−右半个数)。因此只有当 t 落在中位数位置（左右个数相等）时两侧没有净收益；任何更小或更大的 t 都会因为某一侧元素更多而变差。用两个 multiset 维护窗口：left 存较小的一半（大小 = right 或比 right 大 1），right 存较大的一半，同时维护两部分的和。fix 负责平衡两边大小；中位数就是 left 的最大值。代价 = left.size() * median - left_sum + right_sum - right.size() * median（左半全部升到中位数、右半全部降到中位数）。add/rem 按值大小分到两半并 fix。时间复杂度为 O(nlog⁡k)O(n \log k)O(nlogk)。

Sliding Window Inversions

题目大意：给 n 个数（n≤2×105n \le 2 \times 10^5n≤2×105），输出每个长度为 k 的窗口内逆序对的数量。

解题思路：坐标压缩 + 树状数组。右端新加入元素 a[i] 时，窗口内比它大的元素数 = 当前窗口大小 - 不大于它的个数（w - qry(g)，w = min(i, k) 是加入后窗口内的元素数），加上这些就是新增逆序对；左端移除 a[i - k] 时，它与窗口内其他元素形成的逆序对要减去：作为较大者的逆序对数 = 窗口内比它小的个数 = qry(gr - 1)。移除和加入的先后顺序保证不重不漏。时间复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。

Sliding Window Advertisement

题目大意：给 n 个柱子的高度（n≤2×105n \le 2 \times 10^5n≤2×105），对每个长度为 k 的窗口，输出窗口内柱状图中最大矩形的面积。

解题思路：最大矩形一定以某个柱子 i 的高度为矩形的高，其宽度是"以 i 为最小值的最大连续段"与窗口的交。先用单调栈求 L[i]（左边第一个更矮）和 R[i]（右边第一个严格更矮，处理等高并列：左闭右开区间 [L[i]+1, R[i]-1] 内 h[i] 是最小值）。窗口起点 l 包含 i 的范围是 [max(0, i-k+1), min(i, n-k)]；窗口与最小段的交宽 w = min(R[i], l+k) - max(L[i]+1, l) 是 l 的分段线性函数，按 l 与 L[i]、R[i]-k 的大小关系分成 4 段（斜率 +1、0、0、-1），把每段直线 h[i] * w 用 Li Chao 树的区间插入加到对应 l 范围上。最后对每个 l 点查询所有直线的最大值。时间复杂度为 O(nlog⁡2n)O(n \log^2 n)O(nlog2n)。
