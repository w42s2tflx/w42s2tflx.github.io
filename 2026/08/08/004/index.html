Static Range Sum Queries

题目大意：静态数组，qqq 次询问区间 [l,r] 的元素和，中途不修改。

解题思路：前缀和。读入时把 a[i] 原地改成前缀和 a[i] += a[i-1]，则区间 [l,r] 的和就是 a[r] - a[l-1]（两个前缀和相减，a[l-1] 部分被抵消）。预处理 O(n)O(n)O(n)、每次询问 O(1)O(1)O(1)，总复杂度 O(n+q)O(n+q)O(n+q)。

Static Range Minimum Queries

题目大意：静态数组，qqq 次询问区间 [l,r] 的最小值，中途不修改。

解题思路：稀疏表（ST 表）。a[i][j] 表示从位置 i 开始、长度为 2j2^j2j 的区间最小值，递推 a[i][j]=min⁡(a[i][j−1], a[i+2j−1][j−1])a[i][j]=\min(a[i][j-1],\,a[i+2^{j-1}][j-1])a[i][j]=min(a[i][j−1],a[i+2j−1][j−1])。回答 [l,r] 时取 s=⌊log⁡2(r−l+1)⌋s=\lfloor\log_2(r-l+1)\rfloors=⌊log2​(r−l+1)⌋（预处理 logn 数组存每段的长度取对数），答案 =min⁡(a[l][s], a[r−2s+1][s])=\min(a[l][s],\,a[r-2^s+1][s])=min(a[l][s],a[r−2s+1][s])——这两个区间长度都是 2s2^s2s、合起来恰好覆盖 [l,r]。预处理 O(nlog⁡n)O(n\log n)O(nlogn)、询问 O(1)O(1)O(1)。

另解（题解二）：离线 + 单调栈 + 并查集。把询问按右端点 r 分组，从左往右扫描右端点 i：维护一个值单调递增的单调栈，当 a[i] 把栈顶 p 弹掉（a[p] >= a[i]）时，让并查集把 p 的"区间最小值归属"接到 i（fa[p]=i）。这样处理完 i 后，s.get(l) 就是区间 [l,i] 最小值的下标，直接输出 a[s.get(l)]。复杂度近似 O((n+q)α(n))O((n+q)\alpha(n))O((n+q)α(n))。

Dynamic Range Sum Queries

题目大意：支持两种操作：把位置 k 的值改成 u，或询问区间 [l,r] 的和。

解题思路：树状数组维护区间和。单点更新用"新值 - 旧值"的差值：旧值是 sum(l) - sum(l-1)，所以代码里 add(l, r - sum(l) + sum(l-1))；区间和用两次前缀和相减 sum(r) - sum(l-1)。两种操作都是 O(log⁡n)O(\log n)O(logn)，总复杂度 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Dynamic Range Minimum Queries

题目大意：支持两种操作：把位置 k 的值改成 u，或询问区间 [l,r] 的最小值。

解题思路：堆式（迭代式）线段树，叶子在 TREE_SIZE + i。change(k, u) 更新叶子后沿父链不断取 min 重算祖先；get_min(l, r) 用"左指针 l、右指针 r 同时向上爬"的经典写法：l 是奇数就取当前节点并右移、r 是偶数就取当前节点并左移，直到两个指针交叉，被取到的节点恰好不重不漏覆盖 [l,r]。每次操作 O(log⁡n)O(\log n)O(logn)。

Range Xor Queries

题目大意：静态数组，qqq 次询问区间 [l,r] 的异或和，中途不修改。

解题思路：前缀异或。读入时把 a[i] 原地改成前缀异或 a[i] ^= a[i-1]。因为 x⊕x=0x \oplus x = 0x⊕x=0（一个数异或自己抵消），区间 [l,r] 的异或和就是 a[r] ^ a[l-1]，与减法同构。预处理 O(n)O(n)O(n)、每次询问 O(1)O(1)O(1)，总复杂度 O(n+q)O(n+q)O(n+q)。

Range Update Queries

题目大意：支持两种操作：区间 [l,r] 每个位置都加 u，或查询某个位置 k 当前的值。

解题思路：差分 + 树状数组。“区间加"转成"端点加”：[l,r] 加 u 等价于在差分数组的 l 处 +u、r+1 处 -u，那么位置 k 的当前值就是差分数组的前缀和，用 get_sum(1, k) 查询。初始建树也按差分插入（对每个 x 执行 change(i, x)、change(i+1, -x)）。每次操作 O(log⁡n)O(\log n)O(logn)，总复杂度 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Forest Queries

题目大意：n×nn\times nn×n 的地图，* 表示树。qqq 次询问：以 (l,r) 为左上角、(x,y) 为右下角的矩形内有多少棵树，中途不修改。

解题思路：二维前缀和。a[i][j] 读入后改成以 (1,1) 为左上角、(i,j) 为右下角的矩形内的树数，递推 a[i][j]=a[i−1][j]+a[i][j−1]−a[i−1][j−1]+[该格是树]a[i][j]=a[i-1][j]+a[i][j-1]-a[i-1][j-1]+[该格是树]a[i][j]=a[i−1][j]+a[i][j−1]−a[i−1][j−1]+[该格是树]（加一个右上角、减重叠的左上角，用容斥去重）。回答矩形用同样的容斥：a[x][y]−a[x][r−1]−a[l−1][y]+a[l−1][r−1]a[x][y]-a[x][r-1]-a[l-1][y]+a[l-1][r-1]a[x][y]−a[x][r−1]−a[l−1][y]+a[l−1][r−1]。预处理 O(n2)O(n^2)O(n2)、询问 O(1)O(1)O(1)。

Hotel Queries

题目大意：n 家酒店，每家有一定数量的空房。m 个团队依次来，第 j 队需要 x 间房，给它分配最靠左的空房数不少于 x 的酒店，并把该酒店空房数减少 x；没有酒店可分则输出 0。

解题思路：线段树维护区间空房最大值。先把 n 向上补成 2 的幂（代码把 n 改成补足后的 k），叶子依次存各家空房。query(x) 从根开始向下走：若左子树最大值 >= x 就走左子树，否则走右子树，到达的叶子就是最靠左的可行酒店，一次下潜 O(log⁡n)O(\log n)O(logn)；随后 update(id, -x) 减少该酒店空房并沿路用 max 重算。每个团队 O(log⁡n)O(\log n)O(logn)，总复杂度 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

List Removals

题目大意：n 个元素排成列表，依次执行 n 次删除：第 i 次删除当前列表中第 p[i] 个（从 1 数）元素，并输出被删元素的值。

解题思路：线段树维护每个位置是否存活（1 存活 / 0 已删），change 单点改 0/1。query(k) 查找当前第 k 个存活位置：从根向下走，若左子树存活数 >= k 就走左，否则让 k 减去左子树存活数后走右，到达叶子即为要删除的位置。每次"查找 + 置 0" O(log⁡n)O(\log n)O(logn)，总复杂度 O(nlog⁡n)O(n\log n)O(nlogn)。

另解（题解二）：用 pbds 的 ordered_set 存 (位置, 值) 二元组（按键有序），find_by_order(p-1) 直接取当前第 p 个元素输出其值，再用 erase 删除，同样每次 O(log⁡n)O(\log n)O(logn)。

Salary Queries

题目大意：n 个员工各有工资，支持两种操作：把员工 k 的工资改成 u，或询问工资落在 [l,r] 范围内的员工人数。

解题思路：值域线段树（离散化）。把所有初始工资和所有操作里出现的值收集起来排序去重，再用 lower_bound 把每个实际工资映射成值域下标；线段树以"工资"为下标维护人数计数（叶子记该工资的人数），修改就是点更新 ±1\pm1±1，询问把 [l,r] 映射成下标区间后求和。排序 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，每个操作 O(log⁡(n+q))O(\log(n+q))O(log(n+q))。

Visible Buildings Queries

题目大意：n 栋楼，高度数组 h。从某位置向左看，一栋楼"可见"当且仅当它比它左边所有楼都高（即从左到右的"纪录高"）。qqq 次询问：只看区间 [a,b] 内的楼（站在 a 处向右看）能看到几栋。

解题思路：预处理每栋楼"右边第一栋比它更高的楼"。用单调栈从右往左扫描：弹出高度不超过 h[i] 的栈顶（heights[stack.back()] <= heights[i]），栈顶就是 jump[0][i]；高度数组末尾补一个哨兵 INF 保证一定有后继。再做倍增 jump[k][i]=jump[k−1][jump[k−1][i]]jump[k][i]=jump[k-1][jump[k-1][i]]jump[k][i]=jump[k−1][jump[k−1][i]]。回答 [a,b]：从 a 出发、从高层到低层尝试跳，只要 jump[k][pos]≤bjump[k][pos]\le bjump[k][pos]≤b 就跳过去并累加 2k2^k2k，最后答案 =1+=1+=1+ 跳的总次数（a 本身也算一栋）。预处理 O(nlog⁡n)O(n\log n)O(nlogn)、每次询问 O(log⁡n)O(\log n)O(logn)。

Range Interval Queries

题目大意：静态数组，qqq 次询问：下标在 [a,b]、值在 [c,d] 范围内的元素个数。

解题思路：离线 + 树状数组。把每个元素变成事件 (值, 2, 下标)，每个询问拆成两个事件 (c, 1, a, b, id) 与 (d, 3, a, b, id)；把所有事件按值从小到大排序后依次处理，树状数组维护"值不超过当前已处理值的元素位置"（元素事件把其下标置 1，set_val）。利用类型编号（1 < 2 < 3）控制同值事件的先后：处理值 c 的事件 1 时，值恰好为 c 的元素还没插入，于是 result -= 当前区间和，得到"值 < c 的个数"；处理值 d 的事件 3 时，值 ≤d\le d≤d 的元素都已插入，于是 result += 当前区间和。最终 result=#(值≤d)−#(值<c)=#(c≤值≤d)result = \#(值\le d) - \#(值<c) = \#(c\le 值\le d)result=#(值≤d)−#(值<c)=#(c≤值≤d)，即答案。排序 O((n+q)log⁡(n+q))O((n+q)\log(n+q))O((n+q)log(n+q))，处理每个事件 O(log⁡n)O(\log n)O(logn)。

Subarray Sum Queries

题目大意：支持单点改值，每次改完输出整个数组的最大子段和（允许空子段，即结果至少为 0）。

解题思路：线段树节点维护四个量：区间和 val、最大前缀和 pre、最大后缀和 suf、最大子段和 t。合并左右段 L、R：

val=valL+valR,pre=max⁡(preL, valL+preR),suf=max⁡(sufR, sufL+valR),t=max⁡(tL, tR, sufL+preR)val=val_L+val_R,\quad pre=\max(pre_L,\,val_L+pre_R),\quad suf=\max(suf_R,\,suf_L+val_R),\quad t=\max(t_L,\,t_R,\,suf_L+pre_R) val=valL​+valR​,pre=max(preL​,valL​+preR​),suf=max(sufR​,sufL​+valR​),t=max(tL​,tR​,sufL​+preR​)

最大子段和要么完全落在左段、要么完全落在右段，要么跨过中点（左段后缀 + 右段前缀）。叶子若 x<0 则令 t = pre = suf = 0（允许空子段）。每次更新 f(k, x) 改叶子并沿路合并，答案就是根节点的 t[1]。复杂度 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)。

Subarray Sum Queries II

题目大意：数组固定，qqq 次询问区间 [a,b] 内的最大子段和（允许空子段，即结果至少为 0）。

解题思路：线段树节点维护四元组 {total_sum, max_left, max_right, max_sum}，分别表示区间和、最大前缀和、最大后缀和、最大子段和。combine 合并左右段 L、R：

total=L.total+R.total,max_left=max⁡(L.max_left, L.total+R.max_left),max_right=max⁡(R.max_right, L.max_right+R.total),max_sum=max⁡(L.max_sum, R.max_sum, L.max_right+R.max_left)total=L.total+R.total,\quad max\_left=\max(L.max\_left,\,L.total+R.max\_left),\quad max\_right=\max(R.max\_right,\,L.max\_right+R.total),\quad max\_sum=\max(L.max\_sum,\,R.max\_sum,\,L.max\_right+R.max\_left) total=L.total+R.total,max_left=max(L.max_left,L.total+R.max_left),max_right=max(R.max_right,L.max_right+R.total),max_sum=max(L.max_sum,R.max_sum,L.max_right+R.max_left)

Distinct Values Queries

题目大意：数组固定，qqq 次询问区间 [a,b] 内不同数值的个数。

解题思路：离线 + 树状数组。把询问按左端点排序；用 map 把每个值出现的所有位置按"从右往左"的顺序存进 occurrences[v]。扫描左端点 i 从 0 到 n-1，树状数组里维护：每个值只在其当前最靠左的出现位置记 1，其余位置记 0。这样区间 [i, r] 的和恰好等于 [i,r] 内不同值的个数（某个值在 [i,r] 中出现过，当且仅当它"≥i\ge i≥i 的最左出现位置"落在 [i,r] 内）。初始时把每个值最左的出现位置置 1；每次 i 右移一位，就把值 v[i] 的标记从 i 移到它的下一次出现位置（occurrences[v[i]].back()），再回答所有左端点恰好为 i 的询问。复杂度 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Distinct Values Queries II

题目大意：支持单点改值，和询问：区间 [a,b] 内的值是否互不相同（互不相同输出 YES，否则 NO）。

解题思路：对每个位置维护 nxt[i]：值等于 a[i] 的下一个出现位置，不存在则记 INF。用 set 存 (值, 位置) 二元组，find_next(pos, value) 用 upper_bound 找当前值在 pos 之后的下一位置，find_prev 用 lower_bound 找之前的位置。线段树维护区间 nxt 的最小值：若 [a,b] 内的最小 nxt <= b，说明区间内存在两个位置值相同，输出 NO，否则 YES。修改位置 k 为 u 时，先在旧值链上把 k 摘除（把 k 前驱的 nxt 改成 k 的旧 nxt），再插入新值链（更新新值前驱的 nxt 与 k 自己的 nxt）。每次操作 O(log⁡n)O(\log n)O(logn)。

Increasing Array Queries

题目大意：给定数组，qqq 次询问：只看子数组 [l,r]，把它变成不下降序列最少需要多少次"把某个数加 1"操作。

解题思路：离线 + 单调栈 + 树状数组。先看单次贪心：从左往右扫，维护"当前应达到的高度"，凡是低于它的位置都要补足到它的高度，操作数就是所有补足的量和。把左端点从右往左移动时，用单调栈 st 维护一串"墙"（从 i 向右高度严格递增的纪录高点），并给每个位置算一个代价 v[i]：把 i 到下一堵墙 st.front() 之间全部抬到高度 a[i] 所需的操作数，公式为 v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i])v[i]=(st.front()-1-i)\cdot a[i]-(pre[st.front()-1]-pre[i])v[i]=(st.front()−1−i)⋅a[i]−(pre[st.front()−1]−pre[i])，其中 pre 是前缀和。树状数组负责累加这些代价（点加 add、前缀和 query）。当新的 a[i] 盖过若干旧墙（a[i] >= a[st.front()] 不断弹出）时，旧墙的代价失效，先把它们从树状数组删掉，再算入新墙。回答左端点为 i 的询问 [i, r] 时，先在栈中二分定位最后一个 <= r 的墙 st[pos]：pos 之前完整覆盖的墙段用树状数组区间和求出，最后一段不完整的（st[pos]+1 .. r 抬到高度 a[st[pos]]）用前缀和补算。复杂度 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。（全局数组与 add/query 需定义在 solve() 外。）

Movie Festival Queries

题目大意：n 部电影，各有开始与结束时间。qqq 次询问：在时间段 [a,b] 内最多能完整看完几部互不重叠的电影。

解题思路：对单次询问的贪心是"每次都选当前最早结束的那一部"。预处理跳表：nxt[i][0] 表示从时刻 i 开始能看的电影里结束最早的一部，先按开始时间取 min，再做后缀 min（nxt[i][0] = min(nxt[i][0], nxt[i+1][0])）保证它随 i 单调不减；然后倍增 nxt[i][j]=nxt[nxt[i][j−1]][j−1]nxt[i][j]=nxt[nxt[i][j-1]][j-1]nxt[i][j]=nxt[nxt[i][j−1]][j−1]。回答 [a,b] 时从 a 出发、从高层往低层跳：只要 nxt[a][j] <= b 就跳过去并累加 2j2^j2j。复杂度 O((n+q)log⁡V)O((n+q)\log V)O((n+q)logV)，V 是时间值域（代码里 10610^6106）。

Range Updates and Sums

题目大意：数组支持三种操作：区间加 x、区间赋值成 x、区间求和。

解题思路：带两种懒标记的线段树。每个节点记录 lazy_inc（区间加标记）与 has_rev/rev_val（区间赋值标记）。关键约定是赋值优先于加法：执行赋值 revise 时同步把 lazy_inc 清零；pushdown 下传时先传赋值标记、再传加标记。increase 与 revise 在整段覆盖时更新 sum（顺带维护 Max、Min，本题只用 sum）。递归操作：区间完全不交直接返回，完全覆盖直接打标记，否则先 pushdown、再递归左右子树、最后 pushup 合并。每次操作 O(log⁡n)O(\log n)O(logn)。（tr 数组与 build/modify/add/get_sum 等函数需定义在 solve() 外。）

Polynomial Queries

题目大意：数组支持两种操作：区间加等差数列——把 [l,r] 内位置 x 的值加上 (x-l+1)（即依次加 1,2,3,…）；区间求和。

解题思路：区间加等差、区间求和用三棵树状数组实现。一次更新拆成对前缀 [1,r] 与 [1,l-1] 的两次修改（代码里 modify(r, 1, 1-l) 与 modify(l-1, -1, l-1)），二者叠加后恰好只在 [l,r] 上生效。三棵 BIT 分别累加不同阶的系数，利用求和公式 ∑k=1xk=x(x+1)2\sum_{k=1}^{x}k=\frac{x(x+1)}2∑k=1x​k=2x(x+1)​，query(x) 把三棵 BIT 的前缀和按 a+b⋅x+c⋅x(x+1)2a + b\cdot x + c\cdot\frac{x(x+1)}2a+b⋅x+c⋅2x(x+1)​ 组合出位置 1..x 的总和，答案 =query(r)−query(l−1)=query(r)-query(l-1)=query(r)−query(l−1)。每次操作 O(log⁡n)O(\log n)O(logn)。

Range Queries and Copies

题目大意：维护若干个数组（初始只有 1 个），支持三种操作：在某个数组 k 上单点改值、查询某个数组 k 的区间和、把数组 k 整体复制一份追加到末尾。

解题思路：可持久化线段树（主席树）。每棵树的每个节点记录左孩子、右孩子与 sum。build 建出初始版本；change(p, l, r, k, x) 单点修改时只新建路径上的 O(log⁡n)O(\log n)O(logn) 个节点（new Node(*p) 复制一份再改一侧孩子），其余子树与旧版本共享，返回新根。用 trees 数组存每个版本的根：复制数组只需 trees.push_back(trees[k])，新版本与旧版本共享整棵树、不复制数据；查询在对应版本根上递归求区间和。每个操作 O(log⁡n)O(\log n)O(logn) 时间，总空间 O((n+q)log⁡n)O((n+q)\log n)O((n+q)logn)。

Missing Coin Sum Queries

题目大意：n 个硬币，面值数组 c。qqq 次询问：只用下标 [l,r] 内的硬币，无法凑出的最小金额是多少。

解题思路：经典贪心：把硬币按面值升序，维护"当前能连续凑出的最大金额 res"，若下一个硬币 <= res+1 就并入（res += 硬币面值），否则 res+1 就是答案。这里把硬币按最高二进制位（⌊log⁡2ci⌋\lfloor\log_2 c_i\rfloor⌊log2​ci​⌋）分成约 30 组，同一组的值域落在 [2b,2b+1)[2^b,2^{b+1})[2b,2b+1) 内，于是只要组内最小面值能并入，组内其余硬币必然也能依次并入，可以整组求和一次并入。离线按右端点扫描：对每个二进制位用单调栈 + 并查集预处理出任意区间内"该组硬币的最小面值位置"（get(id, l)，栈弹出时把 fa 指向更小的位置），用前缀和 t[i][id] - t[ls[k]-1][id] 快速求组内区间和。回答询问时从低位组到高位组执行贪心，无法并入就 break，输出 res+1。复杂度 O((n+q)log⁡C)O((n+q)\log C)O((n+q)logC)，C 为硬币值域上限。
